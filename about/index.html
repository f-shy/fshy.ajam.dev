About and API

fshy is a catalogue of free, nearly free and cheapest-paid cloud capacity. The build writes each page from one JSON record per offer. The records are the source, and every number on a page comes from a record.

For research and education only. The catalogue records technical facts about third-party services. It is not legal advice, and it makes no statement about whether a use is permitted. The rules that each provider publishes for its service apply to its use.

Query it

  • Remote MCP for agents: claude mcp add --transport http fshy https://fshy.ajam.dev/mcp. The tools are help, search, filter, get, entity, need, sql and worklist. A batch holds at most 5 messages, and at most 1 of them calls sql.
  • HTTP, JSON by default and TSV with .tsv:
    • /api/v1/search?q=gpu: full-text search, names first
    • /api/v1/records?topic=storage&no_card=1&sort=usd_per_tb_month: records that meet conditions, sorted
    • /api/v1/records?topic=storage&iface=s3&free=1: records with a free allowance (free=1)
    • /api/v1/sql?q=SELECT+rid,verdict+FROM+record+LIMIT+5: one read-only SQL statement
    • /api/v1/need/: the best-per-need lists
    • /api/v1/record/compute/oracle-cloud: one record as JSON
    • /api/v1/entity/oracle.json: one provider and all its records
    • /api/v1/: the list of routes
    • /api/v1/help.txt: the query primer: tables, columns, vocabularies and worked SQL
    • /api/v1/schema.sql: the schema of the store
    • /api/v1/vocab.json: the vocabularies
    The API and the MCP tools leave out the records that are marked as duplicates unless you ask for them. The pages list them, so a page can count a few more records than the API.
  • The whole store as SQLite: fshy-public.sqlite.gz (25.4 MB), SHA-256 of the file after gunzip: af3d1c2bda00c8e9ed15143ebed860163a774274d004379d2dfa6c6654bafc69.
  • Files for agents: /llms.txt, and a Markdown version of each topic and provider page.
  • Permalinks: /r/<topic>/<slug> opens the page of a record.

How to read a record

Verdict

A verdict is a judgement of the whole offer for the need of its topic. The data holds no number as a cut-off. A quota is too small (fails-quota) or enough by the judgement of the record. A trial (trial-only) is time-boxed or one-time. Read the free allowance and the limits of the record, and decide for your own need.

★ qualifiesqualifies usable as stated; the read path was probed
caveatqualifies-with-caveat usable, with a named limit or an unprobed read path
trialtrial-only a time-boxed or one-time trial, not a recurring allowance
paidpaid-only no free allowance; listed for its price
fails: identityfails-identity the identity required is not reachable without it
fails: egressfails-egress data cannot be read back out at a usable rate or price
fails: quotafails-quota the free allowance is too small to matter
deaddead the offer or the service no longer exists
self-hosted, last resortself_hosted = 1 software or a node that the user installs, runs and maintains. Self-hosted options are listed last, because this site is for users who have no hardware. Its row shows this label in place of its verdict.

A question mark after an identity value means that the identity kind is a placeholder. Then the card and phone requirements are unknown, not absent.

Freshness

Each record has the date of its last check and the date when its staleness window ends. Your browser compares the second date with today: fresh until or stale since. inherited means that the record was carried from an earlier source, and its check date is an upper bound.

What is published

Only technical data is published: quotas, limits, prices, identity requirements, interfaces, reliability events and the evidence for each. Process notes, personal details and terms-of-service or legality commentary are not published. Of the 427,425 values of the source:

  • 345,371 are published as written;
  • 18,098 are rewritten, for example an archive mirror replaced by its origin URL;
  • 63,580 are not published;
  • 376 belong to 3 records about infrastructure that is not a public offer.

Data as of 2026-11-10, from source commit 3bf4a55f0cd9: 4,866 records, 3,445 providers.

Report an error or a missing offer

Each record has a report an error link. It opens the Correction form with the record filled in. For an offer that the catalogue does not have, use the New offer form. A report is checked against the pages of the provider before a record changes. The issue closes when a publish carries the result.

Do not report a leaked secret, a personal detail or a vulnerability in a public issue. Read the security policy first.

Contribute

The site, the API, the MCP endpoint and the publish tools are in the source repository. A pull request that improves them is welcome: read CONTRIBUTING.md first. A pull request that changes data/ is not merged, because data/ is generated by the export and never edited by hand. Report a correction with an issue.
