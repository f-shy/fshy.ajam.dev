A paid create needs a spend cap above zero and credit covering the sandbox's lifetime at its hourly rate. Per-key rate limits are not enforced yet, and a key carries an approved budget and expiry.
Bindingvolume-quota The one-time USD 20 credit is what runs out first for a new account: at the USD 0.01 per hour rate it is 2,000 sandbox-hours, before the 1,000-at-once or 600-starts-per-minute platform limits.
Identityemail The paid console asks the user to sign in with Google or an email link, and prepaid credit is added by card on Stripe before the first paid create. The sign-in flow is described on the docs page; an API key for server use is created on the Keys page.
EgressThe pricing page prices memory-hours only and states no egress allowance or per-GB price; the console lets the caller lock egress and allow hosts one at a time.
Per-object capDisk is 50 GB, free, at every published size from 1 vCPU / 2 GiB to 8 vCPU / 16 GiB; the per-sandbox disk cap is not stated beyond that.
RetentionBilling starts when the sandbox is booked and stops when it is deleted or reaches its stop time; deletion removes its files. No separate retention period for stored files is published.
Interfacerest, cli, browser REST API at https://cathedral.computer/v1, the ctcli command-line client and a web console; confidential sandboxes have no SSH today and run each line of the console terminal through a line-mode terminal API.
Toolingctcli command-line client; REST API with a cat_sk_* API key sent as a bearer token.
Composes withA paid sandbox can run an agent task and return signed command receipts; an agent can obtain a budgeted key by device login, and files must be saved elsewhere before the sandbox is deleted.
ReliabilitySeveral catalogue products and the pool-claim path are marked Coming soon; one-shot runs are retired; there is no SSH into a confidential sandbox today and no public hardware attestation per room, only an attestation of the machine when it joins the pool.
NotesThe price is USD 0.0025 per GiB-hour at every size, so 2 vCPU / 4 GiB is USD 0.01 an hour and 730 hours is USD 7.30. A new account's USD 20 credit covers 2,000 hours of that size at list price. The ten-minute sponsored starter is anonymous but optional and may not be offered. The hosted sandbox needs prepaid card credit for the first paid create.
