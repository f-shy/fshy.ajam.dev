Free tierPipeline artifacts are exempt from storage billing and follow the pipeline retention policy; a run marked retained indefinitely is not subject to that policy. The 2 GiB free allowance belongs to Azure Artifacts package feeds, a separate service.
unit none; metered on none

Egressstated-absent: the Azure Pipelines retention and artifacts pages state no egress or transfer-out price; they describe REST APIs to download artifacts.
Per-object capstated-absent: the Azure Pipelines retention and artifacts pages state no per-object size cap for pipeline artifacts.
RetentionAzure Pipelines: "No. The pipeline's retention policy and the maximum limits set by the administrator aren't applied when you mark an individual run or release to be retained indefinitely. It remains until you stop retaining it indefinitely."
Interfacerest, cli Artifacts are published and downloaded through pipeline tasks and the Azure CLI (PublishPipelineArtifact, az pipelines runs artifact upload) and through REST APIs; they are not a general byte-store interface.
Toolingnot documented

"Use Copy files instead of Publish build artifacts because data published as build artifacts is still subject to retention cleanup."
