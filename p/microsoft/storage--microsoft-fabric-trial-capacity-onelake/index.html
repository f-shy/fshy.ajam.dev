ToolingGenuinely excellent interface: OneLake speaks the ADLS Gen2 DFS API and the Blob API - https://onelake.dfs.fabric.microsoft.com/<workspace>/<item>.<type>/<path>, plus an ABFS driver URI. Any Azure Storage SDK or rclone 'azureblob' remote can talk to it. 1 TB beats most free tiers on volume.
Composes withTrials are per-user/per-tenant, so theoretically N accounts x 1 TB x 60 days - but the trial expires and the data does not survive usefully.
ReliabilityHard 60-day expiry with a 7-day grace window - this is a trial, not storage. Fine for a one-off bulk ingest/egress burst, useless for a 20 TB archive.
