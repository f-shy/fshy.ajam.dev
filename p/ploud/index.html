Bindingwrite-gated 1 TB free with a working WebDAV endpoint clears the capacity and protocol filters. What binds is the signup: a phone number and an address are collected, and the form is a single-sponsor instance's only gate, so an account that survives is a favour rather than a contract.
Identityany-phone the signup form requires prenom, nom, date of birth, sexe, an international phone number and a postcode, plus the reCAPTCHA v3 human-verification widget. The JavaScript has no SMS or code path, so the only gate actually exercised is an email activation link
EgressNo traffic allotment is published in the wiki or on the portal. The service is presented as free with a donation page and no metering is mentioned
Per-object cap100 MiB upload chunk per the login page's oc_appconfig; the per-object ceiling is the Nextcloud default and is not published
RetentionUntil deleted. Public link expiry defaults to 7 days unless changed. No retention clock on stored files
Interfacewebdav, rest, rclone
Toolingrclone webdav, davfs2, curl -u, any Nextcloud client. The WebDAV endpoint is /remote.php/webdav/ for the legacy path and /remote.php/dav/ for the modern one, documented by the operator itself
Composes withA clean 1 TB WebDAV bucket with no payment and no phone, which drops straight into rclone mount or a Cloudflare-fronted origin. Each account is an independent island and the signup form has a phone field, so farming is not free
ReliabilityA single-sponsor instance operated by PSIADE in Toulouse. A 2024 help.nextcloud.com thread predicted imminent shutdown and reported stale certificates; the instance now answers status.php as Nextcloud 31.0.6.2 with valid TLS, so that post is stale, but one funding decision still ends it. The .jp mirror is dead
NotesThe best free Nextcloud in Europe by volume and the least durable: one sponsor, one data centre, and a 2024 forum thread that has already predicted its closure once. A reader should use it with a second copy and not as the second copy.
