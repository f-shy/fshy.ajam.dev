Free tierusers not on Google AI Pro or Ultra receive 'a meaningful quota, refreshed weekly' and 'a weekly rate limit'; the pricing page lists the plan without a subscription with 'Basic weekly rate limits'. No number is published, and the unit is a weekly share of agent work: the rate limits correlate with 'the amount of work done by the agent'
unit mixed; metered on unstated; the plans and pricing pages state no number. 'Meaningful' is a discretionary allowance, which is harder to design against than a published quota. The free plan's reasoning models are Gemini 3.8 Flash, plus Claude Sonnet 4.6, Claude Opus 4.6 and GPT-OSS-120b, which the models page marks 'Will be removed on November 2, 2026'; Gemini 4 Argon and the Claude 5.5 models are not on the free plan

no numeric quota is published. The page states that rate limits 'correlate with the amount of work done by the agent' and are 'subject to modification'. The CLI's /usage panel (alias /quota) shows 'remaining requests/tokens for each supported model', and a standalone agy -p /usage run returns it as a text report
Bindingrequest-rate the unpublished weekly agent quota binds; there is no number to design against, which is why the row is a caveat rather than a recommendation
Identityemail a personal Google account on any plan, the free one included; a Google Workspace account signs in only after its administrator provisions Antigravity. Second gates: the account holder must be 18 or older, and the account must be associated with a country or territory where Antigravity is available. An account whose age Google holds unverified is verified with a government ID or a credit card authorization (not a charge), with other options in some regions
Egressnot applicable
Interfacecli the agy CLI, the Antigravity App and IDE extensions; model access follows the Google AI plan. Headless runs use credentials cached by one interactive agy sign-in; in a non-interactive environment with no terminal, a run that is not signed in exits with an 'authentication required' error instead of hanging. The vendor changelog lists a fix for print mode output lost in non-TTY runs on Windows (version 1.0.15) and a fix for the print mode hang in a script or subprocess (version 1.1.1)
ToolingAntigravity App, IDE extensions and the agy CLI. agy -p PROMPT (aliases --print, --prompt) is a headless mode intended for direct scripting and CI: it sends one prompt, writes the response to stdout and exits; --output-format selects text, one JSON object or NDJSON events, --json-schema constrains the answer, and --input-format stream-json keeps one process for many turns fed on stdin
Composes withthe free surface of a Google AI plan, not a separate product. With modelProvider: gemini and GEMINI_API_KEY the CLI sends model requests directly to the Gemini API and holds no account session, so a key of inference/google-gemini-api drives the same headless mode, metered by the Gemini API for that key rather than by the account's plan
Reliabilitythe allowance moves with capacity: baseline rate limits are 'primarily determined by available capacity', and usage limits are 'subject to modification'; reaching the service through third-party software can end in suspension or termination of the account. The vendor's CLI tracker holds open issue 1313. It reports that a headless print mode run writes its full result and then never exits for some prompts, on versions 1.4.4 to 1.4.11
NotesThe plans page is first-party for the shape of the quota and silent on its size; a comparison table that prints a number for this provider is quoting an aggregator. Gemini models share one limit 'drawn down according to API pricing', and non-Gemini models stay on a separate fixed limit
Evidence notedocumented the quota structure and the headless mode are documented on first-party pages; no quota number is. A number needs a signed-in account reading /usage before and after a fixed workload, so the rung cannot rise without one
