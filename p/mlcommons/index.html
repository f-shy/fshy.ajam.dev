Free tierMLPerf awards no compute at all. The programme is a measurement, and the submitter supplies the system, quoted: 'The working group defines the AI model to run, the data set against which it gets run, sets rules on what changes to the model are allowed, and measures how fast a given hardware runs the model.' The gate is membership, quoted: 'Membership is required for most benchmark working groups (e.g., Training, Inference, Mobile). There are some public benchmark working groups that have no access requirements where non-members may submit to the benchmark by first signing a Non-member Test Agreement.' The submission requirements list, quoted: 'Join an appropriate MLCommons Working Group', 'A signed Contributor License Agreement', 'Membership in MLCommons OR a signed Non-member Test Agreement', 'A signed trademark license agreement'.

NotesMLPerf is not a compute-awarding programme. The membership sentence could mean that an individual can join, that a company pays dues, or that non-members are fine through the test agreement. The page's own 'Membership and Affiliate' FAQ and the phrase 'if you do not think your organization would be a good fit as a Member' in the GitHub route point at the company-dues reading, and the test-agreement reading is true but ends in a signed agreement that a solo entrant can sign. So the honest verdict is fails-identity for the main suites and a narrow non-member path for the public groups; the hardware cost stands either way.
