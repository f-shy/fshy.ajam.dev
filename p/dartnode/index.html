Identityinstitution A DartNode account and a qualifying public repository. The offer page states the account gate: 'Please log in or register to apply.' The registration form asks for a first name, a last name, an email address and a password, with Google and Discord sign-up offered, and no phone, card, country or ID-document field. The institution gate is the eligibility rule: 'Eligible projects have a public GitHub repository with 1,000+ stars that is at least 90 days old (no forks or archived repos).' A verification code is then added to the repository README to prove maintenance. The human identity is an email address; what qualifies is the project.

The published rule is automatic, which is the interesting part: the gate is reputation measured in stars rather than a human reviewer, so the failure is a number and not a person. Two things to settle. One, whether the 1,000-star floor is still 1,000 today, since the only first-party text is a page that a challenge wall hides from a plain fetch. Two, whether suspension without cause is systematic or was a single event; the Chinese forum reports one case and the sponsor wall lists 1,201 supported projects, which is not a mass-suspension pattern.
