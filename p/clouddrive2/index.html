Bindingnone A ¥4.99/month licence has no byte counter of its own; the pan's quota is what fails first. Naming a CloudDrive2 quota would misattribute another provider's limit.
Identityemail A CloudDrive account, purchased in-app through App Store or Google Play or directly. No phone gate is published.
Egress'传输不限速' on every tier including free. Traffic is the cloud drive's traffic, so the pan's own quota binds, not CloudDrive2's.
Per-object capEncrypted upload is capped at 200 MB per file on every tier except 核心终身版; the cloud drive's own per-file cap still applies beneath it.
RetentionNot applicable: it is a mount and a transfer layer, not a store.
Interfacewebdav, cli The server runs on the local machine and exposes WebDAV; '独立 WebDAV 用户管理' is a Pro feature. Supported sources include 阿里云盘, 百度网盘, 115网盘, 天翼云盘, 123云盘, 迅雷云盘, OneDrive, Google Drive and WebDAV.
ToolingWindows/macOS/Linux/Docker server plus apps for phone, TV and headset. WebDAV means rclone, Infuse, VidHub and any player can mount it.
Composes withOne licence turns five Chinese pans into one WebDAV endpoint, which is the piece AList does not sell: paid support, encrypted folders and cross-cloud copy in one binary.
ReliabilityThe mount is a client-side process: 115's API suspension in 2026 broke third-party mounts for a period, which is the failure mode of every layer that sits on a pan's private endpoints.
NotesRuns on a free VM or a local machine - it is software on somebody else's hardware either way. The 视障用户 lifetime tier at ¥299 is a real discount route documented on the page.
