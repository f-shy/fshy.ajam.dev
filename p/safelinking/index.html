Interfacerest Two documented HTTP endpoints: POST /api to protect (returns the package URL) and GET /check?link=<package>&output=JSON|XML for a link_status check. Container exports: RSDF, DLC, CCF and CNL2. Short links on sflk.in.
endpoint: https://safelinking.net/api
ToolingAny HTTP client; the API is form-encoded and documented in the project's GitHub README. JDownloader has a safelinking decrypter.
Composes withIt is the indirection half of a pipeline: protect a set of host links, then hand the package URL to a downloader. It does not resolve to direct links and does not bypass any host limit.

NotesAnswers half the sector question negatively: it will mint a protected link anonymously over HTTP, but it does not resolve anything to a direct link and it adds a captcha rather than removing one. If a wrapper is wanted, the API exists and is documented; if direct links are wanted, this is not it.
