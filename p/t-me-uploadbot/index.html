Bindingvolume-quota 1 GB/day is about 30 GB/month, so the day counter fails long before 1 TiB. The 500 MB object cap is the second wall and the 20 MB getFile cap only bites on retrieval.
Identityany-phone A Telegram account is needed to message any bot. The bot asks for no API key, token or email of its own.
EgressNo charge. Delivery is a normal Telegram file message, so a later scripted download is capped by the Bot API's 20 MB getFile limit unless the bot streams it over MTProto.
free allowance: none published
Per-object cap'Maximum file size allowed 500MB' - a quarter of Telegram's own 2 GB object ceiling. (500000000 bytes)
RetentionThe fetched file is delivered into the chat that asked for it, so it follows cloud-chat retention; the bot's copy of the URL is not described.
Interfacerest A Telegram chat. Programmatic use means driving the Bot API or an MTProto client to send a URL to @uploadbot; there is no other endpoint.
ToolingAny Telegram client; no API key, token or account with the operator.
Composes withA free 500 MB-per-file URL fetch into Telegram, which is the cheapest way to park a public HTTP file in the cloud without running anything; the 1 GB/day ceiling makes it a per-object tool, not a store.
ReliabilityAn undocumented daily reset and an unpublished retrieval path: after the file lands, whether the bot can hand it back above 20 MB depends on machinery it does not describe.
NotesAbandon if the description loses the 1 GB/day line or the monthly-user count falls to zero. The paid '/upgrade' tier's price was not read.
