Per-object-cap: 1.037 GB observed (no stated ceiling found. The '1 GB' in that model's own title is the author's description, not a platform limit). Write is normal account signup; no curator. Download is anonymous. RANGE VERIFIED: Range: bytes=100-199 returned HTTP/1.1 206 Partial Content, Content-Range: bytes 100-199/1036822737, 100 bytes. So resumable/ranged GET works (this is NOT the RepOD case).
Identityemail email address and a password, or a Google, Apple or Facebook sign-in: the account article says to register or log in with Google, Apple or Facebook, or to choose Create an account at the bottom to use an email or password, then confirm the account from the sent email. No card and no phone number appear in that flow.
EgressBacked by Google Cloud Storage (x-goog-* headers), fronted by files.printables.com with Cache-Control: public, max-age=31536000 and Access-Control-Allow-Origin: *. No egress cap published, no paywall on download, no account needed to download.
Per-object capper-object-cap: 1.037 GB (1036999999 bytes)
Interfacegraphql Undocumented but stable public GraphQL: POST https://api.printables.com/graphql/ with no auth. print(id:N){ name stls{id name fileSize} otherFiles{id name fileSize} downloadPacks{...} } to enumerate; then mutation getDownloadLink(id, printId, source:"model_detail", fileType:"stl"|"other") returns {ok, output:{link}}.
ToolingPlain HTTP and JSON interface. Standard curl or Python requests interact directly with endpoints without special SDKs. Object path parameters use standard UUID identifiers.
Composes withReturned links provide direct Google Cloud Storage object URLs where expiry headers are not enforced. Files remained accessible on 2026-10-21 despite past expiration timestamps. Objects are hotlinkable and enumerable per model identifier.
ReliabilityThe signup page answers a Cloudflare bot challenge to an unauthenticated fetch; the email signup is documented by Prusa's own account article.
