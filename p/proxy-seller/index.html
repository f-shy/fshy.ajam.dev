Authentication is 'username/password or IP allowlist for each order'. A JSON API is documented through five official SDKs (PHP, Node.js, Python, Java, GoLang) reached with an account API key; its base URL and auth header were not read here. A web dashboard handles order, authentication and address listing.
ToolingAny client that speaks an HTTP or SOCKS5 proxy with credentials or an allowlisted source address: curl -x, python requests, rclone --socks5 or --http-proxy, or a host-side hop for a runtime that cannot dial a proxy itself. The vendor's official Python SDK exposes balance(), referenceList(type='isp'), orderCalcIsp(countryId, periodId, quantity) and proxyList(type='isp'), so both the ISP price ladder and the delivered addresses are readable from an account without a browser.
Composes withThe Worker calls the host, the host calls the ISP endpoint, and the upstream sees an AT&T, Windstream or Frontier eyeball address instead of AS13335. At 45 GB a month one 1-IP order covers the whole traffic.
ReliabilityOrders are processed automatically and 'The IP address selection process may take a few minutes', with support to be contacted if the proxies have not arrived within 30 minutes; the location is fixed at purchase and a change needs support. The vendor publishes 99.7% uptime, a 99.5% success rate and about 0.35s response time, all unverified here, and states no address-replacement policy on the ISP page.
NotesReading the ladder from https://proxy-seller.com/price/ was tried and ruled out: that page's ISP tab is drawn client-side and the table in the served HTML is the Residential per-GB ladder. The SDK makes this a scripted read rather than a browser session. The provider contradicts the marketing card and both are quoted rather than reconciled: 'Traffic is uncapped at any volume' against '100 GB of traffic by default' per IP, with no period stated and no way to buy traffic without buying an IP, which is why egress.metered is true while binding stays none at 45 GB a month. The schema's interface enum carries no proxy token, so interface holds 'rest' for the documented JSON API and the proxy protocols are in interface_detail, the shape storage/proxyrack-unlimited-residential already uses for a SOCKS5 product.

The claim the verdict cannot carry is the one the vendor makes loudest: that the delivered addresses sit in those eyeball networks across 200+ Class B and 600+ Class C subnets. No sample address is published, so that stays the vendor's sentence.
