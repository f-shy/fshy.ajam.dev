Per-object-cap 5 GB. The only limit they publish. Extension blocklist is a hard gate on ingress: EXE, ISO, DMG, VBS, SCR refused unless inside a ZIP. No aggregate quota.
Identityemail a first name, last name, email address and password on the free-account form. No card is asked for: the help centre adds card details only to upgrade a paid plan. No phone field is on the form.
EgressNo bandwidth limit stated (their words: 'no storage or bandwidth limits'). Free plan is 'Free Forever' with a 5% transaction fee. No monthly fee, so an unpriced/cheap product costs ~nothing.
Per-object cap5GB per file (5000000000 bytes)
Interfacerest, cli Web upload. REST API + webhooks on paid plans; the digital-product upload itself is form-based.
Toolingcurl/browser; no first-class CLI.
Composes with5 GB/file x unlimited files per product x unlimited products = unbounded account. Every listing is a shard with its own 5 GB ceiling. The cleanest 'shard into 5 GB pieces' target found.
ReliabilityServing path is fine; the operational risk is that a 'digital product' must be a listed product, and free products still sit behind a checkout page. Buyer link is emailed, not a stable public URL. So it is an archive/delivery tier, not a hot-link CDN.
