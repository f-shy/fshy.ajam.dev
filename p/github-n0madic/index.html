NotesThe interesting property is that the transport change happens inside the WireGuard implementation, so the interface and the configuration stay standard: this is the closest thing to a wrapper that a .conf-only router could accept, if the router ran the fork. It does not, so in practice the fork must run on a Linux host at both ends. Zero stars and no releases make it a reference for the approach rather than a deployment.
