NotesThe strongest niche find of this category: a real KVM guest with root, one IPv4 and one IPv6, no card, from a named German sole trader with an imprint, a phone number, a GitHub organisation and a status page. Two things are unresolved. First, runtime_days 30 on the free plan is not explained anywhere read, and it is the difference between a permanent machine and a one-month one; the fix is one approved account watched past day 30, which this category cannot do because it must not register. Second, the FAQ says 10 GB NVMe where the plan page says 20 GB SSD. Neither the egress allowance nor a port speed is published at all. The docs subdomain returned HTTP 530 on both read and fetch, and the browser navigation to it killed the page process, so the documentation route is unread rather than absent.
