Identityemail email
EgressEvery file can mint a public URL on files-cdn.x.ai, Cloudflare-fronted, no API key needed to fetch, no egress charge documented. URL is permanent if the file has no expiry and no expires_after is passed.
Per-object capPer-file 512 MB (512000000 bytes)
RetentionPer-file 512 MB (some pages say 50 MB for the upload reference and 50 MiB for public URLs). Files are PERMANENT by default. expires_after is opt-in.
Interfacerest OpenAI-compatible REST at https://api.x.ai/v1/files. POST upload, GET list, GET {id}, GET {id}/content (streams raw bytes, Content-Type application/octet-stream), DELETE, plus POST {id}/public-url and /public-url/revoke.
Toolingopenai-python with base_url swapped to https://api.x.ai/v1; xai_sdk; curl
Composes withUpload workflow generates public URLs cached at CDN edge locations. Files maintain one active public URL at a time, and repeated requests return the existing public link idempotently.
ReliabilityThe absence of a published total quota is the finding, not an oversight. A third-party comparison site says outright 'no storage limit is stated. xAI says only that limits may vary slightly by platform or subscription'. Treat unverified. Files persist 'until you delete them'. Collections is a separate product with a 100 MB/file cap and requires credits in the account. Public URLs only cover image/png, image/jpeg, image/gif, image/webp, video/mp4, video/webm. So the CDN path is media-only; arbitrary blobs must go through the authenticated content endpoint.
