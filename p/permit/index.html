Bindingvolume-quota The 1,000 MAU cap binds before the per-IP rate limits for a growing application: authorization queries are unlimited, so the count is active users, not checks. The Cloud PDP also shapes requests per client IP at 1000 req/min on /allowed, and logs are kept only 14 days.
Identityemail The first-party quickstart says to sign up at app.permit.io and states users can sign in with a Google, GitHub or Microsoft account, or use enterprise SSO; an email address underlies those sign-ins. The Community pricing table lists its pricing model as Free. Whether the sign-up form asks for a phone number is unverified: behind a sign-up.
Egressnot applicable to authorization decisions: the Cloud PDP answers checks over HTTPS at cloudpdp.api.permit.io, and no data egress quota is stated for the Community plan
Per-object capunverified: no per-object byte size cap is stated; the Community plan caps object counts at 2,000 role assignments, 2,000 resource instances and 2,000 relationship tuples, with 25 roles and 50 resource types
RetentionLogs retention is 14 days on the Community plan; the paid Pro plan lists 14-day audit-log retention as extendable (14 days)
Interfacerest The managed Cloud PDP serves HTTPS check endpoints /allowed, /allowed/bulk, /user-permissions and /authorized_users plus the AuthZen evaluation and search endpoints; SDKs exist for Node.js, Go, .NET, Java, Python and Ruby. The control plane is configured through the dashboard, an API, SDKs, a Terraform provider and GitOps.
endpoint: https://cloudpdp.api.permit.io/allowed
ToolingThe permitio SDKs for Node.js, Go, .NET, Java, Python and Ruby, the Permit API, the Permit CLI and the dashboard at app.permit.io; an SDK points at the Cloud PDP by setting its PDP URL
Composes withApplications call permit.check() against the managed Cloud PDP; policy is authored in the cloud control plane. The self-hosted Edge PDP and Nexus PDP are alternatives for ABAC or in-network decisions and are not the hosted free offer.
ReliabilityThe managed Cloud PDP applies per-IP rate limits over a 1-minute window and returns HTTP 429 with an error body of rate_limited when a client exceeds them; a large deployment behind a shared public IP can be affected. Cloud uptime is stated as best effort on the Community plan.
NotesThe Community plan is the hosted offer. Permit also publishes open-source PDP components and self-hosted Edge and Nexus PDPs, which are last-resort options and are not counted as this hosted record.
