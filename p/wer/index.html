Free tier500 calls in total, of which 1000/month and 100/day are sub-allowances: '总免费额度 500 次, 每月免费额度 1000 次 包含在总免费额度, 每日免费额度 100 次'. Free users are throttled to 3 seconds per request.

Limits

Bindingrequest-rate Calls, not bytes, bind: 1 TiB of monthly transfer is one call per file, so a large library is cheap and a large single file is free. The free tier's 3s/request is the only wall.
Identityemail A console account issues the key. The signup form was not read, so the exact field set is unconfirmed; no phone gate is visible in the docs.
EgressThe API returns a resolved URL; the bytes come from the pan's own CDN. Charges are per call, not per byte: 0.0010 元/次 on balance, 0.00088 元/次 in the largest pack.
Per-object capNot applicable: the resolver returns a URL, it does not store the object. The 123云盘 endpoint notes that large files need the sharing account to hold VIP.
RetentionNot applicable: no bytes are stored by the resolver.
Interfacerest HTTP GET, JSON response, key in the query string: https://api2.wer.plus/api/123pan?key=...&url=...
endpoint: https://api2.wer.plus/api/123pan
ToolingAny HTTP client. Priced per call, so the cost is knowable before a run; QPS 10 for paying users.
Composes withThe metered alternative to a self-run resolver: 1,000,000 resolutions for ¥880 is a fixed cost that does not depend on how much is downloaded.
ReliabilityCoverage is narrow: 123云盘, 蓝奏云, 蓝奏云优享版 and OneDrive are documented. Baidu, Quark, UC, 115 and 迅雷 are absent from the catalogue, which is the mirror image of netdisk-fast-download's paid tier.
NotesIts catalogue is the map of which Chinese pans still allow a third-party resolver to mint a direct link: 123 and 蓝奏 yes, Baidu/Quark/UC/115 no.
Evidence notedocumented The price table, the free allowance, the rate limits and the endpoint were read off the vendor's own doc page. No key was issued and no call was made.
