Bindingrequest-rate At 1 token for a simple query the anonymous allowance is 100 searches a day and a personal key 1,000; the dataset dump, not the API, is the route to the full collection.
Identityemail The API answers with no registration at 100 tokens a day without full text. A key, and the dataset download credentials, come from forms that ask for an email address (an institutional one when registering for an institution); the key, and the dataset link and credentials, are sent to that address. CORE asks about the registrant's circumstances during registration and may follow up to assess eligibility for a free licence. The vendor terms say downloadable dataset access is provided to users representing organisations registered in non-sanctioned countries, and that individual users are directed to the API. Whether a registration as an individual receives any dump link is unverified: behind a sign-up.
Egressnot metered by volume: the API is metered in tokens per day, and the dataset is downloaded over HTTPS with a link and credentials sent by email
free allowance: no byte allowance published

Interfacerest REST at https://api.core.ac.uk/v3 (search/works, outputs, data providers, full-text download) with an Authorization: Bearer key for registered users; the dataset as tar.gz batches over HTTPS listed in a dataset_index.xml, behind a username and password sent by email

Toolingcurl or any HTTP client; wget -c, curl -C - or aria2 for the dataset batches
Composes withThe dataset is the bulk path: the 2024-07-12 dump is 749 GB compressed and about 2.7 TB extracted; older dumps (2020-03-18 at 400 GB compressed) are free, and the more recent datasets are a purchased licence for registering organisations. The API at 100 to 5,000 tokens a day is a lookup and freshness step. The vendor terms provide downloadable dataset access to organisations and not to individual users, so for an individual the API is the route.
ReliabilityThe first anonymous search of 2026-10-30 answered 429 with X-RateLimit-Remaining 0 and an X-RateLimit-Retry-After 10 minutes later, so the anonymous window can be spent before a caller's first request. On 2026-11-02 one residential ISP address made 135 anonymous searches. The x-ratelimit-remaining value rose and fell between calls, which fits counters kept per backend. A 429 names a retry time 10 minutes later, but the next call often answered 200. The 101st call of the day answered 200, and the last four calls answered 429. An address at 429 and a second address at 200 were seen in the same minute, in both orders, so the window is not shared across addresses.
NotesThe caveat is the anonymous ceiling and the gated full text: no full text without registration, and the bulk dump arrives by emailed credentials.
Evidence notedocumented The token allowances, the registration forms and the dataset sizes are vendor pages read on 2026-10-30. One anonymous search was probed the same day and answered 429.
