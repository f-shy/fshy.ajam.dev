Composes withCarries a WireGuard handshake between a free VM and a laptop without opening a port on either, at the cost of installing a client on both ends.
ReliabilityDepends on public HyperDHT bootstrap nodes; symmetric NAT defeats the holepunch and falls back to TCP, which breaks UDP-only protocols. A harness verified the server side and public-DHT peer discovery on 2026-11-05; the end-to-end data path was not testable in that sandbox.
NotesNot a hosted ingress: a third party cannot connect unless they run holesail with the connection string. It qualifies as free UDP capacity between two machines under one control, which covers a WireGuard endpoint only if the far side also runs it. A sandbox verified the server side and public-DHT peer discovery on 2026-11-05 but could not test the data path.
Evidence notedocumented A measured transfer between two peers behind different NATs would show the real throughput and whether the DHT path holds; that is the missing rung.
