Free tierEntirely free of charge, with no limit on the number of cronjobs per account (fair usage expected); each job runs up to 60 times an hour, i.e. every minute
unit unlimited; metered on none; Financed by voluntary donations. Sustaining members get a higher API limit of 5,000 requests a day; scheduling has no paid tier. Status pages, status badges and failure notifications by email or webhook are part of the free service.

Limits
  • request-rate (binding) each job runs up to 60 times an hour (every minute) source
  • request-rate (binding) API: 100 requests per day by default, 5,000 per day for sustaining members source
  • request-rate (binding) API per-method limits such as 5 requests per second, or 1 request per second and 5 requests per minute source
  • per-object-cap 64 KB of response output read per execution source
  • retention-clamped response headers and bodies kept 2 days; last 50 executions per job source
An execution times out after 30 seconds. A job that fails more than 25 times in a row is disabled automatically.
Bindingrequest-rate The one-minute minimum interval and the 30-second timeout bound what a job can drive; the 100-a-day API limit binds only on programmatic job management.
Identityemail The console sign-up form asks for first name, last name, email address and a password; there is no payment step because the service is free.
Egressnot applicable: an outbound HTTP caller; at most 64 KB of each response is read
Per-object capup to 64 KB of each response is read; a larger response aborts the execution
Retentionresponse headers and bodies stored for 2 days; the last 50 executions of each job are viewable (2 days)
Interfacerest a REST API with JSON payloads, authenticated by an API key in an Authorization bearer header; keys are generated in the console and can be restricted to listed IP addresses
endpoint: https://api.cron-job.org/
Toolingany HTTP client against the REST API, or the web console. As a last resort the scheduler source (chronos, GPL) is on GitHub: the user installs and runs the server software on a rented or free machine.
Composes withCalls a free HTTP endpoint (a serverless function or a CI trigger URL) as often as once a minute, so it supplies the schedule that a free compute host without cron lacks, as long as each call finishes within 30 seconds.
ReliabilitySlight delays at peak hours with no punctuality guarantee; jobs that failed often or ran long may be delayed on purpose, and a job is disabled after more than 25 consecutive failures.
