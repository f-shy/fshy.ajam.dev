vCPUs are shared and burst to full cores before settling to a baseline if busy for long stretches. Suspended and stopped machines still pay for disk and the template system disk. A fork counts as a running machine on Free, so the source must be suspended first.
Bindingvolume-quota The $5 one-time credit runs out first: a default 2 vCPU, 4 GiB machine costs $0.054 an hour while running, after which machines are suspended until the workspace is topped up.
Identityemail New accounts get $5 of credit with no card needed, once per email address; the CLI signs the user in, and an agent with no browser can sign itself up with the owner approving by a code.
EgressData out is charged per GiB by region of departure: $0.03 from North America and Europe, $0.06 from Asia-Pacific and South America, $0.18 from Africa and India; an inter-region hop is another $0.009 per GiB each way in North America and Europe. Data coming in is free, and usage is charged every ten minutes.
price per tb: $0.03 per GiB from North America and Europe; $0.06 per GiB from Asia-Pacific and South America; $0.18 per GiB from Africa and India
Per-object capnot applicable: the unit is a whole Firecracker microVM with a persistent /data disk; a Free-plan machine can have up to 20 GiB of disk and the universal template has no compiler, Docker or browser preinstalled
RetentionEverything under /data survives stops, restarts and resizes; the disk lives on one host with no automatic backups. Machines and snapshots on the welcome credit alone are deleted 7 days after a warning when unused for 14 days; credit at zero deletes everything 7 days after the warning, or 30 days if the workspace has ever paid. Command history keeps the newest 100 commands for 30 days. (14 days)
Interfacecli, rest, ssh A CLI with --json output and meaningful exit codes, a REST API with an OpenAPI 3.1 document, and a hosted MCP server with 27 tools over Streamable HTTP; TypeScript and Python SDKs exist for the API.
Toolingthe user installs the quivvo CLI with npm and drives machines from the CLI, REST API or hosted MCP server; an agent with no browser can sign itself up and the owner approves it with a code.
Composes withA machine runs coding agents and keeps state on /data across stops and snapshots; published ports serve HTTPS while the machine runs, and background jobs survive a disconnect for up to 24 hours, so short agent tasks chain through the MCP server while longer servers need a separate always-on offer.
ReliabilitySuspend tries to keep memory but the provider documents only up to 2 GB, so a 4 GiB machine is often stopped instead and loses in-memory processes; a host move gives a cold boot and may drop anything installed outside /data. There are no automatic backups, and credit at zero suspends machines and eventually deletes them and their snapshots.
NotesA Firecracker microVM for coding agents, with root, a persistent /data disk, and CLI, REST and MCP access. The Free plan grants $5 once per email address with no card, runs one machine at a time up to 2 vCPUs and 4 GiB, and suspends it after 15 idle minutes. Egress is metered by departure region from $0.03 per GiB in North America and Europe.
