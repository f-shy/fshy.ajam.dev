Identityemail Signup offers two options: enter your information in the form and select Get Started, or sign up with Google or Github. Reliabilitybest-effort SLA and community support on the free plan; Redis notifies the user before limiting database usage when the bandwidth or throughput limits are exceeded
NotesThe free Redis Cloud plan is 30 MB with one database, 30 connections, 100 ops/sec and 5 GB of transfer. It clears identity (no card) and interface (a real Redis protocol with clients), but the 30 MB ceiling is a hard wall, so the verdict is fails-quota. This is the RedisLabs hosted service, not the Redis Software that a user installs and runs; self-hosted Redis is not the offer here.
