Free tier2 TB per dataset for individual users, 10 TB for Institutional Subscribers. The Data Competition submission type is listed as FREE and carries the same 2 TB / 10 TB ceilings. 'Dataset files may total up to 2 TB or 10 TB for Institutional Subscribers'. Competition files are stored in Amazon S3 and can be downloaded by any logged-in IEEE DataPort user, and 'If Competition has No Access Restrictions, no entry needs to be made in the Access Control List box and all users of IEEE DataPort that are logged in will have access.' That is the only route on this platform where storage is free AND reads are free, because the two paid routes both gate reads: Standard Dataset (free upload) exposes files only to subscribers, and Open Access Dataset costs $1,950 to make them public.
unit TB; metered on stored-bytes
Price0 via Data Competition or IEEE Society membership. Open Access publication is a flat $1,950 per dataset…
Limits
  • per-object-cap (binding) 100 GB/file source
Write-gated + read-gated, and the gate differs by route. Standard Dataset: upload free, read requires IEEE DataPort subscription (~$480/yr). Open Access: read free to all, write costs $1,950 per dataset. Competition: both free, but the entry is framed as a time-limited challenge with start and end dates and 'Competitions must meet eligibility requirements and are not intended for general dataset publication'. Per-file cap is not stated; IEEE's own guidance is 'for large datasets, we recommend uploading a series of files that are 100 GB or less'. A soft 100 GB/file figure. Supported formats list is broad (zip, tar, 7z, iso, hdf5, parquet, avro, orc, mat, wav, mp4 …).
Identityemail email
EgressFree in the ordinary sense. Downloads are served from IEEE's own S3 bucket (ieee-dataport.s3.amazonaws.com, which correctly returns 403 to anonymous listing rather than 200-with-empty-body) and there is no egress meter on the participant side. Real ceiling is per-user concurrency, not bytes.
Per-object cap100 GB/file (100000000000 bytes)
Interfaces3, cli web + s3
ToolingTwo real paths. (1) S3: a subscriber gets an AWS access key/secret and the bucket is ieee-dataport, with the dataset path /ieee-dataport/<DATASET TYPE>/<USERID>/<DATASETID>. AWS CLI, boto3, s3cmd, Cyberduck, CrossFTP, S3 Browser all documented. (2) Competition participants read via the 'AWS S3' tab which reveals per-file S3 URIs plus a 'View AWS Security Credentials' dialog with the secret key. Undocumented but usable: the web upload form needs no subscription at all.
Composes withDatasets are unlimited per account and each carries an independent 2 TB ceiling, so the multiplier is datasets, not accounts. 10 datasets is 20 TB of nominal capacity on one free IEEE web account. Competition module can host several files per competition. Combining the two submission types on one account gives both a subscriber-upload path (S3) and a public-read path (competition).
ReliabilityS3 bucket is real and correctly access-controlled (403, not a fake 200). IEEE may unpublish Standard Dataset entries whose files were never uploaded. Competition entries are time-bounded by design, so treat the competition route as a lease with a declared end date rather than an archive.
