Free tierNo account, no total quota. Per-object only. '1ファイル最大128 GiB。複数ファイルも順番にアップロードできます' (max 128 GiB per file, multiple files uploaded in sequence). Upload form constant data-max="137438953472" = 128 GiB, confirming the number in the markup.

Per-object cap is 128 GiB. Retention is user-selected with optional download-count limits. Read path requires POST operations: GET requests to /download return HTTP 405 with Allow: POST, and a tokenized POST returns HTTP 302 redirecting to the share page requiring form interaction.
Identityanonymous (inferred, not read) not published
EgressNo egress meter or paid bandwidth product; the whole service is stated free ('本サービスは、別途明示する場合を除き無料です').
Per-object cap128 GiB per file (137438953472 bytes)
Retentionper-object-cap 128 GiB. Retention is client-chosen (published-until field showed 'No limit' on a live file) and additionally bounded by a download-count cap the uploader may set
Interfacerest, rclone rest
ToolingNo public API and no rclone backend. Form-POST only, behind a Laravel CSRF token (_token) plus a session cookie, with delpass (delete key, >=8 chars) and optional expiry_datetime/maxcount. The legacy numbered URLs (/u/4144979) still resolve; new uploads get random /u/f_<22-char> URLs.
Composes withAccount-less: unlimited objects per IP x 128 GiB each, with 'No limit' available as the expiry. Chain is a re-upload loop only if you set an expiry; with expiry unset the object has no scheduled deletion.
ReliabilityThis is the legendary Japanese uploader and it is emphatically alive: the public file list was showing uploads from minutes earlier on the day of this run. But it has already had at least one near-death outage that lost voicebanks (UTAU Wiki recorded the site going dark and coming back with a broken certificate), and its own terms say no-expiry is 'not a promise of permanent storage'. Treat it as a live service with a history of vanishing.
