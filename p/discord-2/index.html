Free tierReserve an upload slot with POST /channels/{id}/attachments and PUT the body straight into Discord's Google Cloud Storage bucket. The reservation path accepts up to 500 MiB per file, independent of the 20 MiB message-time limit. Note the file still hits the per-message limit when you actually send it, so 500 MiB only helps if the channel/boost tier allows it.
