Bindingvolume-quota The 1M events a month is the first ceiling for an app with traffic, and the missing Query API means reports are read in the web app only.
Identityemail The sign-up page offers a free account from an email address, with an agreement to the terms; the pricing page states no credit card is required. Any later step is unverified: behind a sign-up.
Egressthe Query API, which downloads reports as CSV, PNG or PDF or exports results to JSON or CSV, is not available on Free; whether the Raw Data Export API is open to a Free project is unverified: the pricing page lists only Ingestion & export API access (Import historical data) as available
Per-object capthe import endpoint accepts up to 2000 events and 10MB uncompressed per request
Retentionevent data is deleted 2 years after ingestion by default on Free, Growth and Enterprise, and a custom policy is an Enterprise feature; session replays are kept 30 days (730 days)
Interfacerest The Ingestion API (import and track endpoints) authenticates with a project token as the basic auth username or with an Owner or Admin service account, at api.mixpanel.com or api-eu.mixpanel.com for EU data residency; an MCP server and Mixpanel Headless (work with Mixpanel as code) are listed as available on Free.
