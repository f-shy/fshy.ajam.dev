Unlimited flags on every plan. The API docs list 500K requests, 1 SSE connection and 3 projects on Free; a request over the plan answers 429. The docs list 14-day free trials on paid plans.
Bindingvolume-quota The 500K monthly request cap binds first for an app that polls flags frequently; a single SSE connection also caps concurrent streaming sessions on the Free plan.
Identityemail The quickstart says to sign up for a free Rollgate account with no credit card required; the architecture page lists user authentication by email and OAuth, and dashboard sign-in by Google and GitHub. The register page capture shows only a Terms and Privacy acceptance line, so the exact form fields are unverified: behind a sign-up; no card, phone or ID is stated at sign-up.

Interfacerest A REST API manages flags, projects and users; SDKs for React, Vue, Angular, Svelte, browser, Node.js, Go, Python, Java, .NET, React Native and Flutter stream a resolved rules bundle over SSE and evaluate flags locally in-process, with no network hop per evaluation.
endpoint: https://api.rollgate.io
ToolingThe 12 official SDKs, the REST API or any HTTP client; the SDK streams flag configuration and evaluates locally.
Composes withServe flags to an app from a worker that uses a Rollgate SDK, keeping the SDK request count under 500K a month; SSE streaming and caching lower the effective request volume.
ReliabilityThe API returns 429 when a plan limit is exceeded. A 99.9% uptime SLA appears on the Growth plan only. Self-hosting is not yet available and is on the roadmap.
