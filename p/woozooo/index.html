Bindingper-object-cap The total is genuinely unlimited and the egress is genuinely free, but a 100 MiB per-file cap over a 10 TiB working set is 100,000 objects, which is a file-count problem before it is a storage one.
Identityany-phone the register form asks for a phone number with an SMS code, then a username and password ('请使用用户名登录，手机号仅用于找回短信验证'); it shows no email field and no country selector. Whether a non-mainland number is accepted is unverified: behind a sign-up
Egressdownloads are stated as unlimited in speed, volume and count, with no login; there is no egress price
Per-object cap100 MiB per file, which the resolver's driver table states and which the free tier does not publish on its own page (104857600 bytes)
Retentionunverified: the vendor home page as read states no share-link lifetime; the account's own retention is not published
Interfacerest
Toolingno WebDAV and no official API; the practical route is the netdisk-fast-download 'lz' driver, which resolves a share link to a direct URL
Composes withthe cheapest place to put files under 100 MiB that must be downloadable without an account, which makes it a config, patch and asset host rather than a data store
ReliabilityShare-link lifetime is not stated on the vendor home page as read. The per-file cap is what stops it from being storage at any scale.
NotesOffers unconstrained total storage capacity constrained by a 100 MiB per-file ceiling. Functions primarily as a lightweight direct-link distribution target for small file archives.
