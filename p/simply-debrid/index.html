Free tierYou can generate download links for up to three different source links per day on sites marked Free. The allowance is shared by devices using the same public IP address. The free allowance resets at midnight UTC each day.

The supported-sites page runs past 1,000 entries and mixes cloud drives, social video and file hosts; the free/Premium split is per-site and was not enumerated.
Bindingpull-count 3 links a day is 90 a month, so 1 TiB would need an 11.4 GiB average per link, and the per-public-IP sharing means a second device or a household NAT spends the same allowance.
Identityemail Free generation needs no account. Premium is a Stripe checkout (card, giropay, EPS, P24); the account itself needs only an email and password.
EgressDownload is served direct from the source site after the link is generated. The plan page promises 'Unlimited link generation' on Premium; no byte allowance is published on either tier.
free allowance: 3 links/day on Free-marked sites, per public IP
Per-object capnot applicable: a URL is unlocked, nothing is stored. The FAQ says 'Supported file sizes depend on the source site, file type and processing required. Very large files or lengthy conversions may fail or take longer to prepare.'
RetentionGenerated links are temporary. (FAQ: 'Generated links are temporary. Try generating a fresh link and check that the original content is still available')
Interfacerest Web generator plus direct HTTP links that can be pasted into any download manager. No public API is documented on the pages read.
ToolingAny HTTP download manager (JDownloader, aria2, curl) once a direct link is generated. No rclone backend and no CLI.
Composes withCheapest per-month route among debrid providers at EUR 3.00/month on the annual plan, but its 3-links-per-day free tier and per-IP sharing make it a fallback rather than a first choice next to a host-specific path.
ReliabilityFree links expire quickly and Premium-only sites return nothing on the free tier; the allowance is tied to the public IP, so a VPN or a shared connection consumes it.
NotesSub-USD-5 on the annual and quarterly terms, above it monthly (EUR 4.99 = USD 5.60). The site is a multi-site downloader as much as a multi-hoster: much of its 1,000-entry list is social and cloud sources that need no premium account, which inflates the host count a reader might take at face value. A 2026 rebuild: three auto-renewing plans where the site previously sold nothing it published. The annual at EUR 35.99 (EUR 3.00/month) is the cheapest per-month paid debrid in the set, and the free 3-link day survived the rebuild, which is the opposite of what AllDebrid did in the same window. Grouped as local-voucher, not as card-only, because a Neosurf cash code is a real cardless route; the verdict still carries a caveat because Neosurf availability is a country question did not resolve, and the local Stripe methods (giropay, EPS, P24) are bank-funded and therefore do not help an account without a bank. Rule used: identity_cost.kind describes the vendor's own gate, verdict describes the reachable route including a reseller or a cash code. The ladder's identity column ('email') is the right conservative reading and its 150 GB row is unaffected. The reset sentence, by contrast, is a genuine find and is the model the other steps lack.
