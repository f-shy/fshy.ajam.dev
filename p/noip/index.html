Egressno DNS query cap published on the pages read
Per-object cap1 hostname on the free plan, on one of 30+ No-IP shared domains; the zone belongs to No-IP, so the user holds no record count of its own; hostnames may be type A, AAAA or Port 80 Redirect
Retentiona free hostname is active for 23 days, may be confirmed in the next 7 days, stops resolving when it expires, sits 14 more days in redemption and is then deleted and open to anyone; an update from a client does not confirm it (30 days)
Interfacerest a dyndns2-style HTTP update request, GET https://dynupdate.no-ip.com/nic/update?hostname=HOST&myip=IP with HTTP Basic auth (the account e-mail address and password), on port 443 over HTTPS or on ports 80 and 8245 over HTTP; the response is a text code such as good, nochg or badauth; the pages read list a RESTful API only under the contact-sales Branded Remote Access plan
Toolingthe free No-IP Dynamic Update Client for Windows, macOS and Linux, any dyndns2-compatible client or router, and curl from cron; confirmation itself is a web or e-mail action with no documented API
Composes witha name for a changing address and nothing else on the free plan; the domains are No-IP's, so the name cannot be a zone of its own, and the 30-day confirmation has to be done by hand
Reliabilitya free hostname silently stops resolving if the 30-day confirmation is missed; the update endpoint answers HTTP 401 with the body badauth for a request without credentials; a client without an approved User-Agent can be rate-limited or blocked, and the badagent and abuse codes tell a client to stop updating
NotesFree confirmation interval: 30 days (23 active, 7 to confirm, then 14 in redemption). The paid Enhanced plan, USD 2.50 a month billed annually for 5 hostnames, lists hostnames that never expire.
