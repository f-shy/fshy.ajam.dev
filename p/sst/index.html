Free tierThe SST Console is free for workspaces with 350 or fewer active resources a month, with no credit card to start; above that it is USD 0.086 per active resource for the first 2,000 and USD 0.032 beyond. The Console is a dashboard over an app that SST deploys into the customer's own AWS account, so the compute is an AWS bill and the Console contributes no runtime.
