EgressFree by construction. Self-hosted; you pay (or don't) for your own bandwidth.
Interfacerest, oci, cli rest (pulpcore REST API), plus repository endpoints for rpm/deb/python/container/generic; also ships OCI images of itself
Toolingpulpcore REST API + pulp-cli, plus podman/docker for the container deploy and standard package clients against published repos. Documented at pulpproject.org/pulpcore/docs/. It is also the backend Fedora COPR uses, which is a working-scale endorsement.
