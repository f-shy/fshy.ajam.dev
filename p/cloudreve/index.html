Bindingwrite-gated Its own documentation says it is not for redistributing other cloud drives, which is exactly the use this topic wants, so the constraint is architectural rather than numeric.
Identityanonymous the operator installs it; a reader needs no account on the bridge
Egressdirect client-side upload and download, so the server does not relay the bytes; the egress is the storage provider's
Per-object capno cap of its own; the cap is the storage policy's
Retentionas long as the operator keeps it running
Interfacerest, webdav, s3
Toolinga Go binary with a Vue front end; REST v4 under /api/v4/*, WebDAV, and S3-compatible policy backends; the nfd-parser project ships a ce driver for it
Composes withthe alternative bridge, and the better one when the upstream is an object store rather than a consumer pan, because it uploads client-side and does not relay through the VPS
ReliabilityThe public demo at demo.cloudreve.org answers /api/v4/site/ping with code 0 and data 4.19.1-pro and has no filesystem, so a scan that stopped at the ping would record a live instance and find nothing behind it.
NotesA v4 instance answers /api/v4/site/ping; v3 answered a different path, and neither exposes an anonymous mount list the way AList does. That is why 1 of 169 hosts classified as Cloudreve and why the class is not a public-instance population at all.
