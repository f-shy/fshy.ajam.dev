ToolingXFileSharing Pro family (sibsoft.net/xfilesharing.html). Same shape as ~hundreds of hosts, so one client works across all of them; discovery is GET /server -> {"url":"https://fs430.uploadhive.com/cgi-bin"} then POST upload.cgi with utype=anon; also used by PolyUploader (github.com/spel987/PolyUploader).
Composes with3 layers: (a) files per host carry no stated limit, (b) 50-day retention resets on download so a periodic re-fetch keeps data alive indefinitely, (c) the whole XFileSharing family is the multiplier. Each host takes one free registration with its own 100s-of-GB-to-2TB pool (see UpZur/FileAxa/Mega4up entries).
ReliabilityDl.cgi returned 'Wrong IP' on every download attempt regardless of referer/cookies. Downloads appear bound to the uploading IP, so a distributed fetch layer needs matching egress IPs.
