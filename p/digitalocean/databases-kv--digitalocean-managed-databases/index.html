Free tierNo free database tier. A new first team receives a USD 5 signup credit that expires 90 days after signup and applies to all products except SaaS Add-Ons; a valid payment method must be added before resources can be created. The smallest PostgreSQL node is USD 15.15 per month.
unit credits; metered on wall-clock; The only free allowance is a one-time USD 5 credit with a 90-day expiry, not a recurring free plan. Managed databases themselves are paid from USD 15.15 per month.

Bindingnone There is no recurring free allowance, so no usage quota binds; the constraints are a USD 5 credit with a 90-day expiry and a payment-method gate, neither of which has a term in the binding vocabulary.
Identitycard signup applies a USD 5 credit to the first team, but a valid payment method must be added before Droplets or other resources can be created. Accepted methods are Visa, Mastercard, American Express, Discover, PayPal, Google Pay and Apple Pay. No phone number or identity document is shown.
EgressDatabase traffic does not use the account bandwidth allowance; the managed databases pricing page lists no separate per-GB egress charge.
Per-object capNo per-object cap is published on the pricing or cluster documentation pages read. The smallest PostgreSQL node has a storage range of 10 GiB to 30 GiB in 10 GiB increments.
RetentionDaily point-in-time backups are included on PostgreSQL, MySQL, MongoDB and OpenSearch. The write-ahead log backs up every five minutes, so the most recent writes may be lost if a cluster must be reprovisioned from backup. No retention period in days is published on the pages read.
Interfacerest, cli a public API and the doctl command line client manage clusters; clients connect to the database engine's native wire protocol over end-to-end SSL
Toolingpsql, mysql, mongosh, redis-cli or the matching engine client; doctl and the DigitalOcean API for cluster management
Composes witha managed cluster placed in a VPC by default, with automated failover, read-only nodes on PostgreSQL and MySQL, and online migration from an existing database
Reliabilityall clusters have automated failover but a single-node cluster is not highly available without a standby; the write-ahead log backs up every five minutes, so recent writes can be lost on recovery from backup
NotesManaged Databases has no free tier. The only no-cost value is the general USD 5 signup credit, which expires in 90 days and requires a payment method; the smallest database node costs more than that credit. The offer is hosted in DigitalOcean datacenters, not software the reader runs.
