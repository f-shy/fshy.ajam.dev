Free tierNo standing free tier: 'Serverless inference is prepaid only. To send serverless inference requests, you need promotional credits or a positive prepaid balance in your Inference and Agents balance or your account prepayment balance, and we deduct usage charges as you incur them. If your credits and both balances run out, access is suspended until you add funds.' The Inference and Agents balance is funded with a preset amount from $5 to $500; promotional credits, where granted, draw first. A new account's credit amount is not published on the inference pages.
unit credits; metered on wall-clock; Prices are shown per 1 million tokens and billed per 1 thousand tokens. The smallest published serverless rate is the open-weight gpt-oss-120b at 'Input $0.10; Output $0.70' USD per 1M tokens. Dedicated Inference is billed per GPU-hour from $2.59 per hour for an AMD MI300X. Any signup credit is unverified: behind a sign-up.
Pricenone stated
Limits
  • request-rate Tier 1: up to 120 requests per minute (RPM) and up to 1.5M tokens per minute (TPM), with 50K playground tokens per day; limits vary by model and tier up to Tier 5 at 1,200 RPM and 25M TPM source
  • write-gated (binding) prepayment gate: a positive Inference and Agents balance or account prepayment balance, or promotional credits, is required before requests are accepted; otherwise access is suspended source
BYOM limits include at most 10/50/100 imported models per team by resource tier, models up to 200 GB, one import at a time, and no use in agents. All published limits are maximums on shared capacity, not guarantees; constrained capacity can queue, throttle or reject requests with 503 even within limits. Tier 1 and Tier 2 have no Anthropic models and no OpenAI models except gpt-oss-120b.
Bindingwrite-gated For a new account the prepaid balance is the first gate to a request: with no credit and both balances at zero, the API suspends access before any request-rate ceiling is reached.
Identitycard The account signup page offers 'Sign Up with Google', 'Sign Up with GitHub' and 'Sign Up with Email'. The payment-methods documentation says 'To create resources or invite additional team members, you need to add a payment method to your team' and lists credit and debit cards, crypto wallets and ACH, while refusing virtual, electron and prepaid cards; a card preauthorisation hold may appear for up to 7 days. A serverless inference request additionally needs a prepaid balance; a model access key is created after sign-in.
EgressNo per-GB egress price is published for inference requests; web search is $10 per 1000 requests and web fetch is $3 per 1000 requests (not charged with Anthropic models), and each request is billed at the model's per-token rate. Promotional credits are drawn first, then the Inference and Agents balance, then the account prepayment balance; when all are empty, access is suspended.
free allowance: no published per-GB or per-token free allowance on the inference price page; promotional credits only where granted
Per-object capnot applicable: the unit is a model request, not a stored object
RetentionToken requests are consumed on call; no stored-object retention applies. BYOM weights persist in a service-managed Spaces location and are billed at $5.00 per month.
Interfacerest, cli An OpenAI-compatible chat-completions REST API; coding agents can use https://inference.do-ai.run as a drop-in proxy, using a model access key. The API base recorded by models.dev is https://inference.do-ai.run/v1 (88 models); a direct GET of that base answered HTTP 404 with a maintenance page on 2026-11-24, so the endpoint is taken from the vendor docs and models.dev.
endpoint: https://inference.do-ai.run/v1
ToolingAny OpenAI SDK by changing the base URL, the doctl CLI and the DigitalOcean API for control-plane tasks, plus the Model Playground in the Cloud Console.
Composes withAn OpenAI-compatible endpoint behind a prepaid balance can back agent stacks that already speak the OpenAI API; the inference router routes each request to a model at that model's published rate with no extra charge during public preview.
ReliabilityPublished RPM/TPM limits are maximums on shared capacity, not guarantees; requests may be queued, throttled or rejected with 503 or an 'overloaded' response when capacity is constrained, and DigitalOcean may change tiers and model classifications. If credits and both prepaid balances empty, serverless inference access is suspended until funds are added.
NotesHosted OpenAI-compatible inference across 88 models, billed per 1M tokens (displayed) per 1,000 tokens (billed) from $0.10/$0.70 for gpt-oss-120b, or per GPU-hour for dedicated deployments. Serverless requests are prepaid only; the Inference and Agents balance is funded $5 to $500 with auto-reload on by default. This is a separate offer from the existing Droplet, GPU Droplet and Harness Runtime records, and no standing free tier is published on the inference pages.
