First-party pages disagree on the trial destination count: two support articles say the registered number plus four verified test numbers (or up to 5 test numbers), while the account getting-started guide says up to 10 destination numbers. Both figures are quoted in evidence.
Bindingwrite-gated The DEMO mode destination whitelist and the ban on buying virtual numbers with trial credit restrict what the account can send to before the EUR 2 credit is used up.
Identityany-phone The sign-up page lists Email, First name, Last name, Password and Phone number and the steps Verify email and Verify number. A verified phone number is required and no card is asked for; for very few countries Vonage cannot create an account automatically.
EgressOutbound SMS and voice calls are the metered service itself; the pricing page lists USD 0.00860 per US LVN SMS message and USD 0.01538 per voice minute, with carrier fees added. SMS delivery attempts run for up to 72 hours by default.
free allowance: EUR 2 free test credit in DEMO mode
Per-object capunverified: the API reference pages read state no hard numeric limit on SMS message length; an over-long message returns error code 12 'Message Too Long'
Retentionnot applicable to stored bytes: messages are delivered and can be looked up, but no explicit message-log retention period is stated on the pages read; SMS delivery is attempted by default for 72 hours, typically 24 to 48 hours
Interfacerest, cli A REST SMS API at rest.nexmo.com with an OpenAPI specification, plus Messages, Voice and Pricing APIs, authenticated with an API key and secret; a Vonage CLI, language SDKs and inbound and outbound webhooks are documented. SMPP is also listed as an option. The Pricing API is rate limited to one request per second.
endpoint: https://rest.nexmo.com
ToolingVonage CLI, language SDKs, the REST API with an OpenAPI description, the Account Dashboard and inbound webhook endpoints
Composes withTransactional SMS and voice for alerts and two-factor authentication; the Verify API adds OTP delivery with voice fallback, and webhooks feed delivery and inbound events into a larger stack.
ReliabilityThe SMS API answers error 1 when sending faster than the account limit, error 9 when credit is insufficient and error 29 for non-whitelisted destinations in demo mode; inbound webhooks are retried for 24 hours without a 2xx answer.
NotesVonage was formerly Nexmo. The free offer is a DEMO mode trial with a [FREE SMS DEMO, TEST MESSAGE] notice on SMS. A verified phone number is required at signup and no card is required. For very few countries Vonage cannot create an account automatically. The trial destination count differs between first-party pages (5 versus 10); both figures are quoted and the conflict is left open rather than resolved.
