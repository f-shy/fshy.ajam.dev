ReliabilityA trace is public-by-default unless you pick Trackable, so it is a poor fit for anything non-geographic.
Evidence notereported reported: the pages read on 2026-11-03 are three OpenStreetMap wiki pages. https://wiki.openstreetmap.org/wiki/Upload states that only GPX traces can be uploaded, several in one zip, tar or tar.gz file. https://wiki.openstreetmap.org/wiki/API_v0.6 states that the GPX upload call requires authentication and that since August 2026 an upload must give the visibility trackable or identifiable (public and private now return an error). https://wiki.openstreetmap.org/wiki/Visibility_of_GPS_traces states that Public and Private were deprecated in August 2026 and that points are available via the API for every visibility level. These are community wiki pages, not a vendor quota page. The absence of a per-user quota, the sign-up form and the API authentication-failure answer are not covered by those pages, and the clause that a Trackable trace is retrievable by id is not stated on those pages, so the rung stays reported.
