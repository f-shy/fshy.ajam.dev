SMS & MMS, WhatsApp and Verify are listed as Enterprise-only features (from USD 1,000/month) in the US data region, so SMS use is gated to the paid tier. The default account usage limit is USD 1,000 a month and the Professional maximum is USD 2,500 a month. The vocabulary has no kind for a spend cap or a time-limited credit, so both are filed as volume-quota.
Bindingvolume-quota The USD 10 trial credit that expires after 3 weeks and the 2 concurrent calls on the free tier are reached before the API rate of 300 requests per five seconds, and the free tier cannot send SMS at all in the US data region.
Identitycountry-phone The signup page at cx.plivo.com/signup answered with a VPN or proxy block, so no form fields were observed there. First-party account and support pages state the registration gate: name, work email address and password, then email activation via a link, then verification of a unique phone number by SMS OTP or voice call. Personal and disposable email domains are rejected, the number must be SMS-enabled, non-VoIP and match the region, and no VPN is allowed during onboarding. A data region is chosen at signup: the United States region requires an international credit or debit card or USD bank transfer, while the India region requires an Indian card, both only for payment after the trial. No card is required to open the free trial.
EgressNot a data-transfer service: calls and messages are billed per minute or per segment, and the API returns JSON over HTTPS with no separate per-GB egress charge stated on the pages read.
Per-object capA single SMS segment holds up to 160 characters in GSM-7 encoding, or 70 characters with Unicode; longer messages are split into billed segments. A call recording file is capped at 2GB.
RetentionCall logs can be retrieved for the last 90 days only; if no end_time filter is given, the Calls API searches the last 7 days and the maximum search range is 30 days. (90 days)
Interfacerest The Voice API is at https://api.plivo.com/v1/Account/{auth_id}/ and uses standard HTTP methods with JSON request and response bodies. All API requests use HTTP Basic Authentication with the Auth ID as username and Auth Token as password. Messaging, phone number and pricing APIs share the same host, and XML documents and the PHLO visual tool cover call flow design.
endpoint: https://api.plivo.com/v1/Account/{auth_id}/
ToolingOfficial server SDKs for Node.js, Python, Go, Java, PHP, Ruby, .NET and Salesforce; cURL or any HTTP client using Basic Auth and JSON; the PHLO visual designer; Browser SDK for WebRTC calls.
Composes withA worker on any host can place calls or send messages through the REST API, and audio streaming or SIP trunking connects calls to a separate voice agent over WebSocket or SIP.
ReliabilityVoice API calls in the US region are billed in 60-second increments starting at answer; calls above the concurrency limit are rejected immediately with hangup cause 5030, and requests above the monthly usage limit answer 403. The default maximum call duration is four hours, extendable to 24 hours.
NotesPlivo is a hosted communications API, not downloadable software; the user runs only their own application code against its REST API, so self_hosted is false. The free offer is a time-limited USD 10 trial credit, not a recurring free tier, and in the US data region SMS and MMS are Enterprise-only, which is why the verdict is trial-only. Trial credits buy an unstated amount of voice or SMS usage. The 90-day figure is a call-record retrieval window, not a published deletion guarantee.
