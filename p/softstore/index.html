The seller states the enforcement explicitly: 'de haber anomalias en estos puntos, la cuenta se bloqueara y se suspendera el servicio sin derecho a devolucion o garantia de reactivacion'. That is a one-IP, non-simultaneous credential sold to an unknown number of buyers.
Bindingper-ip-shaping Nothing about bytes decides this product; the account dies the first time two buyers open it from different addresses, which the seller's own rule anticipates.
Identityemail A Wix store order with an email address.
EgressThe seller publishes no traffic terms. The credential inherits AllDebrid's terms, which the seller restates only as marketing: 'Maxima velocidad de descarga', 'Descargas sin periodos de espera, sin captchas ni publicidad'.
Per-object capnot applicable: the underlying service is AllDebrid, whose own host and file caps apply.
Retention12 months: 'Cuenta Premium AllDebrid, 12 meses'. The page does not say when the 12 months start, so a credential already running when it is sold would deliver less than a year. (365 days)
Interfacerest The buyer gets AllDebrid account details and uses AllDebrid's own panel and API. The seller ships no client.
ToolingAllDebrid's API works because the credential is a real AllDebrid account. The seller names JDownloader, MEGAsync, MiPony and IDM as the intended clients.
Composes withA 12-month resold credential is the longest single payment among debrid providers, which makes the seller's survival part of the product. It chains with Stremio and torrent add-ons like any AllDebrid account.
ReliabilityThe credential is registered by the seller, cannot be re-keyed by the buyer, is pinned to one IP, and blocks without refund on a rule breach. The seller's support promise ('Brindamos soporte tecnico ante cualquier anomalia y durante todo el tiempo contratado') is the only recourse for a 12-month term.
NotesThis is the cleanest written statement of the shared-credential model found in either language: the seller names the three things that break it - no re-keying, one IP, no simultaneous use - and prices a 12-month term against them. If '$900.00' is Mexican pesos the product is about USD 48; if it is US dollars it is twenty times the direct annual price.
