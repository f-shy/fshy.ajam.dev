unit requests; metered on request-count; The bucket itself publishes no request or byte cap; the request limits are those of the E-utilities and OAI-PMH services. An anonymous esearch on 2026-10-30 answered x-ratelimit-limit 3.
Pricenone stated
Limits
  • request-rate E-utilities: more than 3 requests a second per IP address without an API key answers an error; up to 10 a second by default with a key source
  • request-rate OAI-PMH: 3 requests a second, no concurrent requests source
  • per-object-cap ESearch: at most 10,000 returned records per query source
Bindingnone The bucket publishes no request or byte cap and needs no key; the 3 a second E-utilities limit binds only on selection, which the daily inventory replaces.
Identityanonymous No account or key for the bucket: it is read without any log-in. An E-utilities key, for 10 requests a second, comes from the Settings page of an NCBI account, which signs in through federated logins such as Login.gov, Google, Microsoft live.com, ORCiD or an institution.
EgressFree: NLM provides the bucket through the AWS Open Data Sponsorship Program without charge, over HTTPS or S3, with no log-in.
free allowance: no byte cap published
Per-object capone prefix per article version holding its files; ESearch returns at most 10,000 records per query, and the daily inventory CSV has no record limit
Retentionthe bucket is live: a removed article version's prefix and files are deleted with no notification, detectable only by reconciling the daily inventory; inventory reports are kept 30 days; the legacy baseline packages on FTP and the Cloud Service were removed the week of August 24, 2026
Interfaces3, rest S3 bucket pmc-oa-opendata (arn:aws:s3:::pmc-oa-opendata) read with --no-sign-request, or https://pmc-oa-opendata.s3.amazonaws.com/ over HTTPS, with a daily S3 inventory CSV; E-utilities at https://eutils.ncbi.nlm.nih.gov/entrez/eutils/ (esearch with open access[filter]); OAI-PMH at https://pmc.ncbi.nlm.nih.gov/api/oai/v1/mh/; BioC API. The PMC OA Web Service is no longer available and there are no baseline bulk packages.
endpoint: https://pmc-oa-opendata.s3.amazonaws.com/
Toolingaws s3 cp or sync with --no-sign-request, or curl over HTTPS; the daily inventory CSV as the list of article versions; EDirect to page past 10,000 ESearch results
Composes withThe bucket is the bulk path: objects for roughly 8 million article versions, listed in a daily inventory CSV with no record limit; an esearch on open access[filter] counted 8357213 records on 2026-10-30; E-utilities or OAI-PMH select articles by date or licence before the S3 fetch.

Free tier'PMC makes the datasets described below freely accessible on Amazon Web Services (AWS), without charge, through either an HTTPS or S3 URL, and without any log-in requirement for retrieval.' The README reports 'roughly 8 million PMC article versions'.
unit unlimited; metered on none; The bucket is s3://pmc-oa-opendata in us-east-1; the AWS Open Data Sponsorship Program covers the transfer.
PriceUSD 0
Limits
  • request-rate no request cap is published for the S3 bucket; the article-dataset page restricts automated retrieval to the Cloud Service, OAI-PMH, E-utilities and BioC API source
  • per-object-cap one object per article file; measured full-text XML is 109,974 bytes, so a 1 TiB pull is roughly 10 million objects
The 2026-08-24 change removed the legacy FTP and cloud dataset files and left the S3 bucket as the distribution path.
Bindingnone Nothing fails at 1 TiB/month: the whole corpus is smaller than that. At the measured 109,974 bytes per article version, 8 million versions is about 880 GB of XML before PDFs and media - arithmetic from the two published numbers, not a measurement of the bucket.
Identityanonymous 'without any log-in requirement for retrieval'; an unsigned HTTPS GET for a full-text XML returned 200 here. No Earthdata-style account, no API key.
EgressFree and unmetered: NLM pays through the AWS Open Data Sponsorship Program. 'No charges, usage fees or royalties are paid to NLM for these data.' Both https://pmc-oa-opendata.s3.amazonaws.com/<prefix>/<file> and s3:// with --no-sign-request work.
free allowance: unlimited, sponsored
Per-object capnot applicable: one object per article file (JATS XML, plain text, PDF, media). A full-text XML measured here was 109,974 bytes.
Retentionarticles stay while their licence holds; 'If a version is removed from the S3 bucket, its prefix and all associated files are deleted from the bucket with no explicit notification. Inventory reconciliation is the only supported way to detect removals.' The inventory is regenerated daily and kept 30 days.
Interfaces3, rest, cli S3 REST and HTTPS on the same bucket. aws s3 cp --no-sign-request s3://pmc-oa-opendata/<PMCID>.<version>/<PMCID>.<version>.xml, or curl the equivalent https URL. S3 Inventory under inventory-reports/ gives a daily CSV manifest.
endpoint: https://pmc-oa-opendata.s3.amazonaws.com/
ToolingAWS CLI with --no-sign-request, curl, boto3 unsigned, rclone (S3 remote with anonymous access). Any of them reaches the bucket; nothing needs an account.
Composes withThe full-text corpus that pairs with Europe PMC's metadata index: harvest PMID/PMCID lists from Europe PMC or the PMC inventory, then pull the XML here.
ReliabilityRemoved articles vanish with no notification; the inventory lags the bucket by up to a day, so a manifest-driven sync always races deletions.
NotesThis is the strongest no-account research corpus in the sector: 8 million article versions, no login, S3 range reads, a daily inventory. The 2026-08-24 distribution change is the reason a record written before it would name FTP paths that no longer exist.
Evidence notemeasured Two objects were fetched anonymously and hashed here (README.txt 14,524 bytes; one full-text XML 109,974 bytes) and the bucket's accept-ranges is byte. What is not measured is aggregate throughput at 1 and 8 connections.
