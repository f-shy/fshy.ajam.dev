New organizations get USD 5 in usage credits and USD 50 more when they add a card. From December 1, 2026 disks and commits cost USD 0.10 per GiB-month.
unit credits; metered on wall-clock; starting-credit

Bindingnone No monthly minimums, tier floors or annual commits are published. Vers is prepaid: usage is deducted hourly and new computers cannot start at a zero balance.
Identitycard New organizations receive USD 5 in usage credits without a card and USD 50 more when they add a card. The page does not state which identifier opens the account; prepaid credit is bought with a card and running computers are paused when the balance falls USD 5 below zero.
EgressAll network traffic in and out of VMs, in both directions, is metered per MB and billed at USD 0.09 per GB; there is no free allowance.
price per tb: USD 90 per TB
Interfacecli, ssh The docs.vers.sh CLI reference documents the standalone vers CLI binary (HTTPS control plane) and an SSH gateway at try.vers.sh; no REST API reference or SDK was read on that page.
ToolingThe vers CLI, a standalone Rust binary installed locally, and the ssh try.vers.sh gateway; the CLI reference page names no SDK or API library.
Composes withPaused VMs are free, so the shape that pays off is a fleet of branched computers parked between agent steps: 100 paused branches cost nothing, and only the one being worked on bills at USD 0.04 per vCPU-hour.
Reliabilityno reliability event recorded
NotesThe pricing page quantifies the starting credit as USD 5, plus USD 50 when a card is added. Storage is billed from December 1, 2026 at USD 0.10 per GiB-month for VM disks and commit snapshots. The CLI defaults to 2 vCPUs and 4096 MiB, so vCPU time alone at the published rate is USD 58.40 for 730 hours of 24/7 use.
