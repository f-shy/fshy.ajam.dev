Free tierA single metered rate of USD 0.04 per vCPU-hour, billed per second, with memory included and no tiers. Paused VMs, stopped VMs, commits, snapshots and branches do not accrue compute. No monthly minimum and no per-fork fee. 'New accounts get credits to prototype and run small experiments before a card is required' (amount not stated).
unit hours; metered on wall-clock; starting-credit
Pricenone stated
Bindingnone No session cap, no idle reap and no monthly minimum are published; the first thing that actually stops a fleet is the monthly card charge for whatever ran, since paused VMs accrue nothing.
Identityemail The credit amount is not stated, and which identifier the account is created with is not stated in the evidence
Egressnot stated
Interfacecli, ssh The docs.vers.sh CLI reference documents the standalone vers CLI binary (HTTPS control plane) and an SSH gateway at try.vers.sh; no REST API reference or SDK was read on that page.
ToolingThe vers CLI, a standalone Rust binary installed locally, and the ssh try.vers.sh gateway; the CLI reference page names no SDK or API library.
Composes withPaused VMs are free, so the shape that pays off is a fleet of branched computers parked between agent steps: 100 paused branches cost nothing, and only the one being worked on bills at USD 0.04 per vCPU-hour.
Reliabilityno reliability event recorded
NotesStorage for kept commits is billed and its rate is not on the pricing page. Isolation is a full VM rather than a microVM or container. For a month of 24/7 at the CLI default of 2 vCPU / 4 GiB the arithmetic is 2 x 730 x 0.04 = USD 58.40, which sits between bunny.net (USD 43.80 at 2 core / 4 GB) and inis.run (about USD 29.50 equivalent).
