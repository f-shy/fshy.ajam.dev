unit requests; metered on request-count; no credit card is required until usage passes the free tier, and the overage is billed on the 1st of the following month instead of being refused; a billing limit can be set; the UK needs a Flex or Unlimited plan and Australia and New Zealand are outside Pay-As-You-Go

Bindingvolume-quota 1,000 lookups a minute allows far more than 2,500 lookups in a day, so the free daily allowance is met first
Identityemail an account at dash.geocod.io with a name, an email address and a password, behind a terms checkbox; the page says no credit card is required, and a card is asked for only once usage passes the free 2,500 lookups a day
Egressnot applicable: a query API metered in lookups, not bytes
Per-object capa batch request takes up to 10,000 lookups, each field append counting as a lookup; a CSV list job takes up to 1GB per CSV
Retentiondata of spreadsheets processed through the lists API is deleted 72 hours after processing completes (3 days)
Interfacerest HTTPS to api.geocod.io/v2 (GET /geocode and /reverse for one lookup, a POST of a JSON array for a batch of up to 10,000 lookups, and an asynchronous lists API for CSV, TSV and Excel files) with the key in an api_key parameter; spreadsheet geocoding is also in the dashboard; a keyless geocode answered HTTP 403 with Invalid API key
endpoint: https://api.geocod.io/v2/geocode
Toolingany HTTP client; spreadsheet geocoding in the web dashboard
Composes with2,500 permanently storable lookups a day for US, Canada and Mexico addresses on an email account with no card, then USD 1.00 per 1,000; bulk work goes through batch requests of up to 10,000 lookups or CSV list jobs, each lookup costing 1 credit
ReliabilityPay-As-You-Go answers HTTP 429 at the 1,000-lookups-a-minute limit with X-RateLimit headers to read; a lookup past the free daily allowance is billed monthly, not refused
NotesFree requests: 2,500 lookups a day on Pay-As-You-Go. Rate limit: 1,000 lookups a minute. Bulk path: batch requests of up to 10,000 lookups, CSV lists and spreadsheet upload, all billed as lookups.
