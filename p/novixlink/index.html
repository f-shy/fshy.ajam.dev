Two constraints the vocabulary cannot name. First, the ISP label is only what the vendor's own IPLense reading said at first delivery (terms 4.2), so it is a claim about one database's reading of the address rather than a property of the address, and it does not move when that database changes. Second, every LAS-COX plan was shown as 全部售罄 (all sold out) on 2026-10-24, so the one line that passed the registration check could not be bought that day.
Bindingvolume-quota 500 GB a month is about eleven times the gateway's ~45 GB/month, so the quota does not fail at the scale; it is named because it is the only constraint here the vocabulary can express and the one the product states. The constraint that actually decides this record is the registration class, which has no vocabulary value, and it is what the verdict's caveat is about.
Identityemail The registration form asks for a name, an email address and a password and nothing else: no phone, no card, no identity document. Payment is Alipay, card or crypto. Terms 5.2 names Alipay and crypto as methods that cannot auto-debit and a card as the one that can; 6.2 names crypto again, as a payment that can only be refunded to site balance.
Egress500 GB 每月双向流量 (bidirectional traffic per month) on LAX-CUPN Lite, 1000 GB on LAS-COX Lite. The vendor publishes no overage price on either page: what happens past the allowance is not stated, so the allowance is a ceiling without a stated consequence.
free allowance: 500 GB/month on LAX-CUPN Lite; 1000 GB/month on LAS-COX Lite
Retentionnot applicable: a rented machine and its address, not stored bytes. Terms 5.3: on non-payment the VPS, its IP and its data are deleted at expiry, with a grace period of about 48 hours that is stated not to be a guarantee of resource retention.
Interfacessh SSH to the VPS on its static address. SOCKS5 or HTTP proxying is whatever runs on the machine, not a vendor endpoint: the vendor sells the address and the box, not a proxy service. Orders, renewals and IPv4 changes are handled in the customer portal.
ToolingAn SSH client plus a proxy daemon installed on the VPS. The vendor publishes no proxy endpoint, no API and no wrapper. That is a note about tooling and not a reason to reject the provider: the address is the product, and the machine is only how it is held.
Composes withThe Worker opens an outbound connection to the VPS's static IPv4 and the VPS makes the upstream request, so the upstream sees an address in AS2914, AS3257 or AS22773 instead of AS13335.
ReliabilityThe address is static for the life of the plan, but terms 7.3 lets the vendor switch the line, rate-limit, block ports or null-route the IP for at least an hour on a DDoS or attack, and terms 4.2 fixes the ISP label to the IPLense reading at first delivery, so a later re-registration of the range does not reopen the claim.
NotesThe decisive vendor sentence, from terms 4.2: '双 ISP 住宅 IP 和双 ISP 家宽 IP 仅以服务首次交付时的 IPLense 快速模式结果和系统记录作为正式交付标准'. Read against knowledgebase 48, 双 ISP means the ASN name and the company type label both read ISP on one database, not that two networks carry the traffic, so the claim this record tests is exactly the two fields that were measured. Terms 4.3 also matters for how far the measurement travels: a delivered IP need not be in the sampled /24, only in the same ASN and the same operating company, so the pass on 24.120.4.1 is evidence about the prefix sampled and about the ASN, not proof that every address the vendor hands out in that ASN reads ISP. Each line was checked with one address, taken from the test IP the vendor itself publishes.
