The only published number is the earnings rate, not a capacity limit: '$35 per 10k Views (Counted 3 Views per 24 hours)'. A host that pays per view has an incentive to keep serving, which is a stronger retention signal than a promise.
Bindingnone No counter is published, so none can bind as a number. What binds in practice is account action: a pay-per-view host closes an account that burns bandwidth without earning, and that enforcement is invisible until it happens.

ToolingFTP plus an API means an existing upload pipeline can point at it without a wrapper. The site does not publish endpoint documentation on the page read, so the API would have to be discovered.
Composes withBulk video egress: a high-volume video service can put the long tail here at zero cost and keep only the hot set on a paid CDN. The remote-upload path also lets it pull from an existing host without a local copy.
ReliabilityPay-per-view hosting ties the account's survival to earnings: an account used purely as free CDN storage serves bandwidth the operator is not paid for. Expect throttling or deletion to arrive as an account decision, with no published quota to appeal to.
NotesDocumented as an egress surface, not a storage answer: the bytes are only useful if they are served, and this is a place that serves them for free while the vendor monetises the player.
