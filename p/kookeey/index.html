Interfacecli, rest Http/Https/Socks5 for both products, delivery protocols for static lines include Socks5, Http(s), Vmess, Shadowsocks, Wireguard and GRE; an API document is published for automated purchase and management.
ToolingAny client that speaks SOCKS5 or an HTTP proxy, reached from a Worker through a relay that dials SOCKS5. An API document (kookeey.com/apidoc) and a help centre exist. That is a note on tooling, not a reason to reject.
