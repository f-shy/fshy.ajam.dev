Free tierFree account: 1,000 weather records a day (30,000 a month) through the Timeline Weather API and the Query Builder, with forecasts, current conditions and 50+ years of history; 1,000 records and 5 locations per query, 1 concurrent request, and 10,000 weather map requests a month.
unit mixed; metered on object-count; The allowance is counted in weather records: each history record returned counts as one record and a single 15-day forecast query counts as one. Bulk path: Query Builder datasets of up to 1,000 records and 5 locations each on Free, with no dataset scheduling.
Pricenone stated
Limits
  • volume-quota (binding) 1,000 records a day (30,000 a month) source
  • per-object-cap 1,000 records and 5 locations per API query source
  • request-rate 1 concurrent API request source
  • request-rate 10,000 weather map requests a month source
  • per-object-cap Query Builder datasets: 1,000 records and 5 locations each, no scheduling source
  • per-ip-shaping Keyless Timeline calls need no API key or account registration; usage is managed per client IP address under fair-use controls and no fixed request allowance is published source
  • per-object-cap Keyless queries: a maximum query cost of 48 records; a query that would cost 49 is refused with HTTP 401 and the message to split it into smaller queries source
Bindingvolume-quota 1,000 records a day binds: each daily or hourly history row is one record (24 records for a day of hourly data at one location) and a full 15-day forecast for one location is one record, so 1,000 forecast calls a day for one location fit the same allowance.
Identityemail An account is opened with an email address as the username, a validation code emailed to that address, a password and a checked box accepting the terms; the API key is shown when the account is created and stays on the account page.
Egressnot applicable
Per-object cap1,000 records and 5 locations per API query; 1,000 records and 5 locations per Query Builder dataset
Retentionnot applicable: the unit is a record returned
Interfacerest Timeline Weather API over HTTP: parameters go in the query string or in a POST query; a registered account's key goes in the key parameter and supported free requests need no key; contentType selects json, flatjson or csv answers
endpoint: https://weather.visualcrossing.com/VisualCrossingWebServices/rest/services/timeline/
ToolingA keyless request must send Accept-Encoding: gzip; without it the API refuses the request with the text "Bad API Request:Anonymous requests require gzip response support. Send Accept-Encoding: gzip."
Composes withA history-heavy source: one call returns daily or hourly history, current conditions and a 15-day forecast for a location, so 1,000 locations of forecasts or 1,000 rows of history fit in a day.
ReliabilityFair use: an account past the day's fair usage answers HTTP 429 and is held to one concurrent request for the rest of the day; extreme cases are suspended until support restores the account.
NotesBulk path: Query Builder datasets, 1,000 records and 5 locations each on Free. Past the free records, the Metered plan bills USD 0.0001 a record.
