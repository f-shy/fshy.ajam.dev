Free tierFirst 10GB storage is always free; storage above it is billed per byte-hour at USD 6.95/TB/30-days
unit GB; metered on stored-bytes; Class A, B and C API calls are free on pay-as-you-go; Class D calls are free up to 2,500 a day. The API pricing page still prints USD 0.005/GB/month for storage after the first 10 GB, while the pricing page and its billing FAQ print USD 6.95/TB/30-days.
PriceUSD 6.95 per TB per 30 days, pay-as-you-go, after the first 10 GB
Limits
  • volume-quota (binding) 10 GB of storage free; every byte above it is billed at USD 6.95/TB/30-days source
  • volume-quota (binding) egress free up to 3x the average monthly stored bytes; beyond it USD 0.01/GB, except to partner CDNs and compute services source
  • per-object-cap 10 TB per large file (parts of 5 MB to 5 GB); 5 GB per single-request file source
  • request-rate Class D transactions: the first 2,500 calls a day free, then USD 0.004 per 10,000 calls; Class A, B and C calls free source
No minimum file size and no minimum storage duration fees. A public bucket needs a verified email address and a payment history on file, or a small card payment credited to the account balance.
Bindingvolume-quota the 10 GB of free storage is the first ceiling; on the paid tier the next one is the 3x-of-stored egress allowance, which partner-CDN egress does not count against
Identityemail Account creation asks for an email address verified by a link, a password and a data region, and the sign-up page states 'No credit card required.' A public bucket needs a payment history or a small card payment. A help-centre article says enabling B2 on an existing Computer Backup account prompts for a phone number verified by SMS; the account-creation guide names no phone step.
EgressFree up to 3x the average monthly stored bytes (byte-hours over the billing cycle), then USD 0.01/GB; unlimited and free to partner CDNs and compute services (Fastly, Cloudflare, bunny.net, CacheFly, CoreWeave, Equinix Metal, Vultr, phoenixNAP)
free allowance: 3x the average monthly stored bytes; unmetered to the named partner CDNs and compute services
price per tb: USD 0.01 per GB beyond the 3x allowance
Per-object capLarge files can range in size from 5 MB to 10 TB; a file sent in one request is limited to 5 GB
RetentionNo minimum storage duration fees; the pages read state no expiry for stored files
Interfaces3-compatible, rest S3-Compatible API (the S3 syntax, with limited ACL and tagging support) and the B2 Native API (b2_* calls)
ToolingAWS CLI, AWS SDKs, AWS Tools for PowerShell and s3cmd against the S3-Compatible API; any S3 client, rclone's s3 backend among them; the B2 Native API for b2_* calls
Composes withAn S3 origin behind Cloudflare, Fastly or bunny.net: egress to those partner CDNs is free and outside the 3x allowance, so a CDN-fronted public bucket serves reads without the USD 0.01/GB overage.
Reliabilityno throttle, suspension or data-loss event is stated on the pages read; usage above 10 GB of storage or above the 3x egress allowance is billed automatically
NotesS3-compatible object storage: confirmed. B2 Overdrive, the higher-throughput tier, starts at USD 15 per TB a month with unlimited free egress and needs a multi-petabyte commitment, so it is not a separate entry point. Payment is by credit card or invoice.
