The absence is the finding: a service whose product is removing somebody else's limit publishes no limit of its own, so a client cannot budget against it. The Drive-side ceiling is documented one link further down the chain by DriveSeed, which lists '403: User Rate Limit Exceeded - Fixed to Great Extent' as a release note.
Bindingper-ip-shaping At 1 TiB a month the throttle that reappears is Google's per-file and per-session shaping on the Drive object behind the wrapper. HubCloud adds no counter of its own, so nothing else on this record can bind.
Identityanonymous Generating a link needs nothing: 'No account linking needed'. A dashboard exists at /drive/admin for managing files, but the public path does not require it.
EgressEvery download is proxied through HubCloud as a 'high-speed direct download link'; folder shares are 'Download folders as ZIP archives instantly'. Nothing is metered and no allowance is printed.
Per-object capNot stated. Nothing on the page names a size for a wrapped file or for the ZIP a folder share produces.
RetentionNot stated. The wrapper stores a Drive file id, so the link lives as long as the Drive object does.
Interfacerest, unknown REST upload endpoint curl -X POST api.hubcloud.foo/upload, announced as 'New: API v2.0 Released', with a dashboard at hubcloud.foo/drive/admin. The page also offers a 'Pack Manager' that combines several links into one package and a Drive integration that requires no account linking.
endpoint: https://api.hubcloud.foo/upload
ToolingNo client library. The generation step is a form on the page; the API is a single documented POST. Third parties already automate it: hubcloud.cfd is a public 'HubCloud Bypass' page whose only feature is 'Extract direct download links from HubCloud video/drive pages instantly'.
Composes withThe middle layer of the Indian index chain: an index site posts a HubCloud link, HubCloud re-exposes the Google Drive file as a direct link that indexers and apps can hand to a downloader, and the same file is often re-wrapped one layer down by DriveSeed or GDFlix.
ReliabilityThe brand rotates hostnames faster than the index sites update: hubcloud.xyz could not be checked at all because network requests's DNS lookup timed out (503 destination-unchecked, retryable), which establishes nothing about the domain; hubcloud.ink answered an empty 204; and the live host was reached only through hubcloud.foo, which redirects to hubcloud.ist. A client that hard-codes a host breaks within weeks.
NotesThe record prices a link wrapper, not storage: nothing here can be mounted, and the bytes always belong to Google. hubcloud.xyz was the ledger's assumed host and is dead.
