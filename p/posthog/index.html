Free tierFree every month, reset monthly, with or without a card on file: 1M analytics events, 5K session recordings, 1M feature flag requests, 100K exceptions, 1500 survey responses; 1 project, 1-year data retention, unlimited team members; no credit card required
unit mixed; metered on request-count; Each product has its own monthly count (events, recordings, flag requests, exceptions, survey responses), so no single unit of the vocabulary fits; analytics is counted in events, and one batch request can carry many events, so request-count is only the nearest metered_on term. Usage across projects shares one free allowance. On the free plan, events past the allowance are permanently dropped and feature flags return a quota-limited response, so usage stops rather than bills.

  • volume-quota (binding) 5K session recordings, 1M feature flag requests, 100K exceptions and 1500 survey responses per month; 1 project source
  • request-rate 240 per minute and 1200 per hour on analytics endpoints, per personal API key source

Bindingvolume-quota Events past 1M in a month are permanently dropped on the free plan, so the monthly event count is the first ceiling for an app with traffic; the API rate applies only to reads with a personal key.
Identityemail An account is tied to an e-mail address: the wizard creates one from an e-mail address and a region. The pricing and sign-up pages state no credit card is required, and the allowance is the same with or without a card on file. Whether a later step asks for a phone number is unverified: behind a sign-up.
Egressunverified: no egress term on the pages read; data is read back through the private API, rate limited per personal API key (240/minute and 1200/hour on analytics endpoints)
Per-object capEvents over 1 megabyte after processing are discarded; a distinct_id is limited to 200 characters
RetentionEvents and metadata: 1 year on a free plan (7 years on paid). Session recordings: 1 month on the free plan. Logs: 14 days by default.
Interfacerest Public POST-only endpoints (event capture at /i/v0/e, flag evaluation at /flags) take a project token and are not rate limited; private GET, POST, PATCH and DELETE endpoints take a personal API key or OAuth. The US app host us.posthog.com answered 401 to /api/projects/ without a key. The data region (US or EU) is fixed when the account is made.
endpoint: https://us.posthog.com/api/
ToolingPostHog SDKs, the @posthog/wizard command (run with npx), which can create the account and install the SDK, and any HTTP client with a personal API key for the private API
Composes withEvent capture and feature flags for the front end of a free-hosted app, up to 1M events a month, with error tracking in the same project; over the allowance events are dropped, not billed.
ReliabilityEvents above the free allowance are permanently dropped and feature flags return a quota-limited response.
NotesThe free plan stops at its limits instead of billing, so an app sending more than 1M events a month loses the excess. Moving to pay-as-you-go needs a card and raises the project count to 6 and event retention to 7 years.
