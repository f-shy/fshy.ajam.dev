Per-object-cap: 10 TB per single object, 100M objects per bucket. The most permissive object caps in this niche. Retention: 'long-term storage of non-persistent data'; Data Lake has NO on-demand backup ('On-demand backup | Yes | No'), only erasure coding and snapshots. request-rate: not published (27 GB/s aggregate is the claim). Gate: Norwegian university/research affiliation plus RFK allocation.
Identityinstitution Applicants belong to a listed Norwegian organisation (universities and university colleges, governmental research centres, hospitals, industrial parties); the project leader holds a permanent, postdoctoral or temporary position; master and PhD students and guest researchers apply through a colleague.
EgressUnmetered; S3 and HTTPS serve directly, and NIRD S3 is explicitly for 'data sharing with external collaborators' and 'data streaming'.
Per-object cap10 TB per single object (10000000000000 bytes)
Interfaces3, nfs, rclone, cli part of the text of Free tier, above
ToolingRclone (provider = Other, endpoint https://s3.nird.sigma2.no), AWS CLI, s3cmd, MinIO client, Cyberduck. The same data is simultaneously available over POSIX, NFS and S3. 'the same data can be accessed simultaneously through multiple protocols'.
Composes withQuota is per project and RFK-allocated, so the multiplier is project count and the DP/DL split (two resources, 'The two resources have separate quota based on the project allocation'). NIRD Data Lake is pitched at 'structured or unstructured data of any volume larger than 1 TiB'. I.e. the intended workload IS tens of TB.
ReliabilityCRITICAL COST CAVEAT most agents will miss: NIRD is NOT free. The User Contribution Model (v2.2, valid from 1 Oct 2025) prices it at 'NIRD Data Lake 470 NOK per TB/year' and 'NIRD Data Peak 800 NOK per TB/year' for Category A, invoiced yearly to the institution. 20 TiB of Data Lake ≈ 9,400 NOK/yr. The bytes are unmetered but the TB-years are not. This fails the 'free' filter unless an EU-programme exemption applies ('Projects participating in EU programmes are exempted from contribution').
NotesPriced per TB per year for an allocated project: Category A NIRD Data Lake 470 NOK per TB/year and NIRD Data Peak 800 NOK per TB/year (valid from 1 October 2025); projects participating in EU programmes are exempted from contribution.
