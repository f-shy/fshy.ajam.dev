Interfacerest Event ingestion through the HTTP V2 API at api2.amplitude.com (EU residency: api.eu.amplitude.com), with an API key in the JSON body, and through SDKs; an MCP server connects AI tools to Amplitude data on every plan, Free included. Webhooks are not included on Free.
