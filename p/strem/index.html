The addon returns a per-title stream list; each title opened is one request. Its own cache headers are explicit: cacheMaxAge 3600, staleRevalidate 14400, staleError 604800, so one title is cheap to ask twice and a shared proxy is what multiplies the rate. Torrentio has also been down for hosting reasons more than once (issues 288 and 370).
Bindingrequest-rate There is no byte accounting anywhere in the addon; the only thing that breaks at scale is the request rate from one address, which is exactly what the shared-instance reports describe.
Identityanonymous No account for the P2P path. A debrid key is optional and is the provider's, not Torrentio's.
EgressNo byte allowance from the addon: it returns magnet links, and the transfer is between the user (or the debrid provider) and the swarm.
free allowance: none published
Per-object capnot applicable: the addon returns magnet hashes, not bytes
Retentionnot applicable: results are computed per request; the debrid cache behind them is the provider's retention
Interfacerest Stremio addon protocol over HTTP: /stream/<type>/<imdb>.json, /manifest.json and a /configure page that takes a debrid key. Every response is JSON.
endpoint: https://torrentio.strem.fun/stream/movie/tt1254207.json
ToolingAny HTTP client. Stremio or a Kodi addon consumes it directly; AIOStreams, MediaFusion and StremThru chain it behind a single addon. The debrid path needs the provider's API key in the config URL.
Composes withTorrentio resolves an IMDb id to magnets from public trackers, and with a debrid key it asks the provider which hashes are cached; that cached answer is what makes playback start without seeding.
ReliabilityHosting moves and blocks: the tracker's own issues record the VPS being blocked (issue 288) and a DDoS (issue 370), each taking the public instance down for days. The addon's cacheMaxAge is 3600 s, so a cached stream list can outlive the swarm it describes.
NotesStremio addon resolving titles into streamable torrent and debrid cached links. Queries are evaluated per title rather than providing full index scraping.
