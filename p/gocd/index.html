Bindingwrite-gated the binding constraint is the need to install and operate a server and agent on a machine the user provides, since the vendor offers no hosted runner that could be used instead
Identityanonymous the software downloads and runs with no account: the download page links installers and images directly with no sign-up, and a newly installed GoCD server does not require users to authenticate. Optional password-file or LDAP/AD authentication is configured locally by the operator; the Test Drive is a local installer needing no registration
Egresswhatever the machine running the GoCD server and agents charges for outbound traffic; the software meters and caps no traffic itself
Per-object capnot applicable: there is no hosted service to impose a single-object cap; pipeline and artifact limits are set by the user's own server configuration
Retentionwhatever the machine running the GoCD server and agents retains; the software imposes no fixed retention period
Interfacegit, rest, cli a material is usually a source repository (Git, SVN, Mercurial) that the server polls for commits, and a timer or pipeline dependency can also trigger a run. A REST API at go-server-url:8154/go/api reads configuration and build history and can update configuration and execute builds; the API reference offers Shell bindings and curl examples
endpoint: https://go-server-url:8154/go/api (the host is the user's own server)
Toolingthe user installs and runs the GoCD Server and one or more GoCD Agent daemons on a rented or free machine, from OS installers, Zip archives, Docker images or a Kubernetes Helm chart; the agent polls the server for work and executes the build tasks
Composes withno hosted runner lane exists: the Test Drive is a local download-and-run evaluation instance, described as for evaluation purposes only and not for production. The self-hosted server and agents are the last resort; pair them with a free or rented machine. Pipelines can be triggered by Git commits, a timer or an upstream pipeline, and driven through the REST API
Reliabilitythe host, its bill and its uptime belong to whoever runs the instance, so no reliability event at a provider applies to this record; the Test Drive is explicitly for evaluation, not production use
NotesGoCD is a continuous delivery server the user installs and runs; there is no vendor-hosted runner lane. The vendor's Test Drive is a local download-and-run evaluation instance, not a hosted service, so it does not count as a hosted offer. Build container CPU, memory, outbound network access and any fixed artifact retention are set by the user's own server configuration and are unverified.
