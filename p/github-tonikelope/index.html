The app's headline feature is working around the 509: it rotates a proxy list when MEGA blocks an IP. MEGA's own help page warns that third-party tools 'can't detect your quota', which is exactly why a client sees stalls rather than an error.
Bindingper-ip-shaping At 1 TiB/month the IP-based six-hour window is what stops a MEGA download; the workaround is proxy rotation, which the app implements, and the fallback is waiting for the window to reset. Nothing else in the vocabulary binds because MEGA has no per-file cap.
Identityanonymous Public MEGA links download without a MEGA account. An account is only needed for private content or to raise the quota, and the app's own proxy rotation exists because the anonymous quota is the binding limit.
EgressMEGA meters downloads per IP for free and anonymous users, not per file: the limit is 'based on the amount of data downloaded from your IP address over the past six hours' and has no fixed byte value.
free allowance: dynamic, IP-based, six-hour window; no published number
Per-object capMEGA publishes no per-file cap: 'MEGA does not have any file size limits. The only limitations you face are the amount of free space on your local device (if downloading) or in your Cloud drive (if uploading).'
Retentionnot applicable: the user writes to local disk. The MEGA-side file lives until the owner deletes it.
Interfacecli A Java Swing desktop application launched from the jar or the packaged executable. No API documentation and no server mode were found in the repository or README; the closest thing to a machine interface is driving the jar under a virtual framebuffer, or the third-party Docker images that expose its window over VNC.
ToolingJar plus platform executables; AppImage build; community Docker images (vttc08/megabasterd) that wrap the GUI in noVNC. Automating it needs a display server or a wrapper around its GUI, which is a tooling note and not a reason to reject the provider.
Composes withIt is the MEGA leg of a pipeline: pair it with a hosted relay (saveindrive-style MEGA-to-Drive streaming) when no local machine can run the jar.
ReliabilityMEGA answers over-quota requests with HTTP 509 and the window is per IP, so a shared or datacentre address exhausts it fast. MEGA's help page also warns third-party clients can lock an account when used with credentials.
NotesThe 'hosted fork' search turned up containers (self-hosted Docker with noVNC) and an unofficial site megabasterd.com that redistributes builds; neither is a hosted service that accepts a URL. The unofficial site was not used and its binaries were not downloaded.
