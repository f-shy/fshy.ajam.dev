Bindingrequest-rate The only published numbers that can bind are the concurrent-connection caps, because the traffic terms are unstated and the per-file cap is unstated. 50 connections on the 1 TB profile is ample for a copy job and thin for a serving path.
Identitycard a DanubeData account and a payment method. The docs do not describe the signup gate
EgressNo egress price and no traffic quota are published anywhere in the vendor documentation, so this field is false by the schema's own definition (false when traffic out has neither a price nor a quota) and not because the vendor granted anything. The instance is S3-backed and DanubeData sells object storage separately, so a traffic line may exist behind the Nextcloud facade and the docs do not say
Per-object capNot published as a per-file cap. The published per-profile numbers are subdomains and concurrent connections: 3 and 50, 7 and 100, 10 and 200
RetentionUntil deleted. The instance lifecycle is Pending, Provisioning, Running, Error, Destroying, with redeploy from Error. No retention clock is documented
Interfacewebdav, rest, s3
Toolinga WebDAV endpoint on every profile, the Nextcloud clients, and one-scan QR setup for iOS and Android. S3-backed means the same bytes are in an object store, so an S3 tool may reach them without a second copy, but the docs do not publish the bucket
Composes withS3-backed Nextcloud is the cleanest architecture of the four: the bytes live in an object store behind a Nextcloud facade, so either access path should reach the same copy. Ten subdomains per instance is an unusual sharding affordance and it is the only reseller here that offers it
ReliabilityFalkenstein, Germany, the same data centre as Hetzner, so the failure domain is shared with the Hetzner option. Dedicated CPU and memory per instance, automatic TLS renewal. The product is young and the documentation is thin: the WebDAV page returned 404 when requested
NotesThe cheapest 10 TB managed Nextcloud of the five at EUR 3.00/TB/month, and the only one whose storage is documented as an object store behind the Nextcloud facade. Two things are unverified that a buyer needs: the traffic terms, and whether the S3 backend is reachable with credentials the customer holds. The docs describe the second as a property of the product and publish no endpoint.
