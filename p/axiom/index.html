Free tierPersonal, USD 0/month, permanent, no credit card: 500 GB/mo data loading compute, 10 GB-hours query compute, 25 GB storage, 30-day retention, full APL access, all integrations; 3 datasets, 256 fields per dataset, 1 user, 3 monitors, US edge only
unit GB; metered on uploaded-bytes; 500 GB a month is both the free allowance and the maximum data loading on Personal. One GB-hour of query compute is roughly the cost of scanning 1 GB with moderate complexity. Axiom Cloud, the paid plan, is USD 25/month plus usage and includes 1,000 GB of loading, 100 GB-hours of query and 100 GB of storage.

Bindingvolume-quota 10 GB-hours of query compute is roughly 10 GB scanned a month, against 500 GB that can be loaded, so querying runs out long before ingest.
Identityemail The sign-in page creates an account on the first sign-in and e-mails a login link; the pricing page states Personal needs no credit card, and Axiom's Terraform page states that all a free account needs is an e-mail address. A public endpoint also creates a temporary organization with no sign-in: it is deleted with its data after 24 hours unless a person claims it, and claiming it creates an account when none exists.
EgressAll plans include unlimited bandwidth and API access, per the limits page; reading data back is paid in query compute, 10 GB-hours a month on Personal
Per-object cap1 MB per field, 200 bytes per field name, at most 10,000 events per ingest batch; 256 fields per dataset on Personal
RetentionMaximum data retention 30 days on Personal (30 days)
Interfacerest REST API with JSON bodies: ingest and query at the edge deployment's base domain (us-east-1.aws.edge.axiom.co for the US edge, the only edge Personal supports), every other endpoint at https://api.axiom.co, authorised with an API token or a personal access token. api.axiom.co answered 401 to /v2/datasets without a token. OpenTelemetry data is accepted as OTLP over HTTP at https://AXIOM_DOMAIN/v1/traces, /v1/logs and /v1/metrics, where AXIOM_DOMAIN is the base domain of the edge deployment; the metrics endpoint takes Protobuf or JSON.
endpoint: https://api.axiom.co

ReliabilityAn event that would exceed a dataset's field limit is rejected with an error; strings over the field size are replaced with a placeholder.
