Interfacerest, s3 REST at https://api.crossref.org (works, members, funders, journals; JSON; cursor paging); the annual public data file as gzip JSONL over BitTorrent (Academic Torrents, doi:10.13003/nggf-vt1j) or from the Requester Pays S3 bucket api-snapshots-reqpays-crossref with --request-payer requester; monthly snapshots at https://api.crossref.org/snapshots/monthly/ for Metadata Plus tokens only

Toolingcurl or any HTTP client for the API; a BitTorrent client for the public data file; aws s3api get-object --request-payer requester for the S3 copy, which needs an AWS account
Composes withThe annual public data file is the bulk path: the 2026 file holds nearly 180 million records in 208 GB of compressed JSONL across 35909 files, free over Academic Torrents; the REST API with update-date or index-date filters, rows=1000 and a cursor brings a copy current between releases.
ReliabilityOver the limit answers 429; a manual block answers 403 and is lifted through support. The public and polite limits were revised from 1 December 2025.

Monthly snapshots are a Metadata Plus benefit fetched with a Crossref-Plus-API-Token header; the free bulk path is the annual public data file over Academic Torrents. Without a token, a HEAD of the documented URL https://api.crossref.org/snapshots/monthly/latest/all.json.tar.gz answered 200 with a zero-byte text/html body on 2026-10-31.
Bindingrequest-rate One list call a second in the public pool, or 3 in the polite pool, each of at most 1000 rows, decides how many records a day the API yields; the annual public data file is the route to the whole registry.
Identityanonymous No signup or registration. An email address in the mailto parameter or the agent header selects the polite pool with higher limits; it is not a credential. Metadata Plus is an annual subscription that issues an API key.
EgressFree and unmetered. No key, no account, no allowance published.
free allowance: no byte allowance published
Per-object caprows maximum 1000 per call; rows=1000 with a five-field select returned 773,304 bytes in one response on 2026-10-31
RetentionA registered DOI cannot be fully deleted and its metadata can be updated, so a record is corrected rather than removed.
Interfacerest, cli GET https://api.crossref.org/works with rows, cursor and select; content negotiation for single records. The polite pool is signalled with mailto= or a User-Agent carrying an address.
endpoint: https://api.crossref.org/works
Toolingcurl/python-requests; the harvester package and the documented cursor pattern. No SDK required.
Composes withCrossref supplies the DOI-level citation graph and licence metadata; the full text behind each DOI is a separate fetch from the publisher or from an OA mirror such as PMC or Europe PMC.
ReliabilityOver the rate limit answers 429; a manual block answers 403 and is lifted through support. Without a Metadata Plus token the monthly snapshot URLs answer 200 with an empty or stub HTML body instead of an error, so a client must check the bytes it saves.
NotesMetadata only: bibliographic records with funding data, licence information, ORCID and ROR IDs and some abstracts, no full text. The record data-apis/crossref is the home of this offer and adds the annual public data file.
