RetentionA computer is disposable: state is ephemeral by default and a destroy tears it down. A snapshot is a durable checkpoint that survives destroy, a persistent volume keeps disk and paused memory across park and sleep but not destroy, and files that must outlive the sandbox are published to Files.
Interfacerest, cli A TypeScript SDK (@usenaive-sdk/managed-agents) and a CLI (naive computer create/exec/fs/snapshot/pause/delete) against the API base URL https://api.vetta.sh with an API key.

Notesnaïve sells a hosted disposable Linux microVM ('computer') as part of Naive Managed Agents, either provisioned by a session or created directly through the CLI or SDK. A session computer is 1 vCPU / 1 GiB at USD 0.0666 per running hour; the directly created default 2 vCPU / 4 GiB is USD 0.1656 an hour. Idle between turns costs nothing because the machine sleeps. The account starts with 5,000 free credits and no card; a card is required for the 7-day trial and any paid plan. The 12-hour lifetime cap and unenforced failsafes are the caveats.

A computer you create yourself is billed ahead in 10-minute blocks and needs a balance covering one block to create or resume; a session's computer is metered per running second. There is no count limit on computers, only the balance.
Bindingretention-clamped The 12-hour fixed lifetime with no override ends a long-running job whatever the balance, before the free credit or the per-call file cap is spent.
