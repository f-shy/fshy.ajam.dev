1024 MiB/file; 3-100 day retention driven by size; no accounts so no listing or bulk delete; deletion only by knowing the URL.
Bindingretention-clamped files are kept for at most 100 days (3 days minimum, shorter for larger files), so a stored set expires; the 1024 MiB per-file cap sets the object count
Identityanonymous no account: uploads are a plain HTTP POST (curl -F file=@...); the page documents no sign-in step
Egressfree direct HTTPS GET from x0.at, no redirect, no metering; Content-Length served correctly and range requests supported.
Per-object cap1024 MiB per file (1073741824 bytes)
RetentionRetention 3 to 100 days, scaled by file size via MIN_AGE + (MAX_AGE - MIN_AGE) * (1 - size/max_size)^2, so small files live ~100 days and near-max files ~3 days (100 days)
Interfacerest, rclone rest
Toolingplain curl multipart: curl -F file=@x https://x0.at/ (also -F keep_name=1, -F id_length=N). ShareX and Hupl configs published. Open-source server: github.com/Rouji/filehost2 (37 stars). No rclone backend.
Composes withAllows anonymous uploads up to 1 GiB each with generated identifiers. Chaining relies on indexing returned URLs. Retention duration is the binding constraint.
ReliabilityLongest-lived 0x0 derivative still accepting uploads. Provenance is a hobby VPS; no durability guarantee and expiry is silent and size-dependent. Treat as a 3-8 week cache tier, not archive.
Notes1024 MiB per file, no account, no per-account cap. Unlimited uploads. Retention 3 to 100 days, scaled by file size via MIN_AGE + (MAX_AGE - MIN_AGE) * (1 - size/max_size)^2, so small files live ~100 days and near-max files ~3 days.
