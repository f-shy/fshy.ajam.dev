Bindingretention-clamped Thirty days is a hard stop with no renewal in place, and the 1-hour VM shutdown means a VM cannot be a WireGuard node or an always-on monitor even inside that window.
Identityany-phone no card, no payment data, no national ID. A Red Hat account plus a validated phone number: 'We require a valid phone number to reduce the creation of fraudulent accounts'. The FAQ does not say which countries' numbers are accepted, and no country list is published on the page read.
Egressnot published: neither the overview, the FAQ nor the try-it page states a traffic allowance for the sandbox. Routes and services are exposed through the shared cluster's router, which is normal OpenShift ingress.
Per-object capone project per sandbox, on a pre-configured resource quota that 'cannot be changed'
Retention'Your Developer Sandbox is active for 30 days'. Work can be exported before the trial ends and imported into a fresh 30-day trial: 'you can export your work before one trial ends, and import it when you've started your next 30 day trial'.
Interfacerest, cli oc CLI over the cluster API with a login token, plus the OpenShift web console and OpenShift Dev Spaces (a browser VS Code). Pods are ordinary OpenShift workloads; Linux VMs are available through OpenShift Virtualization.
Toolingthe oc or kubectl CLI, or the web console; Dev Spaces needs only a browser
Composes withA real Kubernetes namespace with 14 GB of RAM to schedule against for 30 days, no card, which is the cheapest place to run a long-lived container or a small VM without owning a host.
Reliabilityno reliability event observed. Shared multi-tenant cluster, so a neighbour's load is a plausible cause of a slow pod; the vendor publishes no status page for the sandbox on the pages read.
NotesThe largest no-card machine quota documented: 14 GB of RAM against a real Kubernetes API for 30 days. Three caveats. First, the phone requirement is the identity cost and the FAQ gives no country list, so whether a non-Chinese, non-institutional number passes is unverified. Second, the 14 GB figure comes from podman-desktop.io rather than developers.redhat.com; the exact quota is readable only inside a live namespace with oc describe quota. Third, the 1-hour VM shutdown makes OpenShift Virtualization useless for an always-on node even though it is advertised. A separate OpenShift Dedicated trial exists on the same page at 60 days, but it provisions into a Google Cloud account the applicant owns, which brings its own card question and was not pursued.
Evidence notedocumented The 30-day term, the no-card statement, the phone requirement and the 12-hour/1-hour workload reaps are quoted from Red Hat's own FAQ read. The 14 GB RAM and 40 GB storage quota is from podman-desktop.io, a Red Hat-adjacent documentation site, not from a page on developers.redhat.com, so it is reported rather than documented.
