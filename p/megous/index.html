Limits
  • per-ip-shaping (binding) MEGA counts downloads from the IP over six hours; no fixed number published source
MEGA's help page lists third-party tools as a hazard: 'these tools can't detect your quota', and using them with account credentials can lock the account. Public-link download avoids the credential risk.
Bindingper-ip-shaping The six-hour per-IP window is the only quota in the path; megatools does not rotate proxies, so it is met directly and the reset must be waited for.
Identityanonymous 'megatools dl' takes a public link and needs no login. Account subcommands exist for private files but are not required for the public-link path.
EgressMEGA's IP-based six-hour transfer window applies to the machine running megatools; there is no megatools-side quota or proxy rotation.
free allowance: dynamic, IP-based, six-hour window
Per-object capnot applicable: MEGA states it has no file size limit; the local disk is the cap.
Retentionnot applicable: writes to local disk; no service-side storage.
Interfacecli Subcommands: df, ls, get, put, copy, rm, mkdir, export, reg, test and 'dl' for public links. Streaming is supported with '--path -', so a wrapper can pipe a public link into another process without touching disk.
ToolingNative builds for Windows and Linux, plus source. A shell wrapper is enough; nothing needs a GUI or a display.
Composes withThe streaming flag makes it the cheapest MEGA leg for a pipeline that must not stage the file on local disk: piped output can go straight into an uploader or a hash check.
ReliabilityThe project site was 503 today and the man page had to be read from a mirror; the tool is maintained but the distribution site is not always up. Over-quota downloads fail mid-transfer and resume after the window resets.
NotesCommand-line suite providing native streaming access to MEGA links without requiring a browser.
