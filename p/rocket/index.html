EgressYour own infrastructure. Cloud-hosted workspaces have a storage limit visible in the admin panel, but self-managed does not.
Interfaces3, rest, webdav rest
ToolingRocket.Chat REST API POST /api/v1/rooms.media/{rid} + rooms.mediaConfirm. Storage backends: GridFS (MongoDB, default), AmazonS3/MinIO, Google Cloud Storage, WebDAV, FileSystem. The WebDAV and S3 backends make it pluggable into anything.
Composes withN workspaces x unlimited rooms. The WebDAV backend is the interesting bit: it turns Rocket.Chat into a front-end over any WebDAV store, so it chains rather than multiplies.
ReliabilitySolid; the default GridFS backend stores blobs inside MongoDB, which is a poor choice at TB scale (the docs themselves recommend S3/MinIO). Files can be JWT-protected or public per workspace setting.
