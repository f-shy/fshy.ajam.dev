Apple Silicon only; desktop images are limited to Debian 13, Ubuntu 24.04 LTS and Kali rolling. USB passthrough and Intel host releases are unavailable, and custom ARM64 guest images are preview. The agent sandbox is policy-enforced with allowlisted egress and a daemon TTL.
Bindingwrite-gated The offer is software the user installs on their own Mac, so there is no hosted quota, rate or retention clock to bind; the requirement to install it is the gate.
Identityanonymous No account is required: the site states 'No account. No telemetry. No required cloud. GPL-3.0.' and '0 accounts, telemetry, paid tiers'. Signing in is not an option because there is no vendor-hosted service. The user supplies their own Apple Silicon Mac and local disk.
Egressnot applicable: the software runs on a machine the user supplies, so Dory meters no traffic and publishes no egress price or allowance
Per-object capnot applicable: the unit is a local virtual machine, not a stored object; a managed .dorydrive grows from 128 GiB to 2 TiB and a machine disk is thin-provisioned at 64 GiB
RetentionLocal Linux machines have their own disks and snapshots in the user's .dorydrive, preserved across normal uninstall; retention is set by the user, not by a vendor clock.
Interfacecli, unknown A versioned local JSON contract over stdio, an MCP server implementing protocol 2025-11-25, stable non-interactive CLI schemas and a Docker API context; sandbox VMs are driven by dory sandbox run, not by a public hosted endpoint.
Toolingthe user installs the signed Docker Core macOS app, then optional signed components for Kubernetes, headless Linux and desktop VMs; the user runs the app on their own Apple Silicon Mac and uses the dory CLI or MCP server, with no vendor-run capacity.
Composes withA policy-enforced Linux VM per agent run with read-only mounts, allowlisted egress, resource caps, rollback and TTL cleanup can replace a hosted sandbox only where the user already has an Apple Silicon Mac; a hosted sandbox record ranks ahead of it.
ReliabilityCapability support is labelled supported, preview or unavailable; the agent sandbox and custom guest images are preview, USB passthrough and Intel hosts unavailable, and signed updates keep a last-good snapshot for automatic rollback. No hosted service reliability event exists.
NotesDory is not hosted compute capacity: it is software the user installs and runs on an Apple Silicon Mac. The $0.029 an hour in the operator list has no source on any Dory page. It is the last-resort option: every hosted sandbox of the other providers in this topic ranks ahead of it.
