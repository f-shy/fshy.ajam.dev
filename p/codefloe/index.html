ToolingFull Forgejo API v1 (packages, generic, OCI registry, releases, LFS) + rclone's Gitea/Forgejo-compatible WebDAV-free REST via any HTTP client; OCI via ORAS/skopeo; package registry speaks Generic/Docker/npm/PyPI etc.
Composes withUnlimited free accounts -> 5+20+10+10 = 45 GB of separately-metered pools per identity. Because packages (20 GB) and LFS (10 GB) are separate pools from Git (5 GB), one account yields ~45 GB across four subjects, and each further account carries the same 45 GB. Registry blobs are anonymous-pullable, so shard across repos like any OCI store.
ReliabilitySingle small operator on one Hetzner box; nightly off-site backups with 90-day retention described as disaster recovery, not per-account restore. Explicit published policy of monitoring several accounts used to exceed its quota and deleting/suspending. The chaining path is actively watched, unlike GitLab's.
