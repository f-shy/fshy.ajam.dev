ToolingUpload via Central Portal archive upload (zip/tar.gz up to 1 GB following Maven repo layout) or the maven-deploy-plugin; download via plain GET on repo1.maven.org/maven2/<group>/<artifact>/<version>/<file>. Every Java build tool is a client. No rclone backend.
Composes withWeakest chain in the field because the new quota is per organization per month: 78 MB/month at the p90 threshold means a new org yields ~78 MB/month of headroom. Unlimited free orgs would multiply it, but each org requires a verified namespace and a GPG-signed artefact chain, so the setup cost per GB is the worst here.
ReliabilityData never vanishes (already-published artefacts are explicitly exempt from any enforcement). The failure mode is publishing stopping after the grace period. A bulk writer will hit the release-size threshold in the first month and be blocked. This quota regime is new (2026) and the page says thresholds 'may be adjusted as we learn'.
