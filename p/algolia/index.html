EgressSearch requests are the meter, not bytes. 10,000 search requests/month is ~333/day. The most op-limited of the storage providers compared.
Interfacerest, cli rest
ToolingREST API, official SDKs for ~15 languages, algolia CLI, InstantSearch widgets; records are JSON only
Composes with50K records x ~10 KB average = ~500 MB of usable payload per app. Several free apps would need several accounts. Record-size guidance is 'Avg 10KB/Record max 100KB', so the absolute ceiling is 50K x 100 KB = 5 GB, and that requires exceeding the size guidance.
ReliabilityExtremely reliable CDN-backed search, but it is a search index, not a store: records are tokenized and stored in an inverted index, so storing base64 blobs both inflates size ~33% and destroys index performance. Not usable as blob storage in practice.
