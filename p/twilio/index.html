Trial messaging is restricted to verified recipients (up to 5 per account) and to the sign-up country, and requires Twilio-provided message templates.
unit mixed; metered on request-count; Every SMS or WhatsApp message deducts one free unit; a verification over SMS deducts one SMS unit and one verification unit. Bindingvolume-quota The 100-message, 5-recipient, 30-day trial quota ends free use before the 5MB media cap or the 50-per-day rate is reached; the offer is a trial, not a recurring free tier.
Identityany-phone Sign-up asks for an email address and a personal phone number, both verified, plus information about the project. The sign-up text states: 'Verify your email address.' and 'Verify your personal phone number.' A free trial account needs no credit card. Trial sending is limited to verified recipients and the sign-up country. The identity needed for a paid account that sends A2P messaging, including adding funds and payment details and carrier registration, is unverified: behind a sign-up.
EgressNot a byte-egress offer: messages are sent and read back through the Programmable Messaging REST API and webhooks. Outbound SMS is billed per segment, starting at USD 0.0083 per outbound or inbound segment on a long code (pricing current as of November 2026); no bandwidth egress quota is stated.
free allowance: 100 free SMS messages in the 30-day trial
Per-object capAn MMS message carries up to 10 media files with a total size of up to 5MB; Twilio rejects messages with over 5MB of media.
RetentionMessage bodies and records are kept until the customer requests removal with an HTTP DELETE. Message Logs and the Messages API show records for up to 13 months (400 days) by default, configurable from 7 to 400 days. Records older than 13 months remain accessible through Bulk Export, while MMS media older than 13 months is permanently deleted. Bodies may persist up to 30 days in backups after a DELETE. (400 days)
Interfacerest The Programmable Messaging REST API serves SMS, MMS, RCS and WhatsApp. The API base URL is https://api.twilio.com/2010-04-01 and authentication is HTTP Basic with the API key SID as username and API key secret as password. A separate base URL serves Messaging Services. The Twilio Console and the Message Logs expose the same records.
endpoint: https://api.twilio.com/2010-04-01
ToolingThe hosted API is reached with the Twilio SDKs (twilio-node, twilio-python and others), with curl against the REST API, or from the Twilio Console. No software the user installs and runs is required: the messaging service is hosted by the vendor. This is a hosted service, not a self-hosted offer.
Composes withSend and receive SMS, MMS, RCS and WhatsApp from an application with delivery-status callbacks, inbound webhooks and message scheduling; combine with Messaging Services and other Twilio products. Hosted service only.
ReliabilityTrial messages carry a 'Sent from a Twilio Trial account' prefix and trial numbers are shared Twilio-owned numbers that cannot be kept after upgrade. An unused trial number may be removed after 60 days. Message bodies may persist up to 30 days in database backups after an HTTP DELETE request.
NotesFirst-party pages disagree on the trial SMS allocation and daily cap: the trials table and trial tutorial state 100 SMS messages, a plan help article states 150 messages with a 10-per-day cap, and the trial-restrictions article states a 50-per-day maximum. The trials table is used as the headline value. This offer is a 30-day trial of a hosted messaging API, not a recurring free tier and not self-hosted software.
