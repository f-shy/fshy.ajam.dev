Interfacerest, rsync, cli GET https://api.itch.io/wharf/latest This endpoint does not require authentication.
Toolingbutler CLI (butler push / butler download / butler status) plus the Wharf HTTP API. GET https://api.itch.io/wharf/latest?target=user/game&channel_name=X returns the build manifest. butler does rsync-style block diffing so re-pushes are cheap.
Composes withPushing to a new channel will make a corresponding file appear on your game's page
ReliabilityPushing the same directory twice is a no-op, so versions accumulate as distinct builds rather than overwriting; butler auth uses an API key, and a project can be taken down by moderation (technical effect: URL 404s, data gone).
Notes30 GB uncompressed per build ('the itch.io backend will reject builds with a total uncompressed size that exceeds 30GB'). No documented total-account storage cap; project pages have a soft limit of 20, raisable on request. Free to host, unlimited downloads.
