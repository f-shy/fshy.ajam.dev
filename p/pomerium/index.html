EgressNo byte cap, bandwidth cap or traffic meter is published on the pricing page, the reverse-tunneling page or the native SSH page. Traffic does not pass through the vendor: the data plane runs on a host the user supplies, and the vendor states 'there are no ingress or egress costs'. Interfacessh, cli an OpenSSH client run as ssh -R 0 HOST registers as the upstream of an HTTP or SSH route (runtime flag ssh_upstream_tunnel); pomerium-cli carries TCP routes
Toolingthe user installs and runs the Pomerium Core data plane on a rented or free machine with a public address; the hosted Zero Console configures it; clients use a stock OpenSSH client
Composes withThe hosted Zero control plane and starter domain come first; the byte-carrying data plane is software the user installs and runs on a rented or free machine, so a public reader reaches the tunnel only through a host the user supplies, last in any chain.
Reliabilitythe reverse-tunneling mode is opt-in behind the ssh_upstream_tunnel runtime flag, and an HTTP route times out an upstream request after 30 s by default
NotesFails as a public ingress because no hosted relay exists: every plan runs the data plane on the user's host, and Zero Personal manages only the control plane (configuration, policies, starter domain, certificates). The first paid plan is Zero Business at $9 per user per month billed monthly or $7 billed annually (100 routes, 5 clusters, 20 administrators). The reverse tunnel carries HTTP and SSH routes, not UDP. Pomerium Enterprise has a self-hosted control plane at a custom price.
