Bindingrequest-rate there is no counted quota, so the 1 request per second ceiling, and 4 per minute for a long-running script, is the whole capacity
Identityanonymous no account and no key; each request carries a valid HTTP Referer or a User-Agent that identifies the application, since stock library User-Agents are refused by the policy
Egressnot applicable: a query API, not metered in bytes
Per-object capone query per request, returning at most 40 results
Interfacerest HTTPS GET to nominatim.openstreetmap.org/search (and /reverse, /lookup) with format=json, jsonv2, geojson, geocodejson or xml; no key; a valid HTTP Referer or an application User-Agent is required; without a format parameter the public instance answers with the web page
endpoint: https://nominatim.openstreetmap.org/search
Toolingany HTTP client that sets an identifying User-Agent or Referer; the policy asks apps to go through a caching proxy
Composes witha keyless geocoder for low-volume, user-triggered lookups at 1 request a second; a stored data set of more than a few thousand addresses goes to a keyed provider with storable results (data-apis/geoapify, data-apis/opencage, data-apis/maptiler). Bulk path: no bulk geocoding (systematic queries are banned); the raw data is the weekly OSM planet file (89 GB PBF) or a regional extract. The last resort is self-hosted: the Nominatim software, which the user installs and runs on a rented machine with an imported planet or extract
Reliabilitya requester that sends the same query repeatedly may be classed as faulty and blocked, a banned use (auto-complete, systematic queries, scraping of the details page) leads to a ban, and access can be withdrawn when the definition of heavy use changes
NotesThe hosted public instance of the Nominatim software. Bulk path: no bulk geocoding on the public instance; the raw data is the weekly OSM planet file or an extract.
