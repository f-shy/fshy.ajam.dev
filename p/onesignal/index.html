Free tierFree plan at USD 0/mo with all channels: unlimited mobile push notifications, in-app messaging and Live Activities sessions for organizations with up to 1,000 monthly active users, web push to at most 10,000 subscribers per send, 10,000 email sends per month, 3 active Journeys, 6 audience segments and 6 data tags, and unlimited contacts and API send access.
unit mixed; metered on identity-count; The Free offer has no single unit: mobile push is denominated in monthly active users (MAU), web push in subscribers per send, and email in sends per month. The nearest unit term is mixed. The binding count is organization-wide MAU, a trailing 30-day count of mobile subscription records with at least one session. The 1,000 MAU Free limit takes effect for new customers on 2026-09-01 and existing customers on 2026-10-01.
Pricenone stated
Limits
  • volume-quota (binding) fewer than 1,000 monthly active users organization-wide on Free for mobile push and in-app messaging, counted over a trailing 30-day period source
  • volume-quota (binding) web push to at most 10,000 subscribers per send on Free source
  • volume-quota (binding) 10,000 email sends per month on Free source
  • volume-quota (binding) Event Streams on Free: 1 active stream and up to 1,000 events per month source
  • request-rate Create Message and Cancel message: 150 requests/sec/app on Free, 6,000 requests/sec/app on paid plans source
  • request-rate Create, update or delete users or subscriptions: 1,000 requests/sec/app and 1 request/sec per user or subscription source
  • write-gated application message limit: at most 10 times the number of subscribed Subscriptions delivered in a rolling 15-minute window, after which the app is temporarily disabled source
  • retention-clamped Free plan drops User and Subscription records inactive for more than 18 months and keeps reporting history 30 days source
The channel caps are audience counts (MAU, subscribers per send) rather than byte volumes, so they are filed under volume-quota, the nearest term. The rolling 15-minute application message limit is an app-disable gate filed as write-gated; the schema has no dedicated kind for a burst-disable threshold. API 429 errors throttle requests but never disable an app.
Bindingvolume-quota The organization-wide 1,000 MAU ceiling is the first threshold a growing mobile push audience meets; crossing it pauses mobile push and in-app messages after a 24-hour upgrade window while web push and email continue under their own caps.
Identityemail First-party account docs state: when you sign up at OneSignal.com, a user account is created and tied to your email address, and your email address is used to log in. The Free plan starts with a Get Started link and no card term is stated on the pricing page. The signup page at dashboard.onesignal.com/signup is a JavaScript application whose captured HTML has an empty root element, so no form fields were visible and unverified whether a card or phone is asked at signup (behind a sign-up).
Egressnot applicable as a byte allowance: OneSignal is an outbound messaging service and the pricing and billing pages state no per-GB egress price. Outbound delivery events (Event Streams and webhooks) are metered by event count, not bytes: Free allows 1 active Event Stream and up to 1,000 events per month.
Per-object capunverified: no single per-message payload cap is stated on the pages read; the Create custom events endpoint limits a request body to 1 MB and each event to 2,024 bytes
RetentionFree plan retains only User and Subscription records active in the last 18 months; dormant records may be removed. Dashboard reporting data is kept 30 days on Free, session events 7 days, and audit logs 48 hours. Message event retention starts at Growth (30 days) and is not offered on Free.
Interfacerest REST API over HTTPS with TLS 1.2 or higher on port 443 at api.onesignal.com. It creates messages, users, subscriptions, segments, Journeys and templates, and exports data as CSV. Requests authenticate with an App or Organization API key; the default response timeout is 100 seconds and exceeding a rate limit returns HTTP 429 with a Retry-After header.
endpoint: https://api.onesignal.com
ToolingThe REST API with an App API key from Keys & IDs, callable with any HTTPS client, together with the vendor's mobile and web SDKs that register device subscriptions. The OpenAPI specification for the API is published by the vendor.
Composes withA worker on a hosted compute service posts to POST /notifications to reach up to 1,000 organization MAU by mobile push or web push to at most 10,000 subscribers per send, and Event Streams or webhooks forward delivery events to an external destination.
ReliabilityAbove 1,000 MAU, mobile push and in-app messages stop sending until upgrade; the organization is re-enabled 30 days after deleting active mobile subscriptions and staying under the cap. An app is temporarily disabled when delivered messages exceed 10 times its subscription count in a rolling 15-minute window. Self-serve accounts are disabled after three failed payment attempts.
NotesOneSignal is a hosted messaging service and no self-hosted lane is documented, so self_hosted is left absent. The 1,000 MAU Free limit applies organization-wide across all apps and took effect for new customers on 2026-09-01 and existing customers on 2026-10-01; MAU counts mobile subscription records active in a trailing 30 days even without push opt-in. Mobile push, web push and email are metered separately and should be costed as separate lines. The signup page fields are unverified because the form is rendered by JavaScript.
