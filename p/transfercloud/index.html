Interfacerest web UI plus OAuth connections to 25+ cloud destinations; native FTP/SFTP/WebDAV pulls are also supported. No public API is documented on the page read.

Reliabilitythe service inherits every failure of the destination cloud's OAuth and quota, and a 1.5 GB free cap means large torrents are impossible without paying.
