Shared ASN ($300/yr) and Dedicated ASN Rental ($700/yr) deploy instantly without those documents, and either one originates a prefix rented from IPYE ('If you rent IPs from us and a Dedicated or Shared ASN from us, everything connects natively.').
- binding note: write-gated binds first: the free /48 cannot be announced until an origin ASN exists ('Announcing the prefix needs an origin ASN. Use one you already operate, or add a shared or dedicated ASN from IPYE.'). The prefix carries no traffic allowance of its own, so no byte quota applies to it.
- interface detail: Ordering is a web checkout: my.ipye.com/products/ipv6-rental/48-ipv6/checkout requires ASN(s), Region and Intended Use, takes Name Servers for rDNS as optional, and shows an order summary of Total today: $0.00. No endpoint for ordering or for prefix management is documented; the vendor's API covers reverse DNS and geolocation. The prefix itself is reached by announcing it over BGP from the lessee's own routing daemon, a network interface with no token in the interface vocabulary.
- tooling: A BGP routing daemon on the host that originates the prefix, and a Letter of Authorization from the portal ('Generate Letters of Authorization securely on demand.'). Ordering is a web form and the portal is the management surface, so no wrapper is needed. The one programmatic path is the rDNS and GeoIP API, behind an account: 'Take absolute control via our API and dashboard. Manage Reverse DNS zones, push bulk PTR record updates, and intuitively control WHOIS location configurations instantly.'
- composes with: Announce the free /48 under an origin ASN from compute the user runs, and every request leaving that host presents an address inside one /48 of 65,536 /64s. That is one prefix behind one origin ASN: it meets a gate that counts the /64 and not a gate that counts the ASN.
- reliability: One prefix is one network: every address in the free /48 is announced by the same origin ASN, so a gate counting the ASN or the prefix sees one source however many addresses are used. 'We don't shut down your servers for typical bulk operations' is a vendor statement with no measurement behind it. /use-cases says 'We lease prefixes registered to eyeball broadband networks and assign them to your compute hardware' of its ISP Network Subnets; whether the free /48 is registered that way is unverified.
- notes: The free /48 is a prefix from IPYE at a fixed size and price: $0, 65,536 /64s, deployed immediately, with the same automatic RPKI ROA and route object as the paid sizes, and unannounced until an origin ASN carries it. /ipv6-rental makes no registration-class claim for it. The page separates it from IP Lease, a catalog of listed ranges that includes IPv6 /36 blocks other holders are selling, and from the IPv6 proxy servers on the server bundles page, machines with a prefix already routed to them. Its FAQ answers 'Can I use these for proxies?' with yes and says the page is the prefix alone.
