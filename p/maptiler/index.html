endpoint: https://api.maptiler.com/geocoding/{query}.json
Toolingany HTTP client; the MapTiler Client JS library (geocoding.batch) and the MapTiler SDK JS geocoding control, which is metered in sessions rather than requests
Composes with100,000 storable geocodes a month with no card, shared with map tile requests, so a stored table of up to that many addresses a month can be built through batch calls of 50; past the limit the Free plan stops for the rest of the month, and more is Flex at USD 30 a month or the Geoapify free plan (data-apis/geoapify). Bulk path: the batch endpoint only; no hosted geocoding data download. The last resort is self-hosted: the On-prem Free tile download (OpenStreetMap vectors of 2020) that the user installs and runs with MapTiler Server, tiles only, with no geocoder
