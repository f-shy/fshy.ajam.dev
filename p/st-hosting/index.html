Interfacessh Root shell in an unprivileged LXC container, reached over the IPv6 address. A web control panel at cp.st-hosting.com handles reinstall, rDNS and credit top-up. Delivery is stated at 60 seconds.
Toolingany SSH client; the vendor's own panel for reinstall and rDNS. No API is documented.

NotesThe order link on the product card is an addToCart POST target; fetched as a GET it returns the vendor's empty cart page rather than an error, so the cart URL is recorded but the cart contents could not be read without adding an item, which this category does not do. The Monthly/Annually toggle exists and the annual rate was not captured; only the monthly figure is claimed. Whether the container can be reached over IPv4 through some proxy was not established - the vendor says no, and the LowEndTalk post repeats that an IPv4 address cannot be added to these plans. The IPv6 address count is one per server, with more on request, which is enough for a tunnel endpoint but not for a routed prefix.
