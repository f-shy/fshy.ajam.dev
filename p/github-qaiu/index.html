Bindingwrite-gated The resolver is free and fast and stores nothing, so what binds is the auth table: the pans most in demand, including Baidu, Quark and UC, need a cookie or sit behind the paid professional endpoint.
Identityanonymous the hosted instance is keyless. Self-hosting needs a VPS and no account with any pan
EgressFree. It issues a 302 to the real CDN origin, so the bytes never traverse the resolver and you download straight from the pan's own CDN
Per-object capNot applicable, it stores nothing. What it resolves inherits the upstream per-file cap
RetentionNot applicable; the server caches a resolved link for a per-pan time in minutes set in its configuration (shipped values: 5 for ecpan, 20 for feijipan, 30 for lanzou), and a pan with no entry is not cached
Interfacerest
Toolinghosted instances first: GET https://lz.qaiu.top/parser?url=<encoded share>&pwd=<code> returns a 302 to the pan's CDN, also on the mirror lz0.qaiu.top. Last resort: the user installs and runs the open-source server (a release archive on Java 17 or later, or the Docker image) on a rented or free machine, with the API on port 6400 and the web tool on port 6401; JavaScript and Java parser plugins extend it
Composes withResolve a share link with a hosted instance first (lz.qaiu.top, mirror lz0.qaiu.top), then fetch the returned direct URL with a plain ranged GET. A server the user installs and runs is the last resort; a pan that blocks datacentre addresses, such as feijipan for mainland ranges, is reached through a proxy set in its configuration
ReliabilityIndividual parsers break whenever a provider changes its markup. The project is actively maintained, so pinning a version and watching the README changelog is the operational answer. The README warns that feijipan blocks mainland datacentre IPs and that the public instance should not be depended on
NotesNot storage and recorded as such: it is the fetch path for other people's storage. Two endpoints exist and the split is the finding: lz.qaiu.top is free and covers lanzou, ilanzou, ctfile, wenshushu, feijipan and ecpan, while 189.qaiu.top needs an API key and adds Baidu, Xunlei, Quark, UC, 139, 189 and Unicom. The program can also be self-hosted (the docker span), and lz.qaiu.top is a free public instance.
