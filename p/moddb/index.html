Per-object cap is verified at 8,442,728,905 bytes on published files, with approximately 8 GB observed in practice. Retention is indefinite for hosted files. Uploads require web forms and endpoints enforce browser verification headers.
Identitycountry-phone (inferred, not read) not published
EgressFree, no billing, and the site is Cloudflare-fronted (Server: cloudflare on the live origin). Files are served from the site itself rather than a separate CDN hostname; the mirror endpoint (/downloads/mirror/<id>/<n>/<hash>) is the byte path and is behind the same edge.

Retentionper-object-cap: verified at least 8,442,728,905 bytes on a live file listing; the widely-cited 8192 MB figure is third-party (TWC wiki, marked TBC by its own author) and is contradicted by the 7.86 GB file, so treat ~8 GB as observed-not-documented. retention: indefinite; files stay downloadable for years
Interfacerest, sftp rest
ToolingNo upload API and no SFTP: the write path is the web 'Add File' form at /downloads/add, gated to logged-in members. Read side is plain anonymous HTTP GET from /downloads/mirror/..., plus an MD5 hash published on each file page.
Composes withOne account x unlimited game/mod profiles x unlimited files per profile. Because the unit is a mod page, not a repo, cardinality is bounded only by how many plausible mod entries you create. 8.44 GB verified per file x N files.
