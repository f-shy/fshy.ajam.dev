ToolingPip install openxlab, then first-party subcommands: openxlab dataset upload-file, openxlab dataset upload-folder, openxlab model upload .. with --dataset-repo/--source-path/--target-path. Python SDK mirrors the CLI (upload_file / upload_folder). Also git+LFS. Real, named, documented client. This passes the tooling filter cleanly.
Composes withRepos are per-user and per-org and free to create, so capacity is N repos. OpenXLab is the Shanghai AI Lab's public front door (InternLM, OpenDataLab datasets), so its per-repo sizes are already in the tens-of-GB range. Multiplying across accounts is easy but the per-account ceiling is unknown.
