Per-object-cap: 10 GB per file. 'Individual files larger than 10 GB will not replicate out to our mirrors and can not be downloaded', so the only way past it is to shard. Request-rate: none published; upload is plain SFTP so it is limited by SSH session count, not an API quota. Retention: none. 'Users are responsible for backing up all of their files. SourceForge.net will not restore individual files', and releases persist indefinitely (OpenOffice's mirror alone carries 166.4 MB files from 2015). Reliability: signed mirror redirects are short-lived (see reliability_note).

Interfacesftp, scp, rsync, rclone part of the text of Limits, above
ToolingNative SFTP, SCP, and rsync protocols are supported with documentation on the file release system page. Integrates with rclone via its native SFTP backend, and connects directly to restic, borg, or rsync. TCP port 22 to frs.sourceforge.net is open.
Composes withOne account, many projects. Each project gets an independent tree at /home/frs/project/<unixname>/ and its own mirror distribution; one project admin can hold release-technician rights on many projects. Chained: (20-30 GB practical per project) x (N projects per account) x (N accounts). At 20 projects that is already 400-600 GB; the 10 GB/file mirror limit forces sharding, which is free because FRS is directory-based. Second chain: the same upload endpoint feeds project web space at /home/project-web/<unixname>/htdocs served as <unixname>.sourceforge.io, which is a separate quota-less static origin.
ReliabilityTwo real hazards found by probing. (1) The signed mirror URL from downloads.sourceforge.net 301s to a per-mirror host with an expiring token; You must re-resolve the redirect per session, or the mirror silently returns HTML. (2) There is no hard cap, which means the cap is discretionary — SourceForge mails 'over-quota' notices (the 2006 Inkscape notice shows a 100 MB soft quota on the shell/group dir) and can contact projects using 'significant storage'. Treat it as a soft ceiling that a human can raise or lower.
