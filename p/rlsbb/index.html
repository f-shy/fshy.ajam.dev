Bindingrequest-rate Crawl-delay 10 is the only published request interval among debrid providers, and it is 0.1 req/s, far below what 1 TiB per month pull needs; it is the constraint met first here.
Identityanonymous No account to read the feed or a post. The site pushes registration only for the host accounts it advertises (rapidgator, uploady).
EgressNo byte allowance. The post links uploady.io, nitroflare.com and rapidgator.net for each release, plus a limetorrents search for the same release name.
free allowance: none published
Per-object capnot applicable: an index
RetentionPosts persist. The feed carries the 50 most recent items.
Interfacerest RSS 2.0 at /feed/ (text/xml, 50 items with title, link, dc:creator, pubDate and category). A search portal at search.rlsbb.ru has a 'light' mode that returns titles only.
endpoint: https://rlsbb.cc/feed/
ToolingRSS reader. Each post body is one line of host links, so extraction is a regex over the host URLs plus the protected.to nfo and subtitle links.
Composes withFeed to post to a rapidgator, nitroflare or uploady link for the debrid service; the same post also links a limetorrents search, which gives the torrent path for the identical release.
ReliabilityDomain rotation is the normal failure: the home page title reads 'UK users use .in domain or use VPN' and .cc, .in, .to and .ru all appear on the page. Host link sets change with the affiliate arrangement.
NotesThe only index in the sector that publishes a request interval. Documented as a technical constraint, not a judgement about use.
