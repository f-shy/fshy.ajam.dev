Limits
  • request-rate (binding) 10 per window for the anonymous tier, returned in-band as x-ratelimit-limit: 10 with a reset stamp 42 to 60 s ahead of the request
The llms.txt says limits are per endpoint and IP-based for anonymous traffic, key-based for authenticated traffic, and that a 429 carries Retry-After. The free key raises the quota and is what unlocks magnets.
Bindingrequest-rate Ten requests per window is the hardest published number among debrid providers; at one search per title 1 TiB per month pull exhausts it on every batch, so the key is not optional in practice.
Identityemail A free key is required before magnets, info hashes or .torrent downloads are returned: the response itself carries '_notice: Magnet links, info hashes, and torrent downloads require a free API key. Register at https://torrentclaw.com/register'.
Egressno byte allowance on the API;.torrent files are proxied through cache services, and the swarm transfer is the user's
free allowance: none published

Retentionnot applicable to the caller: results are computed per request; the tracker's own stats are published at /api/v1/tracker-stats
Interfacerest /api/v1/search, /api/v1/torrent/{infoHash}, /api/rss/{popular,recent,search}, /api/v1/torznab (Newznab/Torznab) and /api/stremio/manifest.json. An OpenAPI 3.1 spec sits at /api/openapi.json.
endpoint: https://torrentclaw.com/api/v1/search?q=ubuntu&limit=3
Toolingcurl or any HTTP client; Sonarr/Radarr take the Torznab URL with a key; an MCP server is published as an npm package.
Composes withSearch for a title, take the hash with a key, ask the debrid provider for a cache hit, and let the Torznab endpoint serve the automation stack.
ReliabilityThe anonymous payload is metadata only, so a client that ignores the notice will spend its quota collecting rows it cannot act on; the aggregator also depends on the upstreams it names (YTS, EZTV, Knaben, Prowlarr, Bitmagnet, Torrentio, Torrents.csv and others).
NotesThe only index among debrid providers that publishes its anonymous quota in the response headers, which makes it the honest answer to 'what is the rate limit': 10 per window, and the object itself needs a free key. The caveat is precisely that split.
Evidence notedocumented Three live searches were executed on 2026-10-23 and the rate headers read on each; the docs were read from llms.txt and llms-full.txt. Registering for a key confirms the free tier's real quota.
