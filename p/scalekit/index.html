unit users; metered on identity-count; A user counts as a MAU if they log in or sign up at least once in a billing month. An organization counts as a MAO if it has at least 2 users and at least 1 of them logs in during a billing month. Development, QA, UAT and Staging environments are free and their usage does not count toward production quotas. The separate AgentKit Agent Gateway plan has different limits (5 users, 10,000 tool calls, 5 MCP connectors, 7-day audit log retention), which are not this tier.

Interfacerest A REST API (OpenAPI 3.1.1, API version 1.0.0) covering AgentKit and SaaSKit. All requests use HTTPS with base URLs https://{your-subdomain}.scalekit.dev for development and https://{your-subdomain}.scalekit.com for production. Authentication uses OAuth 2.0 Client Credentials: POST to /oauth/token with client_id, client_secret and grant_type=client_credentials to get a token sent as a bearer credential. Resources include organizations, users, SSO, directory sync, RBAC and sessions.
endpoint: https://{your-subdomain}.scalekit.com
ToolingScalekit SDKs and hosted auth widgets, the npx @scalekit-inc/cli setup tool, or any HTTP client against the REST API with an OAuth client credentials token.
Composes withLogin and user store for a web app; SSO and SCIM add-ons integrate a customer's existing identity provider, and the modular BYOA tier adds SSO or SCIM on top of an in-house auth system.
