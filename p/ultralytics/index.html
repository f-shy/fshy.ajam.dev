100 GB total storage; individual file limits Images 50 MB, Videos 1 GB, dataset archives 10 GB on Free. That 50 MB image cap is the real killer for bulk image corpora, and the 1 GB video cap kills video datasets outright.
Identityemail email (Google/GitHub OAuth available).
EgressNot metered. Storage is the only billed dimension, and models/datasets download without a per-GB charge. No egress line on the pricing page.
Per-object cap20 GB per upload (20000000000 bytes)
Interfacerest, cli rest
ToolingThe ultralytics Python package itself (YOLO) is the client: model.train(data=..., project=...) pushes datasets and weights to the platform; there is also a documented REST API and CLI. Extremely well maintained (the YOLO package is one of the most-installed ML packages).
Composes withUnlimited datasets × but 100 GB account total, so dataset count does not add bytes. The only multiplier is N accounts. Note the asymmetry: 'You can upload unlimited datasets across all plans .. There's no cap on the number of datasets themselves, only on total storage'. So the cap is total, cleanly.
ReliabilityStable commercial vendor with a huge user base. Data is tied to the training platform, so it is a walled garden rather than a general-purpose store. But downloads of your own artifacts are not paywalled.
