Free tierA model whose ID ends in :free is free: requests cost nothing and work with any balance. The Free tier allows 5 requests per minute, 150 per hour, 500,000 uncached input tokens per hour, 100,000 output tokens per hour, 3,000,000 input tokens per day and 1,000,000 output tokens per day. Every request to a free model is collected for data handling.
