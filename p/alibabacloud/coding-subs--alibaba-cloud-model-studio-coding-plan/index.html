Supported models: qwen3.7-plus, qwen3.6-plus, kimi-k2.5, glm-5 and MiniMax-M2.5, and also qwen3.5-plus; models not on the list are not supported. The plan supports the Chat Completions and Messages protocols and not the Responses API. The vendor FAQ states the plan works inside programming tools and not from curl, Postman or Dify
endpoint: https://coding-intl.dashscope.aliyuncs.com/v1
Toolingthe clients that the vendor documents with plan base URLs: Claude Code, Qwen Code, Cursor and OpenClaw among others; the user sets the plan key and the plan base URL in the client
Composes withthe plan key replaces the pay-as-you-go key inside a coding client such as Qwen Code or Claude Code; the quota never falls back to pay-as-you-go, so a key recorded under inference continues the work after the quota ends
ReliabilityPro slots sell first come, first served with a daily restock at 00:00:00 UTC+08:00, so a plan can be sold out; a lapsed plan cannot be renewed and needs a new purchase; at high platform load the vendor queues, throttles or briefly interrupts an account; a key used by scripts or application backends can be suspended or revoked
NotesPro is the only plan that new subscribers can buy. The Lite plan closed to new subscriptions on 2026-03-20 and to renewals and upgrades on 2026-04-13. The vendor sells the Token Plan as a separate product with no migration between the two, and describes Coding Plan Pro as a limited-quantity offer that is no longer available once sold out. The China site sells the same quota at CNY 200 a month under a separate account system. The quota is the vendor's published number and was not measured
