Memory is rounded up to whole GiB; compute and egress are metered by the second and settled hourly; storage is metered by the second and billed monthly. Trial organisations have 1 day of arrears grace instead of 3.
Bindingvolume-quota The one-time CNY 50 balance is the first limit reached: at CNY 0.10 an hour it is 500 hours of a 2 vCPU / 4 GiB sandbox, before outbound traffic or storage above 32 GiB is charged.
Identityemail The dashboard registration form asks for email, username, password and confirmation password. No phone number or ID document is shown. Creating an account creates an organisation and grants the CNY 50 balance.
Egress出向流量 ¥0.60 / GB (CNY 0.60 per GB of outbound traffic), billed per second and settled hourly. Egress is denied by default and each attempt is logged; an allowlist is set at create or changed at runtime.
Per-object capThe default workspace is 32 GiB and each sandbox gets 32 GiB of storage free; storage past 32 GiB is CNY 0.50 per GiB-month at the declared workspace size.
RetentionA paused or stopped sandbox keeps its process state, workspace and IP; a terminated sandbox is irreversible and deletes the disk. When the balance is exhausted sandboxes are cold-stopped with data kept, then destroyed after a grace period of 3 days, or 1 day for trial organisations. (3 days)
Interfacerest, cli, ssh A web console, a downloaded CLI binary and a REST API at api.rayrunos.com/v1; an E2B-compatible endpoint uses E2B_API_URL and E2B_API_KEY. A web terminal and SSH are documented.
Toolingrayrun CLI binary for Linux, macOS and Windows; REST API; E2B SDK compatibility for create, list and delete.
Composes withA sandbox can be created from the CLI, console or API with an egress allowlist; keys are injected by the platform rather than stored in the image, and files persist across stops until the sandbox is destroyed.
ReliabilityEgress is denied by default so package installs need an explicit allowlist; when balance runs out sandboxes are cold-stopped and destroyed after a 1-day grace period for trial organisations, and destruction deletes workspace data irreversibly.
NotesThe per-unit rates are CNY 0.03 per vCPU-hour and CNY 0.01 per GiB-hour, so the 2 vCPU / 4 GiB box is CNY 0.10 an hour; the vendor quotes USD 1 to CNY 6.82, which is about USD 0.0147 an hour. CNY 50 buys 500 hours of that box. Outbound traffic is CNY 0.60 per GB and storage above 32 GiB is CNY 0.50 per GiB-month. The pricing page documents a hosted microVM service; a self-hosted CLI mode is mentioned for E2B compatibility but is not the offer priced here.
