Limits
  • request-rate no published limit on the web client itself; every limit met here belongs to the installed addon source
The real limit is a capability gap, not a counter: without a local Stremio Service there is no torrent streaming and no in-browser conversion, so a P2P result set is unplayable in the browser even though it renders in the list.
Bindingnone Nothing at the Stremio layer counts bytes or requests; the constraints that fail at 1 TiB/month are governed by the addon (rate limit) and the debrid provider (per-object or traffic cap).
Identityemail A Stremio account is required to hold addons and library, which the vendor's own guide treats as step one ('logging in to Stremio Web'). No card and no phone.
EgressStremio does not meter the user. The bytes come from wherever the addon points - the debrid provider or the source host - so no allowance exists at this layer.
free allowance: unlimited
Per-object capnot applicable: a client, not a store
Retentionnot applicable: the addon list and library live in the Stremio account, not on the local device
Interfacerest A single-page web app (10,759-byte HTML shell titled 'Stremio - Freedom to Stream') that speaks the Stremio addon protocol to whatever manifests the account has installed. PWA-installable in Safari for iOS/iPadOS.
Toolingruns in the browser. Its missing half is Stremio Service, the local daemon: 'Stremio Web will still not be fully featured without connecting it to Stremio Service ... some missing features include: converting videos to support the browser, torrent streaming, etc'.
Composes withThe free front end for the whole pipeline: install Torrentio/Comet/MediaFusion/AIOStreams manifest URLs into the account, and a debrid key inside one of them turns Stremio Web into a player that needs no local machine.
ReliabilityThe vendor's help centre still answers 'Can I run Stremio in my browser?' with 'Not at the moment, but this is coming!' (updated 2026-09-03) while the web app is live and documented on their own blog - the support page is stale, not the product.
NotesThis is the piece that makes the free floor a real floor: a browser tab replaces the user and the media player. What it cannot replace is Stremio Service, and that daemon is what a P2P-only stack needs - so in practice Stremio Web forces the debrid key rather than removing the need for one.
