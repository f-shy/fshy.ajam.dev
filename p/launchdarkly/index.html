unit mixed; metered on ; The allowance is counted in service connections (one server-side SDK connected to one environment for a month), client-side MAU (each unique client-side user or device), log lines, trace spans, session replays, errors and AI runs; no single unit term fits. Sign-up starts a 14-day trial with Enterprise features that converts to Developer. When usage keeps exceeding the Developer entitlements the plan converts to read-only mode.

1 project and 3 environments on Developer. REST API rate limits are not published; LaunchDarkly returns them in response headers.
Bindingvolume-quota Each server-side SDK in each environment uses one of the 5 service connections a month, so server-side use meets that count first; client-side apps meet 1K MAU. Continued excess turns the plan read-only.
Identityemail The sign-up form asks for first name, last name, email and password, or a GitHub sign-in, and states no credit card is required; it starts a 14-day trial that continues on the free Developer plan. The GitHub route shows a Complete profile screen for First name, Last name, Work email and Organization, then sends an email to verify the account. Whether a later step asks for a phone number is unverified: behind a sign-up.
Egressnot applicable: flag evaluations reach the SDKs over routes that are never rate limited; no traffic allowance is published
Per-object capunverified: no flag or payload size limit is stated on the pages read
RetentionLogs, traces, session replays and errors are stored one month; AgentControl run and eval data stays 14 days
Interfacerest REST API at https://app.launchdarkly.com/api/v2 with personal or service access tokens (a GET /api/v2/projects without a token answered 401); SDK keys, mobile keys and client-side IDs cannot call the REST API; an OpenAPI specification is published.
endpoint: https://app.launchdarkly.com/api/v2
Tooling30 SDKs (13 client-side, 13 server-side, 4 edge), the Relay Proxy, or any HTTP client against the REST API with an access token.
