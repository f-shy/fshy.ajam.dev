Composes withPer-record unlimited: 1 GB x unlimited personal docs x unlimited free workspaces. Personal (unshared) docs on Free have 'no object or row limits', so the 1 GB/doc is the only ceiling - 1,000 docs = 1 TB in one free account.
ReliabilitySharing a doc flips it into the 50-object / 1,000-row regime and can lock it read-only after a 14-day grace period - the unlimited mode is strictly the unshared mode, which also kills public download links.
