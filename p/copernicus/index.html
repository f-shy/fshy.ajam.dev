The real gate is identity: registration plus a token plus, per dataset, a licence acceptance. The token is a credential and was not created here, so no retrieval was attempted.
Bindingnone Nothing in the seven-kind vocabulary fails at 1 TiB/month that could be measured here; the gate that does fail is identity, which the vocabulary carries in identity_cost rather than in limits.
Identityemail A CDS account (email registration) plus a personal access token copied into .cdsapirc, plus a licence acceptance per dataset. No card and no institution.
EgressFree. The token is identity, not payment.
free allowance: no byte allowance published
Per-object capnot applicable: a retrieval request returns a packaged file (NetCDF, GRIB or ZIP) built from the requested variable, area and period
Retentionthe archive is the product: ERA5 and the other datasets are reissued, not deleted, and a retrieval result is held for a limited period before it must be re-requested
Interfacerest, cli HTTPS API at https://cds.climate.copernicus.eu/api with the cdsapi python client; the token goes in $HOME/.cdsapirc. Process listing at /api/retrieve/v1/processes.
endpoint: https://cds.climate.copernicus.eu/api
Toolingcdsapi (pip install 'cdsapi>=0.7.7') is the vendor's own client; curl can drive the same endpoints with the PRIVATE-TOKEN header.
Composes withThe only free ERA5-class reanalysis source among debrid providers; pair it with a compute sandbox because a full reanalysis pull is tens of GB and needs processing where it lands.
ReliabilityRetrievals are queued and can take minutes to hours at peak; a client must poll a request id rather than expect a stream. No rate was measured because no token exists here.
NotesCaveat is the account and the queue, not the price. This is the clearest example in the sector of a resource that is free but not anonymous: the bytes cost nothing and the token is mandatory.
Evidence notedocumented The setup page was read and the process listing answered anonymously, which proves the service is live but not that a retrieval works. A retrieval with a real token would move this to measured.
