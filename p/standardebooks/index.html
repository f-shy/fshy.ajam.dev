The paywall on bulk ZIPs is a membership gate, not one of the seven vocabulary kinds: it is a purchase, not a rate, a quota or an identity check. The Atom feed also refused an anonymous client with 401, so feed-based crawling is closed.
Bindingnone Nothing in the vocabulary fails at 1 TiB/month because the catalogue is far smaller than that: roughly 1,500 books at about 1 MB each is under 2 GB. The ceiling is corpus size, not service policy.
Identityanonymous No account for per-book downloads or for git clone. A Patrons Circle membership (paid) is the only registration-like gate, and it buys the bulk ZIPs only.
EgressPer-book downloads are free and unmetered. Bulk ZIPs of whole collections are not: 'Access to our bulk downloads is a benefit of Patrons circle membership', a paid donation tier. The Atom feed at /feeds/atom/all answered 401 to an anonymous client on 2026-10-23.
free allowance: no byte allowance published; bulk ZIPs are paywalled, per-book files are not
Per-object capnot applicable: one EPUB/AZW3/KEPUB per book; the measured EPUB is 831,959 bytes
Retentionpermanent: a curated public-domain catalogue, each book also held as a public git repository
Interfacerest, git, cli HTTPS per book, and a two-hop download: /ebooks/<author>/<title>/downloads/<file>.epub returns an HTML 'Your Download Has Started!' page carrying a meta refresh to the same path with ?source=download, which is the actual file. Each title is also a public git repository under github.com/standardebooks.
endpoint: https://standardebooks.org/ebooks/<author>/<title>/downloads/<author>_<title>.epub?source=download
Toolinggit clone of the per-book repository is the only bulk path that needs no donation; wget/curl with the two-hop pattern works per book.
Composes withSmall, high-quality text corpus to pair with Gutenberg's 2.44 TB when typography matters; the git repos give clean XHTML source that a diff pipeline can track.
ReliabilityThe direct .epub URL silently returns 200 with an HTML redirect page instead of the file; a client that trusts the status code saves a 8,777-byte web page as a book. The ?source=download hop is required.
NotesThe caveat is bulk only: the free path is one book at a time or one git clone at a time. The abandoned route was 'download the Atom feed and walk it' - the feed answered 401.
