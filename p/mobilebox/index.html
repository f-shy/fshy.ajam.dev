prices: USD 0.01 per phone-minute for a cloud Android 14 (arm64) phone or a real Android device, USD 0.02 for a large phone with 4 GB RAM and 16 GB storage, USD 0.03 for iPhone and iPad, and from USD 79 a month for dedicated team phones. Residential and mobile IPs bill per GB; free credit has no cash value.
Bindingvolume-quota the per-second billing with a one-minute minimum and the balance hold at start bind first: a short task still costs one minute and a start fails when the balance cannot cover the hold. The free credit amount is unstated.
Identityemail the signup page offers GitHub or Google sign-in, an existing team API key, and email, and says no password is needed; the docs name a configured GitHub/Google provider or a team-issued key, then an agent key created in the dashboard; paid credit is prepaid in USD through Stripe
Egressa data-center IP is included; a residential IP costs USD 8 per GB and a mobile carrier IP USD 15 per GB of traffic, and a customer's own proxy can be set at no charge
Per-object capnot applicable: the unit is a cloud phone, not an object
Retentiona parked phone keeps installed apps, saved app data and logins for free; unsaved in-memory state does not survive a resume, and no maximum park duration is published
Interfacerest, unknown a REST API and a stateless Streamable HTTP MCP server at https://mobilebox.dev/mcp with a bearer API key; 21 MCP tools cover phone lifecycle, app installs, screen observation, actions and recording; the network proxies raise egress price, not a storage interface
Toolingany MCP client or any code that makes HTTP requests; a team-issued key is used to sign in and an agent key is created in the dashboard; a Python package wraps the same REST API
Composes withone phone per task for an agent that tests an app it built in a cloud sandbox without KVM: install the APK, read the screen as numbered elements, tap and swipe, then park the phone so the next task can resume it with saved logins. A hosted service, not self-hosted software. The free credit amount is unstated, so the published price of USD 0.01 a phone-minute is the entry cost after it runs out.
Reliabilityphones can fail to start with no uptime guarantee and data on a phone can be lost; a failed DELETE can still leave a phone, and the docs advise inspecting the account and retrying creates with an Idempotency-Key.
NotesA hosted cloud Android 14 (arm64) phone for agents, USD 0.01 per phone-minute (USD 0.60/hour over 60 minutes) billed by the second with a one-minute minimum; the free credit amount for new workspaces is not published. The list's USD 0.60/hour is 60 × USD 0.01, not a separate list price. Free boot time and free parked phones are included, and signup needs a GitHub/Google account or an email, no card for the free credit.
