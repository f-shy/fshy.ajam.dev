Free tierSnippets are git repositories that count toward the namespace storage size. No limit exists on how many snippets you can create. The default maximum size for a snippet is 50 MB, and a snippet repository is limited to 10 files.

Composes withNo limits exist as to how many snippets you can create. Versioned snippets are considered part of the namespace storage size, so snippets are not a separate storage pool.
ReliabilitySnippets are visible/searchable by other users when public; storage is accounted at namespace level so it is the most likely subject to be capped first if GitLab ever enforces namespace quotas.
