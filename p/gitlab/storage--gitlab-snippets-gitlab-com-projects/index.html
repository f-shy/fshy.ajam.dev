Composes withPersonal snippets are independent of any project, and the default maximum size for a snippet is 50 MB. Versioned snippets are considered part of the namespace storage size, so they are not a separate storage pool.
ReliabilityRead-only lockout is automatic and immediate on exceeding 10 GiB, and it blocks pushes rather than deletes data. Snippets are counted in namespace storage, so they are not a separate free pool.
