ToolingGET /projects/:id/jobs/artifacts/:ref/download?job=NAME, and GET /projects/:id/jobs/:job_id/artifacts (zip). No auth needed against a public project. Upload is automatic from .gitlab-ci.yml artifacts:.
Composes withUnlimited jobs per project x 1 GB per artifact archive, uncounted against quota. Force permanence with expire_in: never or the 'Keep' button. Because 'artifacts from the latest pipeline for the ref' never expire regardless of expire_in, every branch/tag becomes a permanent shelf: unlimited branches x 1 GB.
ReliabilityExpiry is enforced hourly and irreversible. Anything not pinned with never/Keep silently vanishes. Treat as durable only when pinned.
