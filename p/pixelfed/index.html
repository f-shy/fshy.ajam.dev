ToolingPixelfed is a Mastodon-API derivative: POST /api/v1/media (multipart) then POST /api/v1/statuses with media_ids[]. OAuth2 via /api/v1/apps. Any Mastodon client library mostly works.
Composes withPer-object uploads are limited to 14.6 MiB and restricted to image and video formats (JPEG, PNG, GIF, WebP, MP4). Federation across open Pixelfed instances provides distribution across nodes, though single-file limits remain small.
Reliabilitypixelfed.social itself returned HTTP 521 (origin down) throughout this probe; pixelfed.art also 521. The software is fine, the flagship host was not.
