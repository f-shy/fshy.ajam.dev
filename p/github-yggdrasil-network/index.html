the absence of an exit node is the whole finding and it is not a limit of any of the six kinds: it is a capability the network does not have. Yggdrasil routes inside 0200::/7 only, and the project states that reaching the public internet 'can be achieved using proxies or other tunnelling solutions on top of Yggdrasil but this is not something we explicitly aim to provide'
Bindingnone nothing in Yggdrasil binds, because nothing in Yggdrasil carries the traffic. The peer's advertised rate bounds overlay volume and is irrelevant to a public serving path
Identityanonymous the network is keyed by a self-generated keypair, not an account
Egressno byte quota exists anywhere in the protocol, and no peer carries traffic to the public internet: the project states it has no exit nodes. The 2.16 TB per day a 200 Mbit/s peer implies is overlay capacity between two Yggdrasil nodes
