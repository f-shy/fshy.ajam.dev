Per-object capunverified: no per-object size cap is stated on the free-tier pages read; the 4GB figure is the deployment size, not a single-object limit
Retentionthe free deployment is automatically deleted after the 14-day trial; all data including backups is lost if the account is not converted to a paying one (14 days)
Interfacerest, cli the ArangoDB HTTP REST API over TLS, with official drivers for major languages; a web UI (ArangoDB web interface) and a notebook; the FAQ states all ArangoDB drivers are supported as long as TLS is supported
Toolingany ArangoDB driver over HTTPS (arangojs, python-arango, go-driver and others); the built-in web UI and notebook; rclone does not apply
Composes witha managed graph, document and key-value store that can sit behind a free frontend or worker for a public endpoint; Foxx services cannot call the internet by default on the managed platform, which limits server-side chaining unless enabled on request
Reliabilitythe free deployment is deleted at day 14 with all data and backups; single-server and Developer deployments have no high availability and can be restarted at any time; deployments cannot be paused to reduce cost
NotesArangoDB Oasis (now Arango Managed Platform) has no perpetual free tier. Its only free route is a 14-day trial with one 4GB deployment, deleted with all data at the end. A public email provider triggers an SMS phone gate bound one-to-one to an account; a GitHub, Google or Microsoft sign-in avoids that gate. The free self-managed Community Edition is software the reader installs and runs, so it is not a hosted offer and is not the answer here. Paid hourly rates begin at 0.058 USD per hour for a single-server Developer deployment and 52ct/hr for a small deployment in Ohio.
