EgressBandwidth depends on host server allocation. Fronting endpoints with caching CDNs allows media caching to reduce origin egress traffic.
Interfaces3, rest, webdav, rclone rest
ToolingSynapse (Python) or Dendrite/Conduit; standard Matrix media API so rclone's s3/webdav-adjacent tooling plus any Matrix SDK works. Admin media API allows listing and purging media per user/room.
Composes withNot a free provider. The multiplier angle is that media is content-addressed and deduplicated by Synapse, and federation lets you push copies to other homeservers as a second replica.
ReliabilityDefault installs are safe; the risk is operator misconfiguration. Enabling media_retention turns the repo into a TTL cache. Federation media cache is the first thing purged.
