Free tierWith no key, 300 requests per day per IP. A free app key from Stack Apps raises the daily limit to 10,000 per IP; an access token gives a separate 10,000-per-day quota for each user and app pair, up to 5 per user. Every site's content is also published quarterly as an XML data dump.
unit requests; metered on request-count; A keyless call answered 200 with quota_max 300. When one IP uses several keys, the highest key's limit applies to that IP, so more keys do not add quota. Anonymous paging stops at page 25: a page above 25 answered access_denied with no key or token.

Limits
  • request-rate (binding) 300 requests per day per IP with no key; 10,000 per day per IP with a free app key, and an IP using several keys gets the highest key's limit source
  • request-rate (binding) 10,000 requests per day for each user and app pair with an access token; up to 5 such quotas per user source
  • per-ip-shaping more than 30 requests a second from one IP are dropped, with a ban on the order of 30 seconds to a few minutes source
  • request-rate (binding) a response carrying backoff means that method must not be called again for that many seconds; semantically identical requests at most once a minute source
  • per-object-cap 100 items per page and 100 ids per call; page numbers above 25 need an app key or an access token source
The keyless quota is shared by every keyless application on one IP. The network-wide dump download is reported to fail around 19.5 GB for some downloaders.
Bindingrequest-rate An IP gets 300 requests a day with no key and 10,000 with a free key, so a whole-site read goes to the quarterly dump, which has no request count.
Identityemail Keyless reads need nothing: a call with no key answered 200 at 300 requests a day. The 10,000-a-day key needs an application registered on Stack Apps, whose registration page sends a visitor with no session to the login page, and then an API key generated on the application's dashboard, because a new application has no key until one is generated. The Stack Apps signup takes an email and a password, or a Google sign-in; the network signup takes an email and a password, or a Google or GitHub sign-in. The official dump of one site needs a logged-in profile on that site; the official whole-network dump is downloaded from the data dumps page of user preferences on Meta Stack Exchange, which sends a visitor with no session to the Meta Stack Exchange login page; the community copy on the Internet Archive needs no account.
EgressFree: API responses are gzip-compressed JSON with no byte price; the official dumps download free from a logged-in profile, and the community copy on the Internet Archive downloads over anonymous HTTP with Range support
free allowance: no byte allowance published
Per-object capat most 100 items per page and 100 ids per {ids} parameter; page numbers above 25 need an app key or an access token
Retentionthe API serves the live sites; the official dump page offers the current quarterly dump, and Academic Torrents lists community uploads of the network dump from 2024-02-29 to 2026-09-30
Interfacerest JSON over HTTPS GET at https://api.stackexchange.com/2.3/, every response compressed; the authentication documentation says an application key or access token goes in an Authorization header as a Bearer value; OAuth 2.0 for user-scoped calls and writes; quarterly XML dumps as one 7z archive per site, downloaded from the Data dump access page in that site's profile settings (one site for each download; a meta site is a separate download from its own profile), or for the whole network from the data dumps page of user preferences on Meta Stack Exchange; the community copies of the whole-network dump are also distributed as BitTorrent torrents (the interface vocabulary has no BitTorrent term, so the record lists rest); the Stack Exchange Data Explorer runs SQL over a copy refreshed every Sunday.
endpoint: https://api.stackexchange.com/2.3/
ToolingAny HTTP client that decompresses gzip; 7-Zip or p7zip for the dump archives; a BitTorrent client for the Internet Archive and Academic Torrents copies of the network dump.
Composes withThe quarterly XML dump is the bulk path for a whole-site or whole-network read (official download from a logged-in profile, or the anonymous community copy on the Internet Archive and Academic Torrents); the API at 300 requests a day keyless, or 10,000 with a free key, serves fresh lookups; the Data Explorer answers SQL over the weekly copy.
ReliabilityThe network-wide dump came back in October 2026 after a removal of about two years, and downloads of the full archive are reported to fail around 19.5 GB; the Internet Archive copy is a community upload, not an official release.
NotesCaveat: the keyless quota is 300 requests a day, and the 10,000-a-day quota needs an account and a registered app. Bulk path: the quarterly XML dump, per site or for the whole network, from a logged-in profile; the 2026-09-30 network dump is also on the Internet Archive (91.9G) and Academic Torrents (99,497,279,488 bytes) as community uploads.
