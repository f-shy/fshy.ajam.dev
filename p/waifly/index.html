Per-object cap'1 server, 1 MySQL database' on the free plan. An extra server slot costs EUR 1 a month, which is a paid add-on rather than a free cap.
Retention'A server's status is checked daily; it gets suspended after 3 days offline.' A suspended server created less than 7 days earlier 'is deleted after 3 days'; an older one is kept '15 days' and recoverable from backups.waifly.com. An automated inspection runs every 30 minutes. So the machine persists indefinitely while it keeps running, and dies 3 days after it stops.
Interfacesftp, rest a Pterodactyl panel with a live console, file manager, SFTP, databases, scheduled tasks and backups; the docs state 'there is no root access or SSH shell'

ReliabilityThe operator publishes 99.9 per cent measured uptime over 30 days on status.waifly.com; that is the vendor's own figure and unverified independently.
NotesA French host with two named Paris nodes, a documented anti-abuse rule that is unusually explicit about its own suspension clock, and a free plan that needs no card. The founder is named in the documentation but no company registration number was found on any page read, so the entity is a named individual rather than a company. The one thing that would change the verdict is an egress number, which is not published.
