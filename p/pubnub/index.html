Free tierFree: 200 monthly active users or 1 million transactions a month, whichever is reached first, with 1GB data storage kept 7 days, no credit card
unit mixed; metered on ; The two units are monthly active users and transactions. A transaction is one API request, and a payload above 2,048 bytes is billed as one transaction per 2 KiB part. A Free account creates only Testing keysets, which are rate-limited and not meant for live traffic; a Production keyset needs the Starter plan. A Free account holds up to 10 active keysets. A Function deployed on Free pauses 7 days after deployment. Past a Free limit PubNub emails a request to upgrade or reduce usage.

  • retention-clamped message and file retention capped at 7 days on Free source
200 monthly active users, 10 active keysets, and Testing keysets only, which are rate-limited at a rate no page states; concurrent users, channels and devices are not capped on any plan. The vocabulary has no kind for a user count.
Bindingrequest-rate 1 million transactions a month is about 33,000 a day (1,000,000 / 30), and a 32 KiB payload is 16 transactions (32 / 2), so payload size moves this cap more than the 200-user limit does for a single-user workload.
Identityemail The registration form asks for a first name, a last name, an email, a contact email and a password, or a Google sign-in, behind reCAPTCHA; the pricing and registration pages state no credit card is required.
EgressThe pricing page lists storage and bandwidth as included in the plan; usage is counted in transactions, 1 million a month on Free
free allowance: 1 million transactions a month; a payload above 2,048 bytes counts once per 2 KiB part
Per-object cap32 KiB default message payload, channel name and metadata included (up to 2 MB for contract customers); 5 MB per file (32768 bytes)
RetentionMessage Persistence 1 or 7 days on Free, capped at 7 days; files kept 1 or 7 days (7 days)
Interfacerest REST API over HTTP GET with a publish and subscribe key pair from the Admin Portal; PubNub delivers realtime messages over ordinary HTTPS and uses no WebSocket, so subscribe is an HTTP long-poll. The time endpoint at ps.pndsn.com answered 200 without a key.
endpoint: https://ps.pndsn.com
ToolingPubNub SDKs, or any HTTP client against the REST API with a publish key and a subscribe key.
Composes withA fan-out layer for a prototype with few users, with 7 days of message history for a consumer that reconnects.
ReliabilityFree accounts create only Testing keysets, which are rate-limited at an unpublished rate; abnormal traffic on a keyset can draw a temporary rate limit.
NotesBeyond Free, pricing is per monthly active user: the Starter plan is USD 98 a month for 1,000 MAU.
