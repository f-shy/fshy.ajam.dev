Not every GPU type is available in every environment; quotas are listed in the Chalk dashboard. Committed-use contracts unlock volume discounts and self-hosted deployment options on Enterprise.
Bindingvolume-quota No free runtime allowance is published and the meter starts at the per-second resource rate, so usage cost binds before the 24-hour non-preemptible duration or the egress price.
Identityemail The self-service signup page is titled 'Get started with Chalk'; its browser-rendered form shows 'Email' beside an 'or' selector and a 'Log in' link, with no phone, document or card field in the rendered page. The plain HTML fetch renders only a loading spinner, which is why the field was missed earlier. The hosted serverless lane says 'Sign up and your environment is ready.' The card gate inside the dashboard is unverified: behind a sign-up.
EgressNetwork egress is $0.04 per GiB and ingress has no charge. Sandboxes inside a customer cloud account default-deny egress with hostname, CIDR and port allowlists; a hosted lane routes tool calls through the Chalk MCP gateway.
Per-object capnot applicable: the unit is a machine, not an object. Volumes are $0.09 per GiB-month and a sandbox mounts versioned volumes for repos, datasets or model weights.
RetentionA Sandbox is an isolated environment for a single ephemeral task, torn down when the task finishes; no post-run file retention period is published on the read pages and is unverified: behind a sign-up.
Interfacerest, cli, browser A Sandbox is defined and invoked in Python through the chalkcompute SDK; the docs also describe a REST API and a chalk CLI usage command, and a hosted serverless lane reached by signup.
endpoint: https://api.chalk.ai
Toolingthe chalkcompute Python SDK, the chalk CLI and the dashboard; no SSH endpoint or rclone backend is published for the sandbox.
Composes withA sandbox can be given a knowledge cutoff so the MCP gateway replays tools and context against a consistent historical snapshot, and versioned volumes let parallel sandboxes mount the same repo, dataset or model.
ReliabilityPreemptible rates apply unless non-preemptible workloads are explicitly requested, and they run at most 24 hours; Context node cost is independent of load and the branch server shuts down after a default idle period of 1 hour. Sandboxes are torn down when a task finishes, so unsaved work is lost.
NotesHosted serverless Chalk Sandboxes bill per second at $0.0249 per vCPU-hour plus $0.0080 per GiB-hour preemptible with no free allowance; the operator's list prices the 2 vCPU/4 GB shape at $0.245 an hour. A separate enterprise lane deploys the same software inside the customer's own cloud; that deployment is self-hosted and is not recommended while the hosted paid lane exists. No public free tier or trial was found on the read pages.
