Bindingwrite-gated The quota is real and 200 GB is respectable, but the account belongs to a school and the interface list is empty. Either the identity gate or the absent API would stop it alone.
Identityinstitution an institution enrolled in Apple School Manager. The docs state Managed Apple IDs are created and owned by the school
EgressNormal iCloud egress, with no metering on download
Per-object capNot published per file
RetentionThe account is owned by the school. Managed Apple Accounts cannot be converted to personal ones and vice versa, so the bytes are not portable on graduation
Interfaceunknown
Toolingnone. iCloud Drive for Managed Apple Accounts is reachable only through iCloud for Windows, the web app, or a managed device: there is no CloudKit-for-drive path and no WebDAV. This is the blocker, not the quota
Composes with200 GB times N accounts, where every account needs a school. Since no programmatic read path exists, the capacity cannot enter any programmatic stack
ReliabilityThe account is owned by the institution, so the bytes are not yours and do not survive leaving it. 200 GB is also below a 500 GB threshold unless multiplied, and no API exists to multiply it with
NotesA faculty member could obtain this; an individual registrant cannot, and even with a school the bytes are not portable.
