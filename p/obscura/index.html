Interfaceunknown A tunnel through native apps, plus WireGuard configs generated in the account. Protocols: a two-party relay that carries WireGuard over QUIC (the vendor's wording: 'WireGuard-over-QUIC'), and plain WireGuard configs. UDP: the QUIC tunnel is UDP-based by default, with a TCP/TLS tunnel option in the app's Experimental settings. Port forwarding: unverified: no page read states it. SOCKS5: unverified: no page read states a SOCKS5 endpoint. Obfuscation: the QUIC 'stealth protocol' blends in with HTTP/3 traffic; the WireGuard-config mode does not have it. BitTorrent: unverified: no page read states a rule.
ToolingThe vendor's native apps (macOS, iOS, Android, Windows, Linux; source on GitHub), or any WireGuard client with a config generated in the account. Each config holds one of the account's 5 connection slots for as long as it exists.
Composes withA tunnel exit in two hops: a vendor relay that sees the connecting address but cannot decrypt traffic, then a Mullvad exit; the upstream sees a Mullvad exit address.
ReliabilityThe first hop is the vendor's own relay and the exit is Mullvad's, so an outage at either ends the tunnel; the vendor's fallback when UDP is blocked is the TCP/TLS tunnel setting, which 'may reduce performance'.
NotesCheapest yearly price: no yearly plan is offered on the pages read; the only price is USD 8 a month. The product is a front end to Mullvad's exits (see the Mullvad record for that provider's own terms).
