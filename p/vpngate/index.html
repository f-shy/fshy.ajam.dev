EgressNo traffic allowance in either direction is published. The offer is free with no registration, and the far end is a volunteer's own machine. The measured position is a rate rather than a cap: 16 MiB crossed in 918 s.

Interfacecli SSTP carries the tunnel inside TLS. The relay's address is taken from the published node list and the connection is made with an SSTP client; this record measures the SSTP path only.
ToolingAn SSTP client inside a free or rented host with a full TCP stack, driven by hand from the published node list, plus a way to pick and re-pick a node as volunteers drop out. No rclone backend covers SSTP, so a wrapper would have to be written; that is a tooling note, not a verdict.
Composes withA free outbound exit for fetches the gateway would otherwise make from a datacentre address, held as a fallback rather than a primary path because 16 MiB took 918 s.
ReliabilityThe transit TLS terminates at a volunteer's own machine rather than at an audited endpoint, and a volunteer's node can disappear or change its exit address at any time; the measured path was the slowest on the dash.vpn slate.
NotesPerformance and network classification for VPN Gate volunteer SSTP relays. The vendor publishes no data transfer allowance or byte limits, so limits reflect measured connection throughput rather than quota caps. Measured throughput: a 16 MiB payload transferred in 918 seconds (16,777,216 bytes over 918 s, approximately 18,275 bytes per second or 17.8 KiB/s). Network diversity: sweep measurements identified 35 distinct exit autonomous systems across active relays, predominantly residential and carrier networks led by Korea Telecom, SoftBank, KDDI, and LG Powercomm. The measured test transfer exited via AS8369 (INTERSVYAZ).
