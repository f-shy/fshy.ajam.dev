Free tierOne-time free credits for all new and existing users, collected on the console Balance page, announced with the start of billing. No vendor page read states the amount of this credit. The promotions FAQ states that bonus credit from new user registration or Refer & Earn is currently valid for 40 days; the expiry of the January 2026 one-time credit itself is not stated. Calls deduct the complimentary free quota first and then the recharged balance, and an account with insufficient balance cannot use the API

Identityemail overseas users register a Xiaomi account by email or by Google or Facebook sign-in; mainland users by mobile number or third-party sign-in. Real-name authentication applies to mainland users before recharging or buying a package, and overseas users recharge without it
Egressnot published
Interfacerest The platform is served by the first-party Xiaomi MiMo inference API, compatible with OpenAI Chat Completions and Anthropic Messages formats; chat at POST https://api.xiaomimimo.com/v1/chat/completions, models at GET https://api.xiaomimimo.com/v1/models, Anthropic messages at POST https://api.xiaomimimo.com/anthropic/v1/messages; auth is api-key: $MIMO_API_KEY or Authorization: Bearer $MIMO_API_KEY, with a pay-as-you-go key of format sk-xxxxx created on the Console - API Keys page after sign-in. Token Plan uses token-plan-cn.xiaomimimo.com/v1 and Batch Inference uses batch-api-cn.xiaomimimo.com/v1, and regional base URLs and keys are not interoperable.
endpoint: https://api.xiaomimimo.com/v1 (OpenAI-compatible); https://api.xiaomimimo.com/anthropic (Anthropic-compatible)
ToolingOpenAI Python SDK (pip install -U openai) with base_url="https://api.xiaomimimo.com/v1", Anthropic Python SDK with base_url="https://api.xiaomimimo.com/anthropic", or curl against POST https://api.xiaomimimo.com/v1/chat/completions with the api-key header.
Composes withmainland and overseas accounts have separate base URLs and keys, so usage and credit do not aggregate across regions
Reliabilityan automatic keyword-based protection mechanism can block an account as abnormal usage until the vendor reviews it on request
Notesoverseas first-recharge bonus: USD 0.72 once per account on a first top-up of any amount, valid 40 days; it needs a payment so it is not a card-free credit. The first-party inference endpoint is https://api.xiaomimimo.com/v1 (OpenAI) and https://api.xiaomimimo.com/anthropic (Anthropic), confirmed by keyless probes on 2026-11-18; Token Plan and Batch use separate purchase-gated base URLs; the endpoint finding does not change the free-credit verdict. On 2026-11-18 two keyless POSTs returned HTTP 401 Invalid API Key, so the OpenAI-compatible route is live.
