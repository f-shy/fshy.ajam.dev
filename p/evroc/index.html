EgressNo egress charge or allowance is stated on evroc's Think documentation or its cloud-services pages. The object-storage calculator on evroc's own site prices 1 GB of storage at EUR 0.02 per month and 0 GB downloaded monthly at EUR 0.00 outbound, but no Think API egress term is published.
Per-object capNot an object store: the unit is tokens through an OpenAI-compatible inference API. models.dev lists context windows from 448 tokens for Whisper models to 524,288 for GLM-5.2, and output limits from 448 to 262,144 tokens.
RetentionThe shared inference API holds no user objects: a request is billed by tokens and no storage or retention period is stated. Dedicated Model Instances run continuously until the user deletes them.
Interfacerest, cli OpenAI-compatible REST API at https://models.think.evroc.com/v1 with standard clients and LangChain; the evroc CLI manages model instances and API keys.
endpoint: https://models.think.evroc.com/v1
ToolingStandard OpenAI-compatible clients, LangChain and the evroc CLI; the models.dev package is @ai-sdk/openai-compatible.
Composes withA shared model endpoint can be swapped in for another OpenAI-compatible backend with a configuration change, while dedicated GPU instances give predictable hourly cost for a pinned model.
ReliabilityShared Models are busiest 09-17h European time; the service answers 429 when rate limited and 503 with no server available under high load, with a Retry-After header. The exact thresholds are not published and may change.
NotesHosted inference service: evroc operates the GPUs and the user calls an API, so nothing is installed or maintained by the user. The Think Shared Models tier has no always-free token allowance on evroc's own pages; the 500-euro credit is a GPU VM campaign offer with unstated eligibility. A separate Dedicated Model Instances tier bills per GPU-hour and is not priced here. The signup form fields could not be read and are unverified.
