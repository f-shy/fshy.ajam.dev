Free tierFree plan USD 0/month: up to 300 requests a day, REST API and Python SDK, symbol lists and daily prices for stocks, commodities and OTC securities.
unit requests; metered on request-count; The documentation labels nine endpoints as Free: the stock, international stock, ETF, commodity and OTC symbol lists, stock prices, commodity prices, OTC prices and OTC volume. Quotes, intraday prices, fundamentals, news, calendars, insider and institutional data are labelled Standard or Premium. Prices return at most 300 records a call and symbol lists 500, paged with the offset parameter; stock prices cover more than 10 years of daily history. The next plan up is Standard at USD 29 a month with 10 requests per second.
Pricenone stated
Limits
  • request-rate (binding) up to 300 requests a day on the Free plan source
  • per-object-cap 300 records per call for prices; 500 records per call for symbol lists source
Plan gating: only the nine endpoints labelled Free answer a free key; the rest need Standard or Premium. Bulk path: none on Free; the offset parameter pages 300 price records per call.
Bindingrequest-rate 300 requests a day is the only rate cap stated for the Free plan, and each price call returns at most 300 records.
Identityemail The sign-up form takes a first name, a last name, an email, a password and a terms checkbox, with a Cloudflare Turnstile check; it has no card or phone field. Payment methods named for paid plans are cards, PayPal, Google Pay, Apple Pay and Link.
Egressnot metered in bytes; the 300 requests a day bound what a free key can pull
Per-object cap300 records per call for stock, commodity and OTC prices; 500 records per call for symbol lists
Retentionnot applicable: a query API with no stored objects; the stock prices endpoint serves more than 10 years of daily history
Interfacerest GET https://financialdata.net/api/v1/{endpoint} with the key in the key query parameter; format=json (the default) or format=csv. An MCP server exists but is limited to the Professional and Enterprise plans.
endpoint: https://financialdata.net/api/v1/stock-prices
Toolingany HTTP client; an official Python SDK (fdnpy) is published on GitHub
Composes withDaily price history and symbol lists in 300-record pages; fundamentals, quotes and filings are not on the Free plan, so a free stack pairs it with a filings or fundamentals source such as Finnhub or Financial Modeling Prep.
ReliabilityA call with no key answered HTTP 401 with the message Invalid API key.
NotesThe Free plan reaches symbol lists, daily prices and OTC volume only; everything else the documentation lists needs Standard or Premium.
