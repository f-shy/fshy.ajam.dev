A third-party integration guide reports a limit of 100 calls/day and 2000/month for regular users; no Wolfram page states a daily cap.
Bindingrequest-rate The 2,000 calls a month is the one ceiling that a Wolfram page states; a daily or per-second limit, if any, is in the plan summary behind the sign-up.
Identityemail A Wolfram ID is required. Its sign-up form asks for an email (which becomes the Wolfram ID), a first name, a last name and a password, with no card or phone field. The first AppID follows a one-time survey about intended usage and takes an application name and a simple description.
Egressnot applicable: a query API answered per call, not metered in bytes
Per-object capthe LLM API returns at most 6800 characters by default, set with the maxchars parameter
Retentionnot applicable: every answer is computed on the fly for the query, and the FAQ answers no to a data download
Interfacerest REST over HTTP GET with the AppID in the appid parameter: the Full Results API at api.wolframalpha.com/v2/query (XML or JSON), the Short Answers API at api.wolframalpha.com/v1/result (plain text), the Simple API at api.wolframalpha.com/v1/simple (an image) and the LLM API at www.wolframalpha.com/api/v1/llm-api
endpoint: https://api.wolframalpha.com/v2/query
Toolingany HTTP client, or one of the language bindings that the vendor's libraries page lists
Composes withComputed knowledge answers, one call at a time, at 2,000 calls a month. Bulk path: none; the FAQ answers no to a raw-data export and no to a data download. For a table-shaped read of open data, see data-apis/wikidata.
ReliabilityA call to the Full Results endpoint with no AppID answers HTTP 400 with the message Appid Missing.
NotesBulk path: none; the FAQ answers no to both a raw-data export and a data download. Paid plans: the overview page shows no price and its Pricing Information link opens a contact form.
Evidence notedocumented The quota, the sign-up fields and the FAQ answers are read from first-party pages; a keyless call answered 400 Appid Missing.
