Real large package verified: pandoc-3.5.tar.gz is 7,483,625 bytes. Packages must be cabal sdist output (gzipped tar with package.cabal).

Identityemail You can modify various settings for your account, including changing the email address and password, setting email notification preferences, as well as creating authentication tokens, at the [account management page](https://hackage.haskell.org/users/account-management).
EgressFree. Content is served from hackage.haskell.org and the hackage-content.haskell.org CDN. No billing, no bandwidth meter.

Interfacerest rest
Toolingcabal upload / stack upload (write), hup (a dedicated upload client, hackage.haskell.org/package/hup), Hackage server API at hackage-origin.haskell.org/api (open, 62,403-byte route listing), plain HTTPS tarball GET (read).
Composes withunlimited packages x unlimited versions per package (versions are never deleted and the index keeps all of them) x unlimited free Hackage accounts. Content must be a Cabal sdist, but the sdist can contain arbitrary files declared in extra-source-files - so a multi-GB blob can be shipped as a package's data. Multiply: N accounts x M packages x K versions.
ReliabilityImmutable by design - a bad upload cannot be deleted, which is irreversibility risk in the other direction. No documented byte ceiling means the ceiling is empirical and could change without notice. Read path is plain static files and reliable.
