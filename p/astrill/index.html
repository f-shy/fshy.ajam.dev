Limits
  • per-ip-shaping (binding) Port forwarding only on star-marked servers: one pre-selected port on a shared IP, all ports or selected ports on a dedicated IP; BitTorrent and P2P only on star-marked P2P servers source
  • volume-quota none: 'Unlimited bandwidth & server switches' on every plan source
Port forwarding and P2P are both confined to servers marked with a star in the app, so a BitTorrent session needs a P2P server and a forwarded port needs a (possibly different) selected server. The 'Connect unlimited devices in your household' line is a household wording, not a number. The SOCKS5 row is a documented absence: the vendor's blog says it does not provide SOCKS5 proxy settings or credentials.
Bindingper-ip-shaping No byte quota exists ('Unlimited bandwidth'), so the constraint that binds first for a client is the star-marked server set that carries port forwarding and P2P; no rate was measured.
Identityemail The sign-up form on the pricing page asks for 'Your name', 'Your e-mail', password and confirm password, an ALTCHA check, then 'We have sent you a confirmation message with a sign-up link'; it lists Visa, Mastercard, Maestro, American Express, Cirrus, PayPal, Bitcoin, Monero and bank transfer as payment methods. No phone number or identity document is asked on the form. A card is one option among cryptocurrencies, so the structured kind is email.
EgressThe pricing page states 'Unlimited bandwidth & server switches' for every plan and no byte allowance or overage price. metered is false on that statement; no byte was counted through a tunnel.
free allowance: none published: the pages price a term, not a volume
Per-object capnot applicable: an exit address, not an object
Retentionnot applicable: a live tunnel and a rented exit address, not stored bytes
Interfaceunknown Vendor apps for Windows, macOS, Linux, iOS, Android and a router applet; OpenVPN and WireGuard also work from third-party clients per the protocol page (OpenWeb and StealthVPN only from the vendor's software). The vendor provides no SOCKS5 endpoint of its own, so there is no proxy URL to dial. No interface term names a VPN tunnel.
ToolingThe vendor's desktop and mobile apps, or an OpenVPN or WireGuard client for the open protocols; the vendor's router applet for port forwarding on a router. A SOCKS5 or HTTP client has nothing to connect to: the vendor says it supplies no SOCKS5 settings or credentials.
Composes withA compute node runs the vendor's Linux app or an OpenVPN or WireGuard client, so all of its traffic leaves at the chosen server's address; a Worker cannot dial the tunnel directly, and there is no proxy endpoint to hand it.
ReliabilityWhich servers are P2P is shown only in the app and its server list, so the P2P set is unverified beyond the star convention. unverified: no exit-IP registry class was measured.
NotesThe vendor's protocols: OpenVPN, StealthVPN (obfuscated, UDP or TCP), OpenWeb (TCP, DPI-resistant) and WireGuard. Obfuscation is a protocol property here (StealthVPN, OpenWeb), not a setting. Port forwarding: Yes, on star-marked servers: one pre-selected port on a shared IP, all ports or selected ports on a dedicated IP; works with desktop apps and the router applet. BitTorrent rule: Allowed on star-marked P2P servers: 'VPN Servers which allows P2P/Torrent/eMule/eDonkey traffic are marked with a star'.
Evidence notedocumented Documented from the vendor's pricing, protocol, port-forwarding and wiki pages as served. Measured would need a paid account, the cheapest term bought, a tunnel brought up per protocol and the star-marked server set counted.
