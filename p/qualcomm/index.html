Free tierFree compile, profiling and inference on real Qualcomm devices, in the cloud: 'Qualcomm AI Hub Workbench, our platform, is currently completely free to use. We encourage you to submit your models, compile them, and submit inference jobs to both iterate on performance and to check the accuracy and download the target asset'. The workflow is described as 'submit an inference job, running your compiled model on a real device hosted in the cloud', with per-layer timing and runtime logs, and a second job uploads input data and downloads outputs.
unit GiB; metered on wall-clock; free-forever

Bindingnone Qualcomm publishes no request rate, job count, queue depth or model size ceiling beyond a note that models above 2 GB may fail to compile, so the constraint that fails first cannot be named from the documentation.
Identityemail a Qualcomm MyAccount plus an API token taken from Account then Settings, with no payment step described in the getting-started docs, so no card and no hold on that path. Whether the MyAccount signup asks for a phone number is not stated in the evidence, and debit and prepaid acceptance are not stated because nothing is charged
Egressnot stated
Interfacecli CLI: the qai-hub command line tool, documented at workbench.aihub.qualcomm.com/docs/hub/cli.html, plus a Python client and API documented at docs/hub/api.html.
Toolingthe qai-hub Python client, installed with pip3 install qai-hub, which also provides the qai-hub command line tool.
Composes withIt chains with the Qualcomm Device Cloud record already in documented records: AI Hub gives the compile and profile loop on hosted silicon, Device Cloud gives an interactive session with SSH port forwarding on a Snapdragon X Elite machine. Together they cover model work and application work without owning a phone.
Reliabilityno reliability event recorded
NotesThe one gap is the ceiling: 'completely free' with no published quota means the honest reading is free until Qualcomm changes it, and a heavy user could discover a limit the docs never state. The device list page warns that some entries are proxy devices that 'do not host the actual device', so per-model metrics may be modelled rather than measured; the inference-job path explicitly runs on real hardware, and that is the path this finding rests on. No probe was run against the API, so the verdict is qualifies-with-caveat rather than qualifies: the free claim is a vendor FAQ sentence, and the row would need an account, a token and one inference job before it could be called measured.
