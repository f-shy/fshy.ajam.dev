The trial lasts 1 month / 30 days with 1M tokens per day, daily token limit to explore all features, stricter rate limits with fair usage throttling, and all Core Models including chat and embedding.
unit tokens; metered on wall-clock; trial-credit: 30 days of full Core Model access with no card; after the trial the account moves to pay-as-you-go with no automatic charge. The FAQ says 'You get 30 days of full, unrestricted access to all Regolo core models — no credit card required.'

The trial's 1M tokens per day is a daily pool; the FAQ states a 20-million-token daily cap by default on subscription plans, up to 50M on Boost, 100M on Pro and 200M on Scale.
Bindingvolume-quota The 1M-tokens-per-day trial pool runs out before the 30-day window does under sustained use, and the trial adds stricter rate limits and fair-usage throttling on top.
Identityemail The sign-up guide says 'Click Sign Up and complete the registration form' and 'Verify your email address'. The pricing page states no credit card is required for the 30-day trial. Whether a phone number is asked for is unverified: not stated on the sign-up or pricing page read.
EgressNo. Regolo does not charge data egress fees. We believe in open, fair pricing — not in building financial walls around your data.
Per-object capnot applicable: the unit is API tokens, not stored objects; Regolo states zero data retention and no disk persistence, so there is no per-object cap.
RetentionZero Data Retention means Regolo does not store, log, or retain any of the data you send through our APIs — including prompts, completions, and any attached files.
Interfacerest OpenAI-compatible REST API at https://api.regolo.ai/v1, a chat completions endpoint, and a browser dashboard for virtual keys; the provider documents Python, Node.js and cURL clients.
endpoint: https://api.regolo.ai/v1
Toolingthe user installs an OpenAI-compatible client library (Python, Node.js) or uses cURL against the API; no server binary is run by the user and no hardware is owned.
Composes withAn OpenAI-compatible endpoint and key-scoped spend limits let an agent loop swap Regolo into an existing client; the paid Core plan adds a 20-million-token daily cap with per-model usage multipliers, so the free 1M daily allowance binds first.
ReliabilityFair-usage throttling and stricter rate limits apply on the trial; no contractual SLA on Pay-as-you-Go or Subscription plans, and the service disclaims uninterrupted or error-free access.
NotesThe 30-day trial is a time-boxed allowance, not a recurring free tier: 1M tokens a day, no card, verified email, and a switch to pay-as-you-go at trial end. The cheapest paid subscription is the Core plan at EUR 39.00 per month for up to 600M tokens a month with 70% discount on the first 3 months; pay-as-you-go prices start at EUR 0.10 per 1M input tokens on several models. The API model list is readable without a key (HTTP 200, 17 models returned with usage multipliers), while the trial itself requires sign-up.
