Free tierStarter plan USD 0/month: 50 requests per hour, 1000 requests per day, 500 unique symbols per month and 1 GB of bandwidth per month; 30+ years of end-of-day price history
unit requests; metered on request-count; Hourly requests reset every hour, daily requests at midnight EST, and monthly bandwidth on the first of the month at midnight EST; there is no per-minute or per-second limit. The News API reaches 3 months of history. The Power plan is USD 30/month (or USD 300/year) for individuals with 10,000 requests per hour, 100,000 per day and 40 GB per month.

500 unique symbols per month on Starter (no limits kind counts symbols). Bulk path: no bulk path for prices; supported_tickers.zip (805453 bytes, keyless) is a daily ticker list, not prices.
Bindingrequest-rate Pulled steadily, the 1000 per day count binds before the 50 per hour; a burst meets the hourly 50 first.
Identityemail Every API call needs a token from an account. The registration form asks for a username, an email, a password entered twice and a terms checkbox, behind a Cloudflare Turnstile check; it has no card field. Card or PayPal is asked only when signing up for a paid plan.
Egress1 GB of API bandwidth per month on Starter, 40 GB on Power
free allowance: 1 GB per month
Per-object capnot stated per call; 1 GB of bandwidth per month bounds the Starter plan
Interfacerest GET https://api.tiingo.com/tiingo/daily/<ticker>/prices with the token as ?token= or an Authorization: Token header; JSON or CSV via format=; the documentation also describes a WebSocket API. A call with no token answered HTTP 403.
endpoint: https://api.tiingo.com
Toolingcurl or any HTTP client; supported_tickers.zip lists every ticker and is updated daily
Composes withDeep end-of-day history (30+ years) at 1000 calls a day for up to 500 symbols a month; it pairs with FRED for macro series. Marketstack's US end-of-day prices are licensed from Tiingo.
ReliabilityPast the hourly, daily or monthly bandwidth limit the API answers HTTP 429; an end-of-day call past the Starter unique-symbol limit answers HTTP 403.
NotesThe widest free end-of-day history of the market data records (30+ years at 1000 calls a day), against two caveats: 500 symbols a month and no persistent storage on Starter.
Evidence notedocumented The Starter quotas, reset times, storage rule and registration fields are documented on the pricing, documentation and terms pages and in the site's own script bundle. Probes measured that a call with no token answers HTTP 403 and that supported_tickers.zip is served with no key. The 429 and 403 statuses are documented; the bodies and exact reset moments of the cut-offs need a token to measure (unverified: behind a sign-up).
