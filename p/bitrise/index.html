Retentiona terminated session's persistent disk is kept indefinitely as long as the user does not delete it and the stack it was created from remains available; session disks are not backed up and are erased if the stack is removed
Interfacessh, rest, cli a session is created from the terminal, IDE, browser UI or an AI coding agent; a REST API creates, reads, updates and deletes sessions, templates and saved inputs; a VNC desktop is exposed for macOS sessions
Toolingthe Bitrise CLI with bitrise-cli auth login and bitrise-cli rde, an RDE MCP server for AI agents, a VS Code plugin, a browser UI and a REST API

NotesA hosted development VM rather than a code-execution sandbox: macOS M2 Pro Large or Linux up to 4 vCPU at Basic Tier 1.
