Free tierFree plan USD 0 forever: API access to every endpoint at 15 requests per minute and 5,000 requests per UTC calendar month, a hard cap; plus the SEC filings feed, a 5-company watchlist, 2 alert subscriptions and 10 full-text searches a day.
unit requests; metered on request-count; The monthly allowance is account-wide across API keys, the interactive docs and the MCP server, and resets at the start of each UTC calendar month. The six documented endpoints are the filings feed, filing detail by accession number, insider transactions (Forms 3, 4 and 5), institutional holdings (13F), company profile by CIK and company search. Forms kept: 8-K, 10-K, 10-Q, 6-K, S-1, 10-D, Forms 3, 4 and 5, Schedules 13D and 13G, 13F and Form 144; EDGAR is checked every minute. The next plan up is Pro at USD 10 a month billed annually (USD 15 monthly) with 60 requests a minute and 250,000 a month.

Interactive docs tokens keep a fixed limit of 10 requests per minute on every plan. Bulk path: none; list endpoints page 100 items per call with a cursor.
Bindingrequest-rate The 5,000 requests a month hard cap is met long before the 15 per minute rate could be.
Identityemail The sign-up page is labelled free forever, no credit card, and takes a first name, a last name, an email and a password of at least 8 characters under its or-use-email option; an optional field asks where the user heard about the service.
Egressnot metered in bytes; the 5,000 requests a month bound what a free key can pull
Per-object cap100 items per page at most (limit 1-100, default 25), paged with an opaque cursor
Interfacerest GET https://earningsfeed.com/api/v1/{endpoint} with Authorization: Bearer <key>; JSON, cursor-paginated, with an OpenAPI 3.1 spec at /api/v1/openapi.json. An MCP server at https://earningsfeed.com/api/mcp signs in with OAuth on Free, Pro and Trader accounts and shares the same allowance.
endpoint: https://earningsfeed.com/api/v1/filings
Toolingany HTTP client; official Python (earningsfeed) and Node.js (earningsfeed) SDKs; an MCP server
Composes withSEC filings, insider trades and 13F holdings under a hard 5,000-requests-a-month cap, so a free stack uses it for filing lookups and takes prices from a quote feed such as Finnhub or Alpha Vantage.
ReliabilityA minute throttle answers HTTP 429 with code RATE_LIMITED and Retry-After; a spent month answers 429 with code MONTHLY_QUOTA_EXCEEDED, which should not be retried before the UTC reset; a keyless call answered HTTP 401 UNAUTHORIZED.
NotesThe Free plan reaches every endpoint; the binding limit is the 5,000-request monthly hard cap.
