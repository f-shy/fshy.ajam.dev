Identityinstitution The Lab request-access form asks for full name, email, organization name, organization type and team size and states 'Use your company or institution email to receive additional free credits'; the login offers Google or email sign-in and email verification is required. The API is reachable with an account API key or a Google OAuth session; a card is not stated for the signup credit and no phone number or ID document is requested.
EgressResult artifacts are fetched through time-limited download URLs with a url_expires_at timestamp; a public share link needs no key, an email-restricted share link needs a verified Boltz OAuth email. No egress price, allowance or metering term is published.

Per-object capnot applicable: the unit is a biomolecular prediction, not a stored object
RetentionDefault retention is 7 days after a run reaches a terminal state, with a minimum of 1 hour and a maximum of 14 days; the standard policy deletes data 30 days after a run starts and stops active runs at that limit. Results must be downloaded to the user's own storage. (30 days)
Interfacerest, cli REST endpoints under https://api.boltz.bio/compute/v1 driven by the boltz-api CLI, a Python SDK and a TypeScript SDK; a CLI device-code login obtains an OAuth token and API keys are passed in the x-api-key header.
endpoint: https://api.boltz.bio/compute/v1
Toolingthe boltz-api CLI installed from install.boltz.bio, the Python or TypeScript SDK, or any HTTP client sending x-api-key; agents use first-party plugins for Claude Code, Codex and Gemini CLI
Composes withA hosted prediction API for structure, affinity, ADME and molecular design work whose results are downloaded to the user's own storage, so multi-step pipelines need a separate record for durable state.
ReliabilityOutput data is automatically deleted at the retention deadline and download URLs can expire before that deadline; a lifetime workspace spending limit can reject a job once its headroom is used.
NotesThe credit amount is not published; the price beyond credits is stated only as 'from as little as $0.025 a prediction', and the USD 2,000 and USD 100 grants were a two-week launch promotion. Signup requires a verified email and the request-access form favours a company or institution email for additional credits. A test-mode key runs the full lifecycle for free with synthetic results. The Lab platform record and the API record are separate tiers of the same provider.
