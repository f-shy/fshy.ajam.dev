Free tierThe server is a public release on GitHub and costs nothing; the debrid account behind it is the thing that costs. The stable release is Real-Debrid only: 'A self-hosted Real-Debrid webdav server written from scratch.' Nightlies add backends 'beyond Real-Debrid (TorBox, AllDebrid and Usenet)' and need an active sponsorship.
unit unlimited; metered on none
PriceUSD 0 for the gateway; the debrid account is separate
Limits
  • request-rate paces itself to the upstream budget: api_rate_limit_per_minute 250 and torrents_rate_limit_per_minute 75 by default source
  • request-rate paces torrent adds to a 20-second floor it discovered by measurement, because Real-Debrid refuses closer adds source
The gateway's own throttle exists because the upstream's limit is not the documented one: zurg had to add an add-pacing floor and a repair subsystem for links that stop working while the torrent still reports healthy.
Bindingnone A pure client: at 1 TiB/month nothing in zurg fails first, the upstream add floor does. Listed as 'none' because that floor is Real-Debrid's and is recorded there.
Identityanonymous No account with the project; it needs a debrid API token, which it stores in config.yml.
EgressNo meter of its own; it spends the debrid account's unmetered premium traffic.
free allowance: none of its own
Per-object capnot applicable to the gateway; the source account's cap applies.
Retentionnot applicable: the WebDAV tree is a live view of the torrent library.
Interfacewebdav-proxy, rclone, rest Serves the torrent library over WebDAV on localhost:9999 by default, with a per-provider API under /api/providers/realdebrid/ (including /test). rclone mounts the WebDAV; Infuse can read it directly.
endpoint: http://localhost:9999/
ToolingShips a bundle with config.yml, docker-compose.yml, rclone.conf and Plex update scripts; 'rclone and ffprobe are automatically downloaded on first run if not already installed'. Docker image ghcr.io/debridmediamanager/zurg-testing.
Composes withThe bridge that turned debrid into a filesystem for Plex: zurg exposes RD as WebDAV, rclone mounts it, Plex or Jellyfin scans it, and no download ever lands on local disk.
ReliabilityThe stable line is Real-Debrid only; every other backend is a sponsors-only nightly, so a user on the stable release cannot point it at TorBox or AllDebrid at all.
NotesIncluded because it is the de facto answer to 'how does a script get a Real-Debrid library onto a disk without downloading it twice'. Trigger condition: a stable multi-provider release moves this from caveat to plain qualifies.
Evidence notedocumented Repository README and the project's own provider notes were read. Nothing was run: the throughput and mount behaviour are untested here.
