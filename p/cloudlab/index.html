local datasets are ALWAYS ephemeral - node disks are re-imaged after every experiment use, and the manual is explicit that infrastructure is 'not a storage provider' and node disks are 'not configure[d] in any redundant way'. Default experiment lifetime is 'a few hours'; extensions need a written justification reviewed by staff, indefinite needs the steering committee. Usage is metered in node-hours, not bytes. The Emulab parent facility has BYTE-IDENTICAL terms and shares the account: 'Emulab is a public facility, available without charge to most researchers worldwide', but project leaders must still be 'faculty, senior research staff, or others who are relatively senior positions', and an Emulab login is accepted directly as a CloudLab login - so it is a second door onto the same hardware with the same institutional lock.

Toolinggeni-lib RSpec profiles, portal API token, terraform-provider-cloudlab, ssh/scp
