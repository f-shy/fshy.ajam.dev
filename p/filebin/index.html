ToolingPlain HTTP PUT. 'curl -X PUT --data-binary @file -H "filename: probe.bin" https://filebin.net/<bin>/probe.bin'. Open source (github.com/espebra/filebin2, BSD-3) so it can be self-hosted.
Composes withUnlimited distinct bin IDs, each with its own 6-day clock. 'N bins x 6 days' is the only multiplication, and nothing survives week 2.
ReliabilityIMPORTANT INVERSION: a real browser UA (Mozilla/..) gets a 5399-byte 'are you sure / proceed to download' interstitial at HTTP 200; curl's default UA gets the real bytes. Automation works better than a browser here. The opposite of the usual trap. Any client that sets a browser UA (rclone, most HTTP libs, headless Chrome) will silently receive HTML instead of the file.
