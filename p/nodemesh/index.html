Composes withThe agent is the only thing that must run, so it fits a free Linux VM; the game server itself is installed by the platform.
ReliabilityRelay mode collapses every player to one local address, so per-player IP bans stop working; the vendor says the relay is not DDoS protection; a node that goes offline pauses its servers and disconnects players.
NotesBeta, stated on the page: 'you can create this server today, but we have not run it on our own hardware yet'. The free unit is one host, so a second machine needs credits. The relay is documented for game servers; the site does not offer a generic arbitrary-UDP port, so whether a non-game UDP listener works behind it is unstated.
