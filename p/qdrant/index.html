Interfacerest Server-side inference through the cluster own REST/gRPC API: pass a Document (text) or Image object with a "model" name in place of a precomputed vector in the upsert and query routes; auth is the cluster API key in the api-key header. Free Qdrant-hosted models need no extra key. Qdrant-hosted inference runs in the US region for free models and can be called from any region. External-provider models are proxied through the same cluster API with the provider key in a per-request header (openai-api-key / cohere-api-key / jina-api-key / openrouter-api-key).
endpoint: https://<cluster-id>.<region>.cloud.qdrant.io:6333 (REST) / :6334 (gRPC); inference via PUT /collections/<collection>/points?wait=true and POST /collections/<collection>/points/query; no standalone inference host
Toolingthe Qdrant client sends text or images in the upsert and query calls and the cluster embeds them; external providers (OpenAI, Cohere, Jina AI, OpenRouter) are proxied with a per-request provider key header. Python client uses QdrantClient(url=..., api_key=..., cloud_inference=True) and the same route works from the JS/Rust/Java/C#/Go SDKs; without cloud_inference the Python client embeds locally via FastEmbed.
Composes withembedding and search in one call on the same free cluster; the free tier is the cluster of 1 GB RAM and 4 GB disk
