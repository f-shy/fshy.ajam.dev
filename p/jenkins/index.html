Identityanonymous the software needs no account, email, phone, card or institution to download and run; the first admin user is created locally during the post-installation setup wizard on the user's own controller
Egresswhatever the machine the user runs the controller and agents on charges for outbound traffic; no hosted allowance or price is stated

Interfacerest, cli, ssh, browser, git a REST-like remote access API under .../api/, a CLI client (.jar file) reachable over SSH or WebSocket, a web interface, and a Jenkinsfile kept in the project's source control repository
endpoint: the API lives under the installation's own .../api/ path; there is no shared public endpoint because the user runs the controller
Toolingthe user installs and runs the Jenkins controller and one or more agents on a rented or free machine, from a WAR file, native package, installer or Docker image; pipelines are defined in a Jenkinsfile, driven through the web UI, the CLI client or the REST-like remote access API
Composes witha Jenkinsfile in a Git repository defines a pipeline that can be triggered by a source control change or by an HTTP POST to the remote API and runs on a controller and agents the user operates; managed Jenkins distributions sold by other vendors are separate offers and are not needed to run the free software
Reliabilityunverified: no first-party page read states an uptime commitment, ban policy or throttling for the software itself; the host, its bill and its uptime belong to whoever runs the instance, and the project publishes frequent security advisories for the controller and its plugins
NotesThe name 'Jenkins Cloud' does not correspond to a hosted first-party offer. The Jenkins project distributes free, self-hosted automation software that the user installs and runs on a machine they provide; no hosted signup, free tier, price list or metered quota exists. Qualifies-with-caveat because the software is usable without a card, phone or institution but the whole cost and operation of a host falls on the user. Managed Jenkins sold by third parties is outside this record.
