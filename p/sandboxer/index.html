Free tierNo free tier: plans start at $20 a month, charged when you subscribe and renewing monthly until you cancel; the first month buys 100 running sandboxes and machine time at $0.036 an hour for the default 4 vCPU, 8 GB, 50 GB size, billed by the second.
unit hours; metered on wall-clock; The $20 plan returns the whole $20 as machine time; it is about 555 hours of the default size. A wallet without a plan has 10 GB of stopped storage, and no sandboxes can be created without a plan and card.
Pricenone stated
Limits
  • volume-quota $20 a month of machine time at $0.036 an hour for the default size; time packs of $20 never expire source
  • request-rate 600 API calls a minute per API key, with short bursts up to 300 requests and a refill of 10 a second source
  • retention-clamped stopped sandboxes and automatic snapshots are kept 14 days after the last stop; named snapshots until deleted source
  • write-gated (binding) creating, forking or restoring a sandbox answers 402 payment_method_required until a card and plan are added; xlarge requires the $100 plan source
The $20 plan runs 100 sandboxes at once with 12 starts a minute, 60 an hour and 200 a day. Above each window, starts cost $0.03 to $0.07 each up to 3x the limit, then are refused. Storage is 50 GB on the $20 plan and is not billed, but it blocks new sandboxes when full.
Bindingwrite-gated With no free tier and no way to start a sandbox without a plan and a card, the payment gate stops use before the monthly $20 of machine time or the 600-per-minute API rate does.
Identitycard Sign in uses GitHub, Google, an email code, or an email and password. A card is required to start any sandbox: 'Choosing one (dashboard Billing, or sbx billing plan 20) adds your card and charges the first month right away. There's no free trial.' Without a card the dashboard, docs and CLI are usable, but every create answers 402 payment_method_required. No phone or identity document is asked for.
Egressnot metered: 'Do you bill bandwidth? No.' Outbound traffic is not priced, and each sandbox gets a public IPv6 address and HTTPS URLs for its ports.
Per-object capnot applicable: the unit is a machine, not a stored object; a command output keeps 8 MiB per stream and a file upload is limited by the 413 file_too_large error without a published size
RetentionA stopped sandbox keeps its disk and memory snapshot free for 14 days after it last stopped; named snapshots are kept until deleted, and all stopped data counts toward the plan's included storage (50 GB on the $20 plan). (14 days)
Interfacerest, cli, ssh A documented REST API with an OpenAPI spec, a static sbx CLI, TypeScript, Python and Daytona-compatible SDKs, plus SSH and SCP into each full Ubuntu 24.04 microVM.
endpoint: https://sandboxer.com/api/v1/sandboxes
Toolingcurl -fsSL https://sandboxer.com/install | sh installs the sbx CLI; sbx new, sbx exec, sbx ssh, sbx host and sbx fork, and the Python and TypeScript SDKs mirror the API.
Composes withA stopped sandbox resumes from a memory snapshot with its processes intact, which makes a warmed dev server reusable across agent tasks; with no charge for bandwidth, it can serve traffic directly on a public HTTPS port without a separate egress service.
ReliabilityAt zero balance, creates and resumes fail with 402, running sandboxes get a 24-hour grace period and are then stopped with memory and disk kept. Over included storage, new sandboxes wait until data is deleted or the plan is upgraded; auto-delete, off by default, removes least-recently-used stopped sandboxes with at least 7 days' notice. A trial that started before the free trial ended slows a sandbox using 90% of its vCPUs to 1 vCPU.
NotesThe smallest published size, 2 vCPU and 4 GB, is $0.018 an hour, matching the operator's list. Every plan returns its price as machine time, and stopped sandboxes cost nothing. There is no free trial, so the card is the price of any use.
