A maximum monthly budget can be set; when it is reached the service stops signing up new users while other activity continues. Push sending is unlimited and no per-message price is published.
Bindingvolume-quota The subscriber count sets the price from the first subscriber, so the 0-subscriber free state ends as soon as one device opts in.
Identityemail The sign-up form asks for an email address, a password and a confirmation password with a reCAPTCHA, and offers Brevo, Google, GitHub, Facebook and Shopify sign-in. The pricing page states that the 14-day trial needs no credit card. Payment details are taken only when the plan starts, through Stripe.
Egressnot metered per message or per byte: push sending is unlimited on the plan and the bill is based on subscriber count
Per-object capnot stated: no per-payload or per-message size cap is published on the pricing or billing pages read
RetentionBy default navigation data is kept for 3 months; the user decides what data is stored and for how long. If payment fails after the trial, sending is blocked but project and subscriber data is kept for 90 days, after which it is deleted from the servers. (90 days)
Interfacerest, browser A documented RESTful API sends notifications from a backend or CMS, and the Management API automates sends; iOS, Android and web SDKs register devices, and an online dashboard designs notifications and reads real-time analytics. Web and iOS web push register through the browser service worker.
endpoint: unverified: the API base URL is not stated on the pricing or billing pages read
ToolingThe vendor runs the hosted service; the user adds an iOS, Android or web SDK, calls the REST or Management API, and uses the web dashboard. No software is installed to run the push service itself.
Composes withA hosted service with a REST API, web dashboard and SDKs for iOS, Android and the web; no machine is supplied by the user. Self-hosted push servers are a separate option and are considered after this hosted offer.
ReliabilityThe vendor states a push delivery speed of 350k messages per second. Three failed payment collections suspend sending until invoices are paid; unpaid project and subscriber data is deleted after 90 days. European user data is stored in Europe.
NotesWonderPush is hosted software run by the vendor and has no ongoing free tier at a positive subscriber count: the free state is 0 subscribers and a 14-day trial needs no card. Sign-up asks for an email address and a password and needs no card before the trial ends.
