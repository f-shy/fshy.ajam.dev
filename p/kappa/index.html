Interfacerest, cli POST https://kappa.lol/api/upload multipart field 'file'. JSON reply: id, ext, type, checksum (MD5), key, link, delete.
endpoint: https://kappa.lol/api/upload
ToolingAn official uploader exists at github.com/Mald-Entertainment-Studio/uploader; curl works with one multipart POST
Composes withA stored URL with no extension is a clean drop for a script that only needs a link a human can open; it pairs with a checksum check from the client side because the service returns MD5 itself.
ReliabilityThe reply URL carries no file extension (https://kappa.lol/P224n5), so a client that infers type from the URL gets application/octet-stream regardless of the real bytes.
NotesUseful as a one-line anonymous store, unusable as an archive until the cap and retention are measured. The absent extension in the returned URL is the practical trap: a resumption test keyed on Content-Type will see application/octet-stream for every file.
