Interfacerest
Toolingno official open API. The reverse-engineered web API at drive-pc.quark.cn is what the OpenList quark driver uses; the netdisk-fast-download qk parser states that a logged-in cookie is mandatory; the OpenList docs warn quick-transfer now needs a local agent because of the speed limit
Composes withBase free storage is 10 GB per mobile-verified account. Promotional 1 TB allocations granted upon saving shared files expire after promotional periods rather than providing permanent capacity.
ReliabilityThe anonymous path gets metadata and not bytes: a share token and a full file listing with fid and share_fid_token come back with no cookie at all, and the download call is 404 on all four documented hosts. Download tickets are IP-bound, so a link minted on one host dies when replayed from another, which is why every public Quark parser rots within weeks
NotesQuark has largely replaced Baidu Pan as the default share host on Chinese forums, which is why it is recorded in full. The finding that matters for a bridge builder is that the anonymous token lists a whole share and cannot move a byte, and that download tickets are IP-bound so a harvested cookie does not survive a replay.

Bindingwrite-gated 300 GB free, and the TV client cannot write at all, so the direction that fails is the write side: it is a download-and-stream path with no upload, which makes it a serving helper and not a store.
Identityany-phone a Quark or UC account, which is phone-bound in practice; the TV client's own login path exists but does not remove the account requirement
EgressQuark free is shaped to about 1.7 MB/s and about 5 MB/s at peak for 88VIP. The TV client streams in original quality without downloading, which is why the community uses it
Per-object capNot published for the TV client
RetentionThe gift campaigns are one-off per account and campaign-gated. No retention clock on stored files
Interfacerest
Toolinga reverse-engineered TV OAuth client, fully documented in source: the OpenList quark_uc_tv driver hard-codes api https://open-api-drive.quark.cn for Quark and https://open-api-drive.uc.cn for UC, with a public client id, a TV sign key, an app version and a channel. WebDAV comes out once mounted
Composes withThe TV OAuth reads an account through a clean API with no client, so it is a serving and STRM path and not a write path. Paired with a writable pan it covers both directions, which is why the community keeps it alive
ReliabilityThe TV client's client id and sign key are public constants that Alibaba rotates, and when they rotate every mount breaks until the driver is re-patched. The free-tier space campaigns are monthly and quantity-capped, so they are a lottery and not a capacity plan
NotesThe canonical inverse of the public-instance problem. There an instance advertises a write it refuses; here a client is documented as read-only by design. Both are cases where the API's write surface must be read from the driver's own flags and not from the marketing page.
