geospatial raster only (GeoTIFF/COG orthomosaics); target 100 GB/file with resumable S3 multipart; account needed for API access and upload
Identityemail Email. Sign in with a Google account (documented third-party walkthrough: 'Sign in using your google account'), no affiliation or review.
EgressFree. And note the two-tier model: providers who already have cloud storage can 'Register a catalog', in which case OAM stores only metadata and links out ('Indexing uses none of your bandwidth and gives OAM no rights over the imagery').
Per-object cap100 GB/file (100000000000 bytes)
Interfacecli uploader web app at upload.imagery.hotosm.org; STAC API at api.imagery.hotosm.org/stac; eoAPI (raster/vector/stac) behind it
Toolingstactools-hotosm; STAC client; no CLI uploader yet
Composes withOutput is a COG + STAC item, i.e. cloud-native GeoTIFF. Directly readable with GDAL/rio-tiler and range-friendly. But the payload must be an orthomosaic with georeferencing.
ReliabilityThe uploader has undergone rewrites for large file support. No public API upload endpoints were responsive during testing on 2026-10-21.
