NotesThe checkout page's price field is rendered by JavaScript - the HTML carries an empty <span id="price"> with a spinner - so the PLN 34.90 figure is taken from the server-rendered shop page, which prints it as static text under the heading 'Najtaniej'. The stray '3.34PLN' string on the checkout page is the pre-render placeholder and is not used. The shop page renders no sold-out or unavailable marker on any of the six rungs. Not established: whether UDP is forwarded on any of the 10 ports, the exact overage behaviour at 100 Mbit sustained, and the deletion window for an unpaid service. The vendor also runs the same catalogue at host2play.se and host2play.com, with the Swedish site printing 91.90kr/yr for LXC Lite; the Polish storefront was used because it printed a PLN price on a server-rendered page.
