Free tier20 GB automatic on account creation, with an increase process that is explicitly designed to succeed: 'if needed, request reasonable quota increase … all reasonable requests will be approved subject to system capacity limitations'. No absolute ceiling is published. The only stated limit is capacity. So the honest number is 20 GB default with an unbounded-by-documentation increase path, and any 500 GB+ claim depends on a human granting it. A second lever: on publish, the storage is transferred off the author's quota — . 'CUAHSI will assume the burden of storage for published resources'. So publishing frees the quota for reuse.

ToolingHS REST API at /hsapi/ returns JSON from /hsapi/resource/?format=json without authentication. A documented external storage mount feature allows registering resources whose objects reside in external S3 or iRODS storage, functioning as a metadata and DOI catalog layer.
Composes withResources are unlimited; quota is per-user and transferable ('The quota holder … can be transferred between owner[s]'). Publishing moves the bytes off your quota onto CUAHSI's, then the freed 20 GB is reusable — so the pattern is publish-then-refill, repeated. Community/group resources can pool several members' quotas.
ReliabilityUS NSF-funded repository operated via CUAHSI. Anonymous BagIt downloads are operational. Quota increase requests undergo manual review.
