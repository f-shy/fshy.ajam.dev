No rate limit is published. Posts are dated to the minute, which makes the site a usable freshness signal for what a host index is missing.
Bindingnone AvaxHome transfers nothing, so no byte constraint binds. The constraint lives on whichever host a post links to.
Identityanonymous No registration to read. Whether a download from a linked host requires an account depends on that host.
EgressNothing is served by AvaxHome; every download is fetched from the host a post links to.

Interfaceunknown A blog front page with dated posts and category facets (/ebooks/facet/<topic>/). No API, RSS or search endpoint was read.
ToolingBrowser only as read. The dated, faceted structure is easy to crawl; published records own crawler is the tool.
Composes withA source of links rather than capacity: it is where a book, course or piece of software is announced, and the file itself arrives from whichever host the poster chose. That makes it the front end of the debrid chain for text and software, where the torrent indexers carry video.
ReliabilityPosts are made by named contributors ('Posted By: roxul', 'IrGens', 'AvaxHomeAI') and the front page carries an AvaxHomeAI-written editorial post at the top, so the site mixes automated editorial with human uploads. A post's links rot at the host's pace, not the site's.
NotesIt is an index, not a provider: nothing here can be scheduled, mounted or measured for capacity.
