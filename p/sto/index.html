The download limit was not exercised: 10 fetches of one link confirms the threshold, and the second fetch is the interesting one because the first may not count.
Bindingpull-count At 1 TiB a month no published byte cap was hit, but a 10-download link means a re-fetch of the same object fails once ten readers have had it, and 72 hours bounds it again; the pull count is the first of the two that a busy object meets.
Identityanonymous A bare PUT with no cookie, no account and no email returned a link.
EgressDownloads are served from trystocare.com. The site advertises a 10-download limit per link, which makes the link a distribution budget rather than a store.

Interfacerest, cli curl -T file https://ul.sto.care/<name> returns JSON {url, expiresAt}, with the download URL on a different host.

ToolingAny HTTP client that can PUT a file; the transfer.sh one-liner works with the hostname swapped
Composes withA transfer.sh-shaped PUT is the cheapest thing to wire into a script that already speaks that idiom, and the JSON reply makes the link parseable, but 3 days and a per-link download count make it a hand-off, not a mirror.
ReliabilityThe upload host and the download host are different domains, so a client that allow-lists the upload domain breaks at retrieval.
NotesA credible transfer.sh replacement that actually answers, and the only measured relay that returns a machine-readable expiry. The caveat is that its own documentation lives in blog posts rather than a docs page.
