Composes withthe account-free fetch hop: a torrent under 1 GB is fetched and returned as an HTTPS link without signup, which makes it the cheapest way to test whether a tracker or a magnet resolves at all.
Reliabilitythird-party tests report slow transfers and a media player that fails on common formats; the site runs on plain Apache without a CDN and its pricing URL is a 404.
NotesIncluded because it is the only service here that returns a fetched file without any account and without a published byte quota - useful as a resolver test even though the 1 GB cap rules out the 20 GiB case.
