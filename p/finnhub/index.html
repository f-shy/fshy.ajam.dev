Free tierFree plan USD 0/month: 60 API calls/minute; on top of every plan's limit, 30 API calls/second
unit requests; metered on request-count; No daily cap is stated. The free column covers US data: company news for 1 year, earnings calendar for 1 month, EPS surprises for 4 quarters, and a WebSocket of 50 symbols. The Quote endpoint is marked High Usage, not Premium. Candles (OHLCV), tick data, historical NBBO, last bid-ask, splits and most estimates endpoints are marked Premium in the API documentation, so the free plan carries no historical price bars. The All-In-One plan is USD 3500/month.

Limits
  • request-rate (binding) 60 API calls per minute on the free plan source
  • request-rate (binding) 30 API calls per second on every plan source
Bulk path: filings metadata only. The filings endpoint names a Kaggle dataset, SEC Filings 1994-2020, published by Finnhub for bulk download; prices, candles and news have no bulk path.
Bindingrequest-rate 60 calls a minute is the ceiling a free key meets; the 30-per-second limit binds only bursts.
Identityemail The signup form asks for a name, an email and a password, behind a reCAPTCHA; it has no card field. Signing up confirms non-professional status, and the terms use the name and email to file a non-professional subscriber form. When the register call returns a JSON body with status 200 the signup page opens /dashboard, where the docs say the API key is found, and its script holds no email-verification step; a third-party integration guide reports an email verification link before the key is shown, and whether the dashboard withholds the key until that link is followed is unverified: behind a sign-up. A call without a key answers HTTP 401 with 'Please use an API key.'
Egressnot metered in bytes; the call rate bounds what a free key can pull
Per-object capnot applicable: one JSON response per call; the filings endpoint returns up to 250 documents per call
Interfacerest REST under https://finnhub.io/api/v1 with token=KEY in the URL or an X-Finnhub-Token header; a WebSocket stream of up to 50 symbols on the free plan.
endpoint: https://finnhub.io/api/v1
Toolingcurl or any HTTP client; a WebSocket client for the stream
Composes withA free real-time US quote and news feed at 60 calls a minute with no historical bars; history comes from another record, such as Alpha Vantage weekly or monthly series, Twelve Data daily series or Massive Basic end-of-day bars.
ReliabilityInactive users are deleted from time to time; a deleted account needs a new signup.
NotesThe most generous call rate of the four market data records, but the free plan is a live-data plan: quotes, news, calendars and a 50-symbol stream, with candles and tick history behind Premium.
Evidence notedocumented The rate and the plan columns are documented on the pricing page and the API documentation. A keyless probe confirmed the API answers and demands a key; the 60-per-minute cut-off needs a free key to measure.
