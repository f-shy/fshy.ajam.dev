Bindingretention-clamped The trial ends after 30 days and the dashboard locks, before any pageview or API limit matters.
Identityemail The registration form asks for a full name, an e-mail address and a password of at least 12 characters, behind a Friendly Captcha check; no credit card is asked for. The documented flow then sends a four-digit code by e-mail and starts the 30-day trial once it is verified, and Plausible's WordPress page states that registration asks only for a name and an e-mail address.
Egressnot applicable: a hosted dashboard; stats leave through the Stats API at 600 requests per hour per key, a Business plan feature that the trial includes
Per-object capnot applicable: billed by pageviews and custom events, not stored objects
RetentionWhen an unsubscribed trial ends, the dashboard is locked, new stats are no longer collected, and dashboards and stats are eventually deleted after an e-mail warning; paid plans state no retention limit
Interfacerest Stats API: a read-only HTTP interface, POST /api/v2/query with an API key in the Authorization header, 600 requests per hour by default; on the Business plan and during the trial. The Sites API is Enterprise-only.
endpoint: https://plausible.io/api/v2/query
Toolingthe tracking script on the site, and any HTTP client with a Stats API key
