EgressNot free and not public. Layer download is a signed S3 URL obtainable only via an authenticated GetLayerVersion call; there is no anonymous URL surface at all. Lambda invocations also bill per request and GB-second.
Retentionuntil the instance is recycled; not persistent
Interfacerest, rclone, cli rest
ToolingAWS CLI publish-layer-version / get-layer-version; SDKs. Immutability is structural: a layer version is immutable once published, so every write is a new version. No rclone backend.
Composes withAggregate limit is 300 GB unzipped per region across functions and layers. Limits enforce 250 MB per layer, 5 layers per function, and 50 MB per uploaded zip archive. The 250 MB ceiling requires S3-referenced uploads.
ReliabilityVery durable while the function exists; deleting a function version or layer version removes the code. No silent expiry, but no public read path either. The 300 GB is real and effectively unreachable without building your own proxy.
