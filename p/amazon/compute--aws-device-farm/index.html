unit minutes; metered on wall-clock; The pricing page notes that 1,000 minutes is a limited-time trial in place of the standard 250 minutes, and the FAQ states that the trial is one-time and does not renew.

Limits
  • request-rate (binding) at most 5 devices tested simultaneously by default on metered use; remote-access concurrency quota is 2 and metered concurrency can be raised on request source
  • retention-clamped a 150-minute hard limit on an automated test run and on a remote access session source
  • request-rate (binding) a maximum of 250 in-flight jobs per account, a soft limit; runs remain queued at most 24 hours source
  • per-object-cap 4 GB maximum app upload, with video and device logs truncated at 1 GB each source
  • write-gated iOS simulators always bill metered and cannot use unmetered slots; an account must be approved to purchase the requested number of device slots source
Unmetered plans start at USD 250.00 per device slot per month, priced per usage type and device family; private devices start at USD 200 a month; desktop browser tests are USD 0.005 per instance minute.
Bindingrequest-rate The 1,000 trial device minutes are consumed in parallel across devices, so the default concurrency of five devices running for up to 150 minutes each spends a long run fastest; concurrency and the per-run 150-minute cap bind before the file size caps.
Identitycard An AWS account needs a root email address and a phone number verified by SMS, and the advanced sign-up requires a valid payment method before it can proceed; Device Farm further needs an IAM user with permission and the service is available only in us-west-2. Private device and slot purchases are billed to that account.
EgressAll devices have internet connectivity over WiFi; traffic to internal systems can be allow-listed from 54.244.50.32-54.244.50.63, and device traffic is shaped by a chosen network profile. No separate per-GB egress price is published; device minutes are the meter.
Per-object capUploaded app or test archives are capped at 4 GB; generated video and device logs are each truncated at 1 GB and cumulative artifacts at 4 GB (4294967296 bytes)
RetentionApps and test packages are automatically removed after 30 days; logs, video recordings and other artifacts are stored 400 days; devices are cleaned between sessions and data can persist in some cases. (30 days)
Interfacerest, cli, browser A console for scheduling runs and remote access, an HTTPS API with AWS SDKs, a Jenkins plug-in and a Gradle plug-in; Appium, XCTest/XCUITest and instrumentation frameworks drive the devices.
endpoint: devicefarm.us-west-2.amazonaws.com
Toolingthe AWS console, AWS CLI purchase-offering and list-offerings commands, the Device Farm API and AWS SDKs, a Jenkins plug-in and a Gradle plug-in; Device Connect bridges local adb to devices in us-west-2.
Composes withA CI job uploads an app and test package, schedules a run over a device pool and downloads reports, screenshots and video; because uploaded packages are removed after 30 days, results that must outlive that window need a separate storage record.
ReliabilityTest runs and remote sessions end at 150 minutes, runs queued over 24 hours are dropped, iOS apps are re-signed with a wildcard profile which removes several entitlements, and data can persist between sessions in some cases.
NotesA one-time 1,000 device-minute trial on real iOS and Android devices at USD 0.17 a minute afterwards; unmetered slots start at USD 250 a month and private devices at USD 200. An AWS account with a verified phone and a card, plus an IAM user, is required before any test can run.
