Free tierFirst 2 GB of storage and first 100,000 requests per month free. A recurring monthly allowance, described on the pricing page as 'a monthly AWS Free Tier for storage and requests', with no 12-month expiry language attached to CodeArtifact itself. Then $0.05/GB-month storage and $0.05 per 10,000 requests.

2 GB/month free; 100,000 requests/month free; 5 GB max per asset (raisable by quota request); 350 assets per package version; npm publish request capped at 2 GB and NOT raisable; requests are also metered. A 500 GB/day fetch would blow 100k requests instantly; repos are private-only ('CodeArtifact does not publish packages .. to public repositories'), so anonymous pulls do not exist.
Identitycard (inferred, not read) not published
EgressMETERED and this is the killer: 'You pay for all bandwidth into and out of CodeArtifact, except ... Data transferred in from the Internet ... Data transfer between CodeArtifact and another AWS Service in the same AWS Region.' Internet egress is billed at the standard AWS data-transfer-out tiers, aggregated across all AWS services. No Cloudflare Bandwidth Alliance path.
Per-object cap5 GB max per asset (5000000000 bytes)
Interfacerest rest (CodeArtifact API), plus native npm/pip/twine/maven/gradle/nuget/cargo/swift clients through a repository endpoint and a short-lived auth token
Toolingaws codeartifact login --tool npm|pip|twine|nuget|maven, twine upload --repository-url, npm publish; first-class documented tooling.
Composes withPer AWS account: 2 GB free × unlimited AWS accounts. Within one account, storage is a single pooled meter (no per-repo allowance), so 1,000 repositories do not multiply 2 GB. Per-repo limits are on count (1,000 repos/domain, 10 domains/account) not bytes.
ReliabilityTechnically excellent but structurally wrong for this brief: no public/anonymous access at all, and both storage and egress are metered past trivial limits.
