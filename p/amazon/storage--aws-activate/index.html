Per-object-cap: S3 single PUT 5 GiB / multipart 5 TiB. Not binding. request-rate: S3 request rates are effectively unlimited at this scale but each PUT/GET is billed and drains the credit. retention: 'Credits usually expire within 1-2 years depending on the package.'.
Identityinstitution Associated with an Activate Provider and have their Organizational ID
EgressS3 egress is metered and billed from the same credit balance. This is an archive-only play unless fronted by Cloudflare (AWS is a Bandwidth Alliance partner).

Interfaces3-compatible, rclone, cli part of the text of Limits, above
ToolingNative S3 API; rclone backend 's3'; aws-cli; s5cmd for high-concurrency transfers.
Composes withCredits are per AWS account and per organisation ('Have not previously received AWS Activate Credits of equal or greater value'). Portfolio requires an Activate Provider affiliation. The useful multiplier is credit size x expiry window, not account count.
ReliabilityPurely a spend credit: once exhausted, S3 reverts to paid and will bill the card on file. No data-loss mechanism, just an expiry cliff.
NotesFounders tier: '$1,000 in AWS Activate Credits ... Select startups may qualify for up to $5,000 over time'. Portfolio tier: 'up to $200,000 in AWS Activate Credits' for provider-backed (accelerator/VC) startups. Credits cover 'over 200 eligible AWS services' explicitly including 'Storage: ... Amazon S3'.
