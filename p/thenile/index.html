NotesA query token is an abstract unit of CPU and memory. The page defines it but does not convert it, so the allowance cannot be expressed in rows or bytes. That is a discretionary meter in the sense that matters. There is no ceiling a reader can design against, only a price per unit. Two properties make the tier more useful than such a ceiling suggests. The limits are per workspace across unlimited databases, so tenant count is not the constraint. Reaching the limit is an overage and not a refusal. No inactivity or expiry policy is published. The free tier is the only one in this topic where the vendor states that it never pauses.
