Free tierNo storage quota at all. 16 GB per file via the Odysee uploader (4 GB from the plain lbry.com web form). Unlimited claims. Storage cost is a one-time LBC claim deposit, minimum 0.0001 LBC.

Limits

16 GB per file is the real ceiling; no per-day upload cap documented. Every publish needs an LBC deposit, so a large library costs a real (small) crypto balance up front and must be re-staked to keep claims alive.

EgressFree. Files are content-addressed blobs served by the LBRY DHT/reflectors and by Odysee's CDN; retrieval by hash is not metered.

Toolingyt-dlp lbry extractor (verified present). Odysee JSON-RPC at api.na-backend.odysee.com (resolve, claim_search). LBRY Desktop hosts blobs locally under lbrynet/blob.
Composes withUnlimited claims per channel x unlimited channels x unlimited accounts. Because the object is a plain blob, there is no video-duration ceiling to fight. The only cap is 16 GB/file, so capacity = unlimited files x 16 GB.
ReliabilityThis is the only candidate here that stores the original bytes, but the platform is visibly decaying in 2026. Community 'collapse watch' posts and a Sept 2026 outage report; LBRY Inc. wound down. Treat as a live archive with a short expected half-life.
