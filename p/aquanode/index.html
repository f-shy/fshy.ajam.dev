Composes withOne account and one balance across several GPU providers, billed per second, with a pod (environment plus volume) that survives a stop and can restart on another provider. The price is a live minimum across current supply, so it moves between page loads.
Reliabilitypreemptible offers run on hardware contributed by independent hosts, so they can be taken back; on-demand offers run in operator-managed facilities
