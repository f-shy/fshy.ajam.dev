Bindingretention-clamped No byte allowance is published anywhere, so no volume quota can be shown to fail first. What the site itself displays as a failure is an expired account: the status panel reports the expiry and refuses to start the proxy.
Identityemail [translated] Registration takes a username, a password and a verification code obtained from the vendor's Discord: 'one Discord user may register only one account'. The third field reads 'Taiwan mobile phone (not required) - Taiwan mobile numbers only, landlines cannot be used; some features require a phone number, which you can also add later in the account settings'.
Egress[translated] No byte allowance, rate or session length is published on the front page, the how-to page, the terms page or the client download page. The only limit visible is an account expiry, which the status panel reports.; ingress: tcp+udp
free allowance: none published
Interfacecli the downloads page lists per-architecture binaries and a separate FRPC file.
Toolingthe vendor's client builds for Windows 386/amd64/arm64, Linux on 11 architectures, macOS two builds, version 1.1.1; a custom FRPC file is also offered
Composes withA Taiwanese UDP port forward is the missing third leg of an Asia set that already covers Japan and Korea, and it needs no phone number.
ReliabilityNodes provided by other users are described by the vendor as sometimes unstable; the account expiry stops the proxy; Discord membership is checked at start-up.
NotesThe only Taiwanese free service found that forwards UDP on a public port without a public IP, and the cheapest identity cost: a Discord account, with the Taiwanese mobile number explicitly optional and needed only for some features. Two gaps. Every page is silent on volume. And the account appears to carry an expiry that must be renewed, which the status panel reports as a hard stop. Country: Taiwan; the operator writes in Traditional Chinese, and the terms invoke the law of the Republic of China. A user is frp-based: a 'custom client FRPC file' is offered for download.
Evidence notedocumented Port forwarding support for TCP and UDP, client binaries and Discord registration are documented on official pages.
