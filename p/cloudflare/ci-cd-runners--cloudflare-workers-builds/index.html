Free tierWorkers Free: 3,000 build minutes a month, 1 concurrent build, 20 minutes per build, 2 vCPU, 8 GB memory and 20 GB disk. Workers Paid (USD 5 a month minimum): 6,000 build minutes a month, then USD 0.005 per minute, 6 concurrent builds, 4 vCPU
unit minutes; metered on wall-clock; a build minute is the time a project takes to build; the overage price applies on Paid plans only; the Builds API reports whether the build-minute allowance is exhausted and when it refreshes, for non-paid plans only; what a push does once the Free minutes are spent (queued, refused or billed) is unverified: behind a sign-up
Pricenone stated
Limits
  • per-object-cap (binding) 20 minutes per build on Free and Paid; 8 GB memory; 20 GB disk source
  • request-rate 3,000 build minutes a month on Free; 6,000 on Paid, then USD 0.005 per minute source
  • request-rate 1 concurrent build per account on Free, 6 on Paid; Deploy Hooks 10 a minute per Worker and 100 a minute per account source
  • retention-clamped builds and build logs kept 90 days after the build finishes source
a build fails when the Worker name in the dashboard does not match the name in the Wrangler configuration file; Workers Builds does not honour the custom-build settings of the Wrangler file
Bindingper-object-cap a job longer than 20 minutes cannot run on any plan, and the 3,000 Free minutes at one concurrent build hold many full-length builds, so the per-build cap fails before the monthly minutes
Identityemail a Cloudflare account opened with an email address and a password, then verified by email; a GitHub, GitLab or Cursor Origin account authorised to Cloudflare, unless the repository is on Cloudflare Artifacts. Workers Paid adds a USD 5 monthly minimum charge
Egressbuild commands make HTTPS requests and the build image checks their certificates; no page states whether the build container's outbound traffic is restricted or unrestricted (unverified: no build was run); the build's output is a Worker, and the Workers Paid plan states no additional charge for data transfer (egress) or bandwidth
Per-object cap20 minutes per build on every plan; 8 GB memory and 20 GB disk per build; 64 environment variables per Worker
Retentionbuilds and build logs are kept 90 days after the build finishes; the versions and deployments a build created are not removed (90 days)
Interfacegit, rest a push to a connected GitHub, GitLab, Cursor Origin or Cloudflare Artifacts repository runs an optional build command, then a deploy command that defaults to npx wrangler deploy and can be customised; non-production branches run a preview command. A Deploy Hook is a URL that starts a build for one branch on an HTTP POST with no Authorization header
endpoint: https://api.cloudflare.com/client/v4/workers/builds/deploy_hooks/<DEPLOY_HOOK_ID>
Toolingan Ubuntu 24.04 build image with Node.js, Python, PHP, Ruby and Go preinstalled and versions overridable by environment variable or version file; the deploy and preview commands are Wrangler commands
Composes witha 20-minute Ubuntu job on every push or Deploy Hook call, ending in a Worker deploy; an external cron calling a Deploy Hook makes it a scheduled job, and a repository on Cloudflare Artifacts keeps source, build and deploy inside one Cloudflare account. GitHub Actions on a public repository gives longer jobs and comes first
Reliabilityonly GitHub, GitLab, Cursor Origin and Cloudflare Artifacts repositories connect; GitHub or GitLab instances run by their owners do not
NotesConfirmed as a CI runner service whose job is bound to a Worker deploy: every production build ends in the deploy command and every other branch in the preview command. Price per minute: USD 0.005 beyond the 6,000 minutes included in the USD 5 Workers Paid plan. Whether the build container has unrestricted outbound network access, and what happens to a build on Free once the 3,000 minutes are spent, are unverified.
