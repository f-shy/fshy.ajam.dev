Bindingvolume-quota the 5 million stored-dimension allowance is consumed by each vector's dimension count and binds before the 1536-dimension per-vector cap or the 100-index ceiling

Retentionvectors persist in the index until deleted by the owner; the pricing page gives no expiry clock for stored vectors on Workers Free
Interfacerest, cli a Worker binding, an HTTP REST API and the Wrangler CLI (npx wrangler vectorize create); queries from all three count as billable usage
ToolingWrangler CLI and the Cloudflare REST API, called from a Worker with a Vectorize binding
Composes withVectorize is designed to be called from a Worker and paired with Workers AI for embeddings and D1, KV or R2 for the source documents; a free Worker can index and query within the shared Workers Free allowance
ReliabilityV1 indexes are deprecated and held at a separate lower limit of 200,000 vectors per index; new indexes use the generally available limits. The pricing page does not state what happens when a Workers Free allowance is exhausted.
NotesThe allowance is denominated in dimensions, not vectors, so a 768-dimension model stores roughly 6,500 vectors within 5 million stored dimensions. Cloudflare does not publish what happens when a Workers Free allowance is exhausted, only that the free tier will always exist for prototyping. The 50,000-index figure and the $0.10 per additional index price belong to Workers Paid, not to Workers Free.
