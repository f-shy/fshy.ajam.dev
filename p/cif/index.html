5 GiB/day at cif.su is the binding constraint (a two-year fill for 3 TiB). Per-file cap is the global video.file size limit, not separately published; accepted containers include mkv/mov/avi/flac, so arbitrary-ish binaries can be wrapped. Some instances (diode.zone) are unlimited but approval-gated and not open-signup.
Identityemail (inferred, not read) not published
EgressFree. Instance serves HTTP + WebTorrent/HLS; no egress meter. Peers can also seed via BitTorrent, offloading the host.
Interfacerest, rclone rest
Toolingyt-dlp PeerTube extractor (verified present). Native REST API v1: /api/v1/videos, /api/v1/users/me, resumable upload via X-Upload-Content-Length. rclone has no native backend; a shell/curl wrapper is trivial.
Composes withcif.su alone is 5 GiB/day = ~1.8 TiB/year per account with no total ceiling. Multiply across the ~15 open-signup instances in the index and across accounts. hittube.fr is a flat 50 GiB with unlimited daily; arkcast.mycreationhaven.com is 5 GiB with unlimited daily.
ReliabilityVolunteer-run instances disappear without notice. A single admin's disk decision deletes the archive. videoFile.update is disabled on cif.su, so you cannot patch an upload in place.
