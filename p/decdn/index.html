Per-MB payment is mandatory for clients on mainnet. There is no free reader tier. Namespaces gate the origin role ('Once you get approved, the rest of the network accepts your nodes as origins'), so publishing is write-gated by a human. Node bond on testnet is 50,000 TOKEN for anything up to ~1 Gbps; unbonding takes 14 days. 0.4% verification overhead plus node-to-node pull costs.
Identityemail email
Egress$0.01/GB target, set per node and signed into every quote; client sets a ceiling. Testnet is sponsor-funded with a capped allowance. 'there is nothing to pay and no account to make'. But that is testnet money on Arbitrum Sepolia.
Interfacecli Client SDK (Rust; macOS/Linux/Windows, phone/browser in testing) + decdn CLI: decdn get 'decdn:<blake3hash>/?ns=1'. One human-verification step in a browser on first install.
ToolingInstall via curl -fsSL https://up.decdn.org/decdn.sh | sh -s -- get '<uri>' (both scripts returned HTTP 200); PowerShell variant; node operator side is decdn setup / decdn node bond.
Composes withOrigin node in front of your own S3/R2/B2/NFS/local disk stays hidden; bonded nodes cache and re-serve over iroh QUIC with bao-encoded verified streaming. Multi-source fetch splits blobs >64 MiB across up to 4 nodes, one per operator. Publisher's own origin pulls are free. Cache misses cost the serving node, not the publisher.
ReliabilityPublic testnet only (Arbitrum Sepolia, launched 2026-10-13); governance hash blacklist forces nodes to stop serving a listed hash within 24 h, and the origin role is approval-gated.
