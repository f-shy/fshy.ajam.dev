Rates in the table are normalized to USD per hour for comparison; each row lists a billing increment when available, and most rows read 'Not specified'. A quote does not reserve capacity, and being listed in the catalog or benchmarks does not grant access to a provider account.
Bindingvolume-quota the USD 5 credit is what a new user spends first; there is no router-wide concurrency or request ceiling on the read pages, and the per-provider rates determine how long the credit lasts
Identityemail the signup page asks for a name, an organization, an email address and a password, and offers Continue with Google or Continue with GitHub; the CLI browser login opens the same flow and saves the session locally. The free credit needs no provider account and no payment method is shown before credit is used.
Egressno egress price is published on the read pages; a quote through the routing endpoint reports the provider, region and prepaid credit balance before a sandbox is created
Per-object capnot applicable: the unit is a sandbox session, not a stored object
Retentiona sandbox keeps running until the user destroys it or its lifetime expires; closing the terminal or disconnecting a preview does not destroy it, and sandbox and Actions rates may differ
Interfacerest, cli, chat a REST API at https://platform.computesdk.com/api/v1 with an organization API key or OAuth token, a TypeScript SDK that includes the router, the compute CLI, and a remote MCP server
endpoint: https://platform.computesdk.com/api/v1
Toolingnpm install computesdk for the SDK, npm install @computesdk/cli or curl -fsSL https://computesdk.com/install | sh for the CLI, an org API key from Settings, or the remote MCP server with OAuth
Composes withone integration routes across many sandbox providers, with a fallback order and a choice of provider per run; managed compute spends ComputeSDK credit with no provider account, while BYOK lets a provider bill its own usage directly
Reliabilitythe platform does not charge the 5% fee again on each usage charge; the displayed rate is normalized per hour for comparison and the billing increment is listed separately where the provider publishes one, so short-lived sandboxes can cost a different effective rate
NotesA hosted router over many sandbox providers rather than a single sandbox vendor: USD 5 of free compute credit at signup, a 5% fee only when buying more credit, and per-provider rates charged from the organization's balance. The per-provider table lists a 2 vCPU and 4 GB sandbox from USD 0.00604 per hour (agent37) to USD 0.3408 per hour (vercel medium); the operator list's USD 0.31 per hour for 'Sandbox Router' is not a router-wide rate on any page read, so the record states the published per-provider rates instead. The self-hosted SDK libraries are optional clients of this hosted service and come after it, not in its place.
