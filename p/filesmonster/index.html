The bucket is the design: 2555 GB for 365 days is 7 GB a day, and it does not roll over. A client pulling 1 TiB a month would exhaust a year's pass in about four months of use and then be buying a second one.
Bindingvolume-quota At 1 TiB a month the traffic bucket is spent first: 1 TiB is 1024 GB, so the 30-day pass (210 GB) covers five days and the annual pass (2555 GB) covers about two and a half months. The per-IP download count is generous enough that it does not bind before the bucket does.
Identitycard Buying premium needs an email address and a card: 'You will receive your login and password to this email ... You will be billed', with credit card and 'All Available Methods' listed, plus authorised resellers for local payment. No identity document is asked for on the page.
EgressPremium traffic is the allowance: 'Premium account can be used to download any type of content ... within available amount of traffic (Premium traffic)'. Download speed is not limited and multi-threaded downloads and download managers are supported.
free allowance: none published
price per tb: USD 45.40 per TB at 365 days; USD 80.95 per TB at 30 days (computed from the quoted bucket and price)
Per-object capNot stated per file. The premium page advertises 'One file, not multi-volume archives' as a benefit, which is the site saying the free path splits files into parts and the paid path does not.
RetentionNot stated on the pages read.
Interfacerest, unknown Download managers and multi-threaded clients are explicitly supported, which is the practical programme path: the host serves plain HTTP links to an authorised client. 'Download managers supported' and 'Multi-thread downloads are supported' appear in the premium rules.
ToolingJDownloader class clients. No first-party API is advertised; the file host model is link-in, file-out.
Composes withA file host that a debrid broker or a link site points at, not a service that chains outward. Here it is a price reference for the bucket model: 15 days buys 105 GB, which is the same shape as EX-LOAD's daily traffic but sold as a block.
ReliabilityA shared pass is the fastest way to lose one.
NotesThe useful fact is the bucket arithmetic: this host prices traffic in blocks with an expiry, which is the cheapest per-TB shape among debrid providers and still an order of magnitude above a debrid subscription.
