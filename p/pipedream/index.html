unit credits; metered on wall-clock; A credit is 30 seconds of compute; running an action, an MCP tool call, a Connect proxy request and a deployed-trigger emit each use credits, while listing and configuration calls do not. The daily number of free credits is unverified: the documentation names a daily limit without a number, and the figure is behind a sign-up. Unused daily credits do not roll over. Production use with real external users needs the Startup plan. Workflows takes no new sign-ups and shuts down on March 31, 2027; Connect is not affected.
