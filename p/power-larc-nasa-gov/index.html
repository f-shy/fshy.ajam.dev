Free tierFree, keyless REST API for global solar and meteorological data (hourly, daily, monthly and climatology levels; daily series from 1981); no numeric request quota is published, the vendor says there is no set rate limit and usage is monitored.
unit requests; metered on request-count; A single point takes up to 20 parameters on the daily API and 15 on the hourly API; regional requests take one parameter. Bulk path: the complete datastore is in public S3 buckets (s3://nasa-power as Zarr, s3://power-datastore as NetCDF, us-west-2), read with no AWS account, which bypasses the API's rate, transfer and timeout limits. Recent meteorological values are replaced by climate-quality values within 2 to 3 months.

Bindingper-object-cap No request rate is published, so the parameter cap per request is the number that shapes a large pull; the S3 buckets have no such cap.
Identityanonymous No sign-up and no key: keyless API calls and anonymous bucket listings answered HTTP 200; the AWS registry page says no AWS account is required.
EgressJSON, CSV, NetCDF and ASCII answers; the S3 buckets are free of charge to everyone
