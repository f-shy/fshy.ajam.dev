Composes withNothing to multiply. The desktop clients for Windows, macOS and Linux were withdrawn, so every third-party client depends on reverse-engineered web cookies, and the official API path needs identity-verified developer onboarding
ReliabilityThe desktop clients were withdrawn, so third-party access runs on web cookies that break. The share-snap API returns a whole share tree with no auth (a 2.52 PB folder resolved anonymously) and the download call answers 990001 登录超时, so the read gate is absolute
NotesThe quota and the egress both fail, and the identity wall is the reason neither can be tested. The verdict is fails-egress because the read gate is the one that was probed and refused.
