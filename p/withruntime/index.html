There is no free plan and no published session clock: the trial is seven days with USD 5 of usage. A paused machine pays storage; data is deleted 30 days after pausing.
Bindingper-ip-shaping The first thing that fails for this use is ingress: a public address is a USD 5/month add-on, which alone equals the whole budget.
Identitycard Signing up takes no card, but creating a sandbox requires one: until a card is added, calls answer the quoted error code card_required. Adding the card starts the seven-day Pro trial with USD 5 of usage; no hold amount is stated.
EgressNo outbound traffic is free: every GB sent costs USD 0.03, charged from the plan's included usage; inbound traffic is free. Outbound traffic has no plan limit: each machine gets a fair share of its server's link by size.
free allowance: none
Per-object capA Pro machine goes to 8 vCPU and 32 GB memory with 500 GB of fast storage; Growth goes to 16 vCPU, 64 GB and 2 TB; Scale goes to 32 vCPU, 96 GB and 5 TB.
RetentionA paused machine pays only for storage at USD 0.18 per GiB-month; a deleted machine costs nothing. After cancel or unpaid charge, machines pause and their disks, snapshots and volumes are deleted 30 days later.
Interfacerest, cli, ssh HTTP API at api.withruntime.com with TypeScript, Python, Ruby and Go SDKs, a CLI installed with npm install --global withruntime, an MCP server, SSH to a sandbox, and a browser account console

ReliabilityCompute has no one-minute minimum and memory bills only while compute runs; waiting is charged at a 50-millicore CPU floor.
NotesThe arithmetic at 24/7 for 1 GiB sitting idle: 0.05 vCPU x 0.025 + 1 GiB x 0.0075 = USD 0.00875/hour x 730 = USD 6.39. Busy at 1 vCPU: 0.025 + 0.0075 = USD 0.0325/hour x 730 = USD 23.73. Either way over USD 5, and the free tier is 100 hours, not a month. Egress: USD 0.02/GB x 1000 = USD 20 per TB beyond the 100 GiB allowance. Note the vendor's own framing (42% to 88% cheaper) is measured against agents that wait on a model, not against an always-on box, which is why the 730-hour figure is the one that decides.
