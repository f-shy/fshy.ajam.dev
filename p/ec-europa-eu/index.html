Bindingrequest-rate Each query returns kilobytes, so 1 TiB is millions of calls; with no published limit and no bulk file verified, the call rate decides the day's bytes.
Identityanonymous No key and no account: both queries returned 200 to an anonymous client.
EgressFree and unmetered; no authentication at the transport level.
free allowance: no byte allowance published
Per-object capnot applicable: JSON-stat, SDMX-ML or TSV per query. A single-series query measured 2,949 bytes; a whole dataset is a larger query, not a larger object.
Retention'The Eurostat database always contains the latest version of the datasets, meaning that there is no versioning or documentation of past versions of the data.' A revision overwrites.
Interfacerest, cli GET https://ec.europa.eu/eurostat/api/dissemination/statistics/1.0/data/<dataset>?format=JSON&lang=EN&<dimension>=<value>, and the SDMX 2.1 endpoint /api/dissemination/sdmx/2.1/data/<dataset>.
endpoint: https://ec.europa.eu/eurostat/api/dissemination/statistics/1.0/data/
Toolingcurl/python-requests; eurostat and pandasdmx python packages; the query builder on the site generates the URL.
Composes withThe EU-level counterpart to World Bank indicators; the two overlap on national accounts and trade, so a reconciliation step needs both rather than either.
ReliabilityNo versioning: a revision replaces the number in place, so a client that re-runs a query a month later can silently get different data for the same period.
NotesCaveat is bulk: the service is unlimited and free but ships data in small JSON-stat responses, and the old bulk file endpoint is dead. A full Eurostat mirror is millions of queries, which is slow rather than blocked.
Evidence notedocumented Two API responses were measured with byte counts and the web-services page was read. The bulk path is documented as unavailable here, not as a measured success.
