Free tierHobby: free with no credit card; 50,000 monthly retained users per app, unlimited applications, up to 3 dashboard seats
unit users; metered on identity-count; A user counts as retained only after signing in again more than 24 hours after sign-up. Above 50,000 retained users on Hobby a one-month grace period applies before an upgrade is needed. Hobby also includes 1,000 API key creations and 100,000 verifications, 2,500 M2M token creations and 100,000 verifications a month, 100 monthly retained organizations per app with up to 20 members each, and 10,000 protection checks a month. SMS codes and multi-factor authentication are not on Hobby. A development instance is capped at 100 users and delivers at most 20 SMS messages and 100 emails a month.

Dashboard seats are capped at 3 on Hobby; the vocabulary has no kind for a seat count.
Bindingwrite-gated Without a domain the app stays on a development instance, capped at 100 users and 100 emails a month; with a domain, the 50,000 retained users per app is the ceiling.
Identityemail The sign-up form asks for an email address and a password, or a GitHub or Google sign-in, and states no credit card is required. The Clerk CLI needs no account to start: signed out, npx clerk@latest init provisions a claimable application, writes dev keys to .env.local, and signing in later claims it. A production instance also needs a domain with DNS records. Whether a later step of the dashboard sign-up asks for a phone number is unverified: behind a sign-up.
Egressnot applicable: an authentication API; no traffic allowance or egress term is published
Per-object capuser metadata (public, private and unsafe) is limited to 8KB maximum; custom claims copied into the session token should stay under 1.2KB
RetentionApplication Logs are kept 1 day on Hobby (7 days on Pro, 30 days on Business) (1 days)
Interfacerest Frontend API for sign-in and sign-up from the browser, rate limited per IP address; Backend API for administrative tasks, called with a secret key at https://api.clerk.com/v1 (a GET /v1/users without a key answered 401); webhooks for data sync; an OAuth 2.0 authorization server and OpenID Connect identity provider on the instance's Frontend API URL (metadata at /.well-known/oauth-authorization-server, user information at /oauth/userinfo).
endpoint: https://api.clerk.com/v1
ToolingClerk SDKs and prebuilt sign-in components, the clerk CLI (npx clerk@latest), or any HTTP client against the Backend API with a secret key.
Composes withLogin and user store for a web app on free hosting; leaving the 100-user development instance needs a domain with DNS records, which pairs with a cheap or free name from domains-dns.
ReliabilityA rate-limited request answers 429 with a Retry-After header; Hobby email support covers billing, registration and abuse queries only.
NotesA development instance passes its session token in the querystring, which Clerk states is not secure enough for production use. Pro is USD 25 a month (USD 20 billed annually) and charges USD 0.02 a month per retained user above 50,000 per app.
