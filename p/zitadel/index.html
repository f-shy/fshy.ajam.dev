unit users; metered on identity-count; The counted unit is the daily active user (DAU), not the monthly active user. A unique user counts once per day for a login, a token refresh or a machine-to-machine service-user authentication; the monthly total is the sum of each day's count. The unit vocabulary has no term for daily active users; users is the nearest term and the true unit is named here. The pricing page does not state what happens when a Free instance exceeds 100 DAU.

Bindingvolume-quota The 100 daily active users per day is the smallest ceiling: a user who signs in on twenty days spends twenty units, so a small returning user base passes it before the 5,000 Management API requests are used.
Identityemail The register page states 'No credit card needed' and 'No commitment'. The quickstart says a new account verifies its email and sets up a Portal Team; an instance then needs a name, a region and an Instance Administrator, and the quickstart recommends passkeys for the account. RetentionOn the Free plan the Audit Trail History is kept 1 day and logs are kept 30 minutes (2 weeks and 1 day respectively on Pro) (1 days)
Interfacerest, browser A Management API with 5,000 requests included on Free and 500,000 on Pro, served on the instance domain; applications integrate over OIDC with a PKCE login on the ZITADEL-hosted login page, and the docs publish an API reference. The login page is hosted, so a browser reaching it is required for the interactive sign-in flow.
endpoint: https://{instance}.zitadel.cloud
ToolingAn OIDC client or OAuth 2.0 library against the hosted login page, the Management API for administration, and ZITADEL SDKs for the chosen framework.
Composes withAn OIDC identity provider in front of an app on free hosting; a generated instance domain is provided, and the Pro plan adds a custom domain. A separate offer of the same software that the reader installs and runs exists as ZITADEL Enterprise Self-Hosted, listed here last and not counted as a hosted tier.
ReliabilityThe pricing page gives no uptime guarantee to the Free plan; guarantees start at Pro (99.5 percent, add-on 99.95 percent). Login-policy misconfiguration can lock out an instance, and the quickstart advises a backup personal access token and a second administrator.
NotesThe DAU meter makes the 100-unit Free allowance much smaller than a 100-MAU allowance: a user who signs in on twenty days spends twenty units. Pro is USD 100 a month with 25,000 summed DAU included and a custom domain.
