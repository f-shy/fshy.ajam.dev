Interfacecli, rest Token and port are HTTP calls to the connected gateway on port 19999 (/getSignature, /bindPort); the scripts wrap them.
Toolingpia-foss manual-connections scripts with wg-quick and curl/jq, or the official app. Protocols: WireGuard and OpenVPN with UDP or TCP transport, or Automatic. A SOCKS5 proxy with separate credentials and a Shadowsocks proxy (obfuscation) are offered through the Multi-Hop setting. P2P traffic is supported on all server locations.
Composes withA token endpoint plus a bind loop is a five-line cron job on a free VM; the VM then holds a stable public UDP endpoint for the life of the signature.
ReliabilityLosing the 15-minute renewal loop silently drops the port mapping while the tunnel stays up. United States servers cannot forward at all.
NotesVPN provider offering port forwarding on selected server regions. Port forwarding scripts and API integration are maintained in official GitHub repositories.
