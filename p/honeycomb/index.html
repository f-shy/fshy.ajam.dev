Free tierFree, 'free forever': up to 20M events per month and up to 100M metrics data points per month, 2 triggers, distributed tracing, BubbleUp, OpenTelemetry support, Honeycomb MCP; no credit card required
unit mixed; metered on object-count; The allowance counts events and metrics data points, which no single unit of the vocabulary names. Each span of a trace counts as one event, so a trace of 150 spans is 150 events. Pro starts at USD 150 per month for up to 750M events.

Limits
  • volume-quota (binding) 20M events per month (each span is one event) and 100M metrics data points per month source
  • request-rate 2000 events per second on the free tier; traffic above it gets HTTP 429 source
  • retention-clamped 60 days for events and logs source
  • volume-quota (binding) 2 triggers source
Bindingvolume-quota Each span is one event, so a trace of 150 spans uses 150 of the 20M a month; the monthly event count binds before the 2000 events-per-second rate or the 60-day retention.
Identityemail Sign-up takes an e-mail address or a Google account, activated by a link sent to the e-mail, then a team name, a role and how the user heard of Honeycomb; the sign-up page states no credit card is required. The data region (US or EU) is chosen at sign-up. Whether a later step asks for a phone number is unverified: behind a sign-up.
Egressunverified: no egress term on the pages read; the Query Data API is listed among Enterprise features
Per-object capAn event may have 2,000 fields and must be less than 1 MB of uncompressed JSON, and a string field is at most 64KB; the single-event endpoint limits its request body to 1MB raw (potentially compressed)
RetentionEvents and logs: 60-day fixed retention. Time-series metrics datasets: 13-month fixed retention by default. (60 days)
Interfacerest Events and management API under /1/ and /2/ at https://api.honeycomb.io (US) or https://api.eu1.honeycomb.io (EU), keyed by API keys, plus OTLP ingest at the same hosts over gRPC, HTTP/protobuf and HTTP/JSON. A hosted MCP server at https://mcp.honeycomb.io/mcp (US) or https://mcp.eu1.honeycomb.io/mcp (EU) authenticates with OAuth or an API key and is available on every plan, including free. The Query Data API is listed among Enterprise features. api.honeycomb.io answered 401 to /1/auth without a key.
endpoint: https://api.honeycomb.io
ToolingOpenTelemetry SDKs and collectors, the Honeycomb MCP server, and any HTTP client with an API key
Composes withA trace and event store for free compute services instrumented with OpenTelemetry, 20M spans or events a month kept 60 days.
ReliabilityA team over its monthly event limit for a second consecutive month is warned, and after 10 days the Event API accepts one event in ten and rejects the rest.
NotesThe free plan counts events, not bytes, and keeps them 60 days, the longest event retention of the free observability tiers at Better Stack (3 days), Axiom (30 days) and New Relic (at least 8 days).
