Free tierPay as you go: $0 per month for up to 7,500 monthly active users, 5 enterprise connections (SSO/SCIM), unlimited organizations, fully customized hosted login and a custom domain; no credit card needed to start; unlimited team seats
unit users; metered on identity-count; A monthly active user is a user who logs in at least once in a calendar month. SSO and SCIM are counted separately, so a customer using both counts as two connections; the 5 included connections are shared across both types. The pricing page states pay only for what you use starting free up to 7,500 users and shows a calculator for M2M tokens, but does not publish a per-user price past the free allowance.

Interfacerest REST APIs grouped as Authentication APIs (login, MFA, passwordless, social login, usually no authorization required), Management APIs (configuration, require an environment token) and Self-service APIs (user and tenant actions, user or environment token). A bearer token from POST /auth/vendor with a Client ID and API Key authorizes Management calls; OpenAPI specifications and generated SDKs are published.

ToolingFrontegg frontend SDKs (React, Next.js, Angular, Vue, JavaScript) and backend SDKs (Node.js, Python, Java) or JWKS token validation, a generated TypeScript SDK from the OpenAPI spec, or any HTTP client against the REST APIs.
Composes withHosted login and tenant store for a web app; a custom domain pairs with a name from domains-dns, and SSO or SCIM enterprise connections consume the 5 included allowances on Pay as you go.
ReliabilityAn API request that exceeds a rate limit answers HTTP 429 Too Many Requests; the vendor recommends a back-off strategy. Limits are scoped per IP address or per environment ID (Vendor ID).
