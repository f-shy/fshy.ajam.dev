Free tier100 TB of pooled cloud storage per institution, at 'No cost'. Pooled across Drive + Gmail + Photos and all shared drives. Confirmed twice on Google's own pages: 'Schools and universities with Google Workspace for Education subscriptions have a baseline of 100 TB of pooled storage shared across all users' and 'Google Workspace for Education Fundamentals / Standard — 100 TB total for all End Users'.
unit TB; metered on stored-bytes

Limits

Per-object-cap 5 TB per single upload, and 750 GB per user per 24 h (upload+copy). This is the real throttle, and it is refreshing not cumulative. request-rate: standard Drive API quota (per-project, raiseable). retention: none while the tenant is active; data survives account suspension but suspended users still consume the pool. Item cap 500 million items per user. Over-quota: at +25% or 14 days, uploads and Docs creation stop but download keeps working.
Identityinstitution (inferred, not read) not published
EgressNot metered for Drive reads. Google's own storage page says over-quota tenants 'can still sign in to .. view and download their files' — i.e. reads are never blocked by quota. Direct-download URLs are served from Google's edge; put behind Cloudflare if you want a cache.
Per-object cap5 TB per single upload (5000000000000 bytes)
RetentionOver-quota: at +25% or 14 days, uploads and Docs creation stop but download keeps working. (14 days)
Interfacerest, rclone rest
Toolingrclone backend 'drive' (Tier 1, server-side copy, shared-drive support); Google Drive API v3; GAM (github.com/GAM-team/GAM) for admin-side bulk operations; gclone for service-account fan-out.
Composes withOne qualifying institution = one tenant = 100 TB. So the multiplier is domains, not users. Inside a tenant the multiplier is shared drives (unlimited count) and user count: up to 2,500 licenses per new domain, all drawing on the same 100 TB pool. Adding Teaching & Learning add-on licences adds 100 GB each 'with no cap' (paid).
ReliabilityStable for a decade, but Google already abolished the predecessor's unlimited tier (2021 archive: 'Existing customers ... will continue to have unlimited storage until early 2022'). Quota is now hard-capped and admin-auditable, so a tenant can be spotted by whoever administers it.
