Free tierSpark plan: 15 test runs a day in total (10 virtual-device and 5 physical-device runs). Blaze plan: 60 minutes of test time a day on virtual devices and 30 minutes a day on physical devices at no cost before per-hour charges.
unit minutes; metered on wall-clock; The Spark allowance is counted in test runs per day rather than minutes; the Blaze allowance is 60 no-cost virtual-device minutes a day, after which virtual devices are USD 1 per device-hour.

Limits
  • volume-quota (binding) 10 virtual-device test runs and 5 physical-device test runs per day on Spark; on Blaze 60 no-cost virtual-device minutes and 30 physical-device minutes per day source
  • write-gated 60 minutes maximum test duration on virtual devices and 45 minutes on physical devices source
  • request-rate Cloud Testing API 10,000,000 calls per day and 120,000 calls per minute per project; Tool Results API 200,000 calls per day and 2,400 per minute source
Charges are calculated per minute rounded up: a 22-second test bills for one minute. Test Lab is deprecated and will be fully shut down on 2027-09-30.
Bindingvolume-quota The 60 no-cost virtual-device minutes a day, and the 60-minute cap per test run, bind before the much larger API request quotas.
Identityemail The Firebase console sign-in asks to use a Google Account. The Spark plan needs no payment method; running Test Lab from the console requires a Firebase project on the Blaze plan, which links a Cloud Billing account, and a Cloud Billing account requires a payment method such as a major credit card.
Egressnot published as a Test Lab allowance: test execution time is billed, not traffic; the Firebase pricing table lists no separate Test Lab egress price
Per-object capnot applicable: the metered unit is device test time, not an object
RetentionRaw test results are held in a Google Cloud bucket; a bucket the user does not specify is created at no cost, and virtual device instances are deleted after each test run.
Interfacerest, cli, browser Tests are started from the Firebase console, Android Studio or the gcloud CLI; the Cloud Testing API and Tool Results API are available for automation.
Toolinggcloud CLI (gcloud firebase test android ...), the Firebase console, Android Studio integration and the Cloud Testing and Tool Results APIs.
Composes withA CI job uploads an APK and runs a test matrix on Google-hosted virtual Android devices, with raw results written to a Cloud Storage bucket; the paid continuation is USD 1 per virtual device-hour until the service shutdown on 2027-09-30.
ReliabilityTest Lab is deprecated and fully shuts down on 2027-09-30; the console and API stop then. Virtual device instances are deleted after each run, and API quotas are shared across test types.
NotesHosted virtual Android device test time at USD 1 per device-hour above a 60-minute daily no-cost Blaze allowance; the Spark plan caps virtual-device use at 10 test runs a day. The service is deprecated and fully shuts down on 2027-09-30; the successor Developer Device Platform requires billing enabled.
Evidence notedocumented Prices, quotas, the card gate and the shutdown date are quoted from first-party Firebase pages read on 2026-11-25. The exact sign-up form fields of a new Google Account were not read; the console asks for a Google Account and the Spark plan states no payment method needed.
