Retentioncertificates are good for up to 90 days by default and a client may ask for as little as 1 day; the ACME account has no expiry, and an EAB secret must be used within 7 days (90 days)
Interfacerest, cli ACME v2 at https://dv.acme-v02.api.pki.goog/directory (staging at https://dv.acme-v02.test-api.pki.goog/directory) with external account binding required; the EAB key is made with the Public CA API or gcloud publicca external-account-keys create
Toolingcertbot, acme.sh, any ACME client that supports EAB, the gcloud CLI for the EAB key
Composes witha free ACME CA run by a different operator than Let's Encrypt and ZeroSSL, with wildcard names over DNS-01 and certificates down to 1 day; the cost is a Google Cloud project that must be linked to a Cloud Billing account
Reliabilitythe ACME service does not support retrying a challenge, so a client requests a new authorization after a failed validation; no outage history was read
NotesThe 90-day figure is the default for the ACME endpoint. Certificate Manager's own Google-managed certificates are moving to 45 days, which is a different path from a client using ACME directly.
