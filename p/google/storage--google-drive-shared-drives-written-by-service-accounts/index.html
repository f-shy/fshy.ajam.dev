ToolingRclone drive backend with service_account_file + shared drive config (rclone docs still document the SA + shared-drive path and warn its shared client_id is being retired during 2026. Make your own). gclone (156 stars, archived), AutoRcloneV2, 88lex/sa-gen (71 stars, last push 2023-05) automate SA creation but not the new shared-drive target.
Composes withThe chain inverted. Old: unlimited free SAs x 15 GB each. New: SAs are free and unlimited but hold zero bytes, so they become pure WRITE THROUGHPUT/multiplexer against one tenant's pooled shared drive. 750 GB/day is per acting identity, and each SA is a distinct identity, so N SAs lifting into one shared drive gives N x 750 GB/day ingest; the 100 TB pool is the actual ceiling.
ReliabilityThe widely-copied 45 TB recipe now returns 403 storageQuotaExceeded on every upload; every SA-based rclone tutorial written before ~2024 is wrong unless it targets a shared drive. Also reported: a hard ~16 GB SA limit when uploading into a My Drive folder shared with the SA (2024 SO thread). Shared drives are the only working target.
