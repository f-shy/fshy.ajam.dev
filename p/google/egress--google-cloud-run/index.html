NotesCloud Run also requires a card, so it fails identity for a no-card client even before the transport does. Included here because it is the most common answer to "where do I run this".
Evidence noteinferred Cloud Run publishes no page that says "UDP is not supported"; the conclusion follows from the container contract requiring an HTTP listener on one port, and from Google's own developer forum answer that it will not work with UDP. A first-party negative statement would raise this to documented.
