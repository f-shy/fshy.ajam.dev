Free allowance
Each billing account comes with 2,500 free build-minutes per month on e2-standard-2 (2 vCPU, 8 GB memory) in the default pool; the first 100GB of worker SSD is free.

Free tierEach billing account comes with 2,500 free build-minutes per month on e2-standard-2 (2 vCPU, 8 GB memory) in the default pool; the first 100GB of worker SSD is free. The build-minute allowance is promotional and its limit is subject to change
unit minutes; metered on wall-clock; the unit counts minutes a build is in process, not one unit per build; a one-minute build and a sixty-minute build each spend minutes from the same 2,500 per billing account. A Google Cloud billing account is required to reach the Free Tier
Pricenone stated
Limits
  • volume-quota (binding) 2,500 free build-minutes per month per billing account on e2-standard-2 in the default pool; beyond it e2-standard-2 costs $0.006 per minute source
  • request-rate 10 to 30 concurrent builds in the default pool, counted globally as a project quota source
  • per-object-cap the first 100GB of worker SSD is free, up to 4000GB can be requested source
partial minutes are billed at the actual number of seconds consumed, and minutes a build spends queued are not billed
Bindingvolume-quota the 2,500 monthly build-minutes are shared across every project on a billing account and are spent by every build in process, so an active account reaches the promotional allowance before the 10 to 30 concurrent-build quota binds
Identitycard a Google Cloud billing account is required for the Free Tier; the Free Trial sign-up that creates one requires a credit card or other payment method valid for the trial, and in some countries a bank account verification
Egressnetwork egress is charged according to standard Google Cloud rates; no Cloud Build egress allowance or own price is stated
Per-object capthe first 100GB of extra worker SSD is free, and up to 4000GB can be requested; no cap on a single artifact or build input is stated on the pages read
Retentionunverified: the pricing, quotas and free-features pages read state no retention period for build logs, artifacts or the build worker
Interfacecli, rest, git builds are submitted with gcloud builds submit (the Google Cloud CLI) and the Cloud Build REST API at cloudbuild.googleapis.com; build triggers connect a Git repository. No SSH into a build worker is documented on the pages read
endpoint: https://cloudbuild.googleapis.com
Toolingthe gcloud CLI and the Cloud Build REST API; the user supplies a cloudbuild.yaml build configuration and a source archive or a connected repository
Composes witha build runs to completion on a Google-managed worker in the default pool and its result is published to Google Cloud services; a repository trigger, the CLI or the REST API starts each build and each build-minute spends the monthly allowance. No per-build step is a separate hosted runner
Reliabilitythe pricing page calls the 2,500-minute allowance promotional and subject to change; no ban or data-loss event is recorded on the pages read
NotesA managed, Google-run build service where each build spends minutes from a monthly allowance held by the billing account. Retention of build logs and artifacts and the exact standard egress rate are unverified: no first-party page read states them. Private pools and the local builder are separate offers outside this free allowance and are not documented here.
