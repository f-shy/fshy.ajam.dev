Bindingrequest-rate No byte quota and no rate cap are published, so no volume constraint exists in the vocabulary. The one published limit is a unique remote port inside a shared 10001-50000 range, recorded here as request-rate. That is not what breaks at 1 TiB/month; the true failure mode is a volunteer server with no operator obligation, which the vocabulary has no kind for.
