Interfacerest REST APIs at regional endpoints us, eu and br.conversation.api.sinch.com. The Conversation API covers SMS, RCS, WhatsApp, Viber Business and Facebook Messenger, with OAuth2 bearer tokens or HTTP basic auth. SDKs for Node.js, Java, .NET and Python are documented. The standalone SMS REST API reached end of sale on 15 April 2026; new SMS integrations use the SMS channel of the Conversation API.
endpoint: https://us.conversation.api.sinch.com
