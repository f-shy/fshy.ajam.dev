DNS record TTL values must be between 300 and 2592000 seconds, as stated in the LiveDNS API reference.
Bindingwrite-gated The paid domain registration is the gate that fails first, since no free-standing DNS zone is offered; once a domain is held, the 1000 requests per minute per IP rate limit is the next constraint.
Identitycard Account creation at id.gandi.net asks an email address, first name, last name, username and password, an affirmation of being older than 18, and acceptance of the terms; no card is asked at account creation, and a confirmation link must be clicked to activate the account. An identity document may be requested if ownership verification proves necessary. The paid domain that unlocks the free DNS and API needs a payment method.

Retentionzones persist while the domain is registered; no automatic expiry of DNS zones is stated on the pages read
Interfacerest, browser A REST API at https://api.gandi.net/v5/ for domains, records, zones and snapshots, plus a browser dashboard; TSIG keys support AXFR zone transfer to BIND, Knot, NSD and PowerDNS
endpoint: https://api.gandi.net/v5/
Toolingthe Gandi LiveDNS v5 REST API with a Personal Access Token in the Authorization header; curl or any HTTPS/JSON client; the browser dashboard
Composes withFree DNS and a REST API bundled with a paid domain, with DNSSEC, zone snapshots and a domain-ownership verification record endpoint for ACME DNS-01 challenges
ReliabilityA read-only probe of the documented unauthenticated generic nameservers route returned HTTP 401, so keyless programmatic DNS read is unverified. The product page states DNS changes propagate in less than 250 ms, while full resolver visibility can take a few hours.
NotesThe free DNS and REST API are bundled with a paid domain, which is why the verdict is paid-only rather than the qualifies given to a free-standing DNS host.
