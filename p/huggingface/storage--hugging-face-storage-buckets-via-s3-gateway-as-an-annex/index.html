The S3 gateway is single-region (us-east-1), path-style only and ListObjectsV2 only, and does not parse aws-chunked trailing checksums (request_checksum_calculation and response_checksum_validation set to when_required); ACLs, bucket policies, object tagging, object versioning, lifecycle rules, server-side encryption and bucket notifications are not supported, user metadata is not stored, server-side copy works within one namespace only, and incomplete multipart uploads expire after 7 days; 2 GB multipart parts are recommended. The per-file and file-count figures on the storage-limits page are stated for Git-backed repositories only.
Bindingvolume-quota a free account holds 100 GB private, and public storage beyond the first few gigabytes is best-effort under abuse mitigations, so the stored volume binds first
Identityemail the join form's first step asks an email address and a password and shows no phone field and no card field, and whether a later step asks a phone number is unverified; free-tier accounts exist with no credit card on file, and a card is asked for PRO, Team, paid compute and storage above the free tier
EgressEgress and CDN are included in the storage price up to a ratio of 8:1 to total storage; the storage page publishes no price or action above the ratio. GetObject through the single-region S3 gateway usually answers with a redirect to the nearest Hugging Face CDN edge rather than serving the bytes itself.

ToolingAny S3 client: AWS CLI, boto3, s5cmd; hf CLI (hf sync, hf buckets); python huggingface_hub. For this slot: git annex initremote type=S3 host=s3.hf.co region=us-east-1 requeststyle=path (annex needs path-style, which the gateway requires anyway) and dvc remote add ... ; dvc remote modify myremote endpointurl https://s3.hf.co/<namespace>. S3 creds are derived from an HF token via 'Generate S3 credentials' (HFAK... key).
Composes withBuckets are non-versioned, so a versioning layer on top of the S3 gateway keeps history: DVC is documented as a bucket remote through the gateway, and other S3 clients that take a custom endpoint with path-style addressing reach it the same way; storage is deduplicated at chunk level by Xet, and reads go out through the included CDN.
ReliabilityPublic storage on a free account is 'Best-effort': above the first few gigabytes the page names abuse mitigations without a figure; bucket deletions are immediate and unrecoverable; the S3 gateway is single-region (us-east-1).
NotesStorage Buckets are non-versioned, mutable object storage on the Xet backend; the S3 gateway at https://s3.hf.co/<namespace> takes access keys with the HFAK prefix, derived from a Hugging Face access token whose read or write scope they inherit
