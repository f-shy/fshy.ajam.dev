  • request-rate a public Space used as an API may be rate limited by Hugging Face if too many requests are made; no number is published. An Authorization: Bearer token gives better rate limits on public Spaces and charges the caller's GPU quota; anonymous calls use a shared pool with stricter limits. source
Bindingvolume-quota minutes of GPU a day bind long before any request count does
Identityanonymous the Unauthenticated tier needs no account and gets 2 minutes a day; a free Hugging Face account is the 5-minute tier. What a free account signup requires is unverified on the pages read
Egressnot published
Interfacerest the Gradio API of a public Space, called with gradio_client.Client(space_id, token=...).predict(); gradio_client resolves a Space id to *.hf.space. Raw REST routes are schema GET /gradio_api/info or /gradio_api/openapi.json, call POST /gradio_api/call/v2/<api_name>, poll GET /gradio_api/call/<api_name>/<event_id>.
endpoint: https://<owner>-<space>.hf.space/gradio_api/info (pattern, per Space); live example https://openhtr-openhtr-gen.hf.space/gradio_api/info
Toolinggradio_client (pip install --upgrade gradio_client); huggingface_hub for the token; raw curl against the *.hf.space host
Composes withthe hosting side of the same GPU pool is recorded at compute/huggingface-spaces-zerogpu; duplicating a Space to a private one moves the cost to the caller's account
Reliabilityquota left lowers queue priority, and whether a gradio_client call made with a token is counted against that account's quota is not stated on the pages read
