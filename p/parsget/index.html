EgressTraffic is the billed unit: 3 GB/day on the free plan and 100/300/600 GB per month on Basic/Pro/Ultra, counted when the file is downloaded. The pricing footnote says a premium site can draw more than one unit per GB ('ضریب مصرف از سایت‌های پریمیوم ممکنه متفاوت باشه').

Interfacewebdav WebDAV is listed as active from Basic upward ('WebDAV: فعال'); Ultra adds 'همه اتصال‌های ابری'. Download links are plain HTTPS from dl.parsget.com. No public API page was found.
ToolingWebDAV mount through rclone or any WebDAV client on paid plans; a browser extension ('افزونه مرورگر'). No vendor CLI, SDK or rclone backend documented.
Composes withReplaces a shelf of file-host premium accounts for an Iranian client: the file is pulled once into the vendor's Iranian server and then downloaded on domestic half-price traffic.
ReliabilityEverything is drawn against a traffic balance; the per-host multiplier changes the burn rate, and the service is Iranian-hosted, so its international links are the first thing to degrade under filtering or cross-border restrictions.
NotesThe strongest native multi-hoster found in the region: torrent, usenet and hosted file hosts behind one Persian-language account, priced only in Toman. The checkout gateway was not read, so the payment rail is inferred from the market (Iranian shops bill through Shaparak) rather than observed here. Absence of a public API is a tooling note, not a verdict: WebDAV is the programmatic path.
