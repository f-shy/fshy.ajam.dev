EgressServed over HTTP from designated node subdomains (node-name.radicle.garden) without published egress metering. Peer-to-peer replication allows multiple network nodes to mirror repositories without centralized bandwidth charges.
Interfacegit, cli git
Toolingrad CLI (Radicle heartwood), git remote rad://. Real client, actively developed.
Composes withReplication is the chaining primitive: each additional seed that follows your repo (rad id allow-list) is another free full copy and another serving endpoint. Content is addressed by git OID so it is verifiable. But it is a replication multiplier, not a capacity multiplier. Total bytes are still bounded by the largest seed.
ReliabilityAvailability is the weak point, not durability: if no seed holds the repo, it is unreachable until a peer comes back. Garden states it is 'walkaway-safe'. Losing the host does not lose your local repo.
