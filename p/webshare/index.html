The address count is the unit of purchase, not a limit: 20 addresses at the entry tier, 10,000 at the top, and the byte allowance does not multiply with it, because the 250 GB is included per plan.
Bindingvolume-quota The 250 GB included allowance is the only ceiling in the vocabulary this product imposes, and it is the one that would fail first: the per-plan thread ceiling and the address count impose nothing at 599,000 requests a month, while 250 GB is about 5.5 times the gateway's inferred ~45 GB a month, so the quota binds only if volume grows past 250 GB or a second workload shares the plan.
Identitycard Card: a plan is paid with a card (Visa, Mastercard, American Express, Discover, Diners, China UnionPay, JCB, Cartes Bancaires or Interac) or with Google Pay or Apple Pay on a mobile device, and the vendor names no other payment method. The account is opened with an email and a password or with a Google account. An ID check through Stripe Identity is not a purchase gate, but it may be requested later to confirm the payment method or a use case. The account’s free plan needs no card, but it is a separate datacenter offer and not this product.

Retentionnot applicable: an address, not stored bytes. The address itself is static for the life of the plan: 'These proxies are static by default, meaning they keep the same IP address for as long as you need.'
Interfacerest, cli The address is reached as an HTTP proxy or a SOCKS5 proxy endpoint: 'Webshare provides static residential proxies with ISP-issued static IPs, up to unlimited bandwidth, and HTTP/SOCKS5 support'. The plan also exposes a dashboard API and a downloadable proxy list (TXT), and lists IP Authorization among its connection controls. The schema's interface tokens carry no value for a proxy protocol, so the two tokens recorded here mean: rest for the control API, cli for any HTTP or SOCKS5 client.
ToolingAny HTTP or SOCKS5 client connects directly to the proxy address using curl -x, standard language HTTP libraries, or intermediate proxy relays. Proxy endpoint lists can be retrieved programmatically via the dashboard API without panel scraping.
Composes withIt is the rung-5 move for the gateway: the 102 relay Workers supply geographic spread and a per-connection address that are still Cloudflare's, and one Webshare static ISP address supplies an ISP-registered prefix in a non-Cloudflare ASN for the upstreams that refuse Cloudflare's ranges. At $6.00/month for 20 addresses it is the cheapest way to hold several distinct ISP-registered exits at once, and the addresses are static, so a per-upstream choice of exit is possible rather than a per-request draw.
ReliabilityThe address is static per plan, and the vendor offers a Replace Proxies feature and an Auto-Refresh add-on, so a burned address costs a replacement rather than a new plan; the same help article states that hosting-environment checkers may label the address datacenter and that fraud scores differ between tools, and the product page claims 99.97% uptime.
NotesPaid-only: the Static Residential (ISP) product has no free tier, trial or recurring credit, and the account’s free plan is a separate datacenter offer. A purchase buys an address whose ASN is a residential ISP, not a residential hosting environment: the vendor states that the IP address belongs to a residential ISP while the server it runs on sits in a datacenter, so a check of the ASN shows a residential ISP such as AT&T or Comcast, and a check of the hosting environment may show datacenter or hosting. Which of the two signals a refusing upstream reads is unverified without a bought address. The same provider is also filed as debrid/webshare, priced there as an egress path. The interface vocabulary has no token for an HTTP or SOCKS5 proxy endpoint, so the protocols are recorded in interface_detail.
