A synchronous exec has a default 120 s timeout and a 900 s maximum; a streaming or async exec defaults to 30 min with a 7200 s maximum. Disk per account on the node is 50 GiB, and a Space holds 8 vCPU / 4 GiB for a command. GPUs, non-Linux guests and a published SLA are not available.
Bindingvolume-quota The $5 of included monthly usage buys about 42 command-hours at $0.12/hour, so the included allowance runs out before the 50 GiB disk cap or the 4-concurrent-command limit for a single agent.
Identityemail The signup page says 'Start with your work email' and asks for an account shared with the CLI and the API; the plans are paid through Stripe Checkout, so a card is needed to buy a plan or top up credits, but none is named as a signup requirement.
EgressFirst 10 GiB free per Space per billing cycle, overage at $0.03 per GB; egress is metered as bytes sent and received by commands, file reads are free, and the hosted default is an allowlist with package registries and GitHub (private ranges always blocked).
free allowance: 10 GiB per Space per billing cycle
price per tb: USD 30 per TB (from USD 0.03 per GB)
Per-object capnot applicable: the billed unit is command time and files in a Space, with a 512 MiB single-file upload limit and a 2 GiB archive upload limit; 50 GiB of disk per account on the hosted node
RetentionA Space's files persist between commands; Space commits replicate in the background to an object store, and op results and output are kept 7 days.
Interfacerest, cli An HTTP API at https://api.sharkmagic.si (hosted node https://hel1.sharkmagic.si), Python and TypeScript SDKs, and a CLI with shark run, shark cp, shark expose and shark connect; shark connect is not served on the hosted node.
endpoint: https://hel1.sharkmagic.si
Toolingthe shark CLI (pip install sharkmagic) and the Python and TypeScript SDKs; the agent runs its commands through shark run against a hosted Space.
Composes withA persistent Space gives an agent files and services that sleep between commands; the credential proxy keeps API keys outside the microVM, and forks give O(1) copies for parallel jobs. The hosted service is the answer; a self-hosted node (Shark(base_url=..., api_key=...)) is a last resort for readers who run their own node.
ReliabilityNode admission answers 503 out_of_capacity when memory or CPUs are short; at zero balance new work answers 402 credits_exhausted and Spaces hibernate; concurrent writes to the same file conflict and the later commit is not published; no published SLA and no GPUs.
NotesHosted microVM-per-command sandboxes: a Space persists files and services, and every command runs in a fresh Firecracker microVM billed only while it runs. The $5/month Shark Pro plan includes $5 of usage, so it is paid-only with no free plan; self-hosting a node is a last resort.
