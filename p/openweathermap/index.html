Free tierFree plan: 60 calls a minute and 1,000,000 calls a month, summed across every key of the account, for the Current weather API, the 3-hourly forecast for 5 days, Weather maps 1.0, Air Pollution and Geocoding; weather API data update up to 10 min. One Call API 3.0 is a separate pay-as-you-call subscription with 1,000 calls a day free.
unit requests; metered on request-count; No free path to the regularly updated bulk snapshot files: the Free column of Bulk Download (standard presets) is locked, the presets start at the Professional plan (370 GBP a month), and History Bulk is a paid order per location. Free calls go only to api.openweathermap.org. One Call API 3.0 costs 0.0012 GBP a call past 1,000 a day and is opened through a billing form.

Bindingrequest-rate 60 calls a minute held for a month is more than 1,000,000 calls, so the monthly count is the ceiling a steady poller meets first.
Identityemail The signup form asks for a username, an email, a password, a confirmation of age 16 or over and acceptance of the terms, behind a reCAPTCHA; it has no card and no phone field. The key is sent after the email is verified and activates within up to 2 hours. One Call API 3.0 needs a billing form on top of the account.
Egressnot applicable
Retentionnot applicable: the unit is a request
Interfacerest REST over HTTPS with the key in the appid query parameter; free calls go only to api.openweathermap.org, and paid plans are given a different endpoint. bulk.openweathermap.org/sample/ is an open directory of sample files dated 2017 to 2020, among them a city list of 4002796 bytes, that download with no key.
endpoint: https://api.openweathermap.org/data/2.5/weather
Toolingany HTTP client; the key goes in the appid query parameter
Composes withA point-weather source: current conditions and 5-day forecasts per coordinate or city, with one monthly count shared by every key on the account.
ReliabilityPast 60 calls a minute on the Free plan the API answers HTTP 429, and the blocking system suspends the account for a couple of hours to several days at random; the key guide asks for the request to be repeated after 10 minutes and says an email warning comes before a suspension. A call with no key answers HTTP 401, and so does a Free key that asks for another plan's product. The 429 answer and the length of a block with a Free key are unverified: behind a sign-up.
NotesBulk path: none on the Free plan; Bulk Download presets start at the Professional plan and History Bulk is a paid order per location.
Evidence notedocumented Quota, rate, plan contents and signup fields are read from first-party pages; calls with no key to the API and to a bulk file answered HTTP 401, so the free key was not exercised. A call with a free key would move this to measured.
