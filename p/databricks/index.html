Free tierNo published byte quota. Free Edition ships 'serverless compute and default storage, so you can immediately start exploring and building'. Default storage is 'a fully managed object storage platform' and in serverless workspaces you can 'create additional catalogs in either default storage or in your own cloud object storage'. Quotas are documented for compute, jobs, pipelines, model serving and apps. Never for bytes.
unit mixed; metered on stored-bytes
Pricenone stated
Identityinstitution (inferred, not read) not published
EgressNot addressed in the Free Edition docs. Outbound internet is 'restricted to a limited set of trusted domains', which throttles external egress to non-approved hosts.
Interfacerest, rclone, cli rest
ToolingUnity Catalog volumes via SQL (CREATE CATALOG ..) or the Databricks CLI / REST API; no rclone backend. File access requires serverless, Unity-Catalog-enabled compute. 'All interactions with default storage require serverless, Unity Catalog-enabled compute'.
Composes withOne workspace per signup; the docs do not cap workspaces. Storage is uncapped in the docs but only reachable through compute, so the real multiplier is compute quota resets ('your workspace's compute resources will be shut down and unavailable for the rest of the day' on quota exhaustion; data is retained).
ReliabilityStorage without a documented quota but also without a storage-native API. You cannot PUT arbitrary bytes without spinning compute, and compute is throttled to 'the rest of the day'. Custom workspace storage locations are unsupported. Realistically a place to park tabular artefacts, not a 20 TiB blob archive.
