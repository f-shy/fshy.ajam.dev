Free tierThe REST API is free, with up to 100,000 calls per day and an email address as a query parameter; there is no key. Unpaywall no longer makes its own snapshots; the same data is in the OpenAlex public snapshot, free to download from S3 with no AWS account.
unit requests; metered on request-count; The 100,000 figure is a stated limit on use, not a measured cutoff; no per-second rate is published. DOI lookup is the only API endpoint: title search was retired on 2026-09-18 and answers 410. Unpaywall runs on the OpenAlex database since late 2025.

A call without an email parameter answered 422. The search endpoint answers 410 since 2026-09-18.
Bindingrequest-rate At 100,000 calls a day, polling the whole DOI space through the API takes many months, so a whole-corpus read goes to the OpenAlex snapshot, which has no request count.
Identityanonymous No account and no key: each call carries an email address as a query parameter, and a call without one answered 422. The example address in the documentation answered 200, so no account stands behind the address. The OpenAlex S3 snapshot needs no AWS account. The Data Feed is paid and priced by quote.
EgressFree: API responses carry no byte price; the OpenAlex S3 bucket is free to download with no AWS account, the data-transfer fees covered by the AWS Open Data program
free allowance: no byte allowance published
Per-object capone DOI per API call; the Simple Query Tool takes up to 1,000 DOIs per batch and returns results by email
Retentionthe API answers from the live database; Unpaywall snapshots are no longer created; the OpenAlex public snapshot is a point-in-time release, quarterly, on the second Wednesday of January, April, July and October
Interfacerest, s3 GET https://api.unpaywall.org/v2/{DOI}?email=ADDRESS returns one JSON DOI object; bulk: the OpenAlex bucket s3://openalex/data/ read with --no-sign-request, JSON Lines about 745 GB and Parquet about 770 GB as of the September 2026 release; the paid Data Feed serves daily and weekly changefiles and a daily snapshot with an API key.
endpoint: https://api.unpaywall.org/v2/
ToolingAny HTTP client for the API; the AWS CLI (aws s3 sync with --no-sign-request) or any S3 client for the OpenAlex snapshot.
Composes withPer-DOI lookups go to the Unpaywall API at up to 100,000 a day; a whole-corpus read goes to the OpenAlex public snapshot on S3, whose open_access and best_oa_location fields carry the same values; search goes to the OpenAlex API.
ReliabilityTitle search was retired on 2026-09-18 and answers 410; the DOI lookup API and the Data Feed are stated to stay. Unpaywall-format snapshots are no longer made, so a bulk copy is in the OpenAlex format.
NotesBulk path: the OpenAlex public snapshot (s3://openalex, unsigned), which carries the Unpaywall open-access fields in the OpenAlex format; the Unpaywall-format daily snapshot is part of the paid Data Feed.
