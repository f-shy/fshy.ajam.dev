The retention formula is quoted from the service's own plain-text interface page, which is the whole documentation.
Bindingper-object-cap 512 MiB is the hard stop for a single object; at 1 TiB a month that is 2 048 uploads, and the retention curve means the largest objects, which are the ones an archive needs, expire first at 7 days.
Identityanonymous No account, no email, no cookie. The reply body is the URL and the X-Token header is the only credential, for deletion of that one object.
EgressDownloads are served from crafterbin.glennstack.dev with no byte counter; the X-Token response header carries a management token for deletion.
free allowance: none published
Per-object capmax_size = 512.0 MiB (536870912 bytes)
Retentionretention = min_age + (max_age - min_age) * pow((1 - file_size / max_size), 3), with min_age 7 days and max_age 365 days; a small file therefore approaches a year and a 512 MiB file gets 7 days. 'expires' can be set in hours or as an ms epoch. (365 days)
Interfacerest, cli POST multipart/form-data to the bare host with field 'file', or field 'url' to have the server fetch a link. 'secret' (no value) asks for a long unguessable id; 'expires' takes hours or an ms epoch.
endpoint: https://crafterbin.glennstack.dev
Toolingcurl -F'file=@x' or curl -F'url=https://...' https://crafterbin.glennstack.dev; the service is 0x0.st-shaped, so an existing 0x0.st client works after a hostname change
Composes withIt is the only anonymous host among debrid providers that both stores a local file and pulls a URL server-side, so a user can hand it a URL and never upload the bytes itself, and its size-scaled retention gives small files the longest life of anything measured here.
ReliabilityA single hobby instance behind Caddy on Hunchentoot, with no published rate limit; the service runs on one privately operated server, so an outage is silent and unannounced.
NotesRemote URL retrieval operating without account registration. Files are stored on a single community instance, so retention depends on server availability.
