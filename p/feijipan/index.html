Per-object-cap: 10 GB per file for free users ('单文件上传最大支持10G，会员目前最大也是不超过10G'). request-rate: upload throttling exists but is undocumented. The netdisk-fast-download README warns '小飞机近期封号频繁' and that parser use from datacenter IPs is blocked. Free batch upload capped at 30 files.
Identityany-phone any-phone (PRC number for the 2 TB activity; the 1 TB needs a signed developer agreement).
EgressUnmetered and unshaped for everyone, including free: '下载不限速，百兆宽带，下载速度在75~80MB/S。无需开通会员即可享受不限速的下载。会员与非会员享同样的不限速'. Sharing links download without login.

ToolingParsed by both qaiu/netdisk-fast-download (fj, 3.4k stars, returns a 302 direct link via /parser) and ByLsPro/JxPan (Cloudflare Worker). No OpenList driver, no WebDAV. So it is a download target rather than a mountable drive.
Composes with1 TB per signed developer account; 2 TB per account via the activity path (time-limited). Accounts are email/phone based, so N accounts x 1 TB. Per-file 10 GB x unlimited files.
