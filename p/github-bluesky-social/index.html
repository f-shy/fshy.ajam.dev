Interfacecli http-xrpc
ToolingXRPC: POST /xrpc/com.atproto.repo.uploadBlob (binary body + Content-Type) -> returns a blob ref; must then be referenced by a record (e.g. app.bsky.feed.post embed) or it is garbage-collected. Client libs: @atproto/api, atproto Python SDK, goat CLI.
Composes withSelf-hosting a PDS removes the 5 MiB default (it is a config value), so a self-hosted PDS is bounded by YOUR disk, not Bluesky's — that makes it a hosting product, not free storage. On bsky.app's PDS the 5 MiB cap plus the reference requirement makes it useless for bulk. The usable margin is only the 'unreferenced blobs are deleted within minutes' semantics working in reverse: referenced blobs are retained indefinitely.
ReliabilityBlob GC is literal and fast. An upload without a referencing record vanishes. That is the single most important fact about this candidate.
