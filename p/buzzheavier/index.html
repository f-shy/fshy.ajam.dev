No per-file cap (docs: 'name max 500 chars' is the only field limit). Upload rate: 2 req/s and 10 concurrent uploads per IP observed on FileDitch-class peers; Buzzheavier returned no rate headers in probes. Download path is Cloudflare-Turnstile gated: a plain curl GET of a file page returns 403 'Just a moment', and /{id}/download?t=... returns HTTP 204 + 'Hx-Redirect' back to the file page unless the browser completes the human-verification step. Retention: 8d base / +2d per download / 60d cap / permanent at 30 downloads per 60 days; older policy was 15d/+3d/45d/15 downloads.

Composes withAnonymous PUT needs no account at all, so the ceiling is not per-account: it is 'as many files as you can push'. Account IDs are free, non-recoverable, email-less, and unlimited. The 45-day inactivity expiry resets when the same client re-downloads its own file (>10% or the download endpoint), and the same bytes may sit under 2-3 identifiers. Docs also expose ?expiry= and ?burner= for self-expiring uploads.
