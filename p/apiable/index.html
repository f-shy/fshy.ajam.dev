unit requests; metered on request-count; The monthly quota is the only published limit; at it the API answers HTTP 429, and Ratelimit-Limit, Ratelimit-Remaining and Ratelimit-Reset headers report the month's count. The plans page says historic data reach back to 1980 and the home page says 1940. Bulk path: none documented. The public-apis list marks the service as keyless, but a call with no valid key answered HTTP 401.
