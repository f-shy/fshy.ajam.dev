NotesThe cleanest IPv6-only row in this category, and the only one that solves the problem IPv6-only machines actually have. USD 0.99 a month for 256 MB, 5 GB SSD, a 100 Mbps port and 250 GB a month, in Sweden, in stock, with a USD 0.00 setup fee. The reason it beats the cheaper Axivora row is not price: it is that Privex runs its own DNS64 resolver and NAT64 gateway and pre-configures the micro VPS to use them, so an IPv4-only host such as GitHub still resolves. The vendor documents the mechanism, including the well-known 64:ff9b::/96 prefix, so this is a documented capability rather than an inference. Payment is cryptocurrency only and the order form states that plainly, which removes the card question entirely: there is no card field and no fiat rail, so there is no hold to state. The entity is corroborated two ways beyond the vendor's own words: an allocated AS210083 whose registered holder reads 'Privex Privex Inc.', and a contribution agreement in the vendor's own public repository describing 'the corporate entity Privex Inc. registered in Belize City, Belize'. What is not established: the Belize Companies registry record itself, which was reachable but was not queried by name in verification; and whether the 250 GB cap counts in one direction. One reliability note worth carrying: the vendor states port scanning or IPFS in the German and Finnish regions causes automatic suspension without warning, so the Swedish region this plan sits in is the safer choice. The 256 MB with Debian 12 is small but the plan family scales to 512 MB at USD 1.99.
