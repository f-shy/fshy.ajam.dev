Free 8 GB storage, unlimited file size, unlimited bandwidth. Rate limits: public upload init 500/hour (files <1 GB) and 30/hour (>=1 GB) per IP; chunks 500/hour; finalize 30/hour; bulk zip 10/hour per user. Anonymous downloads expire 7 hours after link generation; temp files auto-delete at 7 days.

Composes withrclone WebDAV mount + N free accounts x 8 GB permanent, or the anonymous 1 TB-per-file path for transit. The 8 GB cap is the binding number for storage; 1 TB/file only helps if something downstream holds the bytes.
ReliabilityPer-file cap without matching storage is the classic trap: 1 TB/file x 8 GB total means the big-file capability is unusable without paying. API init returns 401 'Authentication required' without a bearer token, so 'no account needed' only holds for the temp flow.
