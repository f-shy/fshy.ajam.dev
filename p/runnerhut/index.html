NotesA hosted GitHub Actions runner with a free pool large enough for a small private pipeline: 3,000 Linux minutes a month, no cache charge and no egress charge. The rates undercut GitHub list price on every family the page lists, and the one-minute minimum is the only rounding. The free pool is Linux only, and the runners are EU-hosted with data residency in six regions.
