Free tierFree for personal projects (USD 0/month): 10 monitors and 10 heartbeats with 3-minute checks, 1 status page, Slack and e-mail alerts, 100,000 exceptions per month, 5,000 session replays, 3 GB logs retained for 3 days, 3 GB traces retained for 3 days, 30 GB metrics, 3 GB web events retained for 3 days; no credit card
unit mixed; metered on ; The allowance mixes object counts (monitors, heartbeats, exceptions, session replays) and ingested bytes (3 GB per month each of logs, traces and web events, 30 GB of metrics), so no single unit of the vocabulary fits. The check frequency ranges from 3 minutes on free plans to 30 seconds on paid plans. Logs beyond the allowance cost USD 0.10 per GB ingested in Europe, USD 0.15 in the United States and USD 0.35 in Singapore.

Bindingretention-clamped Logs, traces and web events older than 3 days are deleted, so the free telemetry is a 3-day debugging window whatever the volume; the 10-monitor count binds the uptime side.
Identityemail The sign-up form asks for an e-mail address and sends a magic link; Better Stack's own comparison page states the free plan needs no credit card. Phone numbers are added after sign-up under Settings, Account settings, up to three per account. Whether a later step asks for a phone number at sign-up is unverified: behind a sign-up.
Egressunverified: no egress term on the pages read; logs and metrics are read back through a read-only HTTP SQL API
Per-object capunverified: no per-log-line or per-event size is stated on the pages read
RetentionLogs, traces and web events: 3 GB per month retained for 3 days on the free plan. Exceptions and session replays: 90 days. (3 days)
Interfacerest The Uptime (Incidents) API follows JSON:API with an Authorization: Bearer token, global or per team; logs and metrics are queried through a read-only HTTP SQL API with a username and password made per connection. The API host uptime.betterstack.com answered 401 to /api/v2/monitors without a token. The pricing page lists running SQL queries with an HTTP API among the features of the Logs & Traces product, whose included allowance of 3 GB per month is the free tier's, and lists standard querying as included; the SQL API documentation allows up to 4 concurrent log queries and 20 concurrent metric queries with standard querying. Whether a free account can create a SQL API connection is unverified: behind a sign-up. Telemetry is accepted as OTLP over HTTP at https://INGESTING_HOST/v1/traces, /v1/metrics and /v1/logs. A remote MCP server at https://mcp.betterstack.com takes OAuth or an API token and is available on every plan, including free.

ReliabilityLogs, traces and web events are deleted after 3 days on the free plan.
NotesOne account covers uptime checks, heartbeats, a status page, logs, traces, metrics, error tracking and session replay. The telemetry part is small and short-lived (3 GB a month kept 3 days); the uptime part is 10 monitors at a 3-minute interval. Logs was sold as Logtail before the products were unified into Better Stack, and logtail.com now redirects to betterstack.com/log-management; an archived copy of Logtail's pricing page lists a free plan of 1 GB per month with 3-day retention, against 3 GB per month with 3-day retention on the Better Stack free plan now.
