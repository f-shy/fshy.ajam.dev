Bindingvolume-quota The R500 welcome credit is spendable only after a first card payment and bounds how long a sandbox runs; the two-sandbox cap bounds concurrency, not the balance.
Identitycard Sign-up asks for first name, surname, email and password, or a third-party sign-in; usage is charged in rand from a prepaid balance topped up by card through Paystack, and the R500 credit is released only after the first card payment.
EgressSandboxes cannot reach each other, private networks or cloud metadata; egress is limited to the public internet. Managed internet transfer is not separately priced on the pricing page.
Per-object capnot applicable: the unit is a sandbox with up to 5 GB of disk on a free account, not a stored object
RetentionFiles, installed packages and browser logins live on persistent disks and survive restarts; when credits run out, running sandboxes are paused rather than deleted.
Interfacerest, ssh A public HTTPS address per sandbox, SSH access, file APIs, a Python SDK and a hosted MCP server at api.ventaw.com/mcp.
endpoint: https://ventaw.mmogomedia.com/v1
ToolingPython SDK, REST API, hosted MCP server, SSH and file APIs; noVNC for browser and desktop templates.
Composes withR0.45 per vCPU-hour and R0.15 per GB-hour put a two-vCPU, 4 GB sandbox near R1.50 an hour; a public HTTPS URL lets an agent hand results to a separate object-storage record.
ReliabilityWhen the prepaid balance reaches zero, running sandboxes are paused; the vendor states it does not promise that the service will never be interrupted and does not promise data restoration from backups.
NotesPrices are published in South African rand: R0.45 per vCPU-hour, R0.15 per GB-hour and R3.00 per GB-month give about R1.50 an hour at two vCPU and 4 GB, which is roughly the operator list's $0.091 an hour at the rand exchange rate; no first-party USD price is published. The R500 welcome credit follows a card payment, so the free usage is card-gated. There is also an R100 per 30 days always-on plan for one 512 MB VM.
