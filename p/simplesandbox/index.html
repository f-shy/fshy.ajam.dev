'No duration limits' and '~1s cold start' are the advertised shape. Auto top-up adds 1M credits (USD 1) when the balance runs low, which quietly converts a free tier into a paid one.
Bindingvolume-quota USD 1 of CPU credit is spent in about 39 vCPU-hours at the published rate, so an always-on 1 vCPU sandbox exhausts the free month in under two days.
Identityemail 'No credit card required' on the Free plan, with a free API key issued at app.simplesandbox.dev. Card types for paid plans and any authorisation hold are not stated on the page read.
EgressNo network fees: the pricing docs state billing is per-millisecond for compute and memory with no network fees; no traffic allowance is stated.
Per-object capnot applicable: the unit is a sandbox, not an object; no memory or disk allocation is published per sandbox
RetentionThe sandbox advertises 'No duration limits'. Persistent volumes are 1-100 GB, one per sandbox, single attachment, 'currently free only during beta' with future pricing unpublished.
Interfacerest, cli TypeScript/Node SDK ('import { Sandbox } from '@simplesandbox/sdk')') and a REST API, with a free API key issued from the app.
ToolingThe vendor SDK; the sandboxes run on Fly.io infrastructure under the vendor's own isolation.
Composes withA genuinely free, no-card code-execution endpoint with a USD 1 monthly credit is useful as a fallback executor but not as a machine: 1M credits buys about 39 vCPU-hours of CPU time and the memory meter is not published, so it cannot be sized as an always-on box.
Reliabilityno reliability event observed; the platform is a thin layer over Fly.io Machines, so its availability follows a third party's.
NotesArithmetic from the published CPU rate alone: 1 vCPU × 730 h × USD 0.0252 = USD 18.396 a month of CPU time, before any memory charge, which the page does not publish. That number is deliberately not promoted to m24h_usd because a record cannot claim a 24/7 total from one of two meters. The free allowance is USD 1, which is 39.7 vCPU-hours. Region and egress are unverified.
Evidence notedocumented The credit price, the CPU rate, the plan prices, the concurrency caps and the no-card claim are quoted from the vendor's homepage read. The memory meter and the disk rate are not published, so no 24/7 total for a shape is recorded: the vCPU figure alone would understate the bill. What would raise it: the docs' billing page, or an account that reads the meter.
