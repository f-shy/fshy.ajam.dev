Bindingvolume-quota 5 requests a second allows far more than 3,000 credits in a day, so the daily credit quota is met first
Identityemail an account at myprojects.geoapify.com created with an email address, a password of at least 8 characters with its confirmation, an accepted-terms checkbox and a reCAPTCHA, or with Google or GitHub sign-in; a verification link is emailed after sign-up; no credit card for the Free plan
Egressnot applicable: a query API metered in credits, not bytes
Per-object capa batch geocoding job takes up to 1000 addresses
Interfacerest HTTPS to api.geoapify.com/v1/geocode/search and /reverse with the key in the apiKey parameter, and an asynchronous batch endpoint at /v1/batch/geocode/search (POST a job, GET the result as JSON or CSV); a request without a key answers HTTP 401 Invalid apiKey
endpoint: https://api.geoapify.com/v1/geocode/search
Toolingany HTTP client; vendor NPM libraries, an API playground and a batch playground
Composes with3,000 storable credits a day with no card: 3,000 single geocodes, or more addresses through batch jobs of up to 1000 at 0.5 credit each, with results kept with no limit; the same key serves map tiles at 4 tiles a credit. Bulk path: the batch endpoint, plus free country-by-country downloads of OSM-derived localities and postcodes
Reliabilitythe daily quota is soft and the rate is not throttled at once, but steady overuse brings an upgrade request and the account can be blocked if it is ignored; spreading requests over several accounts or projects to stay on a lower plan can disable access
