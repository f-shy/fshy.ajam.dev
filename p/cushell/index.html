Bindingnone A soft cap of 50 Mbit/s per tunnel is published and no byte quota is, so no byte volume is capped. The other limits are shape limits the vocabulary does not name: tunnel count, one tunnel per prefix, and auto-deletion of inactive tunnels. Reachability is IPv6-only, and SIT/GRE need a public IPv4.
Identityemail 'Sign in your way - Google, GitHub, or email. Privacy-first authentication with no vendor lock-in and no unnecessary tracking.'
Egressno monthly byte allowance is published; the terms state a fair-usage soft cap of 50 Mbit/s per tunnel and the FAQ names tunnel count and a best-effort basis; ingress: tcp+udp
free allowance: none published
Retentionnot applicable: a live tunnel, not stored bytes; tunnels inactive 7+ days are auto-deleted
Interfacecli, rest 'Create, manage, and monitor tunnels programmatically' via a REST API; configurations are also downloadable from the dashboard
Toolingwg-quick; iproute2 for SIT/GRE; REST API claimed
Composes withone /64 per tunnel and a browser-free config download make it a fast way to give a single free VM a public address; three tunnels per account covers three instances.
Reliabilityhobby network, 'no SLA': 'This is a hobby project provided on a best-effort basis with no SLA.' The terms add that routes, tunnels and access may change at any time.
NotesA /64 rather than a /48, which still gives every port and protocol but no room to subnet. The REST API is claimed on the landing page; the API documentation URL (?page=api) returned a 504 on 2026-10-23, so whether an API can mint a WireGuard profile unattended is unestablished. Uplinks listed as Cilix Limited and Hurricane Electric LLC; AS209552 is described as a hobby network run by an individual in Belgium.
