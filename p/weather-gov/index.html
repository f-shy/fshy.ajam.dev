Free tierOpen data with no fee, no key and no registration: forecasts, alerts and observations for the United States from api.weather.gov; a User-Agent header is required and the request rate limit is not published.
unit requests; metered on request-count; Station observations are kept for 7 days and alerts for 7 days; a point outside the United States answers HTTP 404. Bulk path: the NOMADS server (120 hits a minute per IP address, counted across the NCEP hosts) and the NOAA Open Data Dissemination buckets on cloud platforms, open to the public; NWS alert archives are held by NCEI.

Identityanonymous No sign-up and no key: a User-Agent string, which can be anything and may carry a contact, is the only identification; the vendor plans to replace it with an API key.
Egressnot applicable
Retentionstation observations are retained for 7 days and alerts for the past 7 days (7 days)
Interfacerest REST over HTTPS at api.weather.gov (GeoJSON, JSON-LD, DWML, CAP and ATOM by the Accept header); an OpenAPI 3.1 specification is published at api.weather.gov/openapi.json
endpoint: https://api.weather.gov/points/{latitude},{longitude}
Toolingany HTTP client that sets a User-Agent; OpenAPI specification for generated clients
Composes withA keyless official US forecast and alert source; pair with api.met.no for coordinates outside the United States and with NOAA's NODD buckets for model files.
ReliabilityA request without a User-Agent answers HTTP 403; over the unpublished limit the API errors and recovers after about 5 seconds.
NotesBulk path: NOMADS and the NODD cloud buckets; no dump through the API itself.
