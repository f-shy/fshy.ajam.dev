Limits
  • per-object-cap 100 DNS records per zone on Solo, including system records; the zone cannot go above the limit source
  • request-rate 2,400 API requests per hour per account by default, 30 per hour per IP unauthenticated, 60 domain availability checks per hour per account source
  • retention-clamped (binding) the 30-day free trial is available once; the card is charged when the trial ends unless cancelled first source
Bindingretention-clamped there is no standing free allowance: the 30-day trial ends once and then every active zone costs USD 0.50 per month, so the trial clock binds before the 100-record cap or the API request rate does
Identitycard the signup form asks for an email address and a password of at least 16 characters with two character types, and offers Google sign-in; an account can be created and the dashboard explored without a plan, but activation to add records needs payment details, and every self-service plan including Solo requires a credit or debit card with no alternative payment method (https://app.dnsimple.com/signup, https://support.dnsimple.com/articles/account-creation, https://support.dnsimple.com/articles/payment-methods, https://support.dnsimple.com/articles/account-activation/)
Egressthe metered quantity is authoritative DNS queries, not bytes out; a zone within its included query allowance has no query fee, and volume above it is billed per million queries
free allowance: 50,000 queries per zone per month on Solo
Per-object cap100 DNS records per zone on Solo, including system records; a zone on Solo cannot grow above the limit, and records above it cannot be added until some are deleted or the plan is changed
Retentionzones persist while the subscription is active; the 30-day free trial is available once, and the card on file is charged when the trial ends unless the account cancels first (30 days)
Interfacerest, cli the DNSimple API is a REST web service API that provides access to domains, zones, records and certificates, authenticated with an access token; the official DNSimple CLI is a command-line interface for that API, and a Terraform provider is published
Toolingthe DNSimple CLI, Terraform provider dnsimple/dnsimple, and official API client libraries for Ruby, Go, Elixir, Node.js, .NET, Java, PHP, Python and Rust
Composes withan authoritative DNS host with a full REST API and CLI, usable as primary or secondary DNS, with DNSSEC and Anycast, that a reader scripts against via token; every active zone carries a monthly charge
Reliabilitythe API returns HTTP 429 when the hourly or per-IP request limit is reached; an expired email verification link after 7 days blocks subscribing and registering until a new one is requested
NotesThe Solo plan has no base fee but no standing free allowance: a one-time 30-day trial, then USD 0.50 per active zone per month plus query volume above 50,000 per zone. A card is required to activate even the free tier. The free tier uses unit none because there is no recurring free amount; the trial is described in retention and the limits rows. No live DNS read was probed. The CLI and Terraform provider are clients of the hosted API, not self-hosted software.
