No numeric quota, rate or object cap is published on the public site; the binding constraint is that the reader installs and operates the server, not a meter.
Bindingvolume-quota The $5.00 of usage is what runs out first at $0.04 per vCPU-hour; the 60-minute free life and the two-sandbox cap bound a session, not the account balance.
Identityanonymous An agent can sign itself up with POST /signup and no person and no card, getting an API key and a claim link for a person; a person signs up in the dashboard with GitHub, Google, GitLab or email and a verified email, and the free credit comes once per person. A card is needed only for full-size sandboxes, CI installation and auto top-up.
Egressnot published for sandboxes: the pricing page names previews and public URLs but states no egress allowance or per-GB price
Per-object capnot applicable: the unit is a 20 GB sandbox disk, not a stored object; retained disks and volumes are billed per GB-month
RetentionOn the free plan each sandbox lives at most 60 minutes from its start and pausing does not stop that clock; a link nobody claims stops working after a month.
Interfacerest, cli, ssh REST API at https://api.groundbox.dev/v1, a Node CLI, SDKs and a hosted MCP server; a sandbox is a Linux VM with exec and file endpoints.
endpoint: https://api.groundbox.dev/v1
Toolingcurl against the REST API, the groundbox CLI, Python and TypeScript SDKs, and MCP clients; a sandbox command runs with sh -c and a WebSocket streams output.
Composes with$0.04 per vCPU-hour running and $0.05 per GB-month paused make a two-vCPU sandbox about $0.08 an hour, which can hand off to S3-compatible buckets and an image registry on the same account.
ReliabilityAt a spend cap, creating or starting a sandbox is refused and running sandboxes are stopped; a sandbox older than 60 minutes on the free plan is deleted with its save points, and a team may be suspended.
NotesThe free plan's $5 of usage covers the per-second sandbox meter; at $0.04 per vCPU-hour a two-vCPU box costs $0.08 an hour. A card is not needed to start but is needed for full-size or long-running sandboxes, and the 60-minute free life is a hard session ceiling. A separate file-sync product on groundbox.io is not this offer.
