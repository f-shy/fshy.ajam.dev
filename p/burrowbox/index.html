Free tierWelcome credit: USD 1, added once your email is confirmed and your card is saved; machines cannot be started without a card on file with auto-refill.
unit credits; metered on wall-clock; The USD 1 is a one-time welcome credit, not a recurring allowance, and it is gated on both email confirmation and a saved card. A card on file with auto-refill is required to start any machine; without a card, creating or starting a machine returns 402.
Pricenone stated
Limits
  • volume-quota USD 1 one-time welcome credit, only after email confirmation and a saved card source
  • write-gated (binding) Without a card, creating or starting a machine returns 402; auto-refill charges the card when the balance falls below a chosen threshold (default USD 5) by a set amount (default USD 20) source
Running machines are stopped when the balance reaches zero and their state is kept; admin accounts do not need a card.
Bindingwrite-gated The card on file with auto-refill is the first gate: no card means no machine can start at all, even with welcome credit, and the credit itself is conditioned on the card being saved.
Identitycard Registration posts email, password and name (POST /api/auth/register) and sends a confirmation email; the billing page states the welcome credit is added once the email is confirmed and a card is saved, and that starting machines requires a card on file with auto-refill. No phone or ID document is stated.
EgressA VPN add-on is priced separately: Proxy at +USD 0.03/h and USD 10/GB, Unlock at +USD 0.06/h and USD 15/GB and USD 3 per 1k connections; no base egress allowance is stated on the billing page.
Per-object capNot applicable: the unit is a machine, not an object. Machine sizes are tiny (0.5 vCPU, 4 GB RAM, 8 GB disk), small (1 vCPU, 6 GB, 12 GB), medium (2 vCPU, 8 GB, 16 GB) and large (4 vCPU, 12 GB, 20 GB).
RetentionA stopped machine keeps its entire filesystem snapshot, installed apps, browser profiles with cookies, and open windows and tabs until the user destroys it; stopped (snapshot) machines cost USD 0.001 per hour.
Interfacerest, cli An MCP endpoint per machine plus a REST API (POST /api/machines, GET /api/machines/{id}/screenshot.jpg) and a dashboard; bearer tokens are API keys (tmk_), machine tokens (tmm_) or OAuth tokens (tmo_).
endpoint: https://burrowbox.dev/api
ToolingAny MCP client, including Claude Code and Cursor, connects over HTTP to a machine's MCP URL; a REST API and a web dashboard also drive machines.
Composes withA machine's persistent browser logins and credential vault survive stop/start, so a long agent task can resume signed in; a per-machine token can be handed to a customer's agent while the platform key stays on the operator's server.
ReliabilityA running machine with an empty balance is stopped and keeps its state; the whole disk is snapshotted on stop and a save point is taken every 30 minutes while running, so at most 30 minutes of change can be lost on a crash.
NotesA persistent Linux desktop machine with a signed-in browser and credential vault, not a short-lived ephemeral sandbox. Price at the 2 vCPU/8 GB medium size is USD 0.16 per running hour, billed by the minute; a stopped snapshot is USD 0.001 per hour. The USD 1 welcome credit is a one-time credit gated on email confirmation and a saved card, and a card with auto-refill is required before any machine can start. The list price at 2 vCPU/4 GB would be USD 0.11/h on the small size, but the small has 1 vCPU/6 GB, so no 2 vCPU/4 GB shape is sold here.
