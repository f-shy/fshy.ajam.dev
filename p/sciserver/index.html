Free tierAnyone can create a free account and run Jupyter notebooks on SciServer Compute containers that sit next to the hosted data. The persistent quota is 10 GB per user and "you may only create up to three containers". The site describes its purpose as letting researchers work with terabytes or petabytes "without needing to download any large datasets", and the default image ships Python 3.7, R 3.6.2, Jupyter Notebook 6.0.3, JupyterLab 1.2.6, TensorFlow 2.0.0 and PyTorch 1.4.0.

Composes withThe composition is data locality rather than raw capacity: SciServer hosts SDSS, GALEX and Gaia releases next to the containers, so a 10 GB quota is not a limit on the analysis because the terabyte inputs never enter the user volume, which is the opposite trade from every other free tier in documented records.
Reliabilityno reliability event recorded
NotesTwo facts argued against a stronger verdict. The image list is frozen around 2019 and 2020, with Python 3.7 and PyTorch 1.4 presented as current, which means the platform's software is roughly six years old and modern packages may not be installable on that base; and no per-container CPU or memory ceiling is published, so the compute side of the offer cannot be sized from the documentation. The 10 GB figure is quoted from the project's own 2021 how-to because the current policy page sits behind a login, and a 2021 figure for a live quota is older than a reader should trust without rechecking. Registration needs only an email or a linked identity. The image-era facts are the ones most likely to be stale in six months.
