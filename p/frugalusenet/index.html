Interfacenntp NNTP over TLS on port 563. No HTTP or object API exists for the download path, which is driven through SABnzbd, NZBGet or nzbdav.
Composes withOne subscription gives a NetNews primary plus a UsenetFarm bonus server, the cheapest two-backbone stack in the sector; add a block only for content older than 5,000 days.
ReliabilityTwo backbones in one plan: NetNews as primary and UsenetFarm as the bonus EU fill server, which is the cheapest way to get two independent feeds without buying two subscriptions.
