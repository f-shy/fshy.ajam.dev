Per-IP bandwidth shaping restricts download rates. Probes observed approximately 128 KB/s on file retrieval, compared to higher throughput from alternative CDN endpoints.
Bindingper-ip-shaping one stream is shaped, and aggregate throughput is the shaped rate times the number of streams
Identityanonymous anonymous
EgressFree, anonymous, no key. These are community-run mirrors of the GitHub CDN, funded by volunteers. Hence the polyculture of hostnames (gh-proxy.com, ghproxy.net, ghfast.top, gh.api.99988866.xyz) and the constant churn.
Interfacerest rest
ToolingPrefix form: https://ghproxy.net/https://raw.githubusercontent.com/<owner>/<repo>/<ref>/<path> and .../https://github.com/<owner>/<repo>/releases/download/<tag>/<asset>. Nothing else to install.
Composes withServes as an edge mirror for GitHub release assets alongside raw file mirrors. Proxies allow distributing reads across ghproxy.net, ghfast.top, and other mirrors for public release downloads.
ReliabilityTreat as a bandwidth multiplier for large files, never as an availability guarantee. Their own issue trackers document the churn (hunshcn/gh-proxy#116 mirror list, 'ghproxy.com 打不开了').
