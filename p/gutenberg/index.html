Limits

  • request-rate the vendor's own harvest example uses wget -w 2 (two seconds between requests); mirrors are the approved bulk path source
Bindingper-ip-shaping At 1 TiB/month the main site blocks the caller long before any byte cap; the mirror network is the only path that carries that volume, and the mirror list is what makes the quota effectively unlimited.
Identityanonymous The home page states 'No fees, no registration, completely free'. No account exists to create; a mirror operator is a volunteer arrangement, not a registration that is needed.
EgressFree and unmetered from the main site and from every mirror. The main site is not a bulk endpoint: 'This website is intended for human users only. Any perceived use of automated tools to access this website will result in a temporary or permanent block of your IP address.' Bulk is approved through rsync mirrors, which the mirroring guide documents.
free allowance: no byte allowance published
Per-object capnot applicable: one file per book per format. No per-file cap is published; the largest objects in the tree are audio ZIPs, and the file list is the only inventory.
Retentionpermanent: the mirroring guide describes a fixed collection that 'changes daily, as new items are added or updated', with no expiry clock.
Interfacerest, rsync, cli plain HTTPS per file (https://www.gutenberg.org/cache/epub/<id>/pg<id>.txt), an OPDS feed at /ebooks/search.opds/, a JSON OPDS2 feed 'currently available for testing', GUTINDEX.ALL and metadata.json for inventory, and rsync mirrors listed in MIRRORS.ALL.
endpoint: https://www.gutenberg.org/cache/epub/<id>/pg<id>.txt
Toolingwget/curl, rsync against any mirror, the OPDS feed for readers. The robot policy's own example is 'wget -w 2 -m -H "https://www.gutenberg.org/robot/harvest?filetypes[]=html"' - two seconds between requests, from the main site, for a bounded harvest.
Composes withThe canonical public-domain text corpus to pair with LibriVox audio and Internet Archive scans of the same titles; a 2.44 TB rsync mirror can be filtered to the zip files only, which drops the audio weight.
ReliabilityMain-site IP blocks are automatic and last days; the generated collection is rebuilt in batches, so a mirror refresh sees traffic spikes rather than a steady delta.
NotesCaveat is the main site, not the catalogue. The catalogue is 2.44 TB and mirrorable, which is more than the stated archive of 20 TiB needs from this one source, but the main site will block a bulk puller within a day. The abandoned route is 'scrape gutenberg.org with parallel connections': the robot policy names it as a blockable offence and the mirror path costs nothing.
Evidence notedocumented The collection size is the vendor's own metadata.json, fetched here; one complete file was downloaded and hashed. What would raise it to measured for the bulk path is an rsync of a filtered subset from a mirror with a byte count, which was not run.
