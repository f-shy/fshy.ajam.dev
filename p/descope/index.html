Bindingvolume-quota The 7,500-MAU ceiling binds first for a growing app; unlike paid tiers, Free Forever has no overages, so passing the user, tenant or SSO limit needs an upgrade.
Identityemail The console sign-in page asks for an email address and offers Google, GitHub, Microsoft and SSO as alternatives; the marketing sign-up page invites a Free Forever account. The pricing page states no credit card for Free Forever. Whether a later registration step asks for a phone number or a card is unverified: behind a sign-up.
Egressnot applicable: a hosted authentication API; no traffic allowance or per-GB egress price is published
Per-object capunverified: no per-object size cap is stated on the pages read; the platform applies a 200-task cap per flow and a 100-user cap on a batch create when a cleartext password is used
RetentionAudit events are retained for 1 week on Free Forever, 1 month on Pro and Growth, and a custom period on Enterprise (7 days)
Interfacerest A REST API over HTTPS with JSON request and response bodies, documented by a downloadable OpenAPI file. Sign-up and sign-in endpoints take the Project ID as a Bearer token; user-scoped endpoints take Project ID and Refresh JWT; management endpoints take a Management Key or Access Key. A 429 answer with a Retry-After header signals a rate limit.
endpoint: https://api.descope.com
ToolingBackend SDKs for Node, Python, Go, Java, Ruby, PHP and .NET, a descope CLI, the REST API with an OpenAPI description, the visual Flows builder, and embeddable admin widgets
Composes withAn OIDC or SAML identity provider in front of apps on free compute, with visual sign-in flows, passwordless and social login, MFA and RBAC; user management runs through the Management API.
ReliabilityRate-limited calls return HTTP 429 with a Retry-After header. Beyond 7,500 MAUs, 10 tenants or 3 SSO connections a warning email and a grace period apply before the app may lose access.
