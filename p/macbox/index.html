Native iOS Xcode projects, workspaces, Swift packages, CocoaPods and XcodeGen are supported on the iOS simulator; React Native, Flutter, signing and TestFlight are not supported by the service itself. The VM has no inbound access to other VMs or the provider network.
Bindingvolume-quota The prepaid credit at USD 0.05 a minute is what depletes first for repeated builds; the 30-minute job and 10-minute unwatched-session caps bound each run.
Identityemail the setup guide says the user signs in with GitHub and a new account gets USD 10 of credit; the sign-in page is a GitHub OAuth prompt asking for a GitHub username or email address and password and requesting read:user and user:email scopes. No card field appears at signup; a cloud agent uses a key added as a secret instead of an interactive login.
Egressthe VM can reach the internet but cannot reach other VMs or the provider network; no transfer allowance or per-GB price is published
Per-object capnot an object-storage offer; no per-file size ceiling is published on the landing or setup pages
Retentioneach user gets their own macOS VM and its build cache stays between runs; unused for 14 days and all of it is deleted, or immediately with macbox purge; a device build archive is kept for 24 hours (14 days)
Interfacecli, rest a macbox CLI and an MCP server that exposes build, test, run, screenshot and simulator interaction tools to Claude Code, Codex, Cursor and other agents; setup uses the guide at api.macbox.build/guide
endpoint: https://api.macbox.build
Toolingone CLI installed with curl or a package manager, plus an API key obtained at signup; agents call macbox commands or the MCP tools, and the Xcode-facing tools run MobileBuildMCP on the hosted Mac
Composes withan agent runs macbox build and macbox test from a Linux or cloud sandbox, gets a live simulator link for run and ui interactions, and receives a signed-off-device archive to sign and upload elsewhere.
ReliabilityThe macOS VM is isolated: it reaches the internet but not other VMs or the provider network. It is deleted after 14 days unused, or immediately with macbox purge. A live session ends after 10 minutes without a viewer or at the 30-minute job limit. Signing and TestFlight are not performed by the service.
NotesThe operator's provider list quotes USD 3.00/h billed per minute, which matches the vendor's USD 0.05 per Mac minute (derived: 0.05 x 60 = USD 3.00 per hour).
