Free tierUnlimited. Free plan: 'Unlimited episodes and unlimited audio, with no storage cap', 'no trial and no expiry date', 'Your episodes are never deleted'. Only three stated limits: one podcast per account, 30 days of analytics history, one voicemail. Max file size 2 GB per episode. With unlimited episodes that is unbounded total capacity.

ToolingOfficial public REST API (api.rss.com/v4, X-Api-Key header, 10 keys/account) that 'create[s] new episodes, upload[s] audio'. But it is gated to the Max plan, NOT Free. On Free the only path is the web UI (no public upload endpoint verified). Third-party native integrations exist (Hindenburg, Auphonic, Zapier) but likewise target paid/API plans.
Composes withN free accounts x unlimited episodes x 2 GB. Card required 'to verify the account' (never charged) is the only friction, so accounts are not trivially mass-produced the way an email-only signup would be. Also accepts .mkv/.mp4/.flac/.wav/.aiff/.ogg/.aac, so non-audio payloads pass the extension filter.
