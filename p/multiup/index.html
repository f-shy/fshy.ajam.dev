Retentionunverified: retention follows each destination host's own policy, and no aggregate statement exists.
Interfaceunknown A web upload form at /en/upload/from-links that accepts HTTP or FTP source links, a host checklist, a terms checkbox and 'Parallel upload'. No API documentation page was found.
ToolingBrowser. The service is designed for interacting uploaders; no CLI or API is documented, so a wrapper drives the form.
Composes withIt turns one URL into N host copies, which is the mirror half of a storage plan: the same file survives one host dying. It does not download to the caller at all, so it composes with a later fetch from whichever host is alive.
ReliabilityMirroring multiplies failure: each destination host can reject, throttle or delete the copy independently, and the index page then lists mixed online/offline links. The site is ad-funded and has run since 2008.
NotesThe best URL-to-many-hosts relay found: one pull, thirty copies, no bandwidth through the caller. The caveat is the account and the 512 MB floor when Filer.net is selected.
