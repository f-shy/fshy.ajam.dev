Interfaceunknown Web form: paste a link, the service fetches it ('Загрузка в один клик'). The account terms state a full API for each account ('каждому аккаунту предоставляется полноценное API'); its protocol and documentation were not found.
ToolingBrowser form, plus an account API stated in the terms. Generated links are valid for up to 24 hours ('Созданные ссылки имеют срок действия до 24 часов со времени генерации'), and the output is a download served by transload.me, so a download manager can take it.
Composes withA cheap per-GB top-up for the handful of hosts a seedbox cannot reach; not a substitute for a full debrid because the host list is 28 names and the speed floor is 1 MB/s.
ReliabilityThe /ru/?p=price tariff page returns an empty body to the readers tried; the per-host pages under /en/premium/ carry the per-GB price. The third-party group-buy thread that carried an earlier RUB price answers 'Запитана тема не знайдена' (topic not found) on 2026-11-03.
NotesOne of very few RU-language multi-hosters still answering in 2026. The caveat is the price: the vendor hides it behind login and the only public figure is 20 months old. The 1 MB/s floor is the number to judge it by, not the host count.
