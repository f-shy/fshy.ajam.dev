Bindingwrite-gated The capacity is unlimited on paper and the gate is a provenance rule plus an upload path nobody has documented. Until one large non-GoPro file is uploaded and accepted, the offer is 100 GB at USD 59.99/yr, which is bad.

Composes withThe most valuable unresolved lead in its group and it is one upload experiment, not a research question. ReliabilityNo public wrapper implements upload, so the write path is undocumented rather than absent: the Quik app clearly uploads. Treat the write path as unproven. The supported non-GoPro file types are MP4, Quicktime/MOV, JPEG, ASF and PNG
