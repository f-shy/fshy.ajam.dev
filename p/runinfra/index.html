Free tier$1 free for a new account. A workspace has one balance, and one credit is USD 1. Two things add to it: the free signup credit of USD 1, once per account, which never expires, and top-ups from USD 5, which last one year from purchase. At zero balance, calls answer 402 and are not billed.
unit credits; metered on none; one-time signup credit, not recurring: at the listed DeepSeek V4.1 Flash input price of USD 0.15 per 1M tokens, USD 1 buys about 6.7M input tokens if spent on input alone
Pricenone stated
Limits
  • request-rate 10,000 requests per minute per key before the first purchase; 50,000 after a purchase from USD 5; 200,000 at USD 200 in total purchases. The signup credit does not raise the limit. source
  • volume-quota (binding) USD 1 in credit once on signup, never expiring; top-ups from USD 5. At zero balance, calls answer 402 and are not billed. source
Tokens per minute are each model's own default before USD 50 in purchases, then at least 20,000,000 per minute at USD 50 and no practical limit at USD 200. Concurrent requests are about a quarter of each model before the first purchase.
Bindingvolume-quota The one-time USD 1 balance is spent before 10,000 requests a minute is reached at ordinary model prices; after a top-up the request-rate limit becomes the next constraint.
Identityemail Sign in with Google, GitHub or an email link, at the email address you already use. If you have no account yet, the first sign-in creates one, with no card required and USD 1 in credit. SAML or OIDC single sign-on is not available today. A card is asked only for a top-up from USD 5, not for the free credit.
Egressnot published: the pricing and account pages state zero data retention and prompt caching but no egress allowance, quota or per-TB price.
Per-object capnot applicable: the unit is API tokens and prepaid credits, not stored objects.
RetentionZero data retention by default. Request and response content is never used for training.
Interfacerest, cli OpenAI-compatible Chat Completions at /v1/chat/completions and Anthropic-compatible Messages at /v1/messages through one workspace key, plus the runinfra command-line tool for setting up coding agents.
endpoint: https://api.runinfra.ai/v1
Toolingthe user installs an OpenAI- or Anthropic-compatible SDK or the runinfra CLI and connects to the hosted API; no server binary is run by the user and no hardware is owned.
Composes withOne key reaches the OpenAI-compatible and Anthropic-compatible routes, so an existing agent loop can be pointed at RunInfra; the free credit is spendable on both, but the 10,000-requests-per-minute key limit and the one-time USD 1 balance bind first.
ReliabilityRequests return 402 at zero balance, and a rate-limited request returns 429 with Retry-After; shared-model congestion errors are not cleared by purchases.
NotesThe free offer is a one-time USD 1 credit, not a recurring allowance, and the service is a paid-per-token hosted inference API. Token prices range from USD 0.05 per 1M input tokens on Nemotron 3.5 Lightning 30B to USD 1.60 on Kimi K3.1 Pro; cached input is cheaper. The API list needs a key (HTTP 401), so no endpoint was probed beyond reachability. A separate startups program offers up to USD 2,700 in credits after approval and is not the published free tier.
Evidence notedocumented The free credit, token rates, key rate limits, sign-in methods and egress silence are quoted from the vendor's own pricing, docs and account pages read on 2026-11-24; the API base URL was probed and answered 401 without a key.
