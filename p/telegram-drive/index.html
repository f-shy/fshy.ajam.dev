Interfaceunknown A GUI application over MTProto (Rust/Tauri/Grammers per the repository); no public HTTP API or CLI is documented. Desktop folder sync is the automation surface.
ToolingWindows, macOS (Intel and Apple Silicon), Linux, Android and Google TV builds, released on GitHub.
