Free tierThe free Community edition: what n8n runs without a license key, with almost the complete feature set of n8n, installed and run by the user on a machine of their own; registering an email address for a free license key unlocks folders, debug in editor and custom execution data
unit none; metered on none; n8n's documentation scopes the execution quota to paid plans, cloud or self-hosted, and the Community edition is not a paid plan. The hosted 14-day Cloud trial is dev-services/n8n-cloud and comes first.
Pricenone stated
Limits
  • per-object-cap 16 MiB payload size by default, raised with N8N_PAYLOAD_SIZE_MAX source
  • retention-clamped saved executions are pruned by default after 336 hours (14 days) or beyond 10000 stored executions source
The Community edition omits paid features such as SSO, environments, external secrets and log streaming. The Docker Compose setup needs at least 4 GB of RAM and 2 vCPUs. The default execution timeout is disabled (-1), and users can set up to 3600 seconds for an individual workflow.
Bindingnone The documentation states no quota for the Community edition; the machine that runs it bounds throughput, and the pruning and payload defaults are environment variables that the user changes.
Identityanonymous No account with n8n is needed to install and run the Community edition: the one-line setup and Docker Compose pages ask for none, and the account is created on the user's own instance at its initial account creation. Registering that instance with an email address is optional and sends a free license key.
Egressnot set by the software: workflows call third-party APIs from the machine the user runs n8n on, so that host's network terms apply
Per-object cap16 MiB maximum payload by default (N8N_PAYLOAD_SIZE_MAX), raised by setting the variable higher; 200 MiB for files in form-data webhook payloads by default (N8N_FORMDATA_FILE_SIZE_MAX)
Retentionsaved executions are deleted on a rolling basis by default, after 336 hours (14 days) or beyond 10000 stored executions; the user changes both settings with environment variables (14 days)
Interfacerest, cli the n8n public REST API is available on all self-hosted editions, and the n8n CLI wraps that API; workflows are also built in the web editor
Toolingthe user installs and runs n8n on a rented or free machine: the one-line setup script (curl -fsSL https://get.n8n.io | sh) or a Docker Compose setup, with the built-in SQLite database or Postgres; the web editor, the public REST API and the n8n CLI. From n8n 3.0, n8n is only distributed through Docker.
Composes withLast resort after the hosted workflow offers (the 14-day n8n Cloud trial in dev-services/n8n-cloud, and the hosted free tiers of Pipedream, Zapier and Inngest): triggers, schedules and integrations run on a machine that the user installs and keeps running.
ReliabilityThe user provides, maintains and keeps running the infrastructure; saved executions are pruned by default after 14 days; from n8n 3.0 n8n is distributed only through Docker and npm installs are deprecated.
NotesSelf-hosted software and the last resort: the hosted offers come first (the 14-day n8n Cloud trial in dev-services/n8n-cloud, and the hosted free tiers dev-services/pipedream, dev-services/zapier and dev-services/inngest). This record is no duplicate of dev-services/n8n-cloud: it is the Community edition that the user installs and runs.
Evidence notedocumented Editions, install paths, the public API, the pruning and payload defaults and the excluded features are read on first-party documentation pages; the installation was not run, and no execution quota for the Community edition is stated on those pages.
