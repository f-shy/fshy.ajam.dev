EgressFree and anonymous. Objects live on Amazon S3 (s3.amazonaws.com/openneuro.org), public-read, ranged, CORS-open. No auth, no egress meter.
Retentionper-object-cap: none published; the real cap is a transient staging worker ('files are stored on a worker with relatively limited storage space'), so very large datasets must be uploaded in batches with ~24 h waits between snapshots. Retention: permanent, every version gets its own DOI; 36-month grace before forced public release (1080 days)
Interfaces3, git, rclone, cli s3
ToolingOpenneuro-cli (openneuro upload) + git-annex, and DataLad. Read side is plain anonymous S3 GET. Any S3 client, rclone's s3 remote with no credentials, or plain curl.
Composes withUnlimited datasets, each a fresh S3 prefix under openneuro.org/ds<ID>/. Because the read side is unauthenticated S3, fetch volume never touches OpenNeuro's app tier.
