Free tierStarter, Production and Enterprise plans include 60 simulator minutes a month until 2027; the Free plan lists Simulators as coming soon, and sessions start only on paid plans.
unit minutes; metered on wall-clock; Starter is $19/month plus additional usage cost. Usage beyond the included minutes is $0.10 per simulator minute, billed per second.
Pricenone stated
Limits
  • volume-quota (binding) 60 simulator minutes a month included until 2027 on Starter, Production and Enterprise; then $0.10 per iOS Simulator or Android Emulator minute source
  • request-rate 115 minutes maximum session duration; 5 concurrencies on Starter up to 2 on macOS source
The session timer starts when the session is ready; the job running the session has a hard limit of the maximum duration plus five minutes. An unnamed session has no idle timeout until --max-idle-time-minutes is set. Sessions wait in the account's job concurrency queue.
Bindingvolume-quota The 60 included minutes a month, then the $0.10 per-minute meter, bind before the 115-minute per-session cap for a single agent.
Identityemail Sessions require a paid Starter, Production or Enterprise plan. Whether a card is collected at signup is unverified: behind a sign-up.
EgressWithout local egress, all traffic from the simulator exits from Expo infrastructure; with --egress local, device traffic exits from the user's computer and the egress client refuses local, private, link-local and multicast addresses.
Per-object capnot applicable: the unit is a simulator session, not an object; one artifact can be up to about 5 GiB.
RetentionJob logs on the session page are available for 30 days after the session is created; session artifacts such as screenshots and recordings are kept until the session is deleted. (30 days)
Interfacerest, graphql, cli, browser, chat Sessions start with the eas simulator CLI, the REST API or a browser live view; agents drive the device with agent-device, Argent or Appium commands, including MCP.
endpoint: https://api.expo.dev/v2/device-run-sessions
ToolingThe EAS CLI and REST API start and stop sessions; Claude Code, Codex, Cursor, agent-device, Argent, Appium and Maestro drive the simulator.
Composes withA coding agent can install a build into an isolated cloud simulator, drive it, and attach a recording to a pull request without a local Mac.
ReliabilityA session that is not stopped runs until its maximum duration or idle limit; the REST API returns controller tokens only while the session is in-progress, and every session is isolated in its own VM.
NotesExpo Simulators is a hosted simulator/emulator service, not user-run software. The Free plan has no Simulators access (listed as coming soon); paid plans include 60 minutes a month until 2027 and then bill $0.10 a simulator minute. Session artifacts survive until the session is deleted; job logs are kept 30 days.
Evidence notedocumented Price, included minutes, session cap and retention are quoted from Expo's own pricing and documentation pages read on 2026-11-25; the signup gate is from the signup page.
