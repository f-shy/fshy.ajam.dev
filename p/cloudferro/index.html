Per-token pricing with monthly invoicing and spend alerts; the product page states a 99.9% uptime SLA. The EUR 250 free-trial credit is valid for 6 months and is described as 'considered per applicant and revocable' on the trial page; the identity fields of the My Portal registration form were not readable.
Bindingvolume-quota Every request spends tokens at the published per-1M-token rates and there is no always-free token allowance, so the token meter is what runs out first for a caller with no trial credit.
Identityemail The registration page asks for 'Email\*', 'First name\*', 'Last name\*', 'Country\*' and 'Password\*' and offers registration through Google, Microsoft, GitHub, LinkedIn, GitLab, yahoo!, BitBucket, X, Creodias, EGI Check In, DUNIA and CODE-DE3. The form asks for no card, phone number or ID document.
EgressThe Sherlock product page publishes no separate egress price; responses are returned over the API from the WAW3-2 region in Poland. CloudFerro's general cloud price list charges EUR 0.0064 per GB for internet transmission out, but that row is for cloud resources, not token responses, so whether it applies to Sherlock is unverified.
Per-object capnot applicable: the unit is tokens sent to an API, not stored objects; Sherlock keeps 'zero logs · zero storage · no model training on prompts'
RetentionZero logs and zero storage: prompts and outputs are not stored. No retention period applies to request bytes.
Interfacerest, browser OpenAI-compatible REST API (chat, completions, embeddings) at https://api-sherlock.cloudferro.com/openai/v1 plus a web Playground and assistants; a Sherlock API key is created in the console after login.
endpoint: https://api-sherlock.cloudferro.com/openai/v1/
Toolingthe openai Python and JS SDKs with base_url swapped, LangChain and LlamaIndex via the OpenAI-compatible provider, CloudFerro Jupyter Notebooks, Managed Airflow and Managed Kubernetes; models.dev lists 5 models under id cloudferro-sherlock with package @ai-sdk/openai-compatible.
Composes withSherlock completions and embeddings combine with CloudFerro Object Storage and Functions for RAG over document and Earth-observation corpora, all inside the EU WAW3-2 region.
ReliabilityThe vendor states zero logs, zero storage and no model training on prompts, processing confined to the WAW3-2 region in Poland, and a 99.9% uptime SLA. No throttle or outage was observed; no request was made.
NotesSherlock has no published always-free token grant: the first-party price list is per 1M tokens in EUR and the product page states 'no minimum commitment'. The EUR 250 trial credit is a separate, application-gated offer whose eligibility for Sherlock usage was not read. A separate record may be warranted if the trial is confirmed to cover Sherlock.
