Reliabilitythe control plane holds jobs in a queue while no enrolled server is online, and drops an autoenrolled agent that has been offline for 15 minutes
NotesPaid only at self-service, and the one documented zero-cost route is the sponsored programme with the CNCF and Ampere. That programme is neither a plan, a seat nor a server of the project's own: it grants a selected project a share of a sponsor-funded pool of Arm64 runners that the vendor operates, shared with every other participating project, and reached with the same runs-on label as a paid fleet. The published pool is 20 build slots shared between all CNCF projects. It is limited to CNCF projects and to Arm CI only, so a project outside the CNCF cannot join it; the vendor granted access to individual non-CNCF projects case by case, runc among them, which it calls an OCI project under the Linux Foundation rather than a CNCF project while counting its minutes in the programme's totals, and it separately lists Atuin, runc and criu among the open-source projects it has sponsored, without naming the programme. A sponsored project keeps its own GitHub organisation, where a maintainer installs the Actuated GitHub App, and it must add the Actuated badge to the top of the README of every repository that uses the runners. The first one-year pilot filled every slot by March 2024, after which the vendor offered a discounted subscription to a company that would fund a maintainer's time. The vendor's FAQ still listed the programme when it was read on 2026-11-04, but no page states whether it accepts projects now, and the Arm servers it ran on were hosted by Equinix Metal, which ended service on 2026-06-30, so its current status is unverified. Hosted runners with a free allowance in this topic come first.
