Free tierEvery new Cloudish API key starts with 0.1 credits (one credit is one US dollar), subject to availability, with no signup form, no email verification and no card; claiming the key to a human account is optional.
unit credits; metered on wall-clock; The operator list's '1.0 h free (one time)' matches 0.1 credits at the $0.1007/hour large size. The grant is one time per key, not a recurring monthly allowance; a child key minted under an existing key gets no free grant of its own.
Pricenone stated
Limits
  • volume-quota (binding) 0.1 free credits one time per new key; credits are prepaid and a key never spends past its balance source
  • request-rate Containers bill per second only while running; an app left without requests sleeps after 15 minutes unless configured always on source
Instance prices per hour: shared $0.0107 (0.1 reserved vCPU, 0.2 GB, burst to 1 vCPU/1 GB), small $0.0297 (0.5 vCPU, 1 GB), medium $0.0533 (1 vCPU, 2 GB), large $0.1007 (2 vCPU, 4 GB); always-on monthly: $7.84 / $21.66 / $38.93 / $73.48. The operator list's $0.101/h is the large size rounded.
Bindingvolume-quota Prepaid credits are what run out first: the agent cannot overspend, and at zero credits new builds and deploys get a 402 and running containers stop within a minute.
Identityanonymous One unauthenticated POST https://cloudish.ai/api/v1/keys returns a key with 0.1 credits: 'There is no browser, signup form, card, or approval step anywhere on that path.' Claiming the key later needs a sign-in with an identity provider Auth0 offers, but claiming is optional.
EgressEach app gets a public https:// subdomain with managed TLS; the pricing page states no separate egress volume allowance or per-GB traffic price. Active custom domains cost 0.01 credits a day.
Per-object capnot applicable: the metered unit is a running container, not a stored object; persistent volumes are offered at 1, 5 or 20 GB per project and are not billed
RetentionA sleeping app's volume, with its data, is kept when credits run out; no day count is published. Unverified: retention period not stated.
Interfacerest, browser An agent mints a key with one unauthenticated POST /api/v1/keys and deploys a Dockerfile or image with POST /api/v1/projects; no local Docker daemon is needed. A dashboard is optional.
endpoint: https://cloudish.ai/api/v1
ToolingThe user calls the REST API from an agent or installs the generated skill.md into a coding agent; builds run server-side.
Composes withA prepaid, capped Cloudish key lets an agent deploy and keep running the apps another provider's model builds, with credit transfers to child keys so each sub-agent's spend is bounded.
ReliabilityAt zero balance, new builds and deploys answer 402 and running containers stop within a minute; volumes and their data are kept. The shared size can be restarted when memory runs short on a busy host; small and larger sizes are fully reserved.
NotesCloudish is a hosted container platform whose initial key is fully anonymous. The 0.1-credit grant is subject to availability and the shared tier can restart under memory pressure. Egress is not separately priced on the pages read; that is a gap rather than a claim of free unlimited traffic.
Evidence notedocumented The instance price table, free credit grant, per-second billing, zero-credit behaviour and unauthenticated key creation are quoted from the first-party home page and API skill page read on 2026-11-25. Retention days and egress volumes are not published.
