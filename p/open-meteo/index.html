Bindingrequest-rate 10,000 calls a day binds a steady poller: 600 a minute reaches the 5,000 hourly cap in under 9 minutes, 5,000 an hour reaches 10,000 in 2 hours, and 10,000 a day over 30 days equals the 300,000 monthly cap.
Identityanonymous No API key, no sign-up and no credit card. GET requests with no credentials answered HTTP 200 from the forecast and archive endpoints, and the s3://openmeteo bucket listed with no credentials.
Egressnot applicable: JSON answers counted as calls; the s3://openmeteo bucket listed with no credentials, and its transfer price was not read
Retentionnot applicable: the unit is a request
Interfacerest, s3 REST over HTTPS GET with query parameters, JSON answers and no key; the archive at archive-api.open-meteo.com; the bulk archive in the public AWS bucket s3://openmeteo (us-west-2) as .om files
endpoint: https://api.open-meteo.com/v1/forecast
Toolingany HTTP client; any S3 client reads the bucket anonymously, and .om files are read with the Open-Meteo OM-file readers for Python, Rust, Swift and TypeScript. Last resort: the user installs and runs the open-source AGPLv3 server on a rented or free machine.
Composes withA keyless point-weather and reanalysis source: forecasts and ERA5 history per coordinate under a 10,000-call daily cap, with the full model archive in a public S3 bucket for bulk pulls.
ReliabilityApplications and IP addresses can be blocked without prior notice; the free API carries no uptime target.
NotesBulk path: s3://openmeteo, read anonymously. Paid plans move the same API to customer-api.open-meteo.com with a key.
