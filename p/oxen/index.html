50 GB storage, 50 GB/month transfer, 5 private repos. No per-file cap published. Public repos are unlimited in COUNT, which is the only multiplier. But the 50 GB is account-level, so repo count does not add bytes.
Identityemail email (self-service signup).
EgressHard-capped at 50 GB of data transfer per month on the free tier. Transfer allowances are exhausted quickly under continuous data retrieval.

Interfacerest, git, cli rest
ToolingGenuine: oxen CLI (oxen add/commit/push/pull, merkle-tree diffing), Python SDK, and a documented REST API. The oxen-server is open source and self-hostable (Oxen positions itself as 'git for data'). This is a real product with a real client, not a wrapper.
Composes with50 GB x N free accounts, but the 50 GB/month transfer cap applies per account too, so chaining accounts multiplies egress but not storage usefulness. 10 TiB would need 205 accounts.
ReliabilityMature, funded, stable. Data is content-addressed and versioned, so no silent expiry. The API host api.oxen.ai did not resolve from this network, which suggests the documented API endpoint has moved or is geo-restricted.
