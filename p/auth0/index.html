Bindingrequest-rate The Management API takes 2 requests a second on Free, so any bulk user administration is slow; sign-ins share the Authentication API's 300 requests a minute.
Identityemail The sign-up page asks for an email address, or a GitHub, Google or Microsoft sign-in, and states no credit card is required. After registration a profile page asks for an Account Type when the email domain is not a corporate one or for a Role when it is, and the user is asked to create a tenant, which takes a tenant name and a region. A custom domain needs credit card verification. Whether a later step asks for a phone number is unverified: behind a sign-up.
Egressnot applicable: an authentication API; no traffic allowance or egress term is published
Per-object capAuth0 states a user profile size limit of 10 KB, and writes over it succeed for now but may start to fail; user_metadata set through the Authentication API Signup endpoint takes at most 10 string fields of at most 500 characters each
RetentionTenant logs are kept 1 day on Free; a Free tenant with no admin login, user login or API call for 150 days is deleted with all its data and cannot be recovered (1 days)
Interfacerest Authentication API (OAuth 2.0 and OIDC endpoints such as /oauth/token and /userinfo) and Management API v2 at https://{tenant}/api/v2/ with a Bearer token; both are served on the tenant's own domain.
endpoint: https://{tenant}/api/v2/
ToolingAny HTTP client or OAuth 2.0 / OIDC library against the tenant's Authentication API and Management API v2.
Composes withAn OIDC identity provider in front of apps on free compute; user import is included on Free, so users can be moved in through the Management API.
ReliabilityA Free tenant inactive for 150 days is deleted and cannot be recovered; Free support is community only.
NotesEssentials starts at USD 35 a month for 500 MAUs (B2C); paid plans add role management, MFA factors and longer log retention.
