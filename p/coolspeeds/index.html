unit none; metered on none; Three independent billing streams: disk plan, premium traffic, converter hours.

Limits

  • volume-quota (binding) premium-pool downloads are prepaid in 10 GB packs; no included allowance source
  • request-rate converter billed per actual CPU minute with a user-chosen priority multiplier; higher multiplier costs more source
The FAQ says premium traffic is only needed 'when a file host requires a premium account and you do not have one'; your own host accounts can be plugged in instead.
Bindingvolume-quota At 1 TiB a month the disk plan is irrelevant (100 GB is $34.80/month) but the premium pool is $36.86 per TiB, prepaid in 10 GB steps, and every byte is billed. That purchase, not a rate limit, is what is met first. The old documentation page still states '$0.30 per GB'; the live pricing page says $0.36 per 10 GB, and this record keeps the live number.
Identityemail An account in the cabinet is required to hold a plan and a traffic balance. The signup form itself was not read; email is the minimum such a cabinet implies and is not confirmed.
Egress'Unlimited traffic' on every disk plan. Downloads that need a premium file-host account are bought separately: '$0.36 per 10 GB ... billed strictly by bytes actually downloaded.'
free allowance: unlimited disk-plan traffic; no included premium-pool allowance
price per tb: USD 0.36 per 10 GB of premium-pool download (USD 36.86 per TiB)
Per-object capnot applicable: the service downloads into a disk plan, it does not publish a maximum object size
RetentionFor the length of the paid plan; the plan can be changed once a day. No post-expiry retention statement found on the pricing page.
Interfaceunknown Browser cockpit at coolspeeds.com/{en,ru}/cabinet.html; ruTorrent 3.x with 19 plugins for torrents; FTP for uploads; a Firefox extension (LeechGrab) routes browser downloads through the vendor's MITM proxy. No public API documented on the pages read.
ToolingWeb UI only as documented; purchase links are plain cabinet URLs (action=s40&days=30), so a plan can be bought by URL. Torrents are handled by the vendor's ruTorrent instance, not by a local client.
Composes withIt replaces a seedbox plus a VPS for the posting workflow: download from a host, repack, upload to 100+ hosts, emit a post. As a pure debrid it is the premium-traffic stream at $0.036/GB.
ReliabilityPayment is crypto and WebMoney only, so a plan cannot be bought with a card; the operator has run since 2011 and bills per byte, but the premium pool is a shared resale pool and the documentation already warns that 'bezotkaznaya rabota ... dlya vsekh failoobmennikov ne garantiruetsya' (uninterrupted operation for all file hosts is not guaranteed).
NotesThe cheapest per-GB figure found among debrid providers. The caveat is payment: crypto or WebMoney only, so a user without either cannot buy it at all. Candidate explanations considered for the price gap between the docs page ($0.30/GB) and the live page ($0.36/10 GB): (1) the docs page is a 2021 capture never updated - supported by its image timestamps uploads/images/gallery/2021-02 and by the pricing page being the later artefact; (2) the two pages price different pools; no evidence. The record keeps the live pricing page.
