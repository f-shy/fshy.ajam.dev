Composes withThis is what makes an *arr stack work without a disk: Sonarr asks Decypharr for a 'torrent', Decypharr adds the magnet to the provider, and the file is served from the provider's library over NFS or SMB.
ReliabilityA mock API is a compatibility promise with two moving targets (the *arr client and the provider); a provider field rename surfaces as a failed grab, not as an error in Decypharr.
NotesThe *arr answer observed here: every integration read among debrid providers is a qBittorrent-shaped shim (this, rdt-client) or a Torznab indexer (Debrid Media Manager), and no *arr application was found with a debrid client of its own. This is the most capable shim read here.
