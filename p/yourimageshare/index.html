Retentionunverified: the page markets 'a permanent direct link' but publishes no retention period or deletion policy on this page.
Interfaceunknown A web form taking up to 40 URLs per submit, returning a page link, direct link, embed code, HTML, BBCode and Markdown per file. No API documentation. Allowed types: JPG, PNG, GIF, WEBP, AVIF, BMP, TIFF, HEIC, HEIF and MP4, WEBM, AVI.
ToolingBrowser. The automated path is blocked: a plain HTTP client got HTTP 403 with a challenge signature, so a wrapper needs a real browser session.
Composes withIt moves an image or clip from a dying host to a live one without using local bandwidth, which is the cheapest fix for hotlink-blocked or expiring media. It is not usable for archives or datasets.
ReliabilityThe site refuses non-browser clients (HTTP 403 with a challenge on a plain GET), so unattended use needs a browser driver. Re-hosted copies depend on this operator's retention, which is unpublished.
NotesThe cleanest anonymous URL-pull found, and the narrowest: media only, 200 MB. It answers 'no install, no account' for one file type class and nothing else.
