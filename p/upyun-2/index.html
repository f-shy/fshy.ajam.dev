Free tierNo standing free tier. Free capacity comes from (a) a 7-day trial with no storage/traffic cap, (b) 61 CNY voucher on real-name signup (1 month), (c) the 又拍云联盟 programme: a one-off 12-month resource grant worth 67 CNY. Described as '一年内每月可免费使用 10GB 存储空间及 15GB 的 CDN 流量'. Billing model is unusual: '按照日 CDN 流量 1:1 免费日存储容量，仅收取对应差值存储容量费用'.
unit mixed; metered on stored-bytes
Pricenone stated
Identitynational-id national-id (实名认证 required for the 61 CNY voucher).
EgressMetered. CDN traffic at ¥0.29/GB. The 1:1 storage-for-traffic credit is the only offset and it only covers storage, never egress.
Interfaces3, rest, rclone, webdav-proxy s3
ToolingOpenList driver uss (bucket + endpoint + operator name/password + anti-leech token, sign_url_expire). Proves the UPYUN REST/S3-ish API is mountable; also a first-class rclone-adjacent target via S3 compatibility.
Composes with10 GB/month per alliance account is a rounding error. The multiplier that would matter: the 1:1 traffic-to-storage credit means a high-traffic public bucket is storage-free. But the egress is what you pay for, so it inverts into a loss.
ReliabilityMature CDN vendor; nothing unstable. The problem is purely economic.
