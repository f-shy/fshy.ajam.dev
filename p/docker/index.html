Free tierUnlimited public repositories on the free Personal plan; NO documented storage cap on public repositories. Docker's own limits table lists only pull-rate and repository counts, with no storage row. Docker's Feb 2025 policy post says storage-based billing is 'indefinitely delayed' with a promised six-month notice.
unit unlimited; metered on stored-bytes
Pricenone stated
Limits
  • per-ip-shaping (binding) 1TiB/day source
Pull count is 100 per 6 hours anonymous or 200 per 6 hours authenticated per IP. No published per-layer size cap, but Docker distribution S3 drivers historically faced issues above 10 GB per layer, recommending shards around 5 GB. Excess request limits return HTTP 429.
Bindingper-ip-shaping one stream is shaped, and aggregate throughput is the shaped rate times the number of streams
Identityanonymous (inferred, not read) not published
EgressFree and unmetered per-GB; the gate is a pull COUNT, not bytes: 'Unauthenticated users: 100 per IPv4 address or IPv6 /64 subnet' and 'Personal (authenticated): 200' per 6 hours. Blobs are served by 307 redirect to a CDN, so one pull can be a multi-GB blob.
RetentionPull count 100 per 6 hours anonymous or 200 per 6 hours authenticated per IP. Large download throughput requires few, large blobs rather than many small ones.
Interfaceoci oci
Toolingoras push / docker push; purpose-built wrapper: github.com/Androsh7/layerstash (chunks >5GB files into ~5GB layers, uploads to Docker Hub or GHCR; author reports 1.8TB personally stored), github.com/xausky/DockerRegisterCloud (654 stars, registry-as-netdisk client with Flutter GUI + direct-download server).
Composes withUnlimited public repos per account, and the free account count itself is unlimited. Layer count per repo is not capped, so a single repo holds arbitrarily many blobs; layerstash's <base-tag>-<chunk_n> scheme makes one repo a striped volume of unlimited size.
ReliabilityStorage is unpriced today but Docker reserves the right to add charges and has flip-flopped before (announced Mar 2025, cancelled Apr 2025); the 100-pull/6h IP limit will throttle any fetch fan-out from one host.
