ToolingFirst-party openMind Hub Client (pip) with upload/download by repo_id, plus git+LFS, plus a web UI. Documented at modelers.cn/docs/zh/openmind-hub-client. This is a genuine HF drop-in: repo types are 'model', 'dataset', 'space', same as HF.
