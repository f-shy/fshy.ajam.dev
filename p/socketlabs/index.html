Free tierNo permanent free tier. After an account is created and verified, a free trial gives Core plan access for one month, or a set amount of credits, with no credit card required. The Core plan allows 40,000 emails per month and costs USD 39.95 per month after the trial.
unit requests; metered on request-count; This is a one-month trial, not a continuing free tier. At the end of the trial the account loses platform access and can no longer send unless it upgrades to a paid plan. Public email accounts such as Gmail are not accepted at signup, so a work or private domain email is needed.

Bindingretention-clamped The free access is one month, after which sending stops without a paid plan, so the trial window fails before the 40,000-email monthly allowance or the 100 requests per 60 seconds API rate is reached.
Identityemail It refuses public domains: 'Public accounts such as Gmail are not accepted'. Account creation passes a two-step review, with an automated analysis and then a human review; the approval guidance asks to 'Provide a valid phone number where you can be reached' and requires a publicly accessible business website. A phone number appears in the review guidance, but whether it is a mandatory form field is unverified: behind a sign-up.
Egressnot applicable: an outbound email sender; volume is counted in emails sent, not in bytes transferred
Per-object capnot applicable: an outbound transactional sender
RetentionFree trial access lasts one month, after which platform access and sending stop without a paid upgrade. The exact reporting-history day windows are unverified: the first-party pricing page renders its feature table without day values.
Interfacerest The primary access path is SMTP relay on ports 25, 2525, 465 (SSL) and 587 (TLS), plus the HTTP Injection API. The schema has no SMTP interface term, so rest is used as the nearest term for the HTTP Injection API.
Toolingany SMTP client, the HTTP Injection API, or first-party SDKs in C#, PHP, Node.js, Python, Go, Java and Ruby
Composes withan outbound transactional sender with no inbound storage, used by an application that sends over SMTP or HTTP injection; the one-month trial window and the 40,000-email monthly Core allowance bound any sustained stack
ReliabilityNew accounts are throttled during an automatic warm-up period over the first weeks of service; by default a server that exceeds its monthly allowance by more than double is temporarily suspended.
NotesSocketLabs has no permanent free tier. The only no-cost access is a one-month Core trial after account verification; public email domains are refused at signup and all new accounts pass a two-step review that may ask for a phone number. The exact reporting-history day windows are unverified on the first-party pages.
