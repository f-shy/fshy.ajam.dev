Free tierFree subscription: unlimited secret storage with up to 2 users, up to 3 projects, and up to 3 machine accounts; a free 14-day trial is offered for the paid tiers
unit unlimited; metered on none; The headline quantity is unlimited secret storage. The free offer also caps users at 2, projects at 3 and machine accounts at 3. Paid Teams and Enterprise include up to 20 and 50 machine accounts and charge USD 1 for each additional machine account.

Each secret belongs to a single project at a time, and a machine account sees only secrets in projects it can access.
Bindingvolume-quota Secret storage is unlimited, so the free-tier count ceilings of 3 machine accounts, 3 projects and 2 users bind before any storage quantity.
Identityemail Email and a master password: the account page says 'Enter your Email address and choose your preferred server location', then 'Bitwarden will email you a verification link', and the free-account page states 'No credit card required!'. No phone number, ID document or institution is asked. Secrets Manager is then enabled inside an organization, and only owners can add it.
Egressnot a byte-transfer service: a secrets vault reached through the web app, the bws CLI and a REST API; the Public API returns 429 Too Many Requests when hit too quickly and the CLI warns that many sessions from one IP in a short span may hit rate limits. No per-GB egress charge is stated.
Per-object capunverified: no per-secret size limit is stated on the first-party pages read
Retentionstored secrets have no stated automatic expiry; on deletion a secret moves to Trash for 30 days and is then permanently deleted and cannot be recovered
Interfacerest, cli A REST Public API compatible with OpenAPI Specification 3 with a published swagger.json, at https://api.bitwarden.com or https://api.bitwarden.eu for cloud, authenticating with OAuth2 client credentials bearer tokens. The bws CLI reads and writes secrets through machine-account access tokens and injects them as environment variables. The SDK has a Rust core with C++, C#, Go, Java, JS, PHP, Python and Ruby wrappers. A web vault exists for setup, but programmatic access is through the REST API and CLI.
endpoint: https://api.bitwarden.com
ToolingThe bws CLI, installed with curl https://bws.bitwarden.com/install | sh or run as the ghcr.io/bitwarden/bws Docker image, the Bitwarden SDK wrappers (Python, Java, Go, C#, JS, PHP, Ruby, C++, Rust) and the Public REST API
Composes withStore CI/CD and application credentials in an end-to-end encrypted hosted vault and inject them at runtime through the bws CLI or an SDK using scoped machine-account access tokens.
ReliabilityAn access token appears once at creation and cannot be retrieved later. The Public API returns 429 when hit too quickly and CLI sessions sharing an IP in a short span may be rate limited. No data loss or ban is stated on the pages read.
NotesA hosted service: the vendor runs the vault, while the bws CLI and SDK are clients the user runs. The free tier stores unlimited secrets but caps users, projects and machine accounts, and enabling the product is gated to organization owners. The per-secret size limit is unverified.
