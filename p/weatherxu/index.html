Free tierFree plan, USD 0: 10,000 API calls a month at up to 10 requests a second, with real-time weather data, basic forecasting and daily forecasts for 5 days; no historical weather.
unit requests; metered on request-count; Each call counts as one request whatever it returns; the X-API-CURRENT and X-API-QUOTA response headers report the month's count and limit, and error code 105 answers once the allowance is reached. Bulk path: none on Free; each call returns one location by latitude and longitude, and the hourly Historical API (start and end timestamps) is on Plus (1 year) and Business (5 years) only. The next plan up is Starter at USD 20 a month for 500,000 calls a month.

endpoint: https://api.weatherxu.com/v1/weather
