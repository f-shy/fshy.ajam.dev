unit users; metered on identity-count; The unit counted is the identity, which is any principal that authenticates to Infisical, human or machine. users is the nearest schema term; the true meter is identity-count, named in metered_on. On every plan including Free: unlimited projects, two-factor authentication, secret sharing, community support, pay by card and annual billing. Paid Secrets Management plans add a 30-day free trial with no credit card. The MIT-licensed core can be self-hosted at no cost on any plan; a supported, licensed self-hosting option is available after talking to sales and is not the hosted offer priced here.

The older comparison table states a project limit of up to 3 on Free, while the Secrets Management summary on the same page states unlimited projects. The tighter figure is recorded here and the disagreement is unresolved. Exceeding a rate limit returns HTTP 429.
Bindingvolume-quota The 5-identity cap fills first for a small team plus its CI pipelines: each human and each machine identity counts, so a project with several distinct permission sets reaches the cap before the per-minute rate limits are approached.

RetentionNo audit log retention on Free; 30 days on Pro, 90 days on Advanced and custom on Enterprise. Secret retention is until deletion by the user and no automatic secret expiry is stated on the pages read.
Interfacerest, cli A REST API over HTTPS supports every dashboard action: reading and writing secrets, managing projects and machine identities, reading audit logs and configuring resources. Cloud endpoints are app.infisical.com/api (US) and eu.infisical.com/api (EU). An OpenAPI specification is served at /api/docs/json. A CLI and SDKs use the same API.
