A credit balance is consumed at the per-second rates; no concurrent box count or session length is published on the pricing page.
Bindingvolume-quota The USD 100 signup credit runs out before any published rate or concurrency cap, since no concurrency or session count limit is stated.
Identityemail The API key page says to go to GBOX AI, log in to an account and create the key in the dashboard. No phone, ID document or card is stated as required for signup.
EgressNo egress allowance or per-GB price is stated on the pricing page; the Android physical device rate includes its network in the per-second charge, and no base traffic price is published.
Per-object capThe unit is a box, not an object. Linux boxes include 10 GiB of storage free; the Android emulator is offered in Medium (4 cores, 8 GB RAM) and Large (8 cores, 16 GB RAM), and a physical device is 8 cores, 8 GB RAM and 128 GB storage.
RetentionNot stated on the pricing page; the SDK exposes create and destroy of boxes and the terms page states a hosted environment is provided with no published retention period.
Interfacerest, cli A GBOX API key from the dashboard is passed as a Bearer token to the REST API; an SDK and a CLI/MCP connector create and drive Android, browser and Linux boxes.
ToolingThe GBOX SDK (npx/npm), a CLI and an MCP server drive boxes; an API key from the GBOX dashboard is required.
Composes withAndroid, browser and Linux boxes share one GBOX account and its USD 100 signup credits, so an agent can move between mobile, browser and desktop tasks on one balance.
ReliabilityPhysical devices are beta and may have limited availability.
NotesGBOX sells hosted Linux, browser and Android environments for agents, with a USD 100 signup credit. The Linux box is priced at USD 0.054 per vCPU-hour plus USD 0.0144 per GiB-hour with 10 GiB storage free; a 2 vCPU/4 GiB box is USD 0.1656 per hour at list rates. The Android Medium emulator is USD 0.0003/second with a 30-second minimum. Registration uses a GitHub account, which supplies the email address; no card is stated for signup. The on-premise deployment mentioned on the benchmark site is a separate option; this record prices the hosted GBOX service.
