10 MB per paste by default (per-instance override); file upload is disabled by default (fileupload = false) and about half the directory shows no file-upload support; burn-after-reading and expiry are server-configurable.
Bindingper-object-cap each document or comment is capped at 10485760 bytes by default; there is no per-account quota because there are no accounts to meter, and each instance sets its own cap
Identityanonymous (inferred, not read) not published
Egressfree, direct from each instance; most are Cloudflare-proxied (the directory lists CSP/Observatory ratings and uptime).
Per-object cap10 Megabytes per document or comment by default (sizelimit = 10485760 bytes); each instance's operator may change it. (10485760 bytes)
RetentionExpiry is chosen per paste from options set by the instance operator: 5min (300 s), 10min, 1hour, 1day, 1week, 1month (30 days), 1year, and never (0, no expiry).
Interfacerest rest
ToolingEncrypted JSON POST to the instance root with X-Requested-With: JSONHttpRequest; official JS client plus community CLIs. github.com/PrivateBin/PrivateBin (8690 stars). Instances are independently operated.
Composes withN instances x 10 MB, and each instance is a separate operator with separate rate policy. So this is the one pastebin class where horizontal sharding across operators is native. Still only ~50 instances, so the aggregate is single-digit GB per round.
ReliabilityInstances are volunteer-run with visible uptime as low as 47-49% in the directory, so shard redundancy is mandatory. Content is client-side encrypted, so the operator cannot dedupe or scan. And cannot recover your key either.
