NotesAggregator claim checked: free-for.dev says '2-core, 512 MB server 24/7 with a verified phone'. The vendor publishes no core count and bills CPU as free, so '2-core' is the aggregator's figure, not the vendor's, and is not recorded here. The anonymous 256 MB tier is the more interesting half and the aggregator omits it. Two servers per IP is the anonymous ceiling. Operating history is unknown: this is a young single-operator service and no suspension report was found, so an operator that keeps prepaid credit is an open risk, not an observed event.
