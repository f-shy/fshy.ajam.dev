Interfacecli, unknown Hosted lane: a remote MCP server at https://mcp.octoparse.com (OAuth or an API key) runs cloud-capable preset templates and exports JSON or CSV; the AgentTools REST API at https://openapi.octoparse.com (x-api-key header) searches and runs the same templates, and the help center gives Free and Basic accounts free records for MCP/API template extraction, but whether a Free account's key is accepted by the AgentTools endpoints is unverified: behind a sign-up. The OpenAPI for tasks, cloud runs and data needs a Standard, Professional or Enterprise account, so Free has no OpenAPI access. Local lane (software the user runs): the Octoparse desktop application builds and runs tasks by point and click, and the npm CLI (Node.js 20 or newer) runs local extraction without the desktop application and takes an account and an API key; the AI recipes README states template runs via MCP and CLI share a monthly row quota on the free plan, but whether the Free plan accepts CLI local runs of custom tasks is unverified: behind a sign-up. The true interface terms are MCP and a desktop application, which the vocabulary lacks
Toolingany MCP-compatible AI client (Claude, ChatGPT, Cursor, VS Code) for the hosted template lane; for custom tasks, the Octoparse desktop application (Windows 10 (64-bit) or higher, macOS 10.15 or higher) or the npm package @octoparse-ai/octoparse-cli (local extraction on Windows x64, macOS or Linux x64), installed and run by the user on a rented or free machine
Composes withthe MCP lane runs preset templates on Octoparse cloud nodes and hands JSON or CSV to an AI agent with no machine at all; Free custom tasks extract only on the machine running the desktop application or the CLI, which must stay on for the run, so a rented or free Windows, macOS or Linux machine is the host
ReliabilityFree runs depend on the device, network and address of the machine that runs them: IP rotation, residential proxies and automatic CAPTCHA solving are paid features, so a protected site blocks a Free run sooner
NotesConfirmed as a no-code scraper with a free plan. Free runs: no run count is stated; 2 local runs at a time, history of the last 5. Pages per run: unlimited pages per crawl, bounded instead by 10,000 rows per export and 50,000 rows a month. Export formats: Excel, CSV, JSON, HTML, XML, plus database export (MySQL, SQL, PostgreSQL, Oracle) and Google Sheets through a service account on Free. The caveat is where Free extraction runs: the only hosted lane on Free is MCP template extraction (2,000 records a week on the help center, 2,000 records a month on the MCP docs page); custom tasks run only on the user's own machine, in the desktop application on Windows or macOS. Cloud extraction starts at Standard, from USD 69 a month billed annually.
