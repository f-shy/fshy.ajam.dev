Free tierManaged Cloud: USD 0.02 per MAU, free under 5,000 monthly active users; a monthly active user is a unique logged-in user on the product in a month, including new signups. Core features are included, and the first 3 dashboard users are free
unit users; metered on identity-count; The counting unit is the monthly active user (MAU), a unique logged-in user per month including new signups. The free allowance is a threshold, not a deduction: the pricing example bills the full user count once it is reached, not only the users above 5,000. Self-hosting the open-source features is free with no MAU limit, but that is software the reader installs and runs and is not counted here as a hosted tier.

MFA is USD 0.01 per MAU and account linking is USD 0.005 per MAU, each with a USD 100 per month minimum; these are add-on meters, not part of the free core.
Bindingvolume-quota The 5,000 MAU threshold binds first: the pricing example bills the full count once it is reached, and enabled add-ons carry a USD 100 monthly floor before the MAU meter matters.
Identityemail The managed signup page offers Google and GitHub sign-in or a form with Full Name, Email and Password; the page states no credit card term. The quickstart then asks the user to sign up for a SuperTokens account and create a Managed deployment, which supplies a Connection URI and an API key. Whether a later step asks for a phone number or a card is unverified: behind a sign-up.
Egressnot applicable: an authentication API served by the backend SDK on the app's own domain; no traffic allowance or egress term is published
Per-object capunverified: no per-object or user-profile size cap is stated on the pages read
Retentionunverified: no log or data retention period for the managed Cloud service is stated on the pages read
Interfacerest, browser A Core Driver Interface (CDI) exposes REST endpoints to the backend SDK; it uses JWT tokens and requires an api-key header. Frontend SDKs call authentication routes exposed by the application's backend SDK, so the frontend never talks to the Core directly. Prebuilt sign-in and sign-up UI is served on the app's /auth route, which a browser reaches. An OpenAPI specification is published.
endpoint: https://{deployment}.supertokens.io
ToolingFrontend SDKs (supertokens-auth-react, supertokens-web-js) and backend SDKs for Node.js, Python and Go; any HTTP client against the CDI with an api-key header.
Composes withEmail and password, social login and passwordless auth behind an app on free hosting; MFA and account linking are metered add-ons that need a paid minimum. A self-hosted open-source Core that the user installs and runs is a separate last-resort option and is not a hosted tier.
ReliabilityHigh-reliability infrastructure is listed as a managed-service-only feature; the pricing page publishes no uptime SLA for the free tier and puts availability-zone SLAs behind contact-for-pricing. The frontend never calls the Core directly, and a self-hosted Core has no API key by default.
