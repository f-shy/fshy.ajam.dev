Free tierAuthKit user management free for the first 1 million monthly active users; staging environments are free; the production environment needs a payment method on file
unit users; metered on identity-count; An MAU is a user who signs up, signs in or updates a profile in a calendar month. AuthKit covers email and password, social login, passkeys, MFA, magic auth and enterprise SSO. SSO and Directory Sync connections cost USD 125 each for the first 15, a custom domain USD 99 a month; Radar includes 1,000 checks. A production environment activates only after a payment method is added, even when usage stays inside the free allowance.
Pricenone stated
Limits
  • volume-quota 1,000,000 monthly active users source
  • write-gated (binding) a payment method is required to activate the production environment; staging environments are free source
  • request-rate 6,000 requests per 60 seconds per API key source
  • request-rate AuthKit: 1,000 reads and 500 writes per 10 seconds per environment source
  • retention-clamped Audit Log events kept 30 days by default source
  • per-object-cap metadata on a user or organization: 10 key-value pairs (documentation page) or 50 (OpenAPI specification), keys up to 40 characters, values up to 600 characters source
Bindingwrite-gated The 1 million MAU allowance applies in a production environment, which activates only after a payment method is added; without one the account has staging only.
Identitycard The sign-up page asks for an email address or a Google sign-in and states no credit card is required, and staging needs none; the production environment activates only after a payment method (card details and cardholder name, billing address) is added. Whether a later step of the dashboard sign-up asks for a phone number is unverified: behind a sign-up.
Egressnot applicable: an authentication API; no traffic allowance or egress term is published
Per-object capmetadata on a user or an organization: up to 10 key-value pairs, each key up to 40 characters and each value up to 600 characters, ASCII only
RetentionAudit Log events are kept 30 days by default and then deleted; longer retention is priced per 1M events (30 days)
Interfacerest REST API at https://api.workos.com with a Bearer API key (a GET /events without a key answered 401); hosted AuthKit sign-in pages; an events API; WorkOS Connect serves OAuth authorization server metadata at /.well-known/oauth-authorization-server and an OpenID configuration at /.well-known/openid-configuration on the AuthKit domain.
endpoint: https://api.workos.com
ToolingWorkOS SDKs for Node, Ruby, Python and other languages, the WorkOS CLI (npx workos@latest), or any HTTP client with a Bearer key.
Composes withA staging environment for building and testing sign-in at no cost; production sign-in for real users needs a card on file.
ReliabilityEmail sent through the shared WorkOS provider (Magic Auth, verification, password reset) can be temporarily limited for unusual volume or spam patterns; a 429 may carry Retry-After.
NotesProvisioning through Stripe Projects (stripe projects add workos/auth) creates a sandbox environment with no account form or credit card prompt; production is a second configuration of the same command. Stripe states that a payment method is added to Stripe once and handed to the provider as a Shared Payment Token when a paid plan is selected, and WorkOS states that production environments require a payment method added in the WorkOS Dashboard; whether the production configuration provisioned through Stripe Projects needs a payment method on the WorkOS team as well is unverified: behind a sign-up.
