Free tierN/A. DVC ships no storage; the remote is whatever free store you configure. Free-tier bytes = the backing store's bytes. Supports Amazon S3 + S3-compatible (MinIO etc. via endpointurl), Azure Blob, GCS, Google Drive, Aliyun OSS, SSH/SFTP, HDFS/WebHDFS, HTTP, WebDAV.

EgressInherited. The HTTP remote is read-only and can sit behind any CDN, which is the only path where DVC itself doesn't add egress cost.
Interfaces3, git, cli part of the text of Free tier, above
Toolingdvc CLI + dvcfilesystem (fsspec). dvc remote add s3://bucket && dvc remote modify myremote endpointurl https://s3.hf.co/<ns> works. Native read-only Git-LFS support means dvc get/dvc import can pull straight from a Hugging Face repo without installing git-lfs.
Composes withOne repo, many remotes (dvc remote add x N), plus dvc push -r <remote> to pick. Any S3-compatible free endpoint multiplies: HF buckets, IA's IAS3, MinIO on a free VM, an Oracle/Cloudflare-adjacent free tier. DVC's content-addressed cache means the same 20 TiB corpus can be pushed to N stores and only the missing blobs transfer.
ReliabilityDVC is an ML-tooling project (treeverse); remote support quality varies by backend. S3-compatible endpoints need endpointurl + often use_ssl/path-style tweaks. Reliability is effectively the backend's.
