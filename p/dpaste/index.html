Toolingcurl -X POST -F 'format=url' -F 'content=<file' https://dpaste.org/api/ returns a plain URL. dpaste is the open-source Django app (github.com/bartTC/dpaste), so the same client works against any instance in the network.
Composes withunlimited anonymous pastes x ~1 MiB. Cross-instance: dpaste.org, dpaste.com, dpaste.de and any self-hosted dpaste all share one API shape, so the same shard writer hits N independent operators. 1 TiB = ~1M pastes; only sane as a metadata/thumbnail tier.
ReliabilityStable across a dozen API calls with no throttling observed. The URL slug is only 4 characters by default (SLUG_LENGTH=4), so paste URLs are enumerable. Do not treat content as private without local encryption.
