Interfacerest Weaviate Embeddings is a managed service at POST https://api.embedding.weaviate.io/v1/embeddings/embed with a JSON body of input / model / dimensions / optional is_search_query, authenticated by an Authorization Bearer token (Weaviate Cloud API key or OIDC token) and an X-Weaviate-Cluster-Url header. Callers reach it through a Weaviate Cloud cluster text2vec-weaviate vectorizer over the cluster REST/gRPC API; no separate key is needed (cluster credentials authorize it).
endpoint: https://api.embedding.weaviate.io/v1/embeddings/embed (POST); called server-side by the cluster text2vec-weaviate vectorizer — callers use their cluster REST endpoint and API key, with no separate embeddings key
ToolingWeaviate client libraries vectorize on import and query; the service is enabled by default for every cluster. Enable vector_config Configure.Vectors.text2vec_weaviate() (Python) / text2vecWeaviate (JS, Java, C#); Go has no direct support and must pass X-Weaviate-Api-Key and X-Weaviate-Cluster-Url headers manually. The optional base_url vectorizer parameter overrides the service origin, but the server accepts only https://api.embedding.weaviate.io or an origin in MODULES_WEAVIATE_EMBEDDINGS_ALLOWED_BASE_URLS.
