Autonomous system numbers associate with specific deployment locations rather than hosting providers as single entities. RackNerd does not operate a dedicated autonomous system: published test IP addresses route via AS35916, AS198566, and AS40676. DediRock does not operate a dedicated autonomous system: test addresses route via AS36352 and AS40676. VolpaByte Frankfurt instances exit via AS24940 (Hetzner). Datalix AS218841 announces zero prefixes, with traffic routing via AS58087. Multi-location providers route traffic across distinct autonomous systems depending on provisioned location.
Bindingnone At about 45 GB a month across about 599,000 requests no volume quota in this set is close: the smallest allowance is DediRock's 1 TB, whose period the card does not print, and even read as a monthly figure that is roughly 22 times the monthly volume; the others are 10 TB a month and 3000 GB a month. What fails first is not a quota but the record shape: an ASN is per location and sometimes not the host's at all, so a single-ASN field per host is wrong before any traffic is sent.
Identityemail The set does not share one gate, and the weakest documented is an email address. Datalix's order page shows the sign-up fields 'Nutzername', 'E-Mail', 'Passwort' and 'Sprache', with no phone field and no identity document; payment is a prepaid account balance. VolpaByte's registration form asks for name, email, phone with a full country selector and address, and its payment step could not be read because the order store was empty: unverified rather than none. RackNerd's signup requirement and DediRock's were not read in their lanes and are recorded there as unverified and not read, so this record does not claim a gate for them.
EgressThe traffic position differs per host and none of the four quotes an ASN in it. Datalix states 10 TB a month on a 1 Gbit uplink and, on exhaustion, quotes 'wird die Geschwindigkeit Ihres Servers auf 10 MB/s (80Mbit/s) begrenzt', with more traffic buyable. RackNerd's specials page lists 3000 GB a month on a 1 Gbps port. DediRock's card states 1 TB of bandwidth and prints no period and no overage price. VolpaByte's plan page lists a 1 Gbit/s connection and no traffic figure at all; its homepage's older copy said 'unlimited traffic'.

Retentionnot applicable: an address, not an object
Interfacessh, cli A VPS is reached by SSH into a root shell, plus the vendor's web control panel: RackNerd, DediRock and Datalix sell KVM guests with root; VolpaByte sells KVM with a WHMCS client area. The egress leaves from the guest's own address, so a SOCKS5 or HTTP proxy is software run on the guest, not a protocol the host sells.
ToolingAny SSH client, plus whatever proxy runs on the guest: a SOCKS5 or HTTP listener, an SSH -D tunnel, or a WireGuard server if the host allows it. No host in this set sells a proxy endpoint or a proxy wrapper, and no wrapper existing is not a rejection: the resource is a machine with a routable address, which is what a proxy needs.
Composes withOne cheap VPS per ASN to hold, each running a SOCKS5 or HTTP proxy, fronted by the Cloudflare-Workers AI gateway as the egress pool: the gateway picks the upstream, the guest supplies the address, and the ASN seen by the far end is whatever the location's upstream announces, which is the fact this record establishes.
ReliabilityThe exit's reputation belongs to whichever upstream announces the address, not to the host named on the invoice: RackNerd's addresses resolve to HostPapa/ColoCrossing, Multacom, Mamut Rahal and Psychz space, and Datalix's own AS218841 announces nothing while its front end sits in AS58087, held by an individual. A host that changes upstream changes the ASN under an unchanged product.
NotesThis record exists because the obvious shape for an ASN field is wrong. The third is what this record carries. It also shows the field is not one value per host but one per location: RackNerd's published test addresses span AS35916, AS198566, AS40676 and AS36352, DediRock's span AS36352 and AS40676, and Datalix's own ASN carries none of its traffic. Any future record that writes one ASN for a multi-location host is a defect, and this record is the evidence for that rule. Two things are stated with less certainty than the rest. Second, VolpaByte: the commission says its Frankfurt location exits from AS24940 Hetzner, and three published YABS runs of VolpaByte Frankfurt guests plus the vendor's own hostnames all return AS211301 Unesty Company, which contradicts it; The structural finding survives either answer, because AS211301 is no more VolpaByte's ASN than AS24940 is. Five records mention an ASN inside tooling or evidence prose and none of those is a field. This record does not correct a wrong ASN in compute/racknerd, dedirock.json, volpabyte-ryzen-kvm-8gb.json or datalix.json, because those files assert no ASN.
Evidence notedocumented The ASN half of the verdict is measured: every ASN in this record was resolved with RIPEstat on 2026-10-24, and the zero-prefix answer for AS218841 was read from as-overview and announced-prefixes, not from a vendor claim.
