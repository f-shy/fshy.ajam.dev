  • request-rate (binding) none published; measured 24 requests in 2.061 s at 8 connections (about 18 requests/second over the request phase) with no 429, and 20 requests in 43.774 s sequentially (latency-bound at about 2.2 s per call)
Bindingrequest-rate The API returns about 11 KB per call, so 1 TiB would take roughly 95 million calls; per-call latency, not any byte quota, is what limits a day. Parallel calls help here, unlike on the file hosts.
Identityanonymous No key: 'API keys and other authentication methods are no longer necessary'. Anonymous GET returned 200 and 324 bytes for per_page=1.
EgressFree and unmetered. No key, no account.
free allowance: no byte allowance published
Per-object capnot applicable: JSON or XML per call, with per_page up to 32,000 rows on some indicators. The responses measured here were 9,735-13,760 bytes each at per_page=50.
Retentionthe indicator series are revised in place; there is no versioned snapshot endpoint documented
Interfacerest, cli GET https://api.worldbank.org/v2/country/{codes}/indicator/{code}?format=json&per_page=N&page=N; format=xml also accepted.
endpoint: https://api.worldbank.org/v2/
Toolingcurl/python-requests; wbgapi and pandas-datareader wrap it. No SDK needed.
Composes withThe economic and social join keys for any national-level dataset; it is metadata-density, not byte-volume, so it pairs with a large byte source rather than replacing one.
ReliabilitySequential calls cost about 2.2 s each from this machine, so an unparallelised harvest spends its day in latency; the API answered all 44 calls made here without a single 429.
NotesA useful contrast among debrid providers: on the file hosts, more connections made things slower; here eight connections made the same 24 calls 21 times faster than one. The difference is latency-bound JSON versus bandwidth-bound files.
Evidence notemeasured 44 calls were made and counted, at 1 and 8 connections, with bytes per response recorded. What is not measured is the point at which throttling starts, because none was reached.
