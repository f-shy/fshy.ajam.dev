Retentionnot stated on the pages read. A third-party indexer comparison claims '4,000+ days retention, 200 million+ Usenet posts indexed, 3,570 newsgroups' (nzbhydra.com, 2026-10-23).
Interfacerest HTML search over HTTP GET against /search/?q=<query>. Each result carries a /details:<id>/ link and an NZB link served as /nzb:<id>/. Both are plain GETs.
endpoint: https://www.nzbking.com/search/?q=<query> ; https://www.nzbking.com/nzb:<id>/
ToolingNo Newznab API found, so Prowlarr and NZBHydra2 cannot add it. A wrapper parses /search and GETs /nzb:<id>/, and the site also offers a per-query RSS feed (the page advertises 'Get query as RSS feed'), which is the cheaper automation route.
Composes withA third unnamed fallback that also exposes an RSS feed per query, so a cron job can watch a name without a scraper.
ReliabilityThe result page loads a cookie-consent script and an analytics tag before results; the results themselves are server-rendered, so a plain GET still sees them.
