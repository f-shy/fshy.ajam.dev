Bindingvolume-quota The 100 monthly active principals cap binds first for a growing application, ahead of the 2-simultaneous-PDP and 5-builds-a-week caps. Beyond 100 principals the next plan is Development from USD 25 a month. Audit logs are kept only 1 week on the free plan.
Identityemail The first-party sign-up walkthrough says to choose to sign in with a Google or GitHub ID or create a new ID with an email address; the Hub landing page states No credit card required. Whether a phone number is asked for is unverified: behind a sign-up.

Per-object capunverified: no per-policy or per-request byte size cap is stated on the pricing page read
Retention1 week of unified audit logs on the Proof of Concept plan; the Development plan raises this to 3 months and Production to 1 year (7 days)
Interfacerest, cli Policies are managed through the Hub interface, the Cerbos CLI and an API; the first-party documentation lists programmatic policy management via the CLI or SDK. Decision checks are served by the Cerbos PDP that runs in the user's environment, while Hub distributes policy bundles to it.
endpoint: https://hub.cerbos.cloud/
ToolingThe Cerbos Hub web interface at hub.cerbos.cloud, the Cerbos CLI and API for policy management, and a Cerbos PDP that the user runs to answer checks; Cerbos Synapse is included on the Proof of Concept plan for data enrichment
Composes withAuthor and version policies in the hosted Hub, which builds them and pushes bundles to PDPs running next to the application; checks stay inside the user's network. The open-source Cerbos PDP can run standalone with no Hub account and is the last-resort, self-run option.
ReliabilityThe proof-of-concept package is stated as for proof of concept use only, with 1 week of audit logs and community support. A PDP needs outbound internet access to fetch bundle updates from Hub; decisions themselves run in the user's environment.
