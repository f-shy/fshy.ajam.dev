Free tierNew accounts receive USD 100.00 of one-time sign-up credit, no card needed to start. It is prepaid balance that does not reset monthly; whatever is left stays. Without a card an account can run up to 4 machines at once of up to 4 vCPU each.
unit credits; metered on wall-clock; The credit is granted once at signup, not monthly, and is held until the email address is verified. The standard plan has no monthly fee.
Pricenone stated
Limits
  • volume-quota (binding) USD 100.00 of one-time sign-up credit; standard plan allows 20 machines at once and 8 vCPU per machine source
  • per-ip-shaping without a card an account can run up to 4 machines at once of up to 4 vCPU each; many accounts from the same email domain or network on one day create nothing until credit is added or auto-recharge is on source
  • retention-clamped a machine with a published port and no autoStopSeconds can be stopped by the platform's idle default unless the plan includes always-on; /tmp and /run are emptied on each stop and start source
Every machine bills a one-minute minimum at the size requested; longer runs bill to the second. A machine larger than the plan allows is refused at create time with the limit in the reply. Disk is billed around the clock, including while stopped.
Bindingvolume-quota The one-time USD 100.00 credit binds first: at the USD 0.04 machine-hour plus USD 0.05 vCPU-hour plus USD 0.0162 GB-hour and USD 0.0001 GB-hour disk rates it funds a few thousand machine-hours, while the 20-machine standard-plan ceiling is a separate create-time refusal.
Identityemail An email-and-password sign-up holds the credit until the address is verified and creates nothing until then unless credit is added or auto-recharge is turned on; no card is needed to start. Adding a card lifts the 4-machine / 4-vCPU no-card ceiling once the account has paid or is a day old.
EgressUSD 0.05 per GB out; an open outbound network or an allowCidrs list is set explicitly, and a stopped machine stops the base, CPU and memory meters while held disk keeps billing
price per tb: USD 50 per TB at the published USD 0.05 per GB rate
Per-object capnot applicable: the unit is a Linux microVM, not an object; machine disk on the standard plan is not published
RetentionThe machine filesystem persists across exec and stop/start; a stopped machine keeps its files and its held disk keeps billing. A recovery point is exported on an API or idle stop at no charge, but excludes /workspace.
Interfacerest The dashboard uses the same REST API a caller can use from code, with a bearer token from /console/keys; the SDKs and CLI are named smol and smolvm.
endpoint: https://api.smolmachines.com
Toolingcurl against the REST API with an SMOL_CLOUD_TOKEN, or the smol SDK and CLI; a saved key from smol auth login wins over the environment token.
Composes withA managed VM with a REST control plane and S3-compatible remote mounts can be driven by an agent SDK and checkpointed to external object storage, while the same workload runs locally through smolvm.
ReliabilityA machine with a published port can be stopped on the platform's idle default without an explicit autoStopSeconds; a node loss loses memory and writes since the last recovery point, and /workspace comes back empty on restore.
NotesThe hosted lane of smol machines' microVM engine: USD 100.00 of one-time credit at an email-only signup, no card needed to start, with usage-priced compute, memory, disk and egress. The one-minute billing minimum and the platform's idle stop of published-port machines are the practical clocks.
Evidence notedocumented Every rate, the sign-up credit, the no-card ceiling and the idle behaviour are quoted from the vendor's own pricing, quick-start and lifecycle pages read on 2026-11-24. smolvm itself is separate self-hostable software; this record prices the hosted smol cloud lane only.
