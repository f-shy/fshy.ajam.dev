unit credits; metered on request-count; The budget is priced per call: a list or filter call costs USD 0.10 per 1,000, a search USD 1 per 1,000, a content download USD 10 per 1,000. A keyless list call on 2026-10-30 answered X-RateLimit-Limit 1000, X-RateLimit-Limit-USD 0.1 and X-RateLimit-Credits-Used 1, so the keyless day is 1,000 list calls. A keyless list call at per_page=100 on 2026-11-02 also answered X-RateLimit-Credits-Used 1, so one call costs one credit at a page size of 100. The API notice says the keyless budget is shared with everyone on the network IP address. The X-RateLimit-Limit value with a free key is unverified: behind a sign-up. The vendor error page prints X-RateLimit-Limit: 10000 in an example.

Bindingrequest-rate The daily credit budget runs out first: a free key buys 10,000 list calls of up to 100 results, about 1,000,000 records a day, so a full copy comes from the snapshot, not the API.
Identityemail The API answers with no key at USD 0.10 a day, and the snapshot bucket needs no account. The free key comes from a sign-up form that asks for a name and an email address behind a CAPTCHA, or from a POST to https://api.openalex.org/api-keys with an email address; the key works only once its email address is verified. No payment method required.
EgressThe API is metered in credits per day, not in bytes. The public snapshot bucket s3://openalex is free to download with no AWS account; the AWS Open Data program covers the transfer, about USD 70 per full download.
free allowance: no byte cap published on the snapshot bucket
Per-object capper_page maximum 100 results; basic paging stops at 10,000 results, and cursor paging past the first page needs a free key; snapshot part files hold up to 400,000 records each
Retentionthe API is a live index; the free public snapshot is a quarterly release on the second Wednesday of January, April, July and October (latest 2026-10-14); a daily snapshot is a Member+ plan benefit
Interfacerest, s3 REST at https://api.openalex.org (GET, JSON; a key as the api_key query parameter or an Authorization: Bearer header); the snapshot in the public S3 bucket s3://openalex under data/jsonl/ (gzip JSON Lines) and data/parquet/, read anonymously with --no-sign-request or over HTTPS, each format with a manifest.json
endpoint: https://api.openalex.org/works
Toolingcurl or any HTTP client for the API; aws s3 sync with --no-sign-request (parallel and resumable) for the snapshot; DuckDB reads the gzip JSONL or Parquet part files directly
Composes withThe S3 snapshot is the bulk path: about 626 million records, about 745 GB compressed as JSON Lines (works alone about 615 GB) or about 770 GB as Parquet, refreshed quarterly; the API at USD 1 a day with a free key covers lookups and the drift between releases, while the daily snapshot and changed-since-any-date filters are Member+ (USD 10,000 a year) benefits.
