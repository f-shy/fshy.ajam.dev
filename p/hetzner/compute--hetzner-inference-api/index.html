Free tierFree of charge as long as the Inference API remains in experimental status; the experiment ends on 8 December 2026. Two open-weight models, Qwen/Qwen3.6-35B-A3B-FP8 and Qwen3.8-27B, each with 262,144 tokens of context and text plus image input. Hetzner says it will email users before the experimental status changes.
unit unlimited; metered on none; The free unit is usage without a token allowance: there is no published credit or byte cap, only per-key rate limits. Usage timestamps and token counts are tracked; request and response content is not stored. The service is offered as is with no availability guarantee and the model list changes during the experiment; GET /v1/models is definitive. models.dev records 2 models at base https://inference.hetzner.com/v1.

Limits
  • request-rate (binding) per API key: 10 requests per 60 s, 4M input tokens per 60 s and 100k output tokens per 60 s; exceeding any limit returns HTTP 429 source
Only a selected list of models is exposed and it changes during the experimental phase; the selection is not a guarantee. A bearer token is required on every request.
Bindingrequest-rate With no charge or token cap, the first limit a caller meets is the 10-requests-per-60-second per-key ceiling, well before the 4M input or 100k output token ceilings.
Identityemail A bearer token is minted after login to a Hetzner account at experiments.hetzner.com. Account registration requires a valid email address, personal or business contact information and a billing address, with a phone number optional for advanced verification, and the email address must be verified by a link. Whether a card or ID check is required before a token can be created is unverified: behind a sign-up.
EgressThe generated response is the payload; no separate egress allowance, quota or price is published for the Inference API.
Per-object capnot applicable: the unit is a model request, not a stored object; the API stores no request or response content for the caller
Retentionnot applicable: the API keeps only usage metadata (request timestamps, token counts) and states it does not store request or response content
Interfacerest OpenAI-compatible REST API with three endpoints: /v1/models, /v1/completions and /v1/chat/completions at https://inference.hetzner.com/v1, usable with any OpenAI-compatible SDK or HTTP client.
endpoint: https://inference.hetzner.com/v1
ToolingAny OpenAI Python or JavaScript SDK pointed at the base URL with a bearer token; the request examples are plain curl and the openai pip package.
Composes withAn OpenAI-compatible endpoint with no per-token charge while the experiment runs can back agent stacks that already speak the OpenAI API, but the 10-requests-per-60-second ceiling and the 8 December 2026 end date make it a temporary bench rather than a durable dependency; durable state needs a separate storage record.
ReliabilityExperimental service offered as is: performance and availability are not guaranteed during high demand, no backups are created, the model list changes during the experiment, and the experiment ends on 8 December 2026.
NotesA free, token-unmetered OpenAI-compatible inference endpoint that runs only until 8 December 2026. Two Qwen models are exposed with text and image input. A Hetzner account and bearer token are needed, so it is not anonymous; the first binding constraint is the 10-requests-per-60-seconds per-key limit. Paid Hetzner cloud servers and the separately catalogued Storage Box and Object Storage offers are different products.
