NotesThe cheapest always-on box with a real egress allowance: 20 TB a month included at EU locations, with additional transfer charged at the rate the page prints for each additional TB (EUR 1.00, in a unit string that reads 'per hour'). The CX23 is EUR 5.99 a month excl. VAT (EUR 0.0096 an hour) and reads 'not available' at the eu-central locations, so it cannot be ordered from Germany or Finland as read. The console bills hourly up to the monthly cap until the server is deleted, and no renewal rate is printed because there is no fixed term. The plan-level record is hetzner-cx23.
