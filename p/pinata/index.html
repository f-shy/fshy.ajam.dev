Composes with1 GB storage per account is the ceiling, so a dedicated gateway can only ever front 1 GB of content per free account. ReliabilityThe architectural point that kills this class: a dedicated gateway is account-scoped, so it cannot be used as a shared egress tier for other people's content, and a shared gateway (gateway.pinata.cloud) is unmetered but serves only public IPFS content.
