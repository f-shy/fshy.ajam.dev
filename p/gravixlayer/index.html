A runtime that exceeds its timeout is terminated. Billing is on allocated size, not observed utilization: a 2 vCPU sandbox that is idle costs the same as one at full CPU.
Bindingvolume-quota The $250 early-access credit is the first limit reached at published rates, ahead of any unpublished session or concurrency cap; pausing stops the CPU and memory charge.
Identityemail The early-access form says 'Email is all we need' and asks for Email; the site says 'Gravix Layer is in private preview. Request access from this site. You do not need a card to start.' No phone, ID or institution is named.
Egressnot published: the pricing section states no egress allowance or price; the network policy is default deny and only named hosts and ports are reachable
Per-object capnot applicable: the billed unit is allocated vCPU, memory and disk time, not an object; no per-object cap is published
RetentionFiles can be mounted from a bucket and kept after the run ends; no retention period for sandbox files is published.

endpoint: https://api.gravixlayer.ai/v1
Toolingthe Gravix Layer Python SDK (github.com/gravixlayer/gravixlayer-python), TypeScript SDK and CLI; sandboxes, browsers and computers are each created with one call.
Composes withSandbox, browser and computer run on one platform with a shared network policy and MCP gateway, so a hosted agent can use all three surfaces under one account; the vendor-managed multi-cloud lane is the hosted offer, while bring-your-own-cloud and on-premises AI Factory are roadmap items and are not recommendations here.
ReliabilityPrivate preview with a request-access gate; hardware-isolated microVMs and a default-deny network policy; one sandbox cannot read another's files; no published SLA.
