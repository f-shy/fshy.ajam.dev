The credit model is the limit that binds, and it is counted per identity rather than per IP or per byte.
Bindingnone The constraint that stops a caller is the account and its credit balance, which is identity, not one of the seven byte or rate constraints.
Identityemail An account is required before a real link is revealed: the home page says an account gets 3 credits to unlock real links. Whether email alone is enough was not established, because the signup flow was not entered.

Interfaceunknown HTML search only. /api and /documentation both return 404 on the same host, so no machine interface is advertised. A Telegram bot exists per the site's own documentation paths.
ToolingBrowser or the Telegram bot. There is no documented REST endpoint; a client would have to drive the search page.
Composes withUse it to find a public MEGA link by filename, then hand that link to a debrid service that accepts MEGA, or to the MEGA client under the account's own transfer quota.
ReliabilityThe index only sees links that were shared publicly; a link that the uploader deleted disappears from results, and the page itself frames results as 'no dead ends' without saying how often it re-checks.
NotesOne of three MEGA search fronts found in a single query (meganz.net, meawfy, zippysharedjs). All three are link indexes over publicly shared MEGA folders, so none can see a private file; the distinction between them is whether the link costs an account, which here it does.
