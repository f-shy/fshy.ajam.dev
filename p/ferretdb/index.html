Free tierA Free Tier is offered for developers, students and small projects; its numeric storage or request allowance is not published on first-party pages. Free Tier instances are temporary and may be stopped or deleted if inactive, and TLS/SSL is not supported on Free Tier instances.
unit mixed; metered on unstated; The first-party Cloud docs name a Free Tier but publish no storage or request quota; a plan subscription is activated only on approval. A size quoted by third parties is not used here.

Bindingretention-clamped No numeric quota is published; the first constraint on a free instance is that it may be stopped or deleted while inactive, and it has no TLS.
Identityemail FerretDB Cloud signup marks Name, Email, Company Name and Password as required and Company URL as optional, then asks the user to click an email verification link. The docs say the user is notified by email upon approval of the chosen plan. No card, phone or ID document is requested at signup.
Egressunverified: no first-party egress allowance, quota or price for FerretDB Cloud is published on the Cloud docs or signup page

RetentionFree Tier instances are temporary and may be stopped or deleted if inactive.
Interfacecli, browser A MongoDB wire-protocol endpoint reached by a mongodb:// connection string whose username, password and endpoint are shown in the instance dashboard. Free Tier connects without TLS; paid tiers require ?tls=true. A web dashboard manages deployments.
Toolingany MongoDB-compatible client (mongosh, MongoDB Compass, official MongoDB drivers)
Composes withA hosted FerretDB endpoint is reachable from any MongoDB driver without changing client code; the open-source FerretDB proxy that the user installs and runs on a rented or free machine is the last-resort option if the hosted tier is not approved.
ReliabilityFree Tier instances are temporary and may be stopped or deleted if inactive; TLS/SSL is not supported on Free Tier, while Pro, Enterprise and Bring Your Own Account Enterprise tiers require TLS.
NotesA hosted MongoDB-compatible document database with a Free Tier, but the free instance is temporary, has no TLS, and a plan needs approval. No dollar price and no numeric free allowance are published on first-party pages; the self-hosted open-source FerretDB proxy is the last resort, not the offer this record describes.
