ToolingTembo's own workspace. It is a coding-agent product that happens to run a VM, not a VPS: no SSH contract is published on the pricing page.
Composes withA full VM at USD 0.1066 an hour for the smallest shape is USD 77.82 a month, so it is not an answer to the cheap-machine questions. It matters here as the case where a full VM is priced by the running second and the binding cost is the USD 60 a month plan that must sit underneath it.
Reliabilityno reliability event observed. Each session runs in a dedicated ephemeral VM, so state that is not in a cached project environment does not outlive the session.
