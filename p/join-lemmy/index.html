ToolingLemmy API v3: POST /api/v3/pictrs/image (multipart) or /api/v3/upload; needs a JWT from POST /api/v3/user/login. pict-rs itself exposes POST /image on its own port (often 8080). On instances that expose it, that is a cleaner upload path than the Lemmy API.
Composes withLemmy is the weakest of the family: most large instances now REQUIRE an application (lemmy.world registration_mode = 'RequireApplication'), and image_mode is frequently set to block uploads entirely or to proxy-only. Multiplier depends entirely on finding a permissive instance.
ReliabilityRegistration gated on the big instances. Also note Lemmy stores federated/remote images too, so operator disk fills from other people's content, which is why uploads get turned off.
