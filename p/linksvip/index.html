The Fshare row shows no 'Used' figure at all, which suggests it is counted differently from the foreign hosts; the vendor separately warns that its Fshare get-link is unstable.
Bindingvolume-quota The 3 GB/day row (Rapidgator, Katfile, Keep2share) is the first thing that fails for a monthly transfer of 1 TiB, at roughly 30 GB/month per host; the Fshare row at 80 GB/day is the only one that clears 34 GB/day.
Identitycard An international card is accepted directly: 'LinksVIP chấp nhận thanh toán Thẻ Ghi nợ hoặc Tín dụng quốc tế Visa/MasterCard.' Vietnamese rails are offered as an alternative (MoMo, ZaloPay, bank transfer, scratch card), so the card is the foreigner's route and the local rails are the shortcut.
EgressMetered per host per day. 'Tất cả các host Premium đều có giới hạn hằng ngày. Bạn vui lòng xem mục Daily Limit để biết chi tiết.' Every other host is uncapped by request count: 'Limit 50 links per host every 24 hours. All other Filehosts are unmetered.'
free allowance: none published; per-host daily maximums apply to paid tiers
Per-object capNo single-file cap is published. The numbers in the host table are per-host daily totals: Fshare 80 GB, Mega 50 GB, 4shared 50 GB, Filefactory 25 GB, Rapidgator 3 GB, Katfile 3 GB.
Retentionnot applicable: the service returns a direct link, it does not store the file
Interfacerest Web form: paste a host URL, receive a direct link. A community PHP wrapper (github.com/0x2f0713/Get-link-LinksVIP.net) calls the same endpoint; no official API is documented.
ToolingBrowser plus IDM/JDownloader for the returned link; a community PHP wrapper exists but is unmaintained; no rclone backend.
Composes withLinksVIP is the cheapest way into Fshare and 4share from outside Vietnam because it takes an international card; at VND 150,000/30 days it costs less than a Fshare VIP month plus the shops it replaces, and the returned link is an ordinary HTTP URL that any download manager can resume.
ReliabilityThe vendor's own notice says the Fshare get-link path is unstable ('Hiện tại hệ thống Get link Fshare hoạt động không ổn định') and Rapidgator was under maintenance at read time; support runs through a Facebook page, not a ticket system.
NotesThe clearest card-payable Vietnamese service found: it is a Vietnamese-operated shop that takes Visa/MasterCard and also sells into the local wallet economy. Caveat is coverage, not access: 3 GB/day on the hosts a foreign client actually wants. Trigger condition: the card rail disappears, or the Fshare daily cap is withdrawn.
