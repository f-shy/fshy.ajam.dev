NotesTwo things are true and easy to confuse. The EUR 50 and EUR 250 credits are closed. The 'free access for all Blender users' claim traces to RNP-014, a 2024 governance proposal, whose own announcement says free access 'would be added to the Render Foundation roadmap if approved'. The network now requires an active Octane licence. The Prime free tier does not include network rendering, so it does not hand over the network.
