The 6000 secret access and 2000 other API requests per minute limits were stated for the Essentials and Standard tiers only. Resource ceilings of 100 apps and 100 integrations per project, 300 secrets, 10 dynamic secrets and 15 syncs per app applied to all tiers.
Bindingvolume-quota The 25-static-secret cap filled first on the Free tier, before the 25-application cap or the per-secret value size was reached.

The signup page itself answered HTTP 503, so the exact form fields are unverified: behind a sign-up. The offer is now closed to new customers.

ReliabilityThe offer was decommissioned by the vendor: end of sale on 2025-06-30, applications deleted at end of life on 2026-07-01. A known API bug disconnected all sync integrations from an app when an edit omitted the sync_integrations field; a deleted application's audit logs were not retained in the UI log viewer.
NotesHCP Vault Secrets was a hosted, multi-tenant secret store, not self-hosted software. Its free allowance was 25 static secrets. The product reached end of sale on 2025-06-30 and end of life on 2026-07-01, so it is dead as of the verification date.
