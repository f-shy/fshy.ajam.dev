Free tier5 GB/month of Smart Tier storage, 2,000 Class A + 20,000 Class B requests, 10 GB/month retrieval, 5 GB/month egress. For 12 months. The separate Lite plan (always-free, never expires) does not carry a published storage allowance on the current pages.

5 GB storage / 5 GB egress / 12 months. Reaching any quota 'suspends the service for that month'. Lite-plan instances are deleted after 30 days of no development activity.
Bindingretention-clamped a clock, not a quota: bytes leave whether or not transfer is completed
Identitycard (placeholder) an account is created using an email address first and payment details are required up front with a nominal hold placed on the card to verify authenticity
Egress5 GB/month egress inside the Free Tier; beyond that it is metered per GB. Not free egress at any useful scale.
free allowance: 5 GB per month
RetentionLite-plan instances are deleted after 30 days of no development activity. (30 days)
Interfaces3-compatible, rclone s3
ToolingIBM COS S3 API. Rclone 's3' provider name 'IBM COS S3'; HMAC or IAM keys; pre-signed URLs (docs note the UI does not generate them, use Cyberduck/clients).
Composes withOne Lite instance per service per org; quota limits are per ORG, not per instance ('New instances that are created in the same org reflect any usage from previous instances'), which deliberately blocks instance multiplication inside an org.
ReliabilityService suspends at quota rather than billing overage. No surprise bills, but no headroom either. Lite instances vanish after 30 idle days.
