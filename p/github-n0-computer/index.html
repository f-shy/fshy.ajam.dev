EgressUDP DHT traffic only, kilobytes. Mainline lookups measured at 37 ms in n0's own example.
Interfaceunknown n0-mainline crate; iroh-mainline-address-lookup (pkarr/BEP 44 records); iroh_mainline_content_discovery (query_dht, query_iroh).
ToolingPublishes a signed endpoint record (endpoint id + UDP socket + timestamp) to a tiny UDP address-index service, then announce_peer for SHA-1(BLAKE3 hash). Discovery returns candidate EndpointIds which are then dialled with normal iroh hole punching.
Composes withRemoves the last central dependency: no DNS, no pkarr relay, no account. Requires at least one reachable address-index service, found by rendezvous hash or a curated BEP 44 record.
ReliabilityExperimental repo (12 stars, last push 2026-10-16). SHA-1 is used only as a keyspace key, so a malicious DHT answer can waste time but cannot corrupt data. Verification is against the BLAKE3 root.
