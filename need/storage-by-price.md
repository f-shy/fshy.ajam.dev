# Bulk storage by price per TB-month

> Storage offers with a parsed price per TB-month, usable or paid-only, cheapest first. Prices in other currencies are converted only with a dated exchange rate that a record cites.

Ranked by `usd_per_tb_month`, ascending; the rows with no parsed number follow, listed and not dropped, and the self-hosted rows come last. The same list: `https://fshy.ajam.dev/api/v1/need/storage-by-price`, the MCP tool `need`, or this SQL:

```sql
SELECT rid, usd_per_tb_month FROM record WHERE topic='storage' AND grp IN ('usable','paid') AND usd_per_tb_month IS NOT NULL AND duplicate_of IS NULL
ORDER BY self_hosted, usd_per_tb_month ASC NULLS LAST
```
