# Free DNS, domains and certificates

Ranked by `vorder`, ascending; the rows with no parsed number follow, listed and not dropped, and the self-hosted rows come last. The same list: `https://fshy.ajam.dev/api/v1/need/dns-domains`, the MCP tool `need`, or this SQL:

```sql
SELECT rid, vorder FROM record WHERE topic='domains-dns' AND grp='usable' AND duplicate_of IS NULL AND coalesce(summary,'') NOT LIKE 'no free %' AND coalesce(summary,'') NOT LIKE 'no published free %' AND coalesce(summary,'') NOT LIKE 'no perpetual free %'
ORDER BY self_hosted, vorder ASC NULLS LAST
```
