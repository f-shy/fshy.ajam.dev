# Debrid and retrieval services priced per TB

> Debrid offers priced per TB-month and not per month, cheapest first. The offers with a monthly price are ranked in debrid-cheapest.

Ranked by `usd_per_tb_month`, ascending; the rows with no parsed number follow, listed and not dropped, and the self-hosted rows come last. The same list: `https://fshy.ajam.dev/api/v1/need/debrid-by-tb`, the MCP tool `need`, or this SQL:

```sql
SELECT rid, usd_per_tb_month FROM record WHERE topic='debrid' AND grp IN ('usable','paid','trial') AND usd_month IS NULL AND usd_per_tb_month IS NOT NULL AND duplicate_of IS NULL
ORDER BY self_hosted, usd_per_tb_month ASC NULLS LAST
```
